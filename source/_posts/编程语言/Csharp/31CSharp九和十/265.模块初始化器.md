**模块初始化器（Module Initializers）** 是 **C# 9.0** 引入的一个非常实用且底层的特性。它非常适合用来做框架开发、依赖注入自动注册以及配合源生成器（Source Generators）使用。


---

# 模块初始化器 (Module Initializers)

## 什么是模块初始化器？
**定义**：它允许你指定一个方法，在包含该方法的**程序集（Assembly/Module）被加载时自动执行**，并且**只执行一次**。而且，它的执行时机非常早，早于任何其他的代码（甚至早于静态构造函数和 `Main` 方法）。

**引入版本**：C# 9.0 / .NET 5

**底层原理**：CLR（公共语言运行时）其实一直都支持模块级别的初始化（IL 代码中的 `<Module>..cctor`），只是以前 C# 语言没有暴露出来。C# 9.0 增加了一个特性标签 `[ModuleInitializer]` 来让开发者安全地使用它。

---

## 基础语法与代码示例
要使用模块初始化器，只需在方法上加上 `[ModuleInitializer]` 特性（位于 `System.Runtime.CompilerServices` 命名空间）。

```csharp
using System;
using System.Runtime.CompilerServices;

namespace MyLibrary
{
    internal class InitializationHelper
    {
        // 这就是一个模块初始化器
        [ModuleInitializer]
        internal static void RunOnAssemblyLoad()
        {
            Console.WriteLine("程序集被加载了！我是最先执行的！");
            // 可以在这里做一些全局配置、依赖注入注册等
        }
    }
}
```

---

## 必须遵守的严格规则
并非所有方法都能作为模块初始化器，编译器有严格的要求。该方法**必须**满足以下所有条件：
1. **必须是静态的 (`static`)**。
2. **必须无参数**。
3. **必须返回 `void`**（不能是 `async void` 或 `Task`）。
4. **不能是泛型方法**，且**不能包含在泛型类中**。
5. **必须可被包含它的模块访问**（通常是 `internal` 或 `public`，如果是嵌套类，不能是 `private`）。
6. **不能是局部方法 (`partial` method)**。

---

## 为什么要用它？

### 场景 A：替代静态构造函数的局限性
* **静态构造函数的问题**：它是**惰性加载**的。只有当类第一次被实例化或访问静态成员时，静态构造函数才会执行。如果你不访问那个类，它永远不执行。
* **模块初始化器的优势**：它是**主动加载**的。只要 DLL（程序集）被加载进内存，它就会执行。非常适合做“无需用户主动触发的全局初始化”。

### 场景 B：配合源生成器 (Source Generators)
在 AOT（提前编译）时代，反射是非常不受欢迎的（影响性能且对 AOT 不友好）。
* 以前，框架喜欢扫描所有程序集，用反射找到特定的类并注册到 IoC 容器中。
* 现在，可以使用 Source Generator 在编译时生成注册代码，并把这些注册代码放到带有 `[ModuleInitializer]` 的方法里。程序跑起来时，直接自动完成注册，**零反射，性能极高**。

### 场景 C：初始化非托管代码 / C++ 库
在使用 P/Invoke 调用底层 C/C++ 库时，有时需要提前设置一些全局环境变量或加载特定的系统 DLL。放在模块初始化器中是最安全、最早的时机。

---

## 如果有多个初始化器怎么办？

如果你在一个程序集里写了多个带有 `[ModuleInitializer]` 的方法，会发生什么？
* **结论**：它们都会执行。
* **幕后工作**：C# 编译器会在底层生成一个全局的 `<Module>` 静态构造函数，并把你的这些方法调用全部塞进去。
* **执行顺序**：编译器决定顺序（通常是按类的全限定名/字母顺序排序）。**千万不要在代码中依赖多个模块初始化器之间的执行顺序**，因为这是未文档化的行为。

---

## 总结
* **特性名**：`[ModuleInitializer]`
* **C# 版本**：C# 9.0
* **核心作用**：程序集加载时自动执行的无参静态 void 方法。
* **最大优势**：比静态构造函数更早触发，非惰性，免去了反射扫描的开销。
