## Stream类以及流的概念
既然你已经知道了 `FileStream`（文件流），那我们就从这里切入。理解“流”的概念，是你从“单纯地操作文件”走向“高级系统IO编程”的关键一步。

### 一、 什么是“流（Stream）”？

在计算机科学中，**流（Stream）是对一串连续数据（通常是字节序列）的抽象表示。**

你可以把它想象成一根**水管**：
*   **数据池：** 硬盘里的文件、内存中的数据块、网络另一端的服务器，这些都是“水库”。
*   **流（水管）：** 我们不直接把整个水库搬过来（因为内存可能装不下，比如一个10GB的视频），而是接一根水管。
*   **读/写（抽水/注水）：** 水（数据）通过水管一点一点地流过来供我们处理，或者我们一点一点地把水注进去。

**为什么需要流的概念？**
1.  **节省内存：** 处理超大文件或网络请求时，不需要把全量数据加载到内存中，可以读一点处理一点。
2.  **统一接口：** 屏蔽了底层介质的差异。不管数据是在硬盘上、在内存里、还是在几千公里外的服务器上，在程序员眼里，它们都是一根“水管”（即相同的代码操作）。

---

### 二、 深入理解 `Stream` 类

在 .NET (C#) 以及大多数面向对象语言中，`Stream` 是一个**抽象基类（Abstract Class）**。

你不能直接 `new Stream()`，因为它只是定义了“水管应该具备哪些功能”，而没有提供具体的实现。你平常用的 `FileStream` 就是 `Stream` 的一个具体实现（子类）。

`Stream` 基类规定了以下三大核心能力：

#### 基础属性（这根水管的状态）
*   `CanRead`: 能不能从中读数据？
*   `CanWrite`: 能不能向里写数据？
*   `CanSeek`: 能不能在数据流中来回跳跃（快进/倒退）？（**注意：不是所有流都能Seek！** 文件流通常可以，但网络流就像现场直播，错过就错过了，不能Seek）。
*   `Position`: 当前读/写到了哪个位置？
*   `Length`: 这个流里的数据总共有多长？

#### 核心操作（这根水管的动作）
*   `Read(byte[] buffer, ...)`: 从流中读取数据，放进你准备好的小桶（数组 buffer）里。
*   `Write(byte[] buffer, ...)`: 把你小桶（数组 buffer）里的数据，倒进流里面。
*   `Seek(long offset, ...)`: 移动当前指针的位置（比如直接跳到文件的第100个字节处）。
*   `Flush()`: 强制把管道里残留的水（缓冲区里的数据）全部推送到目标位置。因为有时候写数据不是立刻写进硬盘的，而是先存在内存缓存里。

#### 资源释放
*   `Close()` / `Dispose()`: 关掉水阀，拆除水管。因为流往往占用操作系统底层资源（如文件句柄、网络端口），用完必须关闭。

### 三、 从 FileStream 到 Stream 家族

因为有了 `Stream` 这个抽象基类，C# 提供了一个庞大的“水管家族”。既然你知道了 `FileStream`，我们来看看它的“兄弟姐妹”：

1.  **`FileStream`（文件流）：**
    *   **介质：** 硬盘。
    *   **特点：** 读写慢（相比内存），但能持久化保存。可以 Seek。
2.  **`MemoryStream`（内存流）：**
    *   **介质：** 内存（RAM）。
    *   **特点：** 极快！通常用于在内存中临时组装数据、加密解密、或者充当临时缓冲区。程序关掉数据就没了。
3.  **`NetworkStream`（网络流）：**
    *   **介质：** 网卡/TCP连接。
    *   **特点：** 用于和服务器、浏览器进行网络通信。**不能 Seek**（`CanSeek` 为 false），数据流过来就必须处理，否则就过去了。

### 四、 Stream 的终极威力：多态与装饰器

理解了 `Stream`，你就能写出极其通用、强大的代码。

**例子 1：面向 Stream 编程（多态）**
假设你要写一个“计算数据MD5哈希值”的方法。
如果你针对文件写，你的参数可能是 `string filePath`；如果你针对内存写，参数可能是 `byte[] data`。
但如果使用 `Stream` 作为参数：

```csharp
public string CalculateMD5(Stream inputStream) 
{
    // 这个方法完全不在乎输入的是文件、内存还是网络数据。
    // 它只管从 Stream 里不断 Read 字节，然后计算。
}
```
通过上面这种写法，你传 `FileStream` 进去，它算文件的MD5；传 `MemoryStream` 进去，它算内存数据的MD5。这就是面向抽象编程的威力。

**例子 2：流的嵌套（装饰器模式）**
流是可以一层套一层的（就像给水管加装滤水器、加热器）。
常见的辅助流（它们本身不产生数据，而是加工数据）：
*   `GZipStream`：用来压缩/解压。
*   `CryptoStream`：用来加密/解密。
*   `StreamReader` / `StreamWriter`：把难懂的字节（byte）翻译成人类可读的字符串（string）。

**嵌套示例：**
你想把一段文字 **加密** 并 **压缩** 后存入 **文件**。
```csharp
// 1. 最底层的物理水管：连接硬盘
using (FileStream fs = new FileStream("data.bin", FileMode.Create))
// 2. 套上一层压缩管
using (GZipStream gz = new GZipStream(fs, CompressionMode.Compress))
// 3. 再套上一层加密管 (假设有AES加密逻辑)
using (CryptoStream cs = new CryptoStream(gz, encryptor, CryptoStreamMode.Write))
// 4. 最外层套一个翻译官（字符串转字节）
using (StreamWriter writer = new StreamWriter(cs))
{
    // 你只需向最外层写入文字，数据会自动经过 加密 -> 压缩 -> 写入文件
    writer.WriteLine("Hello, Stream!"); 
}
```

### 总结
1.  **流 (Stream)** 是一种连续字节数据的抽象概念。
2.  **`Stream` 类** 定义了所有流的通用规范（Read、Write、Seek）。
3.  **`FileStream`** 只是针对硬盘的特定实现。
4.  掌握 Stream 的基类概念，能让你灵活组合操作内存、网络、文件、压缩和加密，写出极其优雅和高性能的代码。
