## System.IO.Directory类

`System.IO.Directory` 是 C# 中用于管理和操作**文件夹（目录）** 的核心类。

与 `File` 类完全类似，`Directory` 也是一个**静态类**（不能 `new`，直接通过 `Directory.方法名` 调用）。它非常适合执行**单次、快速**的文件夹操作。

掌握下面这几个核心场景，就能应对 90% 以上的文件夹处理需求。


### 基础管理操作
这类方法直接改变磁盘上的目录结构。

| **方法名**                       | **说明**       | **备注**                           |
| ----------------------------- | ------------ | -------------------------------- |
| **`CreateDirectory(path)`**   | 创建指定路径的所有目录。 | 即使父级目录不存在，也会一并创建。                |
| **`Delete(path, recursive)`** | 删除目录。        | `recursive` 为 `true` 时才可删除非空文件夹。 |
| **`Exists(path)`**            | 检查目录是否存在。    | 返回 `bool` 值。                     |
| **`Move(src, dest)`**         | 移动目录或重命名。    | 不能跨磁盘驱动器移动。                      |

### 获取目录内容 (最常用)
这是开发中最核心的部分，用于遍历文件系统。

| **方法名**                          | **返回值**               | **说明**                      |
| -------------------------------- | --------------------- | --------------------------- |
| **`GetFiles(path)`**             | `string[]`            | 获取目录下所有文件的**完整路径**。         |
| **`GetDirectories(path)`**       | `string[]`            | 获取子目录的完整路径。                 |
| **`GetFileSystemEntries(path)`** | `string[]`            | 获取目录下所有的文件和子目录。             |
| **`EnumerateFiles(path)`**       | `IEnumerable<string>` | **进阶：** 延迟枚举文件，适合处理文件极多的目录。 |

### 获取父级与根目录
用于在目录树中“向上爬”。

|**方法名**|**返回值**|**说明**|
|---|---|---|
|**`GetParent(path)`**|`DirectoryInfo`|获取指定路径的父目录对象。|
|**`GetDirectoryRoot(path)`**|`string`|获取路径所在的根目录（如 `C:\`）。|
|**`GetCurrentDirectory()`**|`string`|获取应用程序当前的工作目录。|

### 元数据与时间戳
与 `File` 类相似，但针对的是文件夹。

|**方法名**|**说明**|
|---|---|
|**`GetCreationTime(path)`**|获取文件夹创建时间。|
|**`GetLastWriteTime(path)`**|获取文件夹内内容最后一次变动的时间。|

### 场景一：检查与创建文件夹（最常用的起手式）

在保存文件或导出数据前，通常需要确保目标文件夹存在，如果不存在则创建它。

*   **`Exists(string path)`**
    *   **作用**：判断文件夹是否存在，返回 `bool`。
*   **`CreateDirectory(string path)`**
    *   **作用**：创建文件夹。
    *   **超级特性（自动补全）**：它会自动创建**所有缺失的父目录**！比如你直接创建 `C:\A\B\C`，即使 A 和 B 都不存在，它也会一次性把 A、B、C 都建好。如果文件夹已经存在，调用此方法**不会报错**，什么都不会发生。

```csharp
string dirPath = @"C:\MyApp\Exports\2023";

// 经典写法：先判断后创建
if (!Directory.Exists(dirPath))
{
    Directory.CreateDirectory(dirPath);
    Console.WriteLine("文件夹创建成功！");
}

// 其实大部分情况下，直接调用 CreateDirectory 即可，因为系统内部会自动处理存在的情况
```

### 场景二：获取文件夹内的文件（最核心功能）

这是 `Directory` 类使用频率最高的功能：遍历文件夹找文件。

*   **`GetFiles(string path)`**
    *   **作用**：获取指定目录下**所有文件**的**绝对路径**，返回字符串数组 `string[]`。
*   **重载1：`GetFiles(string path, string searchPattern)`**
    *   **作用**：按通配符搜索（如 `*.txt` 找文本，`*.jpg` 找图片）。
*   **重载2：`GetFiles(string path, string searchPattern, SearchOption searchOption)`**
    *   **作用**：决定是否**递归搜索**（是否进入子文件夹里面找）。

```csharp
string myFolder = @"C:\Photos";

// 1. 获取该目录下所有文件（不含子文件夹里的）
string[] allFiles = Directory.GetFiles(myFolder);

// 2. 只获取所有的 .jpg 图片
string[] jpgFiles = Directory.GetFiles(myFolder, "*.jpg");

// 3. 递归搜索：找出该目录及其【所有子文件夹】下的所有 .jpg 图片
string[] allJpgsDeep = Directory.GetFiles(myFolder, "*.jpg", SearchOption.AllDirectories);

foreach (string file in allJpgsDeep)
{
    Console.WriteLine(file); // 输出的是文件的完整路径
}
```

### 场景三：获取子文件夹（遍历目录树）

与 `GetFiles` 用法完全一致，只不过它返回的是文件夹的路径。

*   **`GetDirectories(string path)`**
    *   **作用**：获取目录下的子文件夹路径，返回 `string[]`。同样支持通配符和递归搜索。

```csharp
// 获取 C盘 Windows 目录下的所有第一级子文件夹
string[] subDirs = Directory.GetDirectories(@"C:\Windows");

// 结合 GetDirectories 和 GetFiles 可以实现文件树的遍历
```

### 场景四：删除文件夹

*   **`Delete(string path)`**
    *   **作用**：删除**空**文件夹。如果文件夹里有文件或子文件夹，会报错 `IOException`！
*   **`Delete(string path, bool recursive)`**
    *   **作用**：当 `recursive` 设为 `true` 时，执行**递归删除**。
    *   **避坑警告**：它会把该目录及其里面的所有文件、所有子文件夹瞬间全部抹除，**不进回收站，无法撤销！** 使用前一定要确保路径正确！

```csharp
string tempFolder = @"C:\Temp\MyGarbage";

if (Directory.Exists(tempFolder))
{
    // 强制删除 tempFolder 及其内部的所有东西
    Directory.Delete(tempFolder, true); 
}
```

---

### 场景五：移动与重命名

*   **`Move(string sourceDirName, string destDirName)`**
    *   **作用**：将一个文件夹及其所有内容移动到新位置。
    *   **重命名技巧**：和 `File.Move` 一样，如果目标路径和源路径在同一个父目录下，这其实就是一个**重命名**操作。

```csharp
// 将 OldName 文件夹重命名为 NewName
Directory.Move(@"C:\Data\OldName", @"C:\Data\NewName");
```

---

### 场景六：获取程序的当前工作目录

开发中经常需要知道当前 `.exe` 程序运行在哪个目录下，以便读取相对路径的配置文件。

*   **`GetCurrentDirectory()`**
    *   **作用**：获取应用程序的当前工作目录。
    *   *(注：等同于 `AppDomain.CurrentDomain.BaseDirectory` 或 `Environment.CurrentDirectory`)*

```csharp
string currentPath = Directory.GetCurrentDirectory();
Console.WriteLine($"我的程序运行在这里：{currentPath}");
```

### 高阶技巧：防内存溢出（面试常考）

前面提到的 `GetFiles()` 和 `GetDirectories()` 都有一个弱点：**它们会等到把所有文件都找齐了，打包成一个数组 (`string[]`) 才返回结果。**

如果你对 C 盘根目录执行 `Directory.GetFiles("C:\\", "*.*", SearchOption.AllDirectories)`，程序会卡死很久，并且可能因为把几十万个路径字符串塞入内存而导致**内存溢出 (OOM)**。

**解决方案：使用 `Enumerate` 系列方法（C# 4.0 引入）**

*   `EnumerateFiles(path, pattern, option)`
*   `EnumerateDirectories(...)`
*   `EnumerateFileSystemEntries(...)` (文件和文件夹一起返回)

**它们的优势是：返回 `IEnumerable<string>`（迭代器）。系统找到一个文件，就吐出一个文件供你处理，不需要等待全部找完，极大地节省了内存！**

```csharp
// 极度推荐的读取超大目录的写法！
var hugeDir = @"D:\MassiveFiles";

// 找到一个处理一个，内存占用极低，且几乎没有等待时间
foreach (string file in Directory.EnumerateFiles(hugeDir, "*.txt", SearchOption.AllDirectories))
{
    if (file.Contains("password")) 
    {
        Console.WriteLine($"找到了: {file}");
        break; // 找到想要的文件就可以提前中断，节省大量时间！
    }
}
```

### 总结
1.  **单次操作、增删查改**：用 `Directory`。
2.  **找文件**：小型目录用 `GetFiles`，超大型目录/整个硬盘搜索用 `EnumerateFiles`。
3.  **删文件**：小心使用 `Directory.Delete(path, true)`。
4.  如果你需要多次读取某个特定文件夹的属性（如获取它的父目录、创建时间），则去使用它的兄弟类：实例化一个 **`DirectoryInfo`**。
