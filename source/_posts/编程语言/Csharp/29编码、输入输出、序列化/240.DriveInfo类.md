## System.IO.DriveInfo类

`System.IO.DriveInfo` 是 C# 中专门用于获取**磁盘驱动器（硬盘、U盘、光驱、网络驱动器等）信息**的类。

如果说 `FileInfo` 管文件，`DirectoryInfo` 管文件夹，那么 `DriveInfo` 就是管它们“老巢”（磁盘盘符）的 **“硬件巡视员”**。

它最常见的用途是：**在程序保存大文件之前，检查硬盘剩余空间是否足够**，或者**扫描系统当前插入了哪些 U 盘**。

---

### 如何获取 DriveInfo 对象？（构造函数与静态方法）

获取 `DriveInfo` 有两种常见方式：**查指定盘** 或 **查所有盘**。

**方式一：使用构造函数（查指定盘）**
传入驱动器的盘符（如 `"C"` 或 `"C:\"`）。
```csharp
// 实例化表示 C 盘的 DriveInfo 对象
DriveInfo cDrive = new DriveInfo("C"); 
```

**方式二：使用静态方法（查所有盘 —— 最常用）**
`DriveInfo` 提供了一个非常强大的静态方法 `GetDrives()`，它可以一口气返回电脑上所有的驱动器。
```csharp
// 获取电脑上所有的驱动器（包含本地硬盘、U盘、光驱等）
DriveInfo[] allDrives = DriveInfo.GetDrives();
```

---

### 核心属性 (磁盘的“硬件参数”)

`DriveInfo` 几乎没有复杂的实例方法，它的价值全在**属性**上。

> ⚠️ **致命警告：在使用获取磁盘大小、格式等底层属性前，必须先判断 `IsReady` 属性！**
> 如果光驱里没有光盘，或者读卡器里没有 SD 卡，你直接读取 `TotalSize` 会直接导致程序崩溃抛出异常。

| 属性名                      | 返回值类型           | 描述说明                                                                                                    |
| :----------------------- | :-------------- | :------------------------------------------------------------------------------------------------------ |
| **`Name`**               | `string`        | 获取驱动器的名称（如 `"C:\"`）。                                                                                    |
| **`DriveType`**          | `DriveType`     | **枚举**：标识驱动器类型。常见值有：<br>`Fixed` (固定硬盘)<br>`Removable` (可移动设备，如U盘)<br>`CDRom` (光驱)<br>`Network` (网络映射盘)。 |
| **`IsReady`**            | `bool`          | **极度重要**！指示驱动器是否已准备好。硬盘通常都是 true，但拔掉的U盘或空光驱会返回 false。                                                   |
| **`VolumeLabel`**        | `string`        | 获取或设置卷标（比如你给 C 盘起的名字叫 `"Windows"` 或 `"本地磁盘"`）。                                                          |
| **`DriveFormat`**        | `string`        | 获取文件系统的格式（如 `"NTFS"`, `"FAT32"`, `"exFAT"`）。                                                            |
| **`TotalSize`**          | `long`          | 驱动器的总空间大小（单位：**字节 Byte**）。                                                                              |
| **`TotalFreeSpace`**     | `long`          | 驱动器上的可用空闲空间总量。                                                                                          |
| **`AvailableFreeSpace`** | `long`          | **极度常用**。当前用户可以使用的剩余空间。*(注：通常和 `TotalFreeSpace` 相同，但如果系统设置了**磁盘配额**限制，这个值会更准确)*。                        |
| **`RootDirectory`**      | `DirectoryInfo` | 返回表示该驱动器根目录的 `DirectoryInfo` 对象（方便你顺藤摸瓜去遍历里面的文件夹）。                                                      |

### 经典实战场景

#### 场景一：模拟“我的电脑”，列出所有磁盘详细信息
这个代码可以直接运行，它会像 Windows 资源管理器一样打印出所有磁盘的状态。

```csharp
DriveInfo[] drives = DriveInfo.GetDrives();

foreach (DriveInfo drive in drives)
{
    Console.WriteLine($"\n=== 驱动器 {drive.Name} ===");
    Console.WriteLine($"类型: {drive.DriveType}");

    // ⚠️ 重点：读取详细数据前必须检查 IsReady
    if (drive.IsReady)
    {
        Console.WriteLine($"卷标: {drive.VolumeLabel}");
        Console.WriteLine($"格式: {drive.DriveFormat}");
        
        // 字节转 GB 显示
        double totalGB = drive.TotalSize / 1024.0 / 1024.0 / 1024.0;
        double freeGB = drive.AvailableFreeSpace / 1024.0 / 1024.0 / 1024.0;
        
        Console.WriteLine($"总大小: {totalGB:F2} GB");
        Console.WriteLine($"剩余空间: {freeGB:F2} GB");
    }
    else
    {
        Console.WriteLine("状态: 设备未就绪（可能是空光驱或未插U盘）");
    }
}
```

#### 场景二：下载大文件前，检查磁盘剩余空间是否足够
为了防止写文件写到一半因为“磁盘空间不足”而崩溃，提前检查是一个非常好的编程习惯。

```csharp
public bool CheckSpaceBeforeDownload(string driveName, long requiredBytes)
{
    DriveInfo drive = new DriveInfo(driveName);

    if (!drive.IsReady)
    {
        Console.WriteLine("磁盘未就绪！");
        return false;
    }

    // 判断剩余空间是否大于需要的空间
    if (drive.AvailableFreeSpace < requiredBytes)
    {
        Console.WriteLine($"警告：磁盘空间不足！需要 {requiredBytes / 1024 / 1024} MB");
        return false;
    }

    Console.WriteLine("空间充足，可以开始下载。");
    return true;
}

// 调用示例：检查 D 盘有没有 5GB (5L * 1024 * 1024 * 1024 字节) 的空间
// CheckSpaceBeforeDownload("D", 5L * 1024 * 1024 * 1024);
```

#### 场景三：寻找插入的 U 盘并拷贝数据
结合 `DriveType` 枚举，我们可以专门筛选出某种类型的磁盘。例如，很多自动备份程序就是这样检测 U 盘的：

```csharp
DriveInfo[] drives = DriveInfo.GetDrives();

foreach (DriveInfo drive in drives)
{
    // 只寻找可移动磁盘 (U盘/移动硬盘) 且处于就绪状态的
    if (drive.DriveType == DriveType.Removable && drive.IsReady)
    {
        Console.WriteLine($"发现 U 盘：{drive.Name} ({drive.VolumeLabel})");
        
        // 获取U盘的根目录，并准备拷贝文件进去...
        DirectoryInfo root = drive.RootDirectory;
        // ...执行拷贝操作 ...
    }
}
```

### 总结
1. `DriveInfo` 主要依靠静态方法 **`GetDrives()`** 来获取列表。
2. 它是查看**硬盘总容量 (`TotalSize`)** 和 **剩余容量 (`AvailableFreeSpace`)** 的唯一原生途径。
3. **避坑指南**：无论何时，只要涉及到读取具体容量、卷标、格式，**必须把代码包裹在 `if (drive.IsReady)` 之中**，否则遇到光驱必抛异常！
