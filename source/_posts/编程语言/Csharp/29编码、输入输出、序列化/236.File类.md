## System.IO.File类
`System.IO.File` 是 C# 中日常开发使用频率最高的 I/O 类，没有之一。 

它是一个**静态类**（意味着**没有构造函数**，不需要 `new`，直接通过 `File.方法名` 调用），并且它只提供**静态方法**，没有属性。

`File` 类的最大优势在于 **“傻瓜式操作”**：它会在底层自动为你打开文件、创建流、读写数据、然后安全地关闭文件。你不需要手动写 `using` 释放资源。


**路径转义：** 建议路径字符串前加 `@`（如 `@"C:\data.txt"`），防止反斜杠被识别为转义字符。



### **状态检查与元数据**
这类方法用于“打探”文件的基本信息。

| **方法名**                      | **返回值**          | **说明**            |
| ---------------------------- | ---------------- | ----------------- |
| **`Exists(path)`**           | `bool`           | 检查文件是否存在。         |
| **`GetCreationTime(path)`**  | `DateTime`       | 获取文件的创建日期和时间。     |
| **`GetLastWriteTime(path)`** | `DateTime`       | 获取文件最后一次被修改的时间。   |
| **`GetAttributes(path)`**    | `FileAttributes` | 获取文件属性（如：只读、隐藏等）。 |



### **读取操作 (Read)**
根据文件大小和处理需求选择合适的方法。

|**方法名**|**返回值**|**适用场景**|
|---|---|---|
|**`ReadAllText(path)`**|`string`|**小型文本**，一次性读取全部内容。|
|**`ReadAllLines(path)`**|`string[]`|**中小型文本**，按行读取并存入数组。|
|**`ReadLines(path)`**|`IEnumerable<string>`|**超大型文件**，延迟加载，省内存。|
|**`ReadAllBytes(path)`**|`byte[]`|**二进制文件**（图片、PDF、音视频）。|

### **写入与追加操作 (Write & Append)**
注意：`Write` 系列会覆盖原文件，`Append` 系列是在末尾添加。

|**方法名**|**写入模式**|**说明**|
|---|---|---|
|**`WriteAllText(path, str)`**|覆盖|写入单个大字符串。|
|**`WriteAllLines(path, list)`**|覆盖|写入集合/数组，每项占一行。|
|**`WriteAllBytes(path, bytes)`**|覆盖|写入二进制数据。|
|**`AppendAllText(path, str)`**|追加|常用于记录简单的单条日志。|
|**`AppendAllLines(path, list)`**|追加|批量将多行数据追加到末尾。|


### **物理管理 (Manage)**
涉及文件的移动、复制和消失。

|**方法名**|**参数特点**|**说明**|
|---|---|---|
|**`Copy(src, dest, ovr)`**|`ovr` 可选是否覆盖|复制文件到新路径。|
|**`Move(src, dest)`**|-|移动文件（同目录下移动即为**重命名**）。|
|**`Delete(path)`**|-|删除文件。注意：文件不存在时不报错。|
|**`Replace(src, dest, bak)`**|-|替换目标文件，并为被替换的文件创建备份。|

### 场景一：检查文件是否存在（最常见的起手式）
在读取或删除文件之前，通常需要确认文件在不在，以防报错。

*   **`Exists(string path)`**
    *   **作用**：判断指定路径的文件是否存在。
    *   **返回值**：`bool`。
    ```csharp
    string path = @"C:\temp\config.txt";
    if (File.Exists(path))
    {
        Console.WriteLine("文件存在，可以操作！");
    }
    ```

---

### 场景二：读取文本（读取配置文件、日志、JSON等）
这是 90% 场景中最核心的部分。`File` 提供了三种读取文本的方法，针对不同的需求：

*   **`ReadAllText(string path)`**
    *   **作用**：一口气把整个文件读成一个**大字符串**。
    *   **场景**：读取 JSON、XML 或体积不大的纯文本文件。
    ```csharp
    string jsonContent = File.ReadAllText("data.json");
    ```

*   **`ReadAllLines(string path)`**
    *   **作用**：把文件按行读取，返回一个**字符串数组** (`string[]`)。
    *   **场景**：需要按行处理数据，比如 CSV 文件或行格式的日志，且文件不大。
    ```csharp
    string[] lines = File.ReadAllLines("users.csv");
    Console.WriteLine($"这个文件共有 {lines.Length} 行");
    ```

*   **进阶必学：`ReadLines(string path)`** *(注意：和上面的区别是没有 All)*
    *   **作用**：按行读取，但返回的是 `IEnumerable<string>`（迭代器）。
    *   **核心区别**：`ReadAllLines` 会一次性把整个文件加载到内存；而 `ReadLines` 是**读一行、处理一行、释放一行**。
    *   **场景**：读取**超大文件**（如 2GB 的日志），用这个方法内存占用极低！
    ```csharp
    // 即使文件有几个G，内存也不会爆炸
    foreach (string line in File.ReadLines("huge_log.txt"))
    {
        if (line.Contains("ERROR"))
        {
            Console.WriteLine(line);
        }
    }
    ```

---

### 场景三：写入文本（保存数据、记录日志）
写入同样分为覆盖和追加两种。

*   **`WriteAllText(string path, string contents)`**
    *   **作用**：创建一个新文件，向其中写入字符串。**如果文件已存在，会被直接覆盖清空！**
    *   **场景**：保存设置、生成全新的文件。
    ```csharp
    File.WriteAllText("config.ini", "Theme=Dark");
    ```

*   **`WriteAllLines(string path, IEnumerable<string> contents)`**
    *   **作用**：将一个集合或数组按行写入文件（自动加换行符）。也是**覆盖**模式。
    ```csharp
    string[] names = { "张三", "李四", "王五" };
    File.WriteAllLines("names.txt", names);
    ```

*   **`AppendAllText(string path, string contents)`**
    *   **作用**：在现有文件的**末尾追加**内容。如果文件不存在，会自动创建。
    *   **场景**：写日志文件，持续往里加内容而不破坏原有内容。
    ```csharp
    File.AppendAllText("app.log", "[2023-10-25] 系统启动成功\n");
    ```

*   **`AppendAllLines(string path, IEnumerable<string> contents)`**
    *   **作用**：按行追加集合内容到文件末尾。

### 场景四：处理非文本文件（图片、音视频、PDF、压缩包）
对于非纯文本文件，我们不能当作字符串处理，必须使用**字节 (Byte)**。

*   **`ReadAllBytes(string path)`**
    *   **作用**：将整个文件读取为字节数组 (`byte[]`)。
    *   **场景**：准备上传一张图片到服务器，或者计算文件的 MD5 值。
    ```csharp
    byte[] imageBytes = File.ReadAllBytes("photo.jpg");
    ```

*   **`WriteAllBytes(string path, byte[] bytes)`**
    *   **作用**：将字节数组保存为文件（覆盖模式）。
    *   **场景**：从网络上下载了一段字节流，保存到本地成为图片。
    ```csharp
    File.WriteAllBytes("downloaded_photo.jpg", imageBytes);
    ```

### 场景五：文件系统管理（复制、移动、重命名、删除）
操作文件本身的物理状态。

*   **`Copy(string sourceFileName, string destFileName, bool overwrite)`**
    *   **作用**：复制文件。
    *   **参数**：`overwrite` 如果设为 `true`，当目标路径已有文件时会将其覆盖；如果设为 `false`，遇到同名文件会报错。
    ```csharp
    File.Copy("old.txt", "new.txt", true);
    ```

*   **`Move(string sourceFileName, string destFileName)`**
    *   **作用**：移动文件。
    *   **神仙用法**：在同一个文件夹下移动，就等于**重命名**！
    ```csharp
    // 移动文件
    File.Move(@"C:\A\file.txt", @"D:\B\file.txt"); 
    // 重命名文件
    File.Move("old_name.txt", "new_name.txt"); 
    ```

*   **`Delete(string path)`**
    *   **作用**：删除文件。
    *   **注意**：如果文件不存在，`File.Delete` **不会报错**，它什么也不做。但如果文件被别的程序占用、或者是一个文件夹、或者是只读的，就会抛出异常。
    ```csharp
    File.Delete("useless_file.txt");
    ```

---

### 场景六：获取文件元数据（时间戳）
有时候需要知道文件是何时创建或修改的。

*   **`GetCreationTime(string path)`**：获取文件创建时间（返回 `DateTime`）。
*   **`GetLastWriteTime(string path)`**：获取文件最后一次被修改的时间。
    ```csharp
    DateTime lastModified = File.GetLastWriteTime("data.db");
    Console.WriteLine($"数据库最后更新于: {lastModified}");
    ```

### 核心总结与避坑指南

当你使用 `File` 类时，只需记住以下两点：

1.  **极度方便**：90% 的 CRUD（增删改查）文件操作，都可以直接用 `File` 的这十几个方法搞定，无需关心底层的流操作。
2.  **一个致命弱点（避坑）**：带有 `All` 字眼的方法（`ReadAllText`、`ReadAllBytes`、`ReadAllLines`）都会**一次性将整个文件加载到内存中**。
    *   如果文件只有几KB、几十MB，随便用，没有任何问题。
    *   如果文件高达 **1GB 以上**（比如超大型日志文件或视频文件），使用 `All` 方法会导致程序**内存溢出崩溃 (OutOfMemoryException)**！
    *   **解决方案**：遇到超大文本文件，使用 `File.ReadLines()`（迭代器）；遇到超大二进制文件，老老实实去用 `FileStream` 一点一点搬运。
