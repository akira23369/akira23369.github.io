# System.IO.FileInfo类
`System.IO.FileInfo` 是 C# 中专门用于处理单个文件的**实例类**。

如果说上一节讲的 `File` 类是一套 **“公共工具箱”**（每次用都需要告诉它处理哪个文件），那么 `FileInfo` 就是你给特定文件建立的 **“个人档案”**。

---

## 什么时候用 `FileInfo`？相比 `File` 有什么区别？

这是最常见的问题，记住以下两点即可：

1.  **单次操作选 `File`**：如果你只想对文件进行**一次**操作（比如只读一次文本，或者只删一下文件），用静态类 `File` 最简单，因为不需要 `new` 对象。
2.  **多次操作选 `FileInfo`**：如果你需要对**同一个文件**进行**多次**操作（比如先检查是否存在，再获取大小，然后获取创建时间，最后移动它），请一定用 `FileInfo`！
    *   **原因**：`File` 类每次调用方法都会去操作系统底层进行安全检查和路径解析，消耗较大。而 `FileInfo` 实例化后，会把这些状态**缓存**在内存中，后续调用属性极其高效。

---

## 构造函数 (如何创建档案)

`FileInfo` 只有一个常用的构造函数，要求传入文件的路径（绝对路径或相对路径都可以）。

```csharp
// 实例化一个 FileInfo 对象
FileInfo fi = new FileInfo(@"C:\Temp\myLog.txt");

// 注意：仅仅 new 出来，并不会在硬盘上真实创建一个文件！
// 它只是在内存中创建了一个代表该路径的“代理人”。
```

---

## 核心属性 (获取文件的“身份证信息”)

`FileInfo` 最强大的地方在于获取文件的元数据（大小、时间、扩展名等）。**注意：在读取这些属性前，最好先判断 `fi.Exists`。**

| 属性名                 | 返回值类型           | 描述说明                                                                           |
| :------------------ | :-------------- | :----------------------------------------------------------------------------- |
| **`Exists`**        | `bool`          | 判断文件在硬盘上是否存在（非常重要，**不存在时读取其他属性会报错**）。                                          |
| **`Name`**          | `string`        | 获取文件名（包含扩展名，如 `"myLog.txt"`）。                                                  |
| **`FullName`**      | `string`        | 获取文件的**绝对路径**（如 `"C:\Temp\myLog.txt"`）。                                        |
| **`Extension`**     | `string`        | 获取文件的扩展名（如 `".txt"`），包含前面的点。                                                   |
| **`Length`**        | `long`          | **极度常用**。获取文件大小，单位是**字节(Byte)**。<br>*(注：`File` 静态类没有直接获取大小的方法，只能靠 `FileInfo`)* |
| **`DirectoryName`** | `string`        | 获取文件所在的父目录的绝对路径（如 `"C:\Temp"`）。                                                |
| **`Directory`**     | `DirectoryInfo` | 获取文件所在的父目录，返回一个 `DirectoryInfo` **对象**，方便继续操作文件夹。                              |
| **`CreationTime`**  | `DateTime`      | 获取/设置文件的创建时间。                                                                  |
| **`LastWriteTime`** | `DateTime`      | 获取/设置文件最后修改时间。                                                                 |
| **`IsReadOnly`**    | `bool`          | 获取/设置文件是否为只读。                                                                  |

**代码示例：获取文件详细信息**
```csharp
FileInfo fi = new FileInfo(@"C:\Data\report.pdf");

if (fi.Exists)
{
    Console.WriteLine($"文件名: {fi.Name}");
    Console.WriteLine($"扩展名: {fi.Extension}");
    // fi.Length 返回的是字节，除以 1024 得到 KB，再除以 1024 得到 MB
    Console.WriteLine($"文件大小: {fi.Length / 1024.0 / 1024.0:F2} MB"); 
    Console.WriteLine($"最后修改时间: {fi.LastWriteTime}");
}
else
{
    Console.WriteLine("文件不存在！");
}
```

## 核心方法 (对文件执行动作)

和 `File` 类类似，`FileInfo` 也提供了物理操作的方法，但**不需要再传文件路径了**，因为它自己就知道自己代表哪个文件。

### 物理管理
*   **`CopyTo(string destFileName, bool overwrite)`**: 将文件复制到新位置。
*   **`MoveTo(string destFileName)`**: 移动文件（也可以用来重命名）。
*   **`Delete()`**: 删除当前文件。（如果文件不存在，直接调用也不会报错）。

```csharp
FileInfo fi = new FileInfo("old.txt");
if (fi.Exists)
{
    // 复制一份备份
    fi.CopyTo("backup.txt", true); 
    // 移动/重命名自己
    fi.MoveTo(@"D:\new.txt"); 
    // 注意：MoveTo 之后，fi 对象代表的路径也会自动更新为 D:\new.txt
}
```

### 流与读写包装 (转换为 Stream)
`FileInfo` 不像 `File` 那样提供 `ReadAllText` 这种“傻瓜方法”，它提供的是打开**文件流 (Stream)** 的方法。

*   **`Create()`**: 返回 `FileStream`。在硬盘上真实创建文件，并返回一个可写的流。
*   **`OpenRead()`**: 返回 `FileStream`。以只读模式打开流。
*   **`OpenText()`**: 返回 `StreamReader`。直接打开一个用于读取**文本**的读取器。
*   **`AppendText()`**: 返回 `StreamWriter`。直接打开一个用于**追加文本**的写入器。

```csharp
FileInfo fi = new FileInfo("log.txt");

// 打开一个写入器追加内容 (记得配合 using 释放资源)
using (StreamWriter sw = fi.AppendText())
{
    sw.WriteLine("记录一条新日志：" + DateTime.Now);
}
```

## 一个容易踩坑的必学方法：`Refresh()`

这是一个在面试中和实际开发中经常遇到的**大坑**！

**情景：**
你实例化了一个 `FileInfo` 对象，此时文件大小是 1KB。然后，另一个程序（或者你自己的代码）往这个文件里写入了大量数据，文件变成了 10MB。
如果你此时再次读取 `fi.Length`，**它返回的依然是 1KB！**

**原因：**
正如前面所说，`FileInfo` 出于性能考虑，会在第一次访问属性时把文件的信息（大小、时间等）**缓存**在内存里。外界对文件的改变，它并不知道。

**解决方法：调用 `Refresh()`**

*   **`Refresh()`**: 强制 `FileInfo` 对象清除缓存，重新去硬盘上读取该文件的最新状态。

```csharp
FileInfo fi = new FileInfo("downloading.tmp");

Console.WriteLine($"初始大小: {fi.Length}");

// 假设此时其他线程正在疯狂下载数据写入这个文件...
Thread.Sleep(3000); 

// 必须调用 Refresh，否则拿到的还是之前的大小
fi.Refresh(); 

Console.WriteLine($"3秒后的大小: {fi.Length}");
```

---

## 总结
掌握 `FileInfo`，核心在于理解它的**面向对象特性**。当你需要获取文件的**大小 (Length)**，或者需要在一个方法中**密集地读取该文件的各种属性、随后又对其进行移动、复制操作**时，果断实例化一个 `FileInfo` 来代替频繁调用 `File.XXX`，这会让你的代码既优雅又高效。
