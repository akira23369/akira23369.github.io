# System.IO命名空间

欢迎来到C# I/O（输入/输出）的世界！`System.IO` 是 C# 中用于处理文件、目录、数据流等核心操作的最重要的命名空间。

`System.IO` 中的核心类分为三大类：
1. **路径、文件和目录管理类**（用于操作文件系统本身，如创建、删除、移动文件或文件夹）。
2. **字节流类 (Streams)**（用于在底层以**字节**为单位读写数据）。
3. **读写器类 (Readers/Writers)**（包装了流，用于以更方便的格式，如**文本**或**基本数据类型**，来读写数据）。

下面我将为你详细梳理这些核心类及其常用 API（构造函数、属性、方法）。

---

## 第一部分：路径、文件和目录管理

### `Path` 类 (静态类)
用于对包含文件或目录路径信息的**字符串**执行操作（它不检查文件是否存在，只是纯粹的字符串处理）。

*   **常用方法：**
    *   `Combine(string path1, string path2, ...)`: 安全地拼接多个路径字符串，自动处理多余的斜杠。
    *   `GetExtension(string path)`: 获取文件的扩展名（例如返回 ".txt"）。
    *   `GetFileName(string path)`: 获取路径中的文件名和扩展名。
    *   `GetFileNameWithoutExtension(string path)`: 仅获取文件名。
    *   `GetDirectoryName(string path)`: 获取指定路径的目录信息（去掉文件名部分）。
    *   `GetFullPath(string path)`: 将相对路径转换为绝对路径。

### `File` 与 `FileInfo` 类
这两个类都用于操作文件。**区别在于**：`File` 是静态类，适合进行单一操作（如读一次文件就结束）；`FileInfo` 是实例类，适合对同一个文件进行多次操作（系统不需要每次都去解析路径，性能更好）。

**`File` (静态类)**
*   **常用方法：**
    *   `Exists(string path)`: 检查文件是否存在，返回 bool。
    *   `Copy(string source, string dest, bool overwrite)`: 复制文件。
    *   `Move(string source, string dest)`: 移动或重命名文件。
    *   `Delete(string path)`: 删除文件。
    *   `ReadAllText(string path)`: 打开文件，读取所有文本，然后关闭文件（极度常用）。
    *   `WriteAllText(string path, string contents)`: 创建新文件，写入内容并关闭。若文件存在则覆盖。
    *   `ReadAllLines(string path)`: 读取文件的所有行，返回一个 `string[]` 数组。
    *   `ReadAllBytes(string path)`: 以字节数组 `byte[]` 形式读取文件。

**`FileInfo` (实例类)**
*   **构造函数：**
    *   `FileInfo(string fileName)`: 传入文件路径初始化对象。
*   **常用属性：**
    *   `Name`: 获取文件名。
    *   `FullName`: 获取文件的完整目录绝对路径。
    *   `Extension`: 获取扩展名。
    *   `Length`: 获取文件大小（以字节为单位）。
    *   `Exists`: 指示文件是否存在。
    *   `Directory`: 获取父目录的 `DirectoryInfo` 对象。
    *   `CreationTime` / `LastWriteTime`: 获取创建时间 / 最后修改时间。
*   **常用方法：**
    *   `CopyTo(string destFileName)`: 复制文件。
    *   `MoveTo(string destFileName)`: 移动文件。
    *   `Delete()`: 删除当前文件。

### `Directory` 与 `DirectoryInfo` 类
和文件类同理，`Directory` 是静态类，`DirectoryInfo` 是实例类，用于操作文件夹。

**`Directory` (静态类)**
*   **常用方法：**
    *   `Exists(string path)`: 检查目录是否存在。
    *   `CreateDirectory(string path)`: 创建所有目录和子目录（即使父级目录不存在也会一并创建）。
    *   `Delete(string path, bool recursive)`: 删除目录。`recursive` 为 true 时删除包含的所有子目录和文件。
    *   `GetFiles(string path)`: 返回指定目录下的所有文件的路径字符串数组。
    *   `GetDirectories(string path)`: 返回所有子目录的路径。

**`DirectoryInfo` (实例类)**
*   **构造函数：**
    *   `DirectoryInfo(string path)`
*   **常用属性：**
    *   `Name`, `FullName`, `Exists`, `CreationTime` (与 FileInfo 类似)。
    *   `Parent`: 获取父目录。
    *   `Root`: 获取路径的根部分（如 "C:\"）。
*   **常用方法：**
    *   `Create()`: 创建目录。
    *   `GetFiles()`: 返回当前目录下的 `FileInfo[]` 数组。
    *   `GetDirectories()`: 返回当前目录下的 `DirectoryInfo[]` 数组。

## 第二部分：字节流

流 (`Stream`) 是 C# IO 的核心概念。你可以把它想象成一条传送带，数据以**字节 (byte)** 的形式在上面流动。最常用的是 `FileStream`。

### `FileStream` 类
用于对文件进行字节级别的读取和写入。

*   **常用构造函数：**
    *   `FileStream(string path, FileMode mode)`: 使用指定路径和模式打开流。
    *   `FileStream(string path, FileMode mode, FileAccess access)`: 更精细地控制（如只读、只写）。
        *   *附：`FileMode` 枚举常用值：`Create` (新建/覆盖), `Open` (打开现有), `Append` (追加)。*
        *   *附：`FileAccess` 枚举常用值：`Read`, `Write`, `ReadWrite`。*
*   **常用属性：**
    *   `Length`: 流的总长度（字节）。
    *   `Position`: 获取或设置当前流中的位置（传送带当前的位置）。
    *   `CanRead` / `CanWrite` / `CanSeek`: 判断当前流是否支持读取/写入/查找。
*   **常用方法：**
    *   `Read(byte[] array, int offset, int count)`: 从流中读取字节块并将数据写入给定的缓冲区(`array`)。
    *   `Write(byte[] array, int offset, int count)`: 将缓冲区中的字节块写入流。
    *   `Seek(long offset, SeekOrigin origin)`: 将读写指针移动到指定位置。
    *   `Flush()`: 清除该流的所有缓冲区，使得所有缓冲的数据都被写入到基础文件。
    *   `Close()` / `Dispose()`: 关闭流并释放资源（极其重要！详见文末）。

## 第三部分：读写器

因为 `FileStream` 只能处理 `byte`（字节），如果我们想读写文本（字符串），自己做字节到字符的转换会很麻烦。读写器类就是为了解决这个问题，它们在内部包装了 `Stream`。

### `StreamReader` (读取文本)
*   **常用构造函数：**
    *   `StreamReader(string path)`: 直接传入文件路径。
    *   `StreamReader(Stream stream)`: 传入一个现有的流（如 FileStream）。
    *   `StreamReader(string path, Encoding encoding)`: 指定编码格式（如 `Encoding.UTF8`）。
*   **常用属性：**
    *   `EndOfStream`: 返回 bool，指示是否已到达文件末尾（常用于 while 循环判断）。
*   **常用方法：**
    *   `ReadLine()`: 读取一行字符，直到遇到换行符。
    *   `ReadToEnd()`: 从当前位置一直读取到文件末尾，返回一个大字符串。
    *   `Read()`: 读取下一个字符。
    *   `Close()`: 关闭读取器及底层的流。

### `StreamWriter` (写入文本)
*   **常用构造函数：**
    *   `StreamWriter(string path)`: 覆盖模式写入文本。
    *   `StreamWriter(string path, bool append)`: `append` 为 true 时，在文件末尾追加；为 false 时覆盖。
    *   `StreamWriter(Stream stream)`: 包装一个现有的流。
*   **常用属性：**
    *   `AutoFlush`: 获取或设置一个值，指示是否在每次调用 Write 后自动调用 `Flush()`（设为 true 会略微降低性能，但数据更安全）。
*   **常用方法：**
    *   `Write(string value)`: 写入字符串。
    *   `WriteLine(string value)`: 写入字符串并在末尾自动加上换行符。
    *   `Flush()`: 将缓冲的数据推入底层文件。
    *   `Close()`: 关闭写入器及底层的流。

## 最重要的 C# IO 编程规范：资源释放 (`using` 语句)

由于文件流占用的是**非托管资源**（操作系统级别的文件锁），如果你打开了一个流而不关闭它，其他程序（甚至你自己的程序）将无法再次访问该文件，会报 "文件正由另一进程使用" 的错误。

在 C# 中，我们几乎**必须**使用 `using` 语句块来包裹流和读写器，这样即便发生异常，它也会自动调用 `Dispose()` 关闭流：

**经典写法 (C# 8.0 之前)：**
```csharp
using (StreamWriter sw = new StreamWriter("test.txt"))
{
    sw.WriteLine("Hello IO!");
    // 离开大括号时，自动调用 sw.Dispose() 关闭文件
}
```

**现代写法 (C# 8.0 及以后，推荐)：**
```csharp
using StreamWriter sw = new StreamWriter("test.txt");
sw.WriteLine("Hello IO!");
// 当方法执行结束，变量作用域结束时，自动释放文件
```

## 总结建议
如果你刚刚开始学习，日常任务推荐直接使用 **`File`** 类的静态方法（如 `File.ReadAllText` / `File.WriteAllText`），它们内部已经帮你处理好了流的打开和关闭，写起来最省事。当遇到**非常大的文件**（例如几个G的日志）或者需要**精细控制**（比如只读中间的一部分），再去使用 `FileStream`、`StreamReader` 和 `StreamWriter`。
