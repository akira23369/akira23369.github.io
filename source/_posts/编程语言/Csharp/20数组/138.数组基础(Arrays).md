# 数组基础(Arrays)

## 核心概念

数组是一种用于存储**同等数据类型**的固定大小的线性集合。
*   **强类型 (Strongly Typed)：** 数组一旦声明，其内部只能存储指定数据类型的元素。
*   **固定长度 (Fixed Size)：** 数组在实例化时必须明确指定大小（长度），且在生命周期内无法动态扩容或缩减。
*   **连续内存 (Contiguous Memory)：** 数组在内存中是连续分配的，这使得通过索引访问元素的时间复杂度为 O(1)，具有极高的读取和寻址性能。

## 内存模型与底层机制

根据《CLR via C#》对 .NET 内存分配的深度剖析，理解数组的底层机制至关重要：
*   **数组始终是引用类型：** 无论数组内部存储的是值类型（如 `int[]`）还是引用类型（如 `string[]` 或 `Student[]`），数组对象本身**永远分配在托管堆（Managed Heap）上**。
*   **变量存储：** 指向该数组的引用变量（如 `int[] a`）通常分配在线程的栈（Stack）上。
*   **内部结构：** 在托管堆中，数组对象不仅包含所有的元素数据，还包含作为对象必须的“类型对象指针”（Type Object Pointer）、“同步块索引”（Sync Block Index），以及一个极其重要的隐式字段——**数组的长度 (Length)**。这也是为什么每次访问数组的 `.Length` 属性都能瞬间返回，而不需要遍历整个内存块的原因。

## 数组的声明与初始化

### 默认初始化
使用 `new` 关键字指定类型和长度来创建数组时，CLR 会自动将所有的元素初始化为该类型的默认值（即执行 `default(T)`）。
*   数值类型（如 `int`, `double`）：初始化为 `0`。
*   布尔类型（`bool`）：初始化为 `false`。
*   引用类型（如 `string`, 自定义类）：初始化为 `null`。

```csharp
// 声明一个长度为 5 的整数数组，默认值全为 0
int[] numbers = new int[5];

// 声明一个长度为 3 的字符串数组，默认值全为 null
string[] names = new string[3];
```

### 使用数组初始化器
可以在声明数组的同时直接赋予初始值。参考《C# in a Nutshell》，C# 编译器提供了多种简写语法：

```csharp
// 完整语法
int[] arr1 = new int[5] { 10, 20, 30, 40, 50 };

// 省略长度（编译器会自动推断长度为 5）
int[] arr2 = new int[] { 10, 20, 30, 40, 50 };

// 极简语法（最常用，编译器会自动推断类型和长度进行数组实例化）
int[] arr3 = { 10, 20, 30, 40, 50 };
```

## 索引与边界越界

数组的索引从 `0` 开始。合法的索引范围是 `0` 到 `Length - 1`。

C# 在运行时会进行严格的**边界检查（Bounds Checking）**。如果尝试访问不存在的索引，CLR 会立即抛出 `IndexOutOfRangeException` 异常。

```csharp
int[] scores = { 85, 90, 95 }; // 长度为 3，合法索引为 0, 1, 2

int firstScore = scores[0]; // 获取第一个元素: 85
scores[2] = 100;            // 修改第三个元素

try
{
    // 尝试访问第四个元素，将直接引发异常
    int invalidScore = scores[3]; 
}
catch (IndexOutOfRangeException ex)
{
    Console.WriteLine("访问的索引超出了数组的边界。");
}
```

*补充说明：虽然边界检查保证了内存安全（防止类似于 C/C++ 中的缓冲区溢出攻击），但在极端的性能敏感场景下，这也是一种开销。《Effective C#》中提到，在遍历数组时，标准的 `for (int i = 0; i < arr.Length; i++)` 结构会被 JIT 编译器专门优化，从而安全地消除循环内部的边界检查开销。*

## System.Array 基类

在 C# 中，所有的数组类型（无论是一维、多维还是交错数组）都在编译期隐式继承自 .NET 的抽象基类 `System.Array`。
这意味着即使是原生的 `int[]`，也天生拥有 `System.Array` 提供的众多属性和方法。

常用的预定义功能包括：
*   **`Length` 属性：** 获取数组中的元素总数。
*   **`Array.Sort()`：** 静态方法，对数组进行原地升序排序。
*   **`Array.Reverse()`：** 静态方法，反转数组中的元素顺序。
*   **`Array.Find()` / `Array.FindAll()`：** 结合 `Predicate<T>` 委托，在数组中执行条件搜索。

```csharp
using System;

public class Program
{
    public static void Main()
    {
        int[] data = { 50, 20, 40, 10, 30 };

        // 获取长度
        int length = data.Length; // 结果为 5

        // 原地排序
        Array.Sort(data); 
        // 排序后 data 的内容: { 10, 20, 30, 40, 50 }

        // 反转
        Array.Reverse(data); 
        // 反转后 data 的内容: { 50, 40, 30, 20, 10 }
    }
}
```
