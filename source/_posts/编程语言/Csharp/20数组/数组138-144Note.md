# 第21节：数组

## 第一讲：数组简介

### 引言
数组是编程中最基础的数据结构之一，是**固定大小**、**按顺序排列**的同类型元素集合（可类比为编号的仓库箱子）。C# 数组核心特性：
- **固定大小**：创建时必须指定大小，生命周期内不可更改（动态集合需用 `List`）。
- **从零开始索引**：第一个元素索引为 0，最后一个为 `Length - 1`。

### 工作原理：内存存储
数组的高效性源于其内存布局：
1. **连续内存块**：数组元素在堆上连续存储（无间隙）。
2. **数组变量**：栈上存储的是堆中连续内存块的起始地址（引用）。
3. **元数据**：运行时存储数组长度、元素类型等信息。

数组访问为 **O(1)** 操作：通过 `起始地址 + 索引 × 元素大小` 直接定位内存，无需遍历。

### 为何及何时使用
适用于**大小固定且已知**的集合场景（如文件读取数据、查找表、图像像素），索引访问性能最优。

## 第二讲：处理一维数组

### 引言
一维数组是线性元素列表，最常用的数组类型。

### 语法：声明、实例化与初始化
| 操作 | 示例 | 说明 |
|------|------|------|
| 声明 | `int[] scores;` | 声明引用数组的变量 |
| 实例化 | `scores = new int[5];` | 堆上分配固定大小内存 |
| 初始化（逐个） | `scores[0] = 88; scores[1] = 95;` | 通过索引赋值 |
| 集合初始化 | `string[] names = { "Alice", "Bob", "Charlie" };` | 一行完成声明+实例化+初始化，编译器自动推断大小 |

### 访问元素
通过 `数组名[索引]` 访问/修改元素，**越界访问**（如访问 `names[3]`，有效索引为 0-2）会抛出 `IndexOutOfRangeException`（编译通过，运行崩溃）。

### 示例
```csharp
// 声明+实例化+初始化
int[] highScores = { 980, 955, 940, 890, 875 };

// 访问第一个元素
Console.WriteLine($"最高分是：{highScores[0]}"); // 输出：980

// 修改第三个元素
Console.WriteLine($"原始第三名的分数是：{highScores[2]}"); // 输出：940
highScores[2] = 942;
Console.WriteLine($"新的第三名分数是：{highScores[2]}"); // 输出：942

// 获取数组长度
Console.WriteLine($"该数组包含 {highScores.Length} 个分数。"); // 输出：5
```

## 第三讲：使用 for 循环遍历数组

### 引言
`for` 循环是遍历数组的经典方式，完全控制迭代过程，可直接访问索引。

### 工作原理：标准模式
```csharp
for (int i = 0; i < array.Length; i++)
```
- `int i = 0`：计数器从第一个元素索引（0）开始。
- `i < array.Length`：循环条件（避免越界，禁用 `<=`）。
- `i++`：每次迭代后计数器自增，移动到下一个元素。

### 使用场景
- 需要访问元素索引时。
- 原地修改数组元素时。
- 非标准遍历（反向：`i = array.Length - 1; i >= 0; i--`；跳步：`i += 2`）。

### 示例
```csharp
string[] daysOfWeek = { "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday" };

Console.WriteLine("一周的每一天分别是：");
for (int i = 0; i < daysOfWeek.Length; i++)
{
    Console.WriteLine($" Day {i + 1}: {daysOfWeek[i]}");
}
```

## 第四讲：使用 foreach 循环处理数组

### 引言
`foreach` 循环更简洁、可读性高，适用于**只读遍历**（无需索引）。

### 工作原理
语法：`foreach (类型 变量名 in 集合)`，每次迭代自动将下一个元素赋值给迭代变量，底层通过枚举器实现安全访问。

### "只读"限制
迭代变量是只读的，无法通过其修改数组元素（编译器报错），防止遍历中意外修改集合。

### 使用场景
只需从头到尾读取元素，无需索引/修改，避免 `for` 循环的"差一错误"。

### 示例
```csharp
int[] numbers = { 5, 10, 15, 20, 25 };
int sum = 0;

foreach (int number in numbers)
{
    sum += number;
    // number = 0; // 编译错误：迭代变量只读
}

Console.WriteLine($"数字之和为: {sum}"); // 输出: 75
```

## 第五讲：System.Array 类概述

### 引言
C# 中所有数组（`int[]`/`string[]` 等）均隐式继承抽象基类 `System.Array`，自动拥有其属性和方法。

### 关键实例属性
| 属性 | 说明 |
|------|------|
| `.Length` | 获取所有维度的元素总数（最常用） |
| `.Rank` | 获取数组维数（一维数组为 1，二维为 2） |
| `.IsFixedSize` | 始终返回 `true`（数组大小不可变） |
| `.IsReadOnly` | 标准数组返回 `false`（可修改元素） |

### 静态方法与实例方法
- **实例方法**：极少，如 `GetLength(int dimension)`（获取多维数组指定维度大小）。
- **静态方法**：核心功能（如 `Array.Sort()`/`Array.IndexOf()`），直接调用 `Array.方法名(数组实例)`。

### 示例
```csharp
int[] numbers = { 10, 20, 30 };

Console.WriteLine($"元素总数（Length）：{numbers.Length}"); // 输出：3
Console.WriteLine($"维度数量（Rank）：{numbers.Rank}"); // 输出：1
```

## 第六讲：System.Array.IndexOf

### 引言
`Array.IndexOf` 是静态方法，用于在一维数组中**线性搜索**指定元素，返回其首次出现的索引。

### 工作原理
- 线性搜索：从索引 0 开始逐个检查，找到则返回索引，否则返回 `-1`（未找到的标准约定）。
- 时间复杂度：O(n)（最坏情况遍历所有元素）。

### 示例
```csharp
string[] heroes = { "钢铁侠", "美国队长", "雷神", "绿巨人", "雷神" };

// 搜索存在的元素
int indexOfThor = Array.IndexOf(heroes, "雷神");
Console.WriteLine($"找到 '雷神' 的索引位置: {indexOfThor}"); // 输出: 2

// 搜索不存在的元素
int indexOfBatman = Array.IndexOf(heroes, "蝙蝠侠");
Console.WriteLine($"找到'蝙蝠侠'的索引位置：{indexOfBatman}"); // 输出：-1

if (indexOfBatman == -1)
{
    Console.WriteLine("'蝙蝠侠'不在复仇者联盟数组中。");
}
```

## 第七讲：System.Array.BinarySearch 方法

### 引言
`Array.BinarySearch` 是高效静态方法，用于**已排序数组**的查找（大型数组速度远快于 `IndexOf`）。

### 前提条件
数组必须**升序排序**，否则返回值无意义。

### 工作原理：二分查找（分而治之）
1. 比较目标值与数组中间元素：
   - 相等：查找完成，返回索引。
   - 目标值更小：仅在左半部分继续查找。
   - 目标值更大：仅在右半部分继续查找。
2. 时间复杂度：O(log n)（效率远高于线性搜索）。

### 返回值
- 找到元素：返回索引（≥0）。
- 未找到元素：返回负数（第一个大于搜索值的元素索引的按位补码，指示插入位置）。

### 示例
```csharp
int[] sortedNumbers = { 10, 20, 30, 40, 50, 60, 70, 80 };

// 搜索存在的值
int indexFound = Array.BinarySearch(sortedNumbers, 50);
Console.WriteLine($"在索引处找到 50: {indexFound}"); // 输出: 4

// 搜索不存在的值
int indexNotFound = Array.BinarySearch(sortedNumbers, 45);
Console.WriteLine($"未找到 45。返回: {indexNotFound}"); // 输出: -5（4的按位补码）
```

## 第八讲：System.Array.Clear

### 引言
`Array.Clear` 静态方法将数组中指定范围的元素重置为**默认值**（不删除元素/改变数组大小）。

### 工作原理
- 默认值规则：数值类型→0，bool→false，char→`\0`，引用类型→null。
- 方法签名：`Array.Clear(Array array, int index, int length)`（index：起始位置，length：清除数量）。

### 使用场景
- 重用缓冲区（如网络/文件 I/O 缓冲区）。
- 清除敏感数据（密码/密钥），防止内存泄露。

### 示例
```csharp
string[] userNames = { "Alice", "Bob", "Charlie", "David", "Eve" };
Console.WriteLine("原始数组: " + string.Join(", ", userNames));

// 从索引1开始清除3个元素
Array.Clear(userNames, 1, 3);

Console.WriteLine("清除后的数组: " + string.Join(", ", userNames)); // 输出：Alice, , , , Eve
Console.WriteLine($"数组长度仍为: {userNames.Length}"); // 输出：5
```

## 第九讲：System.Array.Resize

### 引言
`Array.Resize` 看似可修改数组大小，实则为"创建+复制"的假象（数组本质固定大小）。

### 工作原理（面试考点）
1. 创建**新数组**（指定大小）。
2. 复制旧数组元素到新数组（新数组更大则补默认值，更小则截断）。
3. 原数组变量（`ref` 传递）指向新数组，旧数组被 GC 回收。

### 性能影响
涉及内存分配和元素复制，大型数组操作成本高（动态集合优先用 `List`）。

### 示例
```csharp
int[] numbers = { 10, 20, 30 };
Console.WriteLine("原始数组: " + string.Join(", ", numbers)); // 输出：10,20,30

// 扩展数组到5个元素
Array.Resize(ref numbers, 5);

Console.WriteLine("调整后的数组: " + string.Join(", ", numbers)); // 输出：10,20,30,0,0
```

## 第十讲：System.Array.Sort

### 引言
`Array.Sort` 静态方法对一维数组**原地排序**（直接修改原数组，不创建新数组）。

### 工作原理
- 排序算法：Introsort（快速排序+堆排序+插入排序混合，高效且避免最坏情况）。
- 基本类型排序规则：数值升序、字符串字母序。

### 示例
```csharp
// 数字排序
int[] numbers = { 5, 1, 9, 3, 7, 6 };
Console.WriteLine("原始数字: " + string.Join(", ", numbers)); // 输出：5,1,9,3,7,6
Array.Sort(numbers);
Console.WriteLine("排序后数字: " + string.Join(", ", numbers)); // 输出：1,3,5,6,7,9

// 字符串排序
string[] names = { "Charlie", "Alice", "Eve", "Bob" };
Console.WriteLine("原始名称列表: " + string.Join(", ", names)); // 输出：Charlie,Alice,Eve,Bob
Array.Sort(names);
Console.WriteLine("排序后的姓名: " + string.Join(", ", names)); // 输出：Alice,Bob,Charlie,Eve
```

## 第十一讲：System.Array.Reverse 方法

### 引言
`Array.Reverse` 静态方法**原地反转**一维数组元素顺序（直接修改原数组）。

### 工作原理
首尾元素交换（第一个↔最后一个，第二个↔倒数第二个），直至数组中间。

### 示例
```csharp
char[] letters = { 'A', 'B', 'C', 'D', 'E' };
Console.WriteLine("原始字母: " + string.Join(", ", letters)); // 输出：A,B,C,D,E

Array.Reverse(letters);

Console.WriteLine("反转后的字母: " + string.Join(", ", letters)); // 输出：E,D,C,B,A
```

## 第十二讲：多维数组

### 引言
多维数组（矩形数组）是多维度的数组，最常见的是二维数组（行+列的网格/表格）。

### 工作原理
- 声明语法：`type[,] 数组名 = new type[行数, 列数];`（逗号分隔维度）。
- 内存布局：仍为堆上连续内存块（大小=行数×列数），通过 `[行,列]` 计算内存偏移。
- 迭代：嵌套 `for` 循环，用 `GetLength(维度)` 获取大小（0=行数，1=列数）。

### 示例：井字棋棋盘
```csharp
// 3x3 井字棋棋盘
char[,] board = new char[3, 3]
{
    { 'X', 'O', 'X' },
    { ' ', 'X', ' ' },
    { 'O', ' ', 'O' }
};

// 修改元素
board[1, 2] = 'O';

// 遍历输出
Console.WriteLine("当前棋盘状态：");
for (int row = 0; row < board.GetLength(0); row++)
{
    for (int col = 0; col < board.GetLength(1); col++)
    {
        Console.Write($"[{board[row, col]}]");
    }
    Console.WriteLine();
}
```

## 第十三讲：锯齿数组

### 引言
锯齿数组是"数组的数组"，内部每个数组可拥有不同长度（区别于二维数组的固定行列）。

### 工作原理（核心区别）
- 外层数组：一维数组，存储内部数组的引用。
- 内部数组：独立的一维数组，堆上分散存储，长度可不同。
- 声明/实例化：两步完成（先创建外层数组，再初始化内部数组）。

### 示例：月度销售数据
```csharp
// 外层数组包含3个元素（对应3个月）
int[][] monthlySales = new int[3][];

// 初始化内部数组（长度不同）
monthlySales[0] = new int[] { 5, 8, 12, 7, 3 }; // 5天数据
monthlySales[1] = new int[] { 10, 11 }; // 2天数据
monthlySales[2] = new int[] { 2, 4, 5, 9 }; // 4天数据

// 遍历输出
for (int i = 0; i < monthlySales.Length; i++)
{
    Console.Write($"Month {i + 1} Sales: ");
    for (int j = 0; j < monthlySales[i].Length; j++)
    {
        Console.Write(monthlySales[i][j] + " ");
    }
    Console.WriteLine();
}
```

## 第十四讲：对象数组

### 引言
数组元素可为自定义类对象，但需注意"引用数组"的特性（易踩坑）。

### 工作原理（初学者易错点）
- 创建对象数组时，仅分配**引用空间**（初始值为 `null`），未创建实际对象。
- 必须手动实例化每个元素，否则访问时抛出 `NullReferenceException`。

### 示例
```csharp
public class Student
{
    public string Name { get; set; }
}

public class Program
{
    public static void Main(string[] args)
    {
        // 第一步：创建数组（仅3个null引用）
        Student[] classroom = new Student[3];

        // 第二步：实例化每个元素
        for (int i = 0; i < classroom.Length; i++)
        {
            classroom[i] = new Student();
        }

        // 赋值并输出
        classroom[0].Name = "Alice";
        classroom[1].Name = "Bob";
        classroom[2].Name = "Charlie";

        foreach (var student in classroom)
        {
            Console.WriteLine($"学生姓名: {student.Name}");
        }
    }
}
```

## 第十五讲：CopyTo 与 Clone 方法

### 引言
`CopyTo`/`Clone` 是数组复制方法，核心为**浅拷贝**（值类型/引用类型表现不同）。

### 方法说明
| 方法 | 类型 | 功能 |
|------|------|------|
| `CopyTo(Array 目标数组, int 索引)` | 实例方法 | 将源数组元素复制到目标数组的指定索引位置 |
| `Clone()` | 实例方法 | 创建新数组，复制原数组元素（返回 `object`，需强制转换） |

### 浅拷贝核心规则
- **值类型数组**：复制独立值（新数组修改不影响原数组）。
- **引用类型数组**：仅复制对象引用（新数组与原数组指向同一对象）。

### 示例：浅拷贝演示
```csharp
public class Student { public string Name; }

public class Program
{
    public static void Main(string[] args)
    {
        Student[] originalClassroom = new Student[2];
        originalClassroom[0] = new Student { Name = "Alice" };
        originalClassroom[1] = new Student { Name = "Bob" };

        // 浅拷贝
        Student[] clonedClassroom = (Student[])originalClassroom.Clone();

        Console.WriteLine("--- 修改前状态 ---");
        Console.WriteLine($"原始数组[0]: {originalClassroom[0].Name}"); // Alice
        Console.WriteLine($"克隆数组[0]: {clonedClassroom[0].Name}"); // Alice

        // 修改克隆数组的对象属性
        clonedClassroom[0].Name = "Alicia";

        Console.WriteLine("\n--- 修改后状态 ---");
        Console.WriteLine($"原始数组[0]: {originalClassroom[0].Name}"); // Alicia（原数组受影响）
        Console.WriteLine($"克隆数组[0]: {clonedClassroom[0].Name}"); // Alicia
    }
}
```

## 第十六讲：深拷贝

### 引言
深拷贝创建完全独立的数组副本，新数组的对象与原数组无关联（修改不互相影响）。

### 工作原理
C# 无内置泛型深拷贝方法，需手动实现：
1. 创建同大小的新数组。
2. 遍历原数组，为每个元素创建**新对象**（通过拷贝构造函数复制值）。

### 示例
```csharp
public class Student
{
    public string Name;

    // 常规构造函数
    public Student(string name) { this.Name = name; }

    // 拷贝构造函数（复制现有对象的值）
    public Student(Student other)
    {
        this.Name = other.Name;
    }
}

public class Program
{
    public static void Main(string[] args)
    {
        Student[] originalClassroom = { new Student("Alice"), new Student("Bob") };

        // 手动深拷贝
        Student[] deepCopiedClassroom = new Student[originalClassroom.Length];
        for (int i = 0; i < originalClassroom.Length; i++)
        {
            deepCopiedClassroom[i] = new Student(originalClassroom[i]);
        }

        Console.WriteLine("--- 修改前状态 ---");
        Console.WriteLine($"原始数组[0]: {originalClassroom[0].Name}"); // Alice
        Console.WriteLine($"深拷贝数组[0]: {deepCopiedClassroom[0].Name}"); // Alice

        // 修改深拷贝数组的对象属性
        deepCopiedClassroom[0].Name = "Alicia";

        Console.WriteLine("\n--- 修改后状态 ---");
        Console.WriteLine($"原始数组[0]: {originalClassroom[0].Name}"); // Alice（原数组不受影响）
        Console.WriteLine($"深拷贝数组[0]: {deepCopiedClassroom[0].Name}"); // Alicia
    }
}
```

## 第十七讲：重要知识点回顾

### 核心要点
1. **数组基础**：引用类型、固定大小、零索引，变量存储堆内存引用。
2. **遍历选择**：`for` 循环（需索引/修改元素），`foreach` 循环（只读、简洁、安全）。
3. **Resize 本质**：不原地修改大小，而是创建新数组+复制元素（大型数组性能差，优先用 `List`）。
4. **拷贝区别**：
   - 浅拷贝（`Clone()`）：值类型复制值，引用类型复制引用（共享对象）。
   - 深拷贝：手动创建新对象，完全独立（无共享引用）。
5. **内存差异**：
   - 结构体数组：所有元素连续存储在堆上。
   - 类对象数组：仅存储引用，实际对象分散在堆上。
