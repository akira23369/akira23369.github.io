# 字符串格式化与插值

在开发中，经常需要将多个动态变量与静态文本拼接成一个完整的字符串（例如生成日志、输出报告、构建 UI 文本）。C# 提供了不同时代的解决方案来实现这一目标。

## 传统方式：`string.Format`

`string.Format` 是从 C# 早期版本就存在的一种静态方法，采用**基于索引的占位符**机制。

*   **工作原理**：在主字符串中使用 `{0}`、`{1}` 等带有数字索引的占位符。方法签名内部使用了 `params object[]` 关键字，因此可以接收无限数量的参数。运行时会根据占位符的数字索引，将对应顺序的参数值替换进去。
*   **适用场景**：当格式化模板是从外部文件（如 JSON 配置、资源文件 `.resx`）读取时，由于无法在编译期确定变量名，必须使用 `string.Format`。

```csharp
string director = "Sam Raimi";
string movie = "Spider-Man";

// 索引 0 对应 director，索引 1 对应 movie
string formattedString = string.Format("The director of {1} is {0}.", director, movie);

Console.WriteLine(formattedString); 
// 输出: The director of Spider-Man is Sam Raimi.
```

## 字符串插值 (`$""`)

自 C# 6.0 引入了字符串插值语法（在字符串双引号前加上 `$` 符号）。这是目前 C# 开发中最推荐、最易读的格式化方式。

*   **工作原理**：允许直接在字符串的大括号 `{}` 内书写当前作用域下可访问的变量名、属性、表达式甚至是方法调用。
*   **可读性提升**：彻底消除了寻找索引与变量对应关系的心智负担，尤其是在变量较多时，避免了索引写错或参数顺序传错的 Bug。

```csharp
string director = "Sam Raimi";
string movie = "Spider-Man";

// 直接在大括号内放入变量或表达式
string interpolatedString = $"The director of {movie} is {director}.";

// 甚至可以在大括号内直接调用方法或执行运算
string upperCaseString = $"Movie in uppercase: {movie.ToUpper()}";
```

常量也可以用字符串插值
**只有当插值表达式中的所有部分也都是编译时常量时，才能用字符串插值来初始化一个 `const` 字符串。**
这意味着你不能在 `const` 字符串的插值表达式中使用变量、方法调用或任何需要在运行时才能确定的值。

```cs
const string Language = "C#";
const string Platform = ".NET";
// 所有插值部分 (Platform 和 Language) 都是常量，因此这是合法的。
const string FullProductName = $"{Platform} - Language: {Language}";

// 也可以直接在插值中使用字面量
const string Greeting = $"Hello, {"World"}!";



const string Name = "Mark";
// 错误：DateTime.Now 是一个运行时值，不是编译时常量。
const string DateMessage = $"Today is {DateTime.Now}"; 

int number = 10;
// 错误：number 是一个局部变量，不是常量。
const string NumberMessage = $"The number is {number}";

```

## 拓展

为了写出更高质量、高性能的 C# 代码，需要进一步理解格式化的底层逻辑和现代语言特性。

### 编译期转换与性能飞跃 (C# 10 及以上底层机制)
很多初学者认为 `$` 语法仅仅是 `string.Format` 的语法糖。
*   **在 C# 9 及以前**：确实如此，编译器在底层会将 `$"Hello {name}"` 转换为 `string.Format("Hello {0}", name)`，这会产生装箱（Boxing）和多次内存分配。
*   **在 C# 10 及以后（现代 .NET）**：编译器引入了 `DefaultInterpolatedStringHandler`（插值字符串处理程序）。当你使用 `$` 时，编译器不会再调用 `string.Format`，而是直接计算出最终所需的准确字符串长度，并在托管堆上**一次性分配内存**。这意味着在现代 C# 中，**字符串插值 `$""` 在执行性能和内存分配上，彻底碾压了传统的 `string.Format`**。

### 格式说明符
在 `{}` 中，不仅仅可以放变量，还可以通过加冒号 `:` 来精确控制数据的显示格式。这在处理数字、货币和日期时尤为重要。

```csharp
double price = 1299.5;
DateTime releaseDate = new DateTime(2002, 5, 3);

// :C 代表货币格式 (Currency)，:yyyy-MM-dd 代表自定义日期格式
string report = $"Ticket Price: {price:C} | Release: {releaseDate:yyyy-MM-dd}";
// 输出类似: Ticket Price: $1,299.50 | Release: 2002-05-03
```

### 原始字符串字面量与插值的结合 (C# 11 特性)
在处理包含大量大括号 `{}` 的文本（如 JSON 或 HTML 代码）时，使用常规的插值字符串会导致冲突（需要使用 `{{` 来转义）。C# 11 引入了原始字符串字面量 `"""`，可以与 `$` 结合使用。通过使用多个 `$`，可以定义需要多少个大括号才能触发代码插值。

```csharp
string movieTitle = "Spider-Man";
int year = 2002;

// 使用 $$ 前缀，意味着必须出现双大括号 {{ }} 才会触发变量替换
// 内部的单大括号 { } 会被当作普通字符串文本处理，极大地简化了 JSON 的拼接
string jsonPayload = $$"""
{
    "movieName": "{{movieTitle}}",
    "releaseYear": {{year}},
    "metadata": {
        "genre": "Action"
    }
}
""";
```
