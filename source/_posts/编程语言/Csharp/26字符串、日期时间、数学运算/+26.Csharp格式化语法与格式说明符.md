# 一、核心语法公式

在现代 C#（C# 6.0+）中，99% 的格式化都是通过**字符串插值（String Interpolation `$""`）** 或 `ToString()` 完成的。它们的底层语法公式完全一致：

```csharp
{变量或表达式, 对齐宽度 : 格式说明符}
```

*   **变量或表达式**：你要格式化的数据（必须）。
*   **对齐宽度**（可选）：正数表示**右对齐**，负数表示**左对齐**。常用于控制台或日志对齐。
*   **格式说明符**（可选）：控制数据的呈现形式（如保留几位小数、日期格式等）。

**基本示例：**
```csharp
int price = 123;
// 1. 仅变量
Console.WriteLine($"价格: {price}");         // 价格: 123
// 2. 带格式说明符
Console.WriteLine($"价格: {price:C2}");      // 价格: ￥123.00
// 3. 带对齐和格式说明符 (占10个字符，右对齐)
Console.WriteLine($"价格: {price,10:C2}");   // 价格:    ￥123.00
```

# 二、数字格式化

数字格式化分为**标准说明符**（字母+数字）和**自定义说明符**（符号组合）。

## 标准数字说明符
字母代表模式，后面的数字代表**精度**（小数位数或补零位数）。

| 说明符     | 含义                  | 示例代码 (假设 `val = 1234.567`) | 输出结果 (默认中文环境)依赖当前区域设置 | 适用场景             |
| :------ | :------------------ | :------------------------- | :-------------------- | :--------------- |
| **`C`** | Currency (货币)       | `$"{val:C2}"`              | `￥1,234.57`           | 电商价格展示           |
| **`F`** | Fixed-point (固定小数)  | `$"{val:F2}"`              | `1234.57`             | 常规浮点数展示          |
| **`N`** | Number (千位分隔符)      | `$"{val:N2}"`              | `1,234.57`            | 报表、大数字展示         |
| **`P`** | Percentage (百分比)    | `$"{0.1234:P1}"`           | `12.3%`               | 转化率、进度条 (自动乘100) |
| **`D`** | Decimal (十进制整型)     | `$"{12:D4}"`               | `0012`                | **仅限整数**，单据号补零   |
| **`X`** | Hex (十六进制)          | `$"{255:X2}"`              | `FF`                  | 硬件通信、颜色值、加密      |
| **`E`** | Exponential (科学计数法) | `$"{val:E2}"`              | `1.23E+003`           | 科学计算、极大数据        |

```cs
double num = 12345.6789;
Console.WriteLine($"{num:C2}");     // $12,345.68
Console.WriteLine($"{num:N0}");     // 12,346
Console.WriteLine($"{num:F3}");     // 12345.679
Console.WriteLine($"{num:E2}");     // 1.23E+004
Console.WriteLine($"{0.125:P0}");   // 13%

int hexNum = 255;
Console.WriteLine($"{hexNum:X}");   // FF
Console.WriteLine($"{hexNum:X4}");  // 00FF
```


## 自定义数字说明符
当标准说明符不满足时（如电话号码、特殊掩码），使用自定义占位符。

| 说明符 | 作用        | 示例 `1234.56`               |
| --- | --------- | -------------------------- |
| `0` | 占位符，不足补零  | `0000` → `1235`            |
| `#` | 占位符，不足省略  | `####` → `1235`            |
| `.` | 小数点       | `0.00` → `1234.56`         |
| `,` | 千位分隔符或缩放符 | `#,#` → `1,235`            |
| `%` | 百分比       | `#%` → `123456%`           |
| `\` | 转义字符      | `0\\.00` → `1234.56`       |
| `;` | 正负零分段     | `#,##0.00;(#,##0.00);Zero` |


**高频神仙用法：**
```csharp
double num = 1234.5;

// 1. 强制对齐小数点 (0 和 # 混用)
Console.WriteLine($"{num:00000.00}");   // 01234.50

// 2. 缩放数字 (每多一个逗号，缩小 1000 倍) -> 报表常用
double revenue = 15000000; 
Console.WriteLine($"{revenue:0,, 百万}"); // 15 百万 (除了两次 1000)

// 3. 电话号码格式化
long phone = 13812345678;
Console.WriteLine($"{phone:###-####-####}"); // 138-1234-5678

// 4. 正负数与零的三元格式化: 格式为 "正数;负数;零"
int profit1 = 100, profit2 = -50, profit3 = 0;
string format = "+#;-#;持平";
Console.WriteLine($"{profit1:{format}}"); // +100
Console.WriteLine($"{profit2:{format}}"); // -50
Console.WriteLine($"{profit3:{format}}"); // 持平


double num = 1234.56;
Console.WriteLine($"{num:00000}");      // 01235
Console.WriteLine($"{num:#.##}");       // 1234.56
Console.WriteLine($"{num:#,0}");        // 1,235
Console.WriteLine($"{num:#,#.00}");     // 1,234.56

// 分段格式化
double pos = 123.45, neg = -123.45, zero = 0;
Console.WriteLine($"{pos:#,##0.00;(#,##0.00);Zero}");   // 123.45
Console.WriteLine($"{neg:#,##0.00;(#,##0.00);Zero}");   // (123.45)
Console.WriteLine($"{zero:#,##0.00;(#,##0.00);Zero}");  // Zero

```

# 三、日期与时间格式化

## 日期时间格式说明符

| 格式     | 说明           | 示例 (2024-01-15 14:30:25) |
| ------ | ------------ | ------------------------ |
| `yyyy` | 4位年份         | `2024`                   |
| `yy`   | 2位年份         | `24`                     |
| `MM`   | 月份（01-12）    | `01`                     |
| `M`    | 月份（1-12）     | `1`                      |
| `dd`   | 日期（01-31）    | `15`                     |
| `d`    | 日期（1-31）     | `15`                     |
| `HH`   | 24小时制（00-23） | `14`                     |
| `hh`   | 12小时制（01-12） | `02`                     |
| `mm`   | 分钟（00-59）    | `30`                     |
| `ss`   | 秒（00-59）     | `25`                     |
| `fff`  | 毫秒           | `000`                    |
| `tt`   | AM/PM        | `PM`                     |

这是业务开发中最频繁接触的格式化。

## 标准日期时间格式示例

```cs
DateTime now = new DateTime(2024, 1, 15, 14, 30, 25);
Console.WriteLine($"{now:d}");   // 短日期: 2024/1/15
Console.WriteLine($"{now:D}");   // 长日期: 2024年1月15日 星期一
Console.WriteLine($"{now:t}");   // 短时间: 14:30
Console.WriteLine($"{now:T}");   // 长时间: 14:30:25
Console.WriteLine($"{now:f}");   // 完整日期时间(短时间): 2024年1月15日 14:30
Console.WriteLine($"{now:F}");   // 完整日期时间(长时间): 2024年1月15日 14:30:25
Console.WriteLine($"{now:g}");   // 常规日期时间(短时间): 2024/1/15 14:30
Console.WriteLine($"{now:G}");   // 常规日期时间(长时间): 2024/1/15 14:30:25
Console.WriteLine($"{now:u}");   // 排序UTC: 2024-01-15 14:30:25Z
Console.WriteLine($"{now:yyyy-MM-dd HH:mm:ss}"); // 自定义: 2024-01-15 14:30:25
Console.WriteLine($"{now:yyyy年MM月dd日 dddd}"); // 2024年01月15日 星期一
```


## 高频自定义组合 (90% 的场景)
通过组合 `y` (年), `M` (月), `d` (日), `H/h` (时), `m` (分), `s` (秒), `f` (毫秒)。

```csharp
DateTime now = DateTime.Now;

// 标准数据库/日志格式
Console.WriteLine($"{now:yyyy-MM-dd HH:mm:ss}");       // 2023-10-25 14:30:05
// 精确到毫秒 (日志排错必用)
Console.WriteLine($"{now:yyyy-MM-dd HH:mm:ss.fff}");   // 2023-10-25 14:30:05.123
// 中文阅读格式
Console.WriteLine($"{now:yyyy年MM月dd日}");             // 2023年10月25日
// 12小时制带 AM/PM
Console.WriteLine($"{now:yyyy-MM-dd hh:mm:ss tt}");    // 2023-10-25 02:30:05 下午
```
*注意：`MM` 是月份，`mm` 是分钟；`HH` 是24小时制，`hh` 是12小时制。区分大小写极为重要！*

## 标准日期说明符 (API交互与全球化)

| 说明符           | 含义                    | 示例结果                                | 适用场景                            |
| :------------ | :-------------------- | :---------------------------------- | :------------------------------ |
| **`O` / `o`** | Round-trip (ISO 8601) | `2023-10-25T14:30:05.1234567+08:00` | **JSON 序列化、REST API 通信 (绝对重点)** |
| **`R` / `r`** | RFC 1123              | `Wed, 25 Oct 2023 14:30:05 GMT`     | HTTP 请求/响应头中的时间                 |
| **`d`**       | 短日期                   | `2023/10/25`                        | UI 列表展示                         |
| **`g`**       | 常规日期(短)               | `2023/10/25 14:30`                  | UI 文章发布时间                       |

# 四、字符串对齐与补齐

在写控制台工具、生成对齐的文本日志或报表时非常有用。利用 `{var, alignment}`。

```csharp
string[] names = { "Alice", "Bob", "Charlie" };
int[] scores = { 95, 100, 5 };

Console.WriteLine("Name       | Score");
Console.WriteLine("------------------");
for (int i = 0; i < names.Length; i++)
{
    // names 左对齐占 10 位，scores 右对齐占 5 位
    Console.WriteLine($"{names[i],-10} | {scores[i],5}");
}
/* 输出：
Name       | Score
------------------
Alice      |    95
Bob        |   100
Charlie    |     5
*/


int value = 2026;
// 对齐：正数右对齐，负数左对齐
Console.WriteLine($"{value,10}");   // 右对齐，宽度10
Console.WriteLine($"{value,-10}");  // 左对齐，宽度10

// 结合格式化, 右对齐10，,保留两位小数
Console.WriteLine($"{123.456,10:F2}");  // "    123.46"
Console.WriteLine($"{"Name",-10}{"Score",10}");
// Name          Score

// 补零（数值专用）
Console.WriteLine($"{42:00000}");   // 00042
Console.WriteLine($"{42:D5}");      // 00042

```

# 五、枚举格式化
|**说明符**|**名称**|**说明**|**示例 (myColor)**|
|---|---|---|---|
|**G** (或 **g**)|常规 (General)|如果定义了名称，则显示名称；否则显示数值。|`Green`|
|**D** (或 **d**)|十进制 (Decimal)|显示枚举的基础整数值。|`2`|
|**X** (或 **x**)|十六进制 (Hex)|以十六进制格式显示数值（不带 0x）。|`00000002`|
|**F** (或 **f**)|标志 (Flags)|将值视为位标志（Flags），显示组合名称。|`Green`|
枚举不仅可以直接转字符串，还能转数字或十六进制。

```csharp
[Flags]
enum Status { None = 0, Active = 1, Deleted = 2 }

Status s = Status.Active | Status.Deleted;

Console.WriteLine($"{s:G}"); // Active, Deleted (常规文本，自动处理 Flags)
Console.WriteLine($"{s:D}"); // 3 (对应的十进制整型值)
Console.WriteLine($"{s:X}"); // 00000003 (十六进制)
```

# 六、全球化与 Culture (避坑指南)

**这是中高级开发必须掌握的痛点！**
由于格式化默认依赖当前操作系统的区域设置（Culture），同一个程序在中文电脑和欧洲电脑上运行结果可能不同（例如欧洲部分国家的小数点是 `,` 而不是 `.`）。

**场景：将数字或日期拼接进 SQL 语句、JSON 或调用第三方 API 时，绝对不能带文化差异！**

**解决方案：使用 `CultureInfo.InvariantCulture`**

```csharp
double money = 1234.56;

// 错误做法：在德国系统上会输出 "1234,56"，导致 JSON 或 SQL 报错
string badJson = $"money: {money}";

// 正确做法 1：ToString 传入 InvariantCulture
string goodStr1 = money.ToString("n1", CultureInfo.InvariantCulture);

// 正确做法 2：C# 10+ 提供的 FormattableString 简写 (底层其实是 String.Format)
string goodJson = string.Create(CultureInfo.InvariantCulture, $"money: {money:n1}");

Console.WriteLine("Bad JSON: " + badJson);
Console.WriteLine("Good String: " + goodStr1);
Console.WriteLine("Good JSON: " + goodJson);
```

# 七、Guid 格式化

**`Guid` (Globally Unique Identifier)** 是 C# 中的一个**全局唯一标识符**。它是一个 128 位的整数（16 字节），设计初衷是保证在全世界范围内的所有计算机上，通过特定算法生成的每一个 Guid 都是**独一无二**的。
- **唯一性**：由于其位长达到了 128 位，重复的概率极低。低到什么程度呢？即使你每秒产生 10 亿个 Guid，也要持续几百年才会有极小的概率发生碰撞。
- **无序性**：默认生成的 Guid（通过 `Guid.NewGuid()`）是随机的，不具备逻辑上的顺序（虽然也有“连续 Guid”的特殊变体）。
- **标准格式**：通常表示为一组 32 位的十六进制数字。
```cs
Guid guid = Guid.NewGuid();
Console.WriteLine($"{guid:N}");  // 32位: 12345678abcdef12345678abcdef1234
Console.WriteLine($"{guid:D}");  // 带连字符: 12345678-abcd-ef12-3456-78abcdef1234（默认）
Console.WriteLine($"{guid:B}");  // 大括号: {12345678-abcd-ef12-3456-78abcdef1234}
Console.WriteLine($"{guid:P}");  // 圆括号: (12345678-abcd-ef12-3456-78abcdef1234)
```

# 八、C# 现代新特性 (C# 11/12)

## 原始字符串字面量 - JSON/XML 杀手锏
以前在 JSON 里用 `$""` 格式化，大括号 `{}` 会和插值语法冲突，需要写 `{{` 和 `}}` 转义，极度反人类。
C# 11 引入了 `$$"""..."""`，几美元符号就代表需要几个大括号来触发插值：

```csharp
string name = "张三";
int age = 25;

// $$ 表示用 {{ 和 }} 来包裹变量，单独的 { 和 } 被当作普通字符
string json = $$"""
{
    "user": {
        "name": "{{name}}",
        "age": {{age}}
    }
}
""";
```

## TimeSpan 格式化强化
格式化 `TimeSpan` (耗时、倒计时) 时，冒号需要转义（通过 `\` 或直接包含在普通字符串里）。
```csharp
TimeSpan ts = new TimeSpan(1, 2, 30, 45, 123); // 1天 2:30:45.123

// 提取特定部分展示
Console.WriteLine($"{ts.Days}天 {ts.Hours}小时"); // 1天 2小时

// 标准时间间隔 (带毫秒)
Console.WriteLine($"{ts:c}"); // 1.02:30:45.1230000

// 自定义格式 (注意 \ 转义符号，或者在外层用插值)
Console.WriteLine(ts.ToString(@"dd\.hh\:mm\:ss")); // 01.02:30:45
```
