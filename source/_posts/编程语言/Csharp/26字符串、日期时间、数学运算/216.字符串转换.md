# 字符串转换

在 C# 中，`System.String` 类提供了丰富的实例方法和静态方法用于操作和转换字符串。在调用这些方法时，必须牢记一个底层原则：**由于字符串的不可变性（Immutability），所有看似“修改”字符串的方法，实际上都不会改变原对象，而是每次都在托管堆（Managed Heap）上分配并返回一个全新的字符串对象。**

## 字符串大小写转换

`ToUpper()` 和 `ToLower()` 方法用于将字符串转换为全大写或全小写。

**深度扩展：**
根据《Effective C#》的建议，在进行非 UI 展示的系统级字符串比较（如验证字典的 Key、解析文件路径等）时，直接使用无参的 `ToLower()` 或 `ToUpper()` 是危险的，因为它依赖于当前线程的区域性（Culture）。例如在土耳其语中，大写 'i' 的转换规则与英语不同。
系统级操作应始终使用 `ToUpperInvariant()` 或在比较时引入 `StringComparison.OrdinalIgnoreCase`。通常推荐统一转换为大写再比较，因为底层对大写转换进行了高度优化。

```csharp
string role = "Developer";

// 基础用法：返回新对象，原对象不变
string upper = role.ToUpper(); // "DEVELOPER"
string lower = role.ToLower(); // "developer"

// 进阶实践：系统级安全的大写转换（无视系统语言环境）
string safeUpper = role.ToUpperInvariant();
```

## 字符串截取与现代高性能方案

`Substring()` 用于从指定位置截取原字符串的一部分，并生成一个新对象。它有两个常用的重载：
*   `Substring(int startIndex)`：从起始索引一直截取到末尾。
*   `Substring(int startIndex, int length)`：从起始索引截取指定长度的字符。

**深度扩展：**
在进行大量字符串截取操作时，频繁使用 `Substring` 会给垃圾回收器（GC）带来巨大压力（因为每次都创建新对象）。在现代 C# 开发中，针对只需“只读读取”片段的场景，强烈推荐使用 `ReadOnlySpan<char>` 或者 C# 8.0 引入的**范围运算符（Range Operator `..`）**。`Span` 会直接在原内存上切片，实现真正的零内存分配（Zero Allocation）。

```csharp
string text = "C# Developer";

// 1. 传统 Substring 截取 (分配新内存)
string sub1 = text.Substring(3);    // "Developer"
string sub2 = text.Substring(3, 3); // "Dev"

// 2. 现代 C# 切片语法 (本质依然是调用 Substring，分配新内存)
string sub3 = text[3..];  // "Developer"
string sub4 = text[3..6]; // "Dev"

// 3. 高性能最佳实践：ReadOnlySpan (零内存分配)
ReadOnlySpan<char> spanText = text.AsSpan();
ReadOnlySpan<char> devSpan = spanText.Slice(3, 9); // 直接映射原内存，不创建新 string 对象
```

## 字符替换与空白清理

*   **Replace()**：将字符串中所有的指定字符（char）或子串（string）替换为新的字符或子串。
*   **Trim()**：移除字符串**开头和结尾**的所有空白字符（包括空格、制表符 `\t`、换行符 `\n` 等）。但不会移除字符串中间的空格。

**深度扩展：**
`Trim` 家族还包括 `TrimStart()` 和 `TrimEnd()`，可以精确控制只清理头部或尾部。需要注意的是，方法链式调用（如 `text.Trim().Replace("a", "b")`）会在每一步都产生一个临时的中间字符串对象。如果逻辑非常复杂，应当考虑使用 `StringBuilder` 或正则表达式（Regex）。

```csharp
string messyInput = "   Hello World   ";

// 清理两端空格
string clean = messyInput.Trim(); // "Hello World"

// 字符替换
string replaced = clean.Replace('e', 'x'); // "Hxllo World"

// 字符串替换
string masked = clean.Replace("World", "****"); // "Hello ****"
```

## 字符串与数组的相互转换（拆分与拼接）

字符串本质上是字符集合，经常需要在字符串、字符数组（`char[]`）以及字符串数组（`string[]`）之间进行转换。

### 拆分(Split)
`Split()` 实例方法根据指定的分隔符，将一个长字符串拆分为 `string[]` 数组。

**深度扩展：**
在实际业务数据（如 CSV 文件）中，连续出现两个分隔符会导致解析出空字符串。最佳实践是结合使用 `StringSplitOptions.RemoveEmptyEntries` 枚举，它会在底层拆分时自动过滤掉空白项，避免后续数组越界或空指针异常。

```csharp
string data = "Apple,,Banana, Orange";

// 基础拆分（逗号分隔）
string[] rawParts = data.Split(','); 
// rawParts 包含: "Apple", "", "Banana", " Orange" (注意空字符串和前导空格)

// 进阶实践：拆分时同时处理多个分隔符，并过滤空项，并修剪空格
string[] cleanParts = data.Split(
    new char[] { ',', ' ' }, 
    StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries
);
// cleanParts 仅包含纯净的: "Apple", "Banana", "Orange"
```

### 拼接(String.Join)
`String.Join()` 是一个**静态方法**。它接收一个分隔符和一个数组/集合，将集合内的所有元素拼接成一个长字符串。
*底层机制*：`String.Join` 的性能极高。根据《CLR via C#》的解析，它在内部会预先遍历一次集合以计算所需的总字符长度，然后一次性分配足够的内存并进行填充，避免了内存的反复重分配。

```csharp
string[] words = { "How", "are", "you" };

// 使用指定的字符串拼接数组元素
string sentence1 = string.Join(" ", words);   // "How are you"
string sentence2 = string.Join("---", words); // "How---are---you"
```

### 字符串与字符数组互转 (ToCharArray 与 new string)
*   `ToCharArray()`：实例方法，将现有字符串的每一个字符提取出来，生成一个全新的 `char[]`。
*   `new string(char[])`：利用 `String` 类的构造函数，接收一个 `char[]` 并以此创建出一个全新的字符串。

```csharp
string word = "Code";

// 1. String 转 char[]
char[] characters = word.ToCharArray(); 
// characters 内容为 ['C', 'o', 'd', 'e']

// 可以修改字符数组的内容
characters[0] = 'N';

// 2. char[] 转回 String
string newWord = new string(characters); // "Node"
```
