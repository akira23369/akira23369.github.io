在 C# 中，**`string` (字符串)**、**`System.Array` (数组)** 和 **LINQ (语言集成查询)** 被称为处理数据的“黄金三角”。

理解它们协同工作的核心基础是：
1. `string` 在底层实现了 `IEnumerable<char>`，这意味着**一个字符串就是一个字符集合**，可以直接对其使用 LINQ 进行单字符级别的查询。
2. `string.Split()` 会生成 `string[]`（字符串数组），而数组 `System.Array` 实现了 `IEnumerable<T>`，因此可以直接对接所有的 LINQ 扩展方法。
3. `string.Join()` 可以将 LINQ 处理完的集合重新合并为单一字符串。

### 场景一：单字符串的字符级过滤与统计 (`string` + LINQ)
**需求：** 提取字符串中的所有数字，或者统计特定类型字符的数量（如元音字母、大写字母）。
**核心机制：** 直接把 `string` 当作 `char` 的集合来查。

```csharp
using System;
using System.Linq;

public class CharacterAnalysis
{
    public static void Run()
    {
        string input = "Order #8921-A created on 2023!";

        // 1. 提取所有数字字符，并重新拼接为字符串
        // 原理：Where 过滤出数字字符，生成 IEnumerable<char>，然后用 string.Concat 组合
        string numbersOnly = string.Concat(input.Where(char.IsDigit)); 
        Console.WriteLine(numbersOnly); // 输出: 89212023

        // 2. 统计大写字母的数量
        int upperCount = input.Count(char.IsUpper); 
        Console.WriteLine(upperCount); // 输出: 2 (O, A)

        // 3. 检查是否包含特定的字符集（例如是否包含元音）
        char[] vowels = { 'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U' };
        bool hasVowels = input.Any(c => vowels.Contains(c));
        Console.WriteLine(hasVowels); // 输出: True
    }
}
```

### 场景二：字符串数组的清洗与转换 (Array + LINQ)
**需求：** 用户输入了一段混乱的文本，包含多余的空格、大小写不一。我们需要提取出所有有效的单词，并统一转换为首字母大写。
**核心机制：** `Split` 拆分为数组 -> `Select`/`Where` 清洗转换 -> `Join` 合并。

```csharp
using System;
using System.Linq;

public class WordProcessing
{
    public static void Run()
    {
        string messyText = "  apple,  BANANA , ,, orange, Grape  ";

        // 1. Split 拆分为数组，并自动剔除空项和首尾空格
        string[] rawWords = messyText.Split(
            new char[] { ',', ' ' }, 
            StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries
        );

        // 2. LINQ 转换：将每个单词变成 "首字母大写，其余小写"
        var cleanWords = rawWords.Select(word => 
            char.ToUpper(word[0]) + word.Substring(1).ToLower()
        );

        // 3. Join 重新组合为标准字符串
        string result = string.Join(" - ", cleanWords);
        
        Console.WriteLine(result); 
        // 输出: Apple - Banana - Orange - Grape
    }
}
```

### 场景三：数据解析与聚合计算 (String -> Array -> LINQ -> Math)
**需求：** 从一个以逗号分隔的商品价格字符串中，提取出所有大于 50 的价格，并计算它们的总和及最大值。
**核心机制：** 字符串解析为强类型集合，进行数学聚合操作。

```csharp
using System;
using System.Linq;

public class DataParsing
{
    public static void Run()
    {
        string priceData = "10.5, 60.0, 25.5, 120.5, 40.0, 85.0";

        // 拆分字符串，解析为 double 数组，并执行过滤
        double[] expensivePrices = priceData
            .Split(',')                     // 1. 拆分为 string[]
            .Select(p => double.Parse(p))   // 2. 转换为 IEnumerable<double>
            .Where(price => price > 50.0)   // 3. 过滤出大于 50 的项
            .ToArray();                     // 4. 固化为 Array

        // 使用 LINQ 的数学聚合函数
        double totalSum = expensivePrices.Sum();
        double maxPrice = expensivePrices.Max();

        Console.WriteLine($"大于50的商品总价: {totalSum}, 最高单价: {maxPrice}");
        // 输出: 大于50的商品总价: 265.5, 最高单价: 120.5
    }
}
```

### 场景四：高级词频统计 (LINQ 分组 GroupBy)
**需求：** 找出一段日志文本中，出现频率最高的单词。
**核心机制：** 利用 LINQ 的 `GroupBy` 按单词内容分组，利用 `OrderByDescending` 排序。

```csharp
using System;
using System.Linq;

public class FrequencyAnalysis
{
    public static void Run()
    {
        string logText = "Error timeout. Warning memory. Error CPU. Error timeout. Warning disk.";

        // 拆分并清理标点符号
        string[] words = logText.Split(
            new char[] { ' ', '.' }, 
            StringSplitOptions.RemoveEmptyEntries
        );

        // 核心 LINQ 词频统计流水线
        var wordFrequency = words
            .GroupBy(w => w.ToUpper())                   // 1. 忽略大小写进行分组
            .Select(g => new { Word = g.Key, Count = g.Count() }) // 2. 投影为匿名对象
            .OrderByDescending(x => x.Count)             // 3. 按出现次数降序排列
            .First();                                    // 4. 获取排名第一的项

        Console.WriteLine($"最高频单词: {wordFrequency.Word}, 出现次数: {wordFrequency.Count}");
        // 输出: 最高频单词: ERROR, 出现次数: 3
    }
}
```

### 场景五：System.Array 原生方法 vs LINQ 的性能考量
**深度架构知识：**
虽然 LINQ 写起来非常优雅，但 LINQ 每次调用都会创建新的迭代器和集合（分配新的托管堆内存）。在对性能和内存要求极高的底层场景下，直接使用 `System.Array` 的原生静态方法（原地修改或直接查找）往往是更优的选择。

```csharp
using System;
using System.Linq;

public class ArrayVsLinq
{
    public static void Run()
    {
        string[] users = { "Zack", "Alice", "Bob", "Charlie", "Alice" };

        // 场景 A：反转数组
        // LINQ 方式（生成并返回一个全新的集合，原数组不变）
        var reversedLinq = users.Reverse().ToArray(); 
        
        // System.Array 方式（直接在原数组内存上原地反转，零内存分配，性能极高）
        Array.Reverse(users); 

        // 场景 B：查找所有满足条件的元素
        // LINQ 方式
        var aUsersLinq = users.Where(u => u.StartsWith("A")).ToArray();

        // System.Array 方式（底层针对数组结构做了极度优化，速度比 LINQ 快）
        string[] aUsersArray = Array.FindAll(users, u => u.StartsWith("A"));
        
        // 场景 C：排序
        // LINQ 方式（生成新集合）
        var sortedLinq = users.OrderBy(u => u).ToArray();
        
        // System.Array 方式（快速排序原地修改）
        Array.Sort(users);
    }
}
```

### 总结建议
1. **日常业务逻辑 / 数据提取转换**：毫不犹豫地使用 `string.Split()` + `LINQ`，代码的易读性和可维护性是最高优先级。
2. **高频调用的底层框架 / 游戏开发（如 Unity）**：警惕 LINQ 带来的 GC（垃圾回收）压力，优先考虑 `string.IndexOf`、`System.Array` 的原生静态方法以及 `ReadOnlySpan<char>` 来实现零内存分配的处理。
