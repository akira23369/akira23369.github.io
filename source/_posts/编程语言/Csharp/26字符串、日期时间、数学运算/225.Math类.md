# Math类
`Math` 类是一个**静态类**（Static Class），位于 `System` 命名空间下。它提供了进行基本数学、三角函数、对数以及其他常见数学运算的静态方法和常量。由于它是静态类，不能被实例化，所有方法均通过 `Math.方法名()` 直接调用。

## 数学常量

`Math` 类提供了两个最常用的数学物理常量，返回类型均为 `double`。

*   **`Math.PI`**: 表示圆周率 $\pi$，常用于圆的面积、周长计算以及角度与弧度的转换。值约为 `3.1415926535897931`。
*   **`Math.E`**: 表示自然对数的底数 $e$。值约为 `2.7182818284590451`。

```csharp
double radius = 5.0;
// 计算圆的面积：π * r^2
double area = Math.PI * radius * radius; 
Console.WriteLine(area); // 输出: 78.53981633974483

Console.WriteLine(Math.E); // 输出: 2.718281828459045
```

## 取整与截断方法

这是实际业务开发中（如金融、电商价格计算）最常用的分类。特别要注意负数的处理逻辑。

*   **`Math.Floor(double d)` (向下取整)**: 返回小于或等于指定数字的**最大整数**。
*   **`Math.Ceiling(double d)` (向上取整)**: 返回大于或等于指定数字的**最小整数**。
*   **`Math.Truncate(double d)` (截断)**: 直接移除数字的小数部分，仅保留整数。
*   **`Math.Round(double d)` (四舍五入)**: 将数字舍入为最接近的整数。
    *   *补充重要知识点*：C# 默认的 `Math.Round` 采用的是 **“银行家舍入法”**（四舍六入五成双，即当小数刚好是 0.5 时，向最近的偶数舍入）。如果需要传统的“四舍五入”，需要传入额外的枚举参数 `MidpointRounding.AwayFromZero`。

```csharp
// --- Floor (向下取整) ---
Console.WriteLine(Math.Floor(3.8));   // 输出: 3
Console.WriteLine(Math.Floor(-3.2));  // 输出: -4 (注意：往更小的方向走)

// --- Ceiling (向上取整) ---
Console.WriteLine(Math.Ceiling(3.2)); // 输出: 4
Console.WriteLine(Math.Ceiling(-3.8));// 输出: -3 (注意：往更大的方向走)

// --- Truncate (直接砍掉小数) ---
Console.WriteLine(Math.Truncate(3.8));  // 输出: 3
Console.WriteLine(Math.Truncate(-3.8)); // 输出: -3 (与 Floor 负数表现不同)

// --- Round (舍入) ---
Console.WriteLine(Math.Round(3.5)); // 输出: 4 (最近的偶数)
Console.WriteLine(Math.Round(2.5)); // 输出: 2 (最近的偶数，银行家舍入)

// 传统四舍五入 (Half-up)
Console.WriteLine(Math.Round(2.5, MidpointRounding.AwayFromZero)); // 输出: 3
// 保留两位小数的四舍五入
Console.WriteLine(Math.Round(3.14159, 2)); // 输出: 3.14
```

## 基础算术与极值比较

*   **`Math.Abs(value)` (绝对值)**: 返回数字的绝对值（去掉负号）。支持 `int`, `double`, `decimal` 等多种重载。
*   **`Math.Sign(value)` (符号判断)**: 判断数字的符号。正数返回 `1`，负数返回 `-1`，零返回 `0`。
*   **`Math.Max(val1, val2)` (最大值)**: 返回两个数字中较大的一个。
*   **`Math.Min(val1, val2)` (最小值)**: 返回两个数字中较小的一个。

```csharp
// 绝对值
Console.WriteLine(Math.Abs(-50.5)); // 输出: 50.5

// 符号判断 (常用于判断趋势增减)
Console.WriteLine(Math.Sign(-99)); // 输出: -1
Console.WriteLine(Math.Sign(0));   // 输出: 0

// 极值限制 (常用于边界值处理，如分页索引不能小于1)
int pageIndex = -2;
int validPage = Math.Max(1, pageIndex); 
Console.WriteLine(validPage); // 输出: 1
```

## 乘方与开方

*   **`Math.Pow(double x, double y)`**: 返回 $x$ 的 $y$ 次幂 ($x^y$)。
*   **`Math.Sqrt(double d)`**: 返回指定数字的平方根 ($\sqrt{d}$)。
*   **`Math.Cbrt(double d)`**: 返回指定数字的立方根 ($\sqrt[3]{d}$)。

```csharp
// 计算 2 的 3 次方
Console.WriteLine(Math.Pow(2, 3)); // 输出: 8

// 计算 16 的平方根
Console.WriteLine(Math.Sqrt(16));  // 输出: 4

// 计算 27 的立方根
Console.WriteLine(Math.Cbrt(27));  // 输出: 3
```

## 对数函数

*   **`Math.Log(double a)`**: 返回数字的自然对数（以 `Math.E` 为底）。
*   **`Math.Log(double a, double newBase)`**: 返回以指定数字（`newBase`）为底的对数。
*   **`Math.Log10(double a)`**: 返回以 10 为底的对数（常用对数）。

```csharp
// 自然对数 ln(e) = 1
Console.WriteLine(Math.Log(Math.E)); // 输出: 1

// 计算以 2 为底，8 的对数 (2 的几次方等于 8)
Console.WriteLine(Math.Log(8, 2));   // 输出: 3

// 计算以 10 为底，1000 的对数
Console.WriteLine(Math.Log10(1000)); // 输出: 3
```

## 三角函数

**核心要点**：C# 中所有的三角函数运算，传入的参数和返回的结果均使用**弧度 (Radians)**，而不是角度 (Degrees)。
*   角度转弧度公式：`弧度 = 角度 * (Math.PI / 180)`

**常用 API：**
*   **`Math.Sin(double a)`**: 计算正弦值。
*   **`Math.Cos(double a)`**: 计算余弦值。
*   **`Math.Tan(double a)`**: 计算正切值。
*   **`Math.Asin(double d)`**: 计算反正弦值（返回弧度）。
*   **`Math.Acos(double d)`**: 计算反余弦值。

```csharp
// 1. 准备角度并转换为弧度
double degrees = 90.0;
double radians = degrees * (Math.PI / 180);

// 2. 正弦函数 Sin(90度)
Console.WriteLine(Math.Sin(radians)); // 输出: 1

// 3. 正切函数 Tan(45度)
double rad45 = 45.0 * (Math.PI / 180);
// 注意：由于浮点数精度问题，结果可能是 0.9999999999999999
Console.WriteLine(Math.Round(Math.Tan(rad45), 4)); // 四舍五入后输出: 1

// 4. 反正弦函数 Asin
// 已知正弦值为 1，求对应的角度
double sineValue = 1.0;
double radResult = Math.Asin(sineValue);
// 弧度转回角度：角度 = 弧度 * (180 / Math.PI)
double degResult = radResult * (180 / Math.PI);
Console.WriteLine(degResult); // 输出: 90
```
