# 字符串的局部修改（插入与移除）

尽管字符串在 C# 中具有**绝对的不可变性（Immutability）**，但 `System.String` 类依然提供了看似能够“修改”字符串内容的方法：`Insert` 和 `Remove`。

在使用这两个方法时，必须牢记其底层执行逻辑：**它们绝对不会在原有的内存地址上进行修改。** 每次调用这些方法，公共语言运行时（CLR）都会在托管堆中分配一块全新的内存，将修改后的最终字符组合拷贝进去，并返回这个新对象的引用。原字符串对象保持完全不变。

## 字符串插入：`Insert` 方法

`Insert` 方法用于在字符串的指定索引位置切开，并嵌入一段新的子串。原来位于该索引及之后的字符会被整体向右平移。

*   **方法签名**：`Insert(int startIndex, string value)`
*   **参数解析**：
    *   `startIndex`：目标插入位置的索引（从 0 开始）。
    *   `value`：需要插入的新字符串。

```csharp
string originalName = "developer";

// 目标：在索引 4 的位置（字符 'e' 和 'l' 之间）插入 "scad"
// 底层操作：计算新长度(9 + 4 = 13)，分配新内存，拷贝 "deve"，拷贝 "scad"，拷贝 "loper"
string updatedName = originalName.Insert(4, "scad");

// 原字符串未受任何影响
Console.WriteLine(originalName); // 输出: developer
// 返回了全新的字符串对象
Console.WriteLine(updatedName);  // 输出: devescadloper
```

## 字符串移除：`Remove` 方法

`Remove` 方法用于从字符串中裁切掉一部分字符，并将剩余的部分拼接在一起。这是一个非常容易产生参数误解的方法。

*   **核心重载 1**：`Remove(int startIndex, int count)`
    *   **避坑指南**：第二个参数是**要删除的字符数量（Length/Count）** ，**绝对不是**结束位置的索引。这是开发中极易出现 `ArgumentOutOfRangeException` 异常的地方。
*   **核心重载 2（扩展补充）**：`Remove(int startIndex)`
    *   如果不传入数量参数，它会直接从 `startIndex` 开始，**把后面所有的字符全部删光**。

```csharp
string text = "developer";

// 场景 1：移除中间的特定长度字符
// 目标：从索引 2 ('v') 开始，往后删掉 4 个字符 ("velo")
string trimmedText = text.Remove(2, 4); 
// 输出: deper

// 场景 2：截断字符串 (扩展知识点)
// 目标：保留前 3 个字符，后面的全部丢弃
string truncatedText = text.Remove(3);
// 输出: dev
```

## 深度拓展与性能考量

**1. 内存拷贝的隐性成本**
`Insert` 和 `Remove` 在底层都依赖于非常基础的内存拷贝操作（类似于底层的 `memmove` 或数组的 `Array.Copy`）。
*   当调用 `Insert` 时，CLR 需要先开辟一块更大的内存，将前半部分拷入，将新串拷入，再将后半部分拷入。
*   当调用 `Remove` 时，CLR 需要开辟一块较小的内存，将保留的前半部分和后半部分分别拷入。

**2. 最佳架构实践：避免在循环中使用**
由于上述的内存分配与拷贝机制，**极其不建议在循环（如 `for` 或 `while`）中频繁调用 `Insert` 或 `Remove`**。
如果在业务逻辑中需要对一段文本进行大量、多次的插入和删除（例如富文本编辑器的底层数据流处理、构建复杂的长篇报表），这种做法会导致托管堆中产生海量的废弃字符串对象（内存碎片），引发垃圾回收器（GC）的频繁启动，导致程序卡顿（GC Pause）。

**正确的替代方案**：
面对高频的修改场景，必须转而使用 `System.Text.StringBuilder` 类。`StringBuilder` 内部维护了一个可动态扩容的字符数组（`char[]`），它的 `Insert` 和 `Remove` 方法是直接在原数组内存块上移动字符，直到最后调用 `ToString()` 时才生成最终的 `String` 对象，从而实现了性能的指数级提升。
