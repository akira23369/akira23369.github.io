# DateTime

## DateTime 概述
`DateTime` 是 C# 中用于表示日期和时间的**内置值类型（结构体 Struct）**，位于 `System` 命名空间下。它可以精确存储从公元 0001 年 1 月 1 日午夜到 9999 年 12 月 31 日晚上 11:59:59 之间的任意时间点。

*   **组成部分**：包含日期（年、月、日）和时间（时、分、秒、毫秒）信息。
*   **默认状态**：如果只指定日期而不指定时间，时间默认被初始化为午夜 `00:00:00`
*   **毫秒的定义**：1 秒 = 1000 毫秒。毫秒的有效取值范围是 0 到 999。

## DateTime 的初始化与转换

由于不能直接将字符串赋值给 `DateTime` 类型的变量，必须通过解析（Parsing）或实例化来进行赋值。

### 字符串解析为 DateTime
可以通过两种常用的静态方法将符合规范的字符串转换为 `DateTime` 对象。默认解析格式通常为 `yyyy-MM-dd HH:mm:ss.fff`。

```csharp
using System;

class Program
{
    static void Main()
    {
        // 方式一：使用 DateTime.Parse()
        // 这是 DateTime 结构体自带的静态方法
        string dateString1 = "2000-12-31 11:59:59.999";
        DateTime dob1 = DateTime.Parse(dateString1);

        // 方式二：使用 Convert.ToDateTime()
        // 这是 Convert 类的静态方法，底层逻辑与 DateTime.Parse 类似
        string dateString2 = "2023-01-15";
        DateTime dob2 = Convert.ToDateTime(dateString2); // 时间默认为 00:00:00
    }
}
```

### 使用构造函数
在实际开发中，如果已知年、月、日等整型数据，**强烈建议直接使用构造函数**，这比字符串解析的性能更好，且不易引发格式异常。

```csharp
// 仅指定日期（年，月，日）
DateTime dateOnly = new DateTime(2023, 10, 1); 

// 指定日期和时间（年，月，日，时，分，秒）
DateTime dateAndTime = new DateTime(2023, 10, 1, 14, 30, 0); 
```

## DateTime 常用静态属性 (API 详解)

静态属性用于获取当前系统时间，属于类级别调用。

*   **`DateTime.Now`**: 获取运行代码时计算机上的当前本地日期和时间。
*   **`DateTime.Today`**: 仅获取当前本地日期，时间部分被设置为 `00:00:00`。
*   **`DateTime.UtcNow`**: 获取当前的协调世界时 (UTC) 日期和时间，不受本地时区影响，常用于数据库存储。

```csharp
DateTime currentDateTime = DateTime.Now;
Console.WriteLine(currentDateTime); // 输出示例: 2023-10-25 15:30:45

DateTime currentDate = DateTime.Today;
Console.WriteLine(currentDate);     // 输出示例: 2023-10-25 00:00:00

DateTime utcDateTime = DateTime.UtcNow;
Console.WriteLine(utcDateTime);     // 输出示例: 2023-10-25 07:30:45 (假设本地是UTC+8)
```

## DateTime 常用实例属性 (API 详解)

通过实例属性，可以从一个已有的 `DateTime` 对象中提取单独的日期或时间部分。这些大多返回 `int` 类型。

### 获取基础时间分量
*   **`Year`**: 获取年份。
*   **`Month`**: 获取月份 (1-12)。
*   **`Day`**: 获取日期 (1-31)。
*   **`Hour`**: 获取小时 (0-23)。
*   **`Minute`**: 获取分钟 (0-59)。
*   **`Second`**: 获取秒 (0-59)。
*   **`Millisecond`**: 获取毫秒 (0-999)。

```csharp
DateTime myDate = new DateTime(2000, 12, 31, 23, 59, 59, 999);

int year = myDate.Year;               // 2000
int month = myDate.Month;             // 12
int day = myDate.Day;                 // 31
int hour = myDate.Hour;               // 23
int minute = myDate.Minute;           // 59
int second = myDate.Second;           // 59
int millisecond = myDate.Millisecond; // 999
```

### 获取进阶日期信息
*   **`DayOfWeek`**: 返回一个枚举值，表示当前日期是星期几。
    *   可以通过强制类型转换 `(int)` 获取对应的数字：星期日 (Sunday) 对应 0，星期六 (Saturday) 对应 6。
*   **`DayOfYear`**: 返回当前日期是当前年份的第几天 (1-366)。会自动处理闰年逻辑。

```csharp
DateTime testDate = new DateTime(2000, 12, 31);

// DayOfWeek 示例
DayOfWeek weekday = testDate.DayOfWeek;
Console.WriteLine(weekday.ToString()); // 输出: Sunday
Console.WriteLine((int)weekday);       // 输出: 0

// DayOfYear 示例
// 2000 年是闰年，12 月 31 日是该年的最后一天
int dayOfYear = testDate.DayOfYear;
Console.WriteLine(dayOfYear);          // 输出: 366
```

## DateTime 的输出与格式化

当调用 `Console.WriteLine(dateTime)` 时，C# 会隐式调用 `dateTime.ToString()` 方法。
默认的输出格式严重依赖于当前操作系统（Windows控制面板 -> 区域和语言选项）的设置。

*   **短日期 (Short Date)**：通常只包含数字，如 `10/25/2023` 或 `yyyy-MM-dd`。
*   **长日期 (Long Date)**：通常包含月份的文本名称，如 `October 25, 2023`。
*   格式占位符区分大小写：`M` 代表月份 (Month)，`m` 代表分钟 (Minute)。

### 显式控制输出格式
为了避免在不同操作系统上输出结果不一致，实际开发中建议向 `ToString()` 传递指定的格式字符串。

```csharp
DateTime now = DateTime.Now;

// 依赖系统的默认输出
Console.WriteLine(now.ToString()); 

// 自定义格式输出 (摆脱操作系统区域设置的干扰)
Console.WriteLine(now.ToString("yyyy-MM-dd HH:mm:ss")); // 输出如: 2023-10-25 15:30:45
Console.WriteLine(now.ToString("MMM dd, yyyy"));        // 输出如: Oct 25, 2023
```

*(注：对于非标准字符串向 `DateTime` 转换的需求，需要使用 `DateTime.ParseExact`，这属于高级格式化控制的内容。)*
