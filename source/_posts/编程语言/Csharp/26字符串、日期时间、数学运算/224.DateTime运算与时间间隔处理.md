# DateTime运算与时间间隔处理

## 日期的比较 (CompareTo)

在进行日期相减（如计算年龄、工龄）之前，通常需要比较两个日期的先后顺序，以确保计算逻辑的合理性（例如：当前日期必须大于入职日期）。

除了使用常用的关系运算符（`>`、`<`、`==`）外，C# 提供了 `CompareTo` 方法用于精确比较。

### `CompareTo` 方法详解
*   **方法定义**: `public int CompareTo(DateTime value);`
*   **返回值说明**: 返回一个整数，表示当前实例与参数日期的先后关系。
    *   **小于 0 (通常为 -1)**: 当前日期 **早于** 参数日期。
    *   **等于 0**: 两个日期（包含日期和时间部分）**完全相同**。
    *   **大于 0 (通常为 1)**: 当前日期 **晚于** 参数日期。

### 日期比较代码示例
```csharp
using System;

class Program
{
    static void Main()
    {
        DateTime today = DateTime.Now;
        DateTime joinDate = new DateTime(2025, 1, 1); // 假设一个未来的入职日期

        int comparisonResult = today.CompareTo(joinDate);

        if (comparisonResult > 0)
        {
            Console.WriteLine("入职日期在过去，可以计算工龄。");
        }
        else if (comparisonResult < 0)
        {
            Console.WriteLine("错误：入职日期在未来，无法计算工龄！");
        }
        else
        {
            Console.WriteLine("今天刚入职！");
        }
    }
}
```

## 日期的相减与 TimeSpan 结构

日期的相减操作用于计算两个时间点之间的差值。C# 中可以通过调用 `Subtract` 方法或直接使用 `-` 运算符来实现。

**核心机制**：两个 `DateTime` 对象相减，返回的不再是 `DateTime`，而是一个专门表示时间间隔的结构体 —— **`TimeSpan`**。

### 获取时间间隔
```csharp
DateTime today = DateTime.Now;
DateTime dateOfJoining = new DateTime(2015, 1, 1);

// 方式一：使用 Subtract 方法
TimeSpan experience1 = today.Subtract(dateOfJoining);

// 方式二：直接使用减号运算符 (推荐，更简洁)
TimeSpan experience2 = today - dateOfJoining;
```

### TimeSpan 核心 API 详解
`TimeSpan` 表示一个时间段（如 10天5小时30分钟）。了解它的属性非常关键，尤其是带 `Total` 前缀和不带前缀的属性的区别。

*   **分量属性** (仅返回当前时间段中的某个部分，通常有最大值限制)：
    *   `Days`: 获取整天数部分。
    *   `Hours`: 获取小时部分（取值范围 0-23）。
    *   `Minutes`: 获取分钟部分（取值范围 0-59）。
*   **总量属性** (将整个时间段折算为单一单位，返回 `double` 浮点数)：
    *   **`TotalDays`**: 将时间间隔转换为总天数（包含小数表示的小时/分钟折算）。
    *   `TotalHours`: 转换为总小时数。
    *   `TotalMinutes`: 转换为总分钟数。

### 综合实战：计算具体的年、月工龄
以下逻辑使用固定的数学换算（一年=365天，一月=30天）将 `TimeSpan.TotalDays` 转换为易读的“X年Y个月”。


*(注：此处引入了 `Math.Floor` 方法，用于向下取整，直接截断小数部分，保留完整的年数或月数。)*

```csharp
using System;

class Program
{
    static void Main()
    {
        DateTime today = new DateTime(2021, 10, 11);
        DateTime joinDate = new DateTime(2015, 1, 1);

        if (today.CompareTo(joinDate) > 0)
        {
            // 1. 获取总天数
            TimeSpan ts = today - joinDate;
            double totalDays = ts.TotalDays; // 约 2475 天

            // 2. 计算完整年数 (向下取整)
            double years = Math.Floor(totalDays / 365); // 2475 / 365 ≈ 6.78 -> 取 6

            // 3. 计算剩余天数
            double remainingDays = totalDays - (years * 365);

            // 4. 计算完整月数 (假设每月 30 天，向下取整)
            double months = Math.Floor(remainingDays / 30); 

            // 5. 格式化输出
            Console.WriteLine($"{years} Years and {months} Months"); 
            // 输出结果: 6 Years and 9 Months
        }
    }
}
```

## 日期的相加与时间推演

在已知某个日期的基础上，如果需要推算未来或过去的日期（如：合同到期日、发货前10天等），可以使用 `DateTime` 结构提供的一系列 `Add` 方法。

### DateTime 的不可变性
**重要概念**：`DateTime` 对象是不可变的。调用所有的 `Add...` 方法都**不会修改原变量的值**，而是会**返回一个新的 `DateTime` 对象**。必须使用变量来接收返回值。

### 常用推演 API
*   **`AddDays(double value)`**: 增加（或减少）指定的天数。
*   **`AddMonths(int months)`**: 增加（或减少）指定的月数。会自动处理月末逻辑（如 1月31日加1个月会变成 2月28/29日）。
*   **`AddYears(int value)`**: 增加（或减少）指定的年数。会自动处理闰年的 2月29日 问题。
*   **`AddHours(double value)`**: 增加（或减少）小时数。
*   **`AddMinutes(double value)`**: 增加（或减少）分钟数。

*(注：如果需要向前推算过去的日期，只需向上述方法中传入**负数**即可。)*

### 日期推演代码示例与链式调用

```csharp
using System;

class Program
{
    static void Main()
    {
        // 初始日期：2021年1月1日
        DateTime initialDate = new DateTime(2021, 1, 1);

        // 1. 推算未来的日期 (加 10 天)
        DateTime futureDate = initialDate.AddDays(10);
        Console.WriteLine($"10天后: {futureDate.ToString("yyyy-MM-dd")}"); // 2021-01-11

        // 2. 推算过去的日期 (减 10 天，传入负数)
        DateTime pastDate = initialDate.AddDays(-10);
        Console.WriteLine($"10天前: {pastDate.ToString("yyyy-MM-dd")}"); // 2020-12-22

        // 3. 链式调用 (推算 20个月又5天 之后的日期)
        // 因为每个 Add 方法都返回新的 DateTime，可以直接点出下一个方法
        DateTime complexFutureDate = initialDate.AddMonths(20).AddDays(5);
        
        Console.WriteLine($"20个月零5天后: {complexFutureDate.ToString("yyyy-MM-dd")}");
        // 输出: 2022-09-06
    }
}
```
