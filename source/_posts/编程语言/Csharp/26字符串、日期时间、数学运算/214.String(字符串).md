# String (字符串)

## String 的本质与底层映射
在C#中，所有的字符串本质上都是预定义类 `System.String` 的对象。它是 `System` 命名空间的一部分。
*   **关键字映射**：C# 提供的 `string` 关键字（全小写）仅仅是 .NET 框架中 `System.String` 类的别名。在编译时，这两者是完全等价的。
*   **字符集合**：字符串是 Unicode 字符的只读集合。C# 中的 `char` 类型占据 16 位（UTF-16 编码），因此 `string` 可以表示包含全球各种自然语言、数字、空格及特殊符号的字符。
*   **容量限制**：理论上，C# 中一个字符串最大支持包含约 20 亿（2 billion）个字符（占用约 4GB 内存），但在实际应用中受限于系统的可用连续内存。

```csharp
// 以下两种声明方式在底层生成的IL代码完全一致
string aliasString = "Hello World";
System.String classString = "Hello World";
```

## 内存分配与引用类型特性
字符串是**引用类型（Reference Type）**。
*   **堆与栈**：声明一个字符串变量时，变量本身（存储的是内存地址）被保存在**栈（Stack）** 中，而实际的字符串对象（包含具体的字符数据）被分配在**托管堆（Managed Heap）** 中。
*   **空字符串**：使用双引号 `""` 创建的是一个真实的字符串对象，称为空字符串。它在堆中占用内存，只是其字符数量为0。

```csharp
// str变量在栈上，指向堆中值为"C# Guide"的对象
string str = "C# Guide"; 

// 空字符串对象，已分配内存
string emptyStr = ""; 
```

## 核心特性：不可变性
这是 C# 字符串最重要的特性（《CLR via C#》中对此有极大篇幅的强调）。
**字符串一旦在堆中被创建，就绝对无法被修改。**
任何看似修改字符串的操作（如拼接、替换、转大写等），实际上都没有改变原对象，而是**在堆中创建了一个全新的字符串对象**，并将变量的引用指向这个新对象。旧对象如果没有被其他变量引用，将等待垃圾回收（GC）。

```csharp
string greeting = "Hello";
// 下面的操作不会修改原有的"Hello"对象
// 而是创建了一个全新的对象"Hello World"，并让greeting指向它
greeting = greeting + " World"; 
```
*补充原理*：不可变性带来了很多好处，包括**线程安全**（多个线程可以安全地同时读取同一个字符串而无需加锁）以及支持**字符串驻留池（String Interning）**。

## 关键属性与索引器
`System.String` 类提供了丰富的成员来操作字符串。

*   **Length 属性**：返回字符串中的字符总数（包括空格和特殊符号）。这是一个**只读属性**（仅包含 `get` 访问器），因为字符串长度在创建后不可变。
*   **索引器（Indexer）**：字符串内部维护了从 `0` 开始的索引。可以通过索引器 `[]` 访问特定位置的字符，返回值类型为 `char`。这也是只读的，无法通过索引器修改字符。

```csharp
string text = "C# 13";

// 1. 获取长度
int length = text.Length; // 返回 5 (包含中间的空格)

// 2. 访问特定字符
char firstChar = text[0]; // 返回 'C'
char spaceChar = text[2]; // 返回 ' '

// text[0] = 'D'; // 编译报错！索引器是只读的，符合字符串的不可变性
```

## 补充
基于《Effective C#》与《代码大全》中的最佳实践，补充以下高频开发知识点：

**1. 字符串驻留机制 (String Interning)**
CLR 为了节省内存，内部维护了一个哈希表（驻留池）。默认情况下，代码中出现的**字面量字符串**如果内容相同，CLR 只会在堆中创建一个对象，让多个变量指向同一个地址。
```csharp
string a = "hello";
string b = "hello";
// a 和 b 指向堆中的同一个内存地址，避免了内存浪费
bool isSameReference = object.ReferenceEquals(a, b); // 返回 true
```

**2. 字符串拼接的性能陷阱与 StringBuilder**
由于字符串是不可变的，在循环中大量使用 `+` 或 `+=` 拼接字符串会导致在堆中产生大量的临时废弃对象，给垃圾回收器（GC）带来巨大压力。
*   **解决方案**：在需要频繁修改或拼接字符串的场景下，必须使用 `System.Text.StringBuilder` 类。它在底层维护一个字符数组，允许直接修改内存中的字符而不产生新对象。
```csharp
using System.Text;

StringBuilder sb = new StringBuilder();
for(int i = 0; i < 1000; i++)
{
    // 不断在原有内存块后追加，不会产生1000个临时string对象
    sb.Append(i.ToString()); 
}
string finalResult = sb.ToString(); // 最后只生成一次最终的字符串对象
```

**3. 空字符串的最佳表示方式**
虽然可以使用 `""`，但在专业C#代码中，推荐使用 `string.Empty` 来表示空字符串，这在表达意图上更清晰。此外，判断字符串是否为空的最佳实践是使用内置方法：
```csharp
string input = string.Empty; // 推荐用法

// 完美的非空校验方式：同时检查 null 和 空字符串
if (string.IsNullOrEmpty(input))
{
    // 处理逻辑
}
```
