# 集合基础入门

## 集合的概念与核心特征
集合（Collection）是用于存储和管理一组对象（数据）的特殊类。与只能存储单一数据的独立变量不同，集合提供了一种结构化的方式来处理数据集合。

*   **数据类型多样性**：集合不仅可以存储基本数据类型（如 `int`, `double`），还可以存储自定义的引用类型（如 `Employee`, `Student` 类的实例）。
*   **动态扩容机制**：默认情况下，集合的初始状态是空的。与传统数组不同，集合不需要在创建时预先指定大小，它允许在运行时动态地添加或移除元素。
*   **索引访问**：大部分有序集合（如 `List<T>`）像数组一样，支持通过从 `0` 开始的索引来访问、修改元素。
*   **丰富的内置操作**：集合类通常自带大量用于数据操作的方法，如搜索（Search）、排序（Sort）、条件过滤和数据复制等。

## 泛型集合 vs 非泛型集合
在 C# 的发展历程中，集合主要分为两大流派。理解它们的区别是编写高性能 C# 代码的关键。

### 非泛型集合
*   **命名空间**：`System.Collections`
*   **特点**：可以把任意类型的元素放入同一个集合中（异构集合）。因为非泛型集合（如 `ArrayList`）底层使用的是 `object` 类型来存储数据。
*   **底层缺陷（来自《CLR via C#》的深入理解）**：
    *   **类型不安全**：编译器无法在编译时检查类型，容易在运行时引发 `InvalidCastException`。
    *   **性能损耗（装箱与拆箱）**：当将值类型（如 `int`）存入非泛型集合时，会发生**装箱（Boxing）**（在堆上分配内存并复制值）；取出时又需要**拆箱（Unboxing）**。这会给垃圾回收器（GC）带来巨大压力，严重影响程序性能。
*   **最佳实践**：在现代 C# 开发中，**应全面废弃非泛型集合**。

### 泛型集合
*   **命名空间**：`System.Collections.Generic`
*   **特点**：在声明集合时，必须通过尖括号 `<T>` 指定集合内部存储的元素类型。一旦指定，该集合只能存储同质（同类型）的数据。
*   **优势**：
    *   **类型安全**：编译器会强制进行类型检查，杜绝向 `List<int>` 中添加 `double` 或 `string` 的情况。
    *   **极高的性能**：存储值类型时不再需要装箱和拆箱，直接在底层数组中操作。

## 数组(Arrays)与集合(Collections)的使用场景抉择

虽然集合提供了极大的灵活性，但在实际项目中，选择数组还是集合取决于具体的需求场景。

*   **使用集合的场景（绝大多数情况）**：
    *   当无法预估数据量的大小时（例如：从数据库读取员工列表、接收用户不定量的输入）。
    *   需要频繁进行增加、删除元素操作时。
*   **使用数组的场景（特定优化情况）**：
    *   数据量在编译时或运行时已经明确固定，且不会再发生改变。
    *   例如：存储一年中的 12 个月、一周的 7 天等。
    *   **底层拓展**：即使是 `List<T>`，其底层本质上依然是维护了一个数组。当向 `List<T>` 中添加元素导致容量不足时，`List<T>` 会在后台自动创建一个容量通常为当前两倍的新数组，并将旧数据复制过去。如果数据量绝对固定，直接使用数组可以节省集合类内部动态扩容带来的轻微开销。

## 核心代码示例：`List<T>` 的使用

以下代码展示了现代 C# 中泛型集合 `List<T>` 的常见用法，涵盖了基本类型和自定义类的存储。

```csharp
using System;
using System.Collections.Generic; // 必须引入此命名空间

namespace CollectionDemo
{
    // 自定义类，用于演示存储对象的集合
    public class Employee
    {
        public int Id { get; set; }
        public string Name { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // ==========================================
            // 示例 1：存储基本数据类型的泛型集合 (List<int>)
            // ==========================================
            
            // 使用 C# 的 new() 目标类型推断语法（现代 C# 写法）
            List<int> numbers = new(); 

            // 动态添加元素
            numbers.Add(10);
            numbers.Add(20);
            numbers.Add(30);

            // 通过索引访问元素 (索引从 0 开始)
            Console.WriteLine($"第一个元素是: {numbers[0]}"); // 输出 10

            // 移除元素
            numbers.Remove(20); // 移除值为 20 的元素
            
            // ==========================================
            // 示例 2：存储自定义对象的泛型集合 (List<Employee>)
            // ==========================================
            
            List<Employee> employees = new();

            // 向集合中添加对象
            employees.Add(new Employee { Id = 1, Name = "Alice" });
            employees.Add(new Employee { Id = 2, Name = "Bob" });

            // 编译时类型安全：尝试添加非 Employee 类型的对象会导致编译报错
            // employees.Add("This will not compile"); 

            // 遍历集合
            foreach (Employee emp in employees)
            {
                Console.WriteLine($"员工编号: {emp.Id}, 姓名: {emp.Name}");
            }
        }
    }
}
```

**后续学习路径提示**
除了最常用的 `List<T>` 之外，C# 还提供了多种适用于不同场景的泛型集合类，在后续的实际开发中需要根据数据结构特性进行选择：
*   **`Dictionary<TKey, TValue>`**：用于存储键值对，提供 O(1) 接近常数级别的极速查找。
*   **`HashSet<T>`**：用于存储不重复的元素，常用于数学集合运算（交集、并集）或去重。
*   **`Queue<T>`** 与 **`Stack<T>`**：用于实现先进先出（FIFO）或后进先出（LIFO）的特定数据流转逻辑。
