# 自定义集合`IDictionary<TKey, TValue>`

## 为什么需要`IDictionary<TKey, TValue>`?
前四篇我们讲的 `IList<T>` 非常强大，但它有一个致命的限制：**只能通过整数索引（0, 1, 2...）来访问元素**。

试想一下这些场景：
*   你想通过“身份证号”快速查找到“人”。
*   你想通过“英文单词”快速查找到“中文释义”。
*   你想通过“设置项名称”获取“设置的值”。

如果用 `IList<T>`，你只能写个 `for` 循环从头遍历到尾去比对，如果数据有 100 万条，查找速度会慢得令人发指（时间复杂度 O(N)）。
为了实现**通过自定义的“键（Key）”实现瞬间查找（时间复杂度接近 O(1)）**，C# 提供了字典接口：`System.Collections.Generic.IDictionary<TKey, TValue>`。

### IDictionary 的家族地位与特殊性
`IDictionary` 的继承链有点特殊，它是围绕着 **`KeyValuePair<TKey, TValue>`（键值对结构体）** 展开的：

`IEnumerable<KeyValuePair<TKey, TValue>>` 
    ↳ `ICollection<KeyValuePair<TKey, TValue>>` 
        ↳ **`IDictionary<TKey, TValue>`**

如果你要实现 `IDictionary`，你必须实现以下核心专属成员：
1.  **`TValue this[TKey key] { get; set; }`**：**字典索引器**。方括号里传的不再是 `int`，而是你的 `Key`。
2.  **`ICollection<TKey> Keys`**：获取字典里所有的“键”。
3.  **`ICollection<TValue> Values`**：获取字典里所有的“值”。
4.  **`void Add(TKey key, TValue value)`**：添加一组键值对（如果 Key 已存在，标准做法是抛出异常）。
5.  **`bool ContainsKey(TKey key)`**：极速判断某个 Key 是否存在。
6.  **`bool Remove(TKey key)`**：根据 Key 移除整条数据。
7.  **`bool TryGetValue(TKey key, out TValue value)`**：安全获取值（不抛异常的获取方式，极其常用）。

### 写一个“永不报错”的默认值字典
使用原生 `Dictionary<TKey, TValue>` 时，最烦人的就是：如果你去读一个不存在的 Key，它会直接抛出 `KeyNotFoundException` 导致程序崩溃。每次都要写 `if (dict.ContainsKey(key))`，太繁琐了！

今天我们来手写一个 **`DefaultDict<TKey, TValue>`**（借鉴 Python 中的神仙数据结构 defaultdict）：**如果你查找的 Key 不存在，它不报错，而是自动返回一个你事先设定好的默认值。**

```csharp
using System;
using System.Collections;
using System.Collections.Generic;

public class DefaultDict<TKey, TValue> : IDictionary<TKey, TValue>
{
    // 内部依然封装一个标准的 Dictionary 来干重活
    private Dictionary<TKey, TValue> _innerDict = new Dictionary<TKey, TValue>();
    
    // 我们自定义的只读属性：默认值
    private readonly TValue _defaultValue;

    // 构造函数：要求实例化时必须提供一个默认值
    public DefaultDict(TValue defaultValue)
    {
        _defaultValue = defaultValue;
    }

    // ================= 1. IDictionary 专属成员 =================

    // 【核心魔法在这里】：重写索引器
    public TValue this[TKey key]
    {
        get 
        { 
            // 如果存在，返回真实值；如果不存在，返回我们设定的默认值！
            if (_innerDict.TryGetValue(key, out TValue value))
            {
                return value;
            }
            return _defaultValue; 
        }
        set 
        { 
            _innerDict[key] = value; 
        }
    }

    public ICollection<TKey> Keys => _innerDict.Keys;
    public ICollection<TValue> Values => _innerDict.Values;

    public void Add(TKey key, TValue value) => _innerDict.Add(key, value);
    public bool ContainsKey(TKey key) => _innerDict.ContainsKey(key);
    public bool Remove(TKey key) => _innerDict.Remove(key);
    public bool TryGetValue(TKey key, out TValue value) => _innerDict.TryGetValue(key, out value);


    // ================= 2. ICollection<KeyValuePair> 成员 =================
    // 注意：因为字典的底层元素是 KeyValuePair，所以这里的 ICollection 方法处理的都是 KeyValuePair

    public int Count => _innerDict.Count;
    public bool IsReadOnly => false;

    public void Add(KeyValuePair<TKey, TValue> item) => ((ICollection<KeyValuePair<TKey, TValue>>)_innerDict).Add(item);
    
    public void Clear() => _innerDict.Clear();
    
    public bool Contains(KeyValuePair<TKey, TValue> item) => ((ICollection<KeyValuePair<TKey, TValue>>)_innerDict).Contains(item);
    
    public void CopyTo(KeyValuePair<TKey, TValue>[] array, int arrayIndex) => ((ICollection<KeyValuePair<TKey, TValue>>)_innerDict).CopyTo(array, arrayIndex);
    
    public bool Remove(KeyValuePair<TKey, TValue> item) => ((ICollection<KeyValuePair<TKey, TValue>>)_innerDict).Remove(item);


    // ================= 3. IEnumerable 成员 =================
    
    public IEnumerator<KeyValuePair<TKey, TValue>> GetEnumerator() => _innerDict.GetEnumerator();
    IEnumerator IEnumerable.GetEnumerator() => _innerDict.GetEnumerator();
}
```

## 测试字典：统计词频

在普通的字典里，统计词频是非常啰嗦的。看看使用我们自定义的 `DefaultDict` 有多爽：

```csharp
class Program
{
    static void Main()
    {
        // 实例化时告诉它：如果 Key 不存在，默认值为 0
        var wordCount = new DefaultDict<string, int>(0);

        string[] words = { "apple", "banana", "apple", "orange", "banana", "apple" };

        Console.WriteLine("--- 开始统计词频 ---");

        foreach (var word in words)
        {
            // 魔法时刻！
            // 如果是普通的 Dictionary，这里直接 wordCount[word]++ 会抛出异常！
            // 但我们的字典如果发现没这个单词，会返回 0，然后 0+1=1，再赋值回去。完美！
            wordCount[word]++; 
        }

        // 遍历字典 (注意遍历出来的是 KeyValuePair 类型)
        foreach (KeyValuePair<string, int> kvp in wordCount)
        {
            Console.WriteLine($"单词 [{kvp.Key}] 出现了 {kvp.Value} 次");
        }

        // 测试一个完全不存在的单词
        Console.WriteLine("\n--- 测试不存在的 Key ---");
        Console.WriteLine($"单词 [watermelon] 出现了 {wordCount["watermelon"]} 次"); 
        // 完美输出 0，不崩溃！
    }
}
```

**运行结果：**
```text
--- 开始统计词频 ---
单词 [apple] 出现了 3 次
单词 [banana] 出现了 2 次
单词 [orange] 出现了 1 次

--- 测试不存在的 Key ---
单词 [watermelon] 出现了 0 次
```

## 总结：集合大一统
读到这里，你已经征服了 C# 集合的两大基本盘：

1.  **线性大系（按位置排队）**：
    `IEnumerable<T>` (看) ➔ `ICollection<T>` (动) ➔ `IList<T>` (定点打击)
2.  **映射大系（按键值对应）**：
    `IEnumerable<KeyValuePair>` (看) ➔ `ICollection<KeyValuePair>` (动) ➔ `IDictionary<Key, Value>` (哈希映射)

**面试必考知识点提醒**：
*   遍历 `IDictionary` 时，迭代器 `foreach` 抓取到的每一个元素，它的类型都是 **`KeyValuePair<TKey, TValue>`**。
*   字典的核心优势是用空间换时间，增删改查的时间复杂度通常都是 **O(1)**。
*   自定义字典类时，依然强烈建议内部封装现成的 `Dictionary<TKey, TValue>`，除非你需要自己实现红黑树或者特殊的哈希算法（极其罕见）。
