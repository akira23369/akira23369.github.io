# 第 22 节：集合 (Collections)

## 第一讲：集合简介

## 引言

虽然数组是基础数据结构，但它们有一个主要限制：它们是**固定大小**的。在大多数实际应用中，你无法提前知道需要存储多少项。

**集合 (Collections)** 是为解决这个问题而设计的类。它们是动态数据结构，相比数组，关键优势在于可以根据需要**动态增长和缩小**。.NET 框架提供的集合类主要位于 `System.Collections` 和 `System.Collections.Generic` 命名空间中。

## 为何及何时使用集合

- 无法预先知道项目的数量。
    
- 需要频繁添加或移除项目。
    
- 需要比基本数组更强大的搜索、排序功能。
    

## 最佳实践：泛型与非泛型

- **非泛型集合**（如 `ArrayList`）：存储为 `object`，缺乏类型安全性，存在**装箱 (Boxing)** 性能问题。
    
- **泛型集合**（如 `List<T>`）：提供**编译时类型安全**，性能显著提升。**应优先使用泛型集合。**
    

---

## 第二讲：`List<T>`

## 引言

`List<T>` 是 .NET 中最常用的集合类。它本质上是一个**动态数组**，既支持索引访问，又能灵活增删。

## 工作原理：内部数组与容量

1. **初始分配**：创建时分配一个小型的内部数组（如容量 4）。
    
2. **添加元素**：放入内部数组。
    
3. **扩容机制**：当数组满时，`List<T>` 会创建一个更大的新数组（通常是原容量的 **2 倍**），将旧数据复制过去，然后丢弃旧数组。
    

## 核心属性

- **Count**：当前包含的元素实际数量。
    
- **Capacity**：内部数据结构无需调整大小即可容纳的元素总数。

```cs
List<string> shoppingList = new List<string>();
// 初始计数: 0, 初始容量: 0 (或默认值)
Console.WriteLine($"初始计数: {shoppingList.Count}, 初始容量: {shoppingList.Capacity}");

shoppingList.Add("苹果");
shoppingList.Add("香蕉");

// 添加 2 项后：数量：2，容量：4 (假设默认初始容量为4)
Console.WriteLine($"添加 2 项后：数量：{shoppingList.Count}，容量：{shoppingList.Capacity}");
```

## 第三讲：Add 与 AddRange 方法

- **`Add(T item)`**：将单个项目添加至列表**末尾**。
    
- **`AddRange(IEnumerable<T> collection)`**：高效地将另一个集合（数组或其他列表）的所有元素添加至末尾。它比循环调用 `Add` 效率更高，因为只需计算一次扩容。
    

```cs
List<int> numbers = new List<int> { 10, 20 };

// 使用 Add 方法添加单个元素
numbers.Add(30); 

int[] moreNumbers = { 40, 50 };

// 使用 AddRange 方法一次性添加数组
numbers.AddRange(moreNumbers); 

// 输出: 10, 20, 30, 40, 50
Console.WriteLine("最终列表: " + string.Join(", ", numbers));
```

---

## 第四讲：Insert 和 InsertRange 方法

- **Insert(int index, T item)**：在指定的索引位置插入。
    
- **性能注意**：这是一个 **O(n)** 操作。插入位置之后的所有元素都必须向右移动一位。
    


```cs
List<string> guests = new List<string> { "Alice", "Charlie", "David" };

// 在索引 1 处插入 "Bob"
guests.Insert(1, "Bob"); 

// 结果: { "Alice", "Bob", "Charlie", "David" }
Console.WriteLine("修正后的宾客名单: " + string.Join(", ", guests));
```

---

## 第五讲：删除方法 (Remove 系列)

| **方法**                    | **功能描述**                                 |
| ------------------------- | ---------------------------------------- |
| **Remove(T item)**        | 移除找到的**第一个**匹配项。返回 bool 表示是否成功。          |
| **RemoveAt(int index)**   | 移除指定索引处的元素。后续元素向左移动。                     |
| **RemoveRange(i, count)** | 从索引 `i` 开始移除连续 `count` 个元素。              |
| **RemoveAll(Predicate)**  | 移除所有符合条件的元素（使用 Lambda 表达式）。              |
| **Clear()**               | 移除所有元素。`Count` 变为 0，但 `Capacity` 通常保持不变。 |


```cs
List<int> scores = new List<int> { 10, 25, 88, 42, 95, 15, 88 };

scores.Remove(88); // 移除第一个 88
scores.RemoveAt(2); // 移除当前索引 2 的元素
scores.RemoveAll(score => score < 20); // 移除所有小于 20 的分数

scores.Clear(); // 清空列表
```

## 第六讲：查找方法 (IndexOf, Contains, BinarySearch)

- **Contains(T item)**：检查是否存在，返回 bool。内部调用 `IndexOf`。
    
- **IndexOf(T item)**：返回首次出现的索引，未找到返回 -1（线性搜索，O(n)）。
    
- **BinarySearch(T item)**：使用**二分查找**。**前提：列表必须已排序**。效率极高 (O(log n))。
    


```cs
List<string> planets = new List<string> { "Mercury", "Venus", "Earth", "Mars" };

bool hasEarth = planets.Contains("Earth"); // True
int marsIndex = planets.IndexOf("Mars"); // 3

planets.Sort(); // 排序后方可进行二分查找
int venusIndex = planets.BinarySearch("Venus");
```

## 第七讲：排序与反转

- **Sort()**：原地修改列表顺序。默认升序。自定义类需实现 `IComparable<T>`。
    
- **Reverse()**：原地反转列表。
    


```cs
List<int> scores = new List<int> { 88, 54, 95, 72, 68 };
scores.Sort();    // 54, 68, 72, 88, 95
scores.Reverse(); // 95, 88, 72, 68, 54
```

---

## 第八讲：ToArray 和 ForEach

- **ToArray()**：创建一个新的数组副本。常用于需要固定快照或适配老 API。
    
- **`ForEach(Action<T>)`**：`List<T>` 特有的方法。虽然简洁，但通常推荐使用标准的 `foreach` 循环以增强可读性和通用性。
    

```cs
List<string> technologies = new List<string> { "C#", "SQL", "Azure" };

// 转换为数组
string[] techArray = technologies.ToArray();

// 使用 ForEach 方法配合 Lambda
technologies.ForEach(tech => Console.WriteLine($"- {tech}"));
```

## 第九讲：Find 系列方法 (谓词搜索)

这组方法接受 `Predicate<T>` (即返回 bool 的委托)。

- **Exists**：是否存在符合条件的项。
    
- **Find**：返回第一个匹配项，未找到返回 `default(T)`。
    
- **FindAll**：返回包含所有匹配项的**新 List**。
    
- **FindIndex**：返回第一个匹配项的索引。
    


```cs
// 查找价格小于 50 的首个商品
Product cheapItem = products.Find(p => p.Price < 50);

// 查找所有可负担物品
List<Product> affordableItems = products.FindAll(p => p.Price < 200);
```

## 第十讲：ConvertAll 方法

- **功能**：通过转换逻辑创建一个**新类型**的列表。
    
- **注意**：在现代开发中，通常被 LINQ 的 `.Select().ToList()` 取代，因为后者更通用。
    


```cs
List<string> numberStrings = new List<string> { "10", "25", "50" };
// 将字符串列表转换为整数列表
List<int> integers = numberStrings.ConvertAll(s => int.Parse(s));
```

## 第十一讲：字典 (Dictionary<K, V>)

## 引言

键值对集合。键 (Key) 必须唯一。

## 工作原理：哈希表 (Hash Table)

通过 `GetHashCode()` 计算索引。查找、添加、删除的平均时间复杂度为 **O(1)**。

```cs
Dictionary<int, string> studentRoster = new Dictionary<int, string>();

studentRoster.Add(101, "Alice");
studentRoster[102] = "Bob"; // 索引器语法：存在则覆盖，不存在则添加

// 安全访问
if (studentRoster.TryGetValue(103, out string name)) {
    Console.WriteLine(name);
}
```

---

## 第十二讲：排序列表 (SortedList<K, V>)

- **特点**：自动按键 (Key) 排序。
    
- **权衡**：
    
    - **查找**：快 (O(log n))。
        
    - **增删**：慢 (O(n))，因为需要移动数组元素保持顺序。
        
- **场景**：查找频繁，但增删较少，且需要保持有序。
    

---

## 第十三讲 & 第十五讲：非泛型遗留类 (Hashtable & ArrayList)

- **ArrayList** 对应 `List<object>`。
    
- **Hashtable** 对应 `Dictionary<object, object>`。
    
- **缺点**：非类型安全、**装箱/拆箱**损耗性能。
    
- **面试结论**：现代 C# 开发中应**始终优先使用泛型版本**。
    

---

## 第十四讲：`HashSet<T>`

- **特点**：无序、**元素唯一**。
    
- **核心用途**：
    
    - 高性能包含性检查 (`Contains` 为 O(1))。
        
    - 数学集合运算：并集 (`UnionWith`)、交集 (`IntersectWith`)、差集 (`ExceptWith`)。

## 第十六讲 & 第十七讲：栈与队列

## `Stack<T>` (LIFO - 后进先出)

- **Push**：压入顶部。
    
- **Pop**：弹出并返回顶部。
    
- **Peek**：查看顶部不弹出。
    
- **场景**：撤销 (Undo) 功能、方法调用栈。
    

## `Queue<T>` (FIFO - 先进先出)

- **Enqueue**：入队（末尾）。
    
- **Dequeue**：出队（开头）。
    
- **Peek**：查看开头不移除。
    
- **场景**：打印队列、任务调度。
    

---

## 第十八讲 & 第十九讲：对象集合与关系

- **引用存储**：集合中存储的是对象的**引用**。修改从列表中获取的对象会修改原始对象。
    
- **建模关系**：类中包含集合属性（如 `Team` 类包含 `List<Player>`）。
    
- **最佳实践**：在构造函数或属性声明处初始化集合，防止 `NullReferenceException`。

## 第二十讲：接口层次结构

1. **`IEnumerable<T>`**：基础，支持 `foreach`。
    
2. **`ICollection<T>`**：支持修改（Add, Remove, Count）。
    
3. **`IList<T>`**：支持索引访问。
    
4. **`IDictionary<K, V>`**：支持键值对访问。
    

---

## 第二十一讲：IEnumerable 与 IEnumerator

- **IEnumerable**：可枚举对象。承诺提供一个 `GetEnumerator()` 方法。
    
- **IEnumerator**：迭代器（游标）。包含 `MoveNext()`、`Current` 和 `Reset()`。
    
- **解耦**：这种设计允许同一集合上有多个独立的枚举过程。
    

---

## 第二十二讲：迭代器与 yield return

- **yield return**：简化迭代器实现的语法糖。
    
- **延迟执行 (Deferred Execution)**：代码在真正迭代时（如 `foreach` 循环中）才运行，不会立即生成整个列表，节省内存。
    


```cs
public IEnumerable<int> GetEvenNumbers(int max) {
    for (int i = 2; i <= max; i += 2) {
        yield return i; // 暂停执行并返回一个值
    }
}
```

---

## 第二十六讲：`IEquatable<T>`

- **目的**：提供类型安全的相等性比较。
    
- **优势**：避免值类型的**装箱**损耗，提升性能。
    
- **法则**：重写 `Equals` 必须重写 `GetHashCode`。
    

---

## 第二十七讲 & 第二十八讲：比较接口

- **`IComparable<T>`**：**内部**比较器。定义对象的“自然排序”逻辑（如 `Product` 按价格排）。
    
- **`IComparer<T>`**：**外部**比较器。定义多种不同的排序规则（如按名称排、按库存排）。
    

```cs
// 外部比较器示例
public class NameComparer : IComparer<Product> {
    public int Compare(Product x, Product y) => x.Name.CompareTo(y.Name);
}
// 使用
products.Sort(new NameComparer());
```

---

## 第二十九讲 & 第三十讲：协变与逆变

- **协变 (out)**：允许使用更派生的类型。`IEnumerable<string>` 可以赋值给 `IEnumerable<object>`。
    
- **逆变 (in)**：允许使用更通用的类型。`Action<object>` 可以赋值给 `Action<string>`。
