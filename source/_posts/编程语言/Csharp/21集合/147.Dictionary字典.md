# `Dictionary<TKey, TValue>` 字典

## 一、 核心概念与底层逻辑

`Dictionary<TKey, TValue>` 位于 `System.Collections.Generic` 命名空间下。
*   **本质**：它是一个**哈希表（Hash Table）** 的泛型实现。它存储的是键值对（`KeyValuePair<TKey, TValue>`）。
*   **键（Key）的绝对规则**：
    1.  **唯一性**：字典中绝不能有重复的 Key。
    2.  **不可为 null**：Key 不能是 `null`（会抛出 `ArgumentNullException`），但 Value 可以是 `null`（如果是引用类型）。
*   **底层魔法（极度重要）**：哈希表（Hash Table） + 解决冲突的链地址法（拉链法）。
    字典内部维护了两个数组：`int[] buckets`（哈希桶）和 `Entry[] entries`（实际存数据的实体数组）。当你存入一个键值对时，C# 会调用 Key 的 `GetHashCode()` 方法算出一个整数，然后经过取模运算，决定把它丢进哪个 `bucket`。
*   **时间复杂度**：因为它通过数学计算直接定位内存地址，不需要像 List 那样从头遍历。正因为哈希算法的存在，字典的**增、删、改、查，平均时间复杂度全部是 O(1)**！（这就是它为什么快得离谱的原因）。

## 二、 核心属性

### `Count` (实际键值对数量)
*   **说明**：获取字典中当前实际包含的键值对数量。
*   **时间复杂度**：O(1)（内部有私有变量记录）。
*   **示例**：
```csharp
Dictionary<string, int> ages = new Dictionary<string, int> { {"Alice", 25}, {"Bob", 30} };
Console.WriteLine(ages.Count); // 输出: 2
```

### `Keys` (键的集合)
*   **说明**：获取包含字典中所有键的集合（`Dictionary<TKey, TValue>.KeyCollection`）。
*   **时间复杂度**：获取属性 O(1)，遍历它 O(n)。
*   **示例**：
```csharp
Dictionary<int, string> users = new Dictionary<int, string> { {1, "Admin"}, {2, "User"} };
foreach (int key in users.Keys) {
    Console.WriteLine($"用户ID: {key}"); 
}
```

### `Values` (值的集合)
*   **说明**：获取包含字典中所有值的集合。
*   **时间复杂度**：获取属性 O(1)，遍历它 O(n)。
*   **示例**：
```csharp
foreach (string value in users.Values) {
    Console.WriteLine($"用户角色: {value}"); 
}
```

## 三、 索引器 - 最常用的读写方式

### `this[TKey key]` (通过方括号 `[]` 访问)
*   **说明**：获取或设置与指定的键关联的值。
*   **读数据（Get）**：如果 Key 存在，返回 Value。**如果 Key 不存在，直接抛出 `KeyNotFoundException` 异常！**（这是新手最常犯的错）。
*   **写数据（Set）**：如果 Key 存在，**覆盖/更新**旧值；如果 Key 不存在，**新增**该键值对。
*   **示例**：
```csharp
Dictionary<string, string> config = new Dictionary<string, string>();

// --- 写入 (Set) ---
config["Theme"] = "Dark";    // Key不存在，新增 ["Theme", "Dark"]
config["Theme"] = "Light";   // Key已存在，覆盖！变成 ["Theme", "Light"]

// --- 读取 (Get) ---
string currentTheme = config["Theme"]; // 返回 "Light"

// 危险操作：
// string lang = config["Language"]; 
// 报错：KeyNotFoundException，因为字典里没有 "Language"
```

## 四、 添加元素

### `Add(TKey key, TValue value)`
*   **说明**：将指定的键和值添加到字典中。
*   **时间复杂度**：O(1)。
*   **与索引器的区别（面试必考）**：如果添加的 Key 已经存在，`Add()` 方法会**直接抛出 `ArgumentException` 异常**；而索引器 `[]` 会静默覆盖旧值。
*   **示例**：
```csharp
Dictionary<string, int> scores = new Dictionary<string, int>();
scores.Add("Math", 95);

// scores.Add("Math", 100); 
// 报错：ArgumentException: 已添加了具有相同键的项。
```

### `TryAdd(TKey key, TValue value)` 
*(推荐，.NET Core+ / C# 7+)*
*   **说明**：尝试将键值对添加到字典中。
*   **返回值**：`bool`。如果 Key 不存在，添加成功并返回 `true`；如果 Key 已存在，**不报错**，什么都不做，直接返回 `false`。
*   **最佳实践**：当你无法确定 Key 是否存在，又不想用 `try-catch` 捕获异常时，用它最优雅。
*   **示例**：
```csharp
Dictionary<int, string> cache = new Dictionary<int, string>();
bool added1 = cache.TryAdd(1, "Data_A"); // true, 存入 [1, "Data_A"]
bool added2 = cache.TryAdd(1, "Data_B"); // false, 字典里依然是 "Data_A"
```

## 五、 移除元素

### `Remove(TKey key)`
*   **说明**：从字典中移除带有指定键的键值对。
*   **返回值**：`bool`。找到并移除返回 `true`；没找到该 Key 返回 `false`（不会报错）。
*   **时间复杂度**：O(1)。
*   **示例**：
```csharp
Dictionary<string, string> dict = new Dictionary<string, string> { {"A", "Apple"}, {"B", "Banana"} };
bool isRemoved = dict.Remove("A"); // true, 移除了 Apple
bool isRemoved2 = dict.Remove("C"); // false, 啥也没发生
```

### `Remove(TKey key, out TValue value)` 
*(.NET Core+ 特性)*
*   **说明**：移除指定的键，并同时**获取被移除的值**。
*   **优势**：以前你要获取并移除一个值，得先用 `[]` 读取，再 `Remove`，要查两次哈希表。现在一次搞定，性能翻倍。
*   **示例**：
```csharp
Dictionary<int, string> tasks = new Dictionary<int, string> { {101, "Compile"} };
if (tasks.Remove(101, out string removedTask)) {
    Console.WriteLine($"移除了任务: {removedTask}"); // 输出: 移除了任务: Compile
}
```

### `Clear()`
*   **说明**：清空字典中的所有键值对。
*   **时间复杂度**：O(n)。（与 List 类似，清空数据，但不缩减底层数组的 Capacity 容量）。
*   **示例**：
```csharp
dict.Clear();
// dict.Count 变为 0
```

## 六、 查找与安全读取

### `ContainsKey(TKey key)`
*   **说明**：确定字典是否包含指定的键。
*   **时间复杂度**：O(1)（极速）。
*   **示例**：
```csharp
Dictionary<string, int> inventory = new Dictionary<string, int> { {"Sword", 1} };
if (inventory.ContainsKey("Sword")) {
    Console.WriteLine("你有剑！");
}
```

### `ContainsValue(TValue value)`
*   **说明**：确定字典是否包含特定值。
*   **时间复杂度**：O(n) **（警报！极度缓慢！）**
*   **避坑指南**：字典是专门为 Key 查询优化的。如果你要查 Value，字典只能从头到尾遍历所有的桶。**如果你的代码里频繁出现 `ContainsValue`，说明你的数据结构选错了**，你应该再建一个字典反向映射，或者改用 List。
*   **示例**：
```csharp
bool hasItemWithQuantity1 = inventory.ContainsValue(1); // true，但很慢
```

### `TryGetValue(TKey key, out TValue value)` 
*   **说明**：获取与指定键关联的值。
*   **返回值**：`bool`。如果找到，返回 `true` 且 `out value` 为对应值；如果没找到，返回 `false` 且 `out value` 为该类型的默认值（如 `null` 或 `0`）。
*   **为什么它是神？（性能对比）**：
    *   *菜鸟写法*：`if (dict.ContainsKey(key)) { var val = dict[key]; }` （这会导致底层算两次 Hash，找两次内存）。
    *   *老鸟写法*：`if (dict.TryGetValue(key, out var val)) { ... }` （底层只找一次，安全又高效）。
*   **示例**：
```csharp
Dictionary<string, string> ips = new Dictionary<string, string> { {"Server1", "192.168.1.1"} };

// 优雅且高效的读取方式：
if (ips.TryGetValue("Server1", out string ip)) {
    Console.WriteLine($"找到了 IP: {ip}");
} else {
    Console.WriteLine("服务器不存在");
}
```

## 七、遍历字典

字典在 C# 中实现了 `IEnumerable<KeyValuePair<TKey, TValue>>`。
注意：**字典的遍历顺序是“不确定的”**（通常是元素添加的顺序，但随着删除和内部重建，顺序可能打乱。千万不要依赖字典的遍历顺序！需要顺序请用 `SortedDictionary`）。

### 传统 `foreach` 遍历
```csharp
Dictionary<string, int> fruits = new Dictionary<string, int> { {"Apple", 5}, {"Banana", 10} };

foreach (KeyValuePair<string, int> kvp in fruits) {
    Console.WriteLine($"键: {kvp.Key}, 值: {kvp.Value}");
}
```

### 使用C# 7+的元组解构 - **强烈推荐**
利用 C# 语法糖，代码极其清爽：
```csharp
foreach (var (fruitName, count) in fruits) {
    Console.WriteLine($"水果: {fruitName}, 数量: {count}");
}
```

## 八、独家补充高级特性

这里全是大厂面试和底层架构优化必考的内容：

### 自定义对象作为 Key (踩坑重灾区)
如果你用 `string` 或 `int` 做 Key，系统自带了完美的 Hash 算法。**如果你用自己写的类/结构体作为 Key，必须重写 `GetHashCode()` 和 `Equals()` 方法！** 否则，字典比较的是对象的内存地址，会导致你存进去的东西永远取不出来！

**标准写法示例 (或者让你的类实现 `IEquatable<T>`)**：
```csharp
public class Point {
    public int X { get; }
    public int Y { get; }
    public Point(int x, int y) { X = x; Y = y; }

    // 必须重写 Equals
    public override bool Equals(object obj) {
        if (obj is Point p) return X == p.X && Y == p.Y;
        return false;
    }

    // 必须重写 GetHashCode (经典算法：利用 HashCode.Combine)
    public override int GetHashCode() {
        return HashCode.Combine(X, Y); // .NET Core 提供的神器
    }
}

// 这样字典才能正确识别两个坐标一样的 Point 是同一个 Key
Dictionary<Point, string> map = new Dictionary<Point, string>();
map.Add(new Point(1, 1), "Spawn Location");
```

### 容量预分配 `EnsureCapacity(int)`
和 `List<T>` 一样，字典在不断 `Add` 的过程中也会触发扩容。字典的扩容更耗时，因为它不仅要拷贝数组，还要**重新计算所有元素的 Hash 分配位置（Rehash）**。
*   **最佳实践**：如果知道大概要塞入多少数据，直接在 `new` 的时候传入容量，或者调用 `EnsureCapacity`。
```csharp
// 预先分配 10000 的容量，避免扩容卡顿
Dictionary<int, string> bigDict = new Dictionary<int, string>(10000); 
```

### C# 10 / .NET 6+性能怪兽：`CollectionsMarshal`
**场景**：你要统计一段文本里每个单词出现的次数（词频统计）。
*常规写法*（2次 Hash 查找）：先 `TryGetValue`，拿到旧值+1，再 `dict[word] = newVal`。
*黑科技写法*（0内存分配，1次 Hash 查找，直接修改值类型引用）：
```csharp
using System.Runtime.InteropServices;

Dictionary<string, int> wordCount = new Dictionary<string, int>();
string[] words = { "hello", "world", "hello" };

foreach (string word in words) {
    // ref 获取字典内部存储 value 的直接引用！
    // 如果 key 不存在，它会自动创建并返回引用（初始值为 int 默认值 0）
    ref int countRef = ref CollectionsMarshal.GetValueRefOrAddDefault(wordCount, word, out bool exists);
    
    // 直接操作内存里的值，性能起飞！
    countRef++; 
}
// wordCount: {"hello": 2, "world": 1}
```

### 线程安全性 (ConcurrentDictionary)
*   **警告**：`Dictionary<T, T>` **绝对不是线程安全的！**。如果多线程同时修改字典，不仅会抛出异常，在老版本的 .NET 中甚至会导致**死循环（CPU 100% 飙升）**！
*   **解决方案**：多线程环境请毫不犹豫地使用 `System.Collections.Concurrent.ConcurrentDictionary<TKey, TValue>`。它内部使用了细粒度锁和无锁算法，极其安全且高效。
    *   特有方法：`TryAdd`, `TryGetValue`, `GetOrAdd` (神级方法), `AddOrUpdate`。

### `Dictionary` vs `Lookup` vs `Hashtable`
对比：
*   **`Dictionary<TKey, TValue>`**：1个键对应1个值。泛型，类型安全，性能最高。
*   **`ILookup<TKey, TElement>`**：1个键对应**一个集合**（多个值）。由 LINQ 的 `ToLookup()` 生成，**不可修改**，适合按分类聚合数据。
*   **`Hashtable`**：C# 1.0 的遗留产物。非泛型（存 object），会导致值类型严重装箱拆箱（Boxing），**现代 C# 开发中永远不要再使用它**。

## 九、 总结提炼

1.  **查读口诀**：读取就用 `TryGetValue`，判断有无 `ContainsKey`。绝对不用 `ContainsValue`！
2.  **增改口诀**：直接覆盖用 `dict[key] = val`，安全插入用 `TryAdd`，严谨防重用 `Add`。
3.  **自定义 Key 口诀**：用类做 Key 必写 `Equals` 和 `GetHashCode`，否则找不着。
4.  **容量口诀**：大数据初始化先给 Capacity，免得扩容（Rehash）卡死 CPU。
5.  **多线程口诀**：只要涉及多线程，立刻换成 `ConcurrentDictionary`。
