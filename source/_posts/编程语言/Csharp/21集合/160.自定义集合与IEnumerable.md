# 自定义集合与`IEnumerable<T>`

## 为什么要升级到`IEnumerable<T>`？
上一篇我们提到的非泛型 `IEnumerable` 返回的是 `object`。这意味着如果你遍历的是整数 `int`，每次遍历都会发生装箱（Boxing）和拆箱（Unboxing），不仅没有类型提示，还会严重拖慢运行速度。

从 C# 2.0 开始，微软引入了泛型。我们现在编写自定义集合，**几乎 100% 都会使用泛型接口 `IEnumerable<T>`**。

## `IEnumerable<T>` 的特殊之处
`IEnumerable<T>` 继承自非泛型的 `IEnumerable`。
这就意味着，如果你要实现 `IEnumerable<T>`，你**必须同时实现两个 `GetEnumerator()` 方法**：
1. 返回 `IEnumerator<T>` 的泛型方法。
2. 返回 `IEnumerator` 的非泛型方法（通常通过隐式或显式接口实现来兼容老代码）。

## 手动实现 `IEnumerable<T>`（了解原理）

假设我们要写一个“智能购物车”（`ShoppingCart`），里面装的是 `Product` 对象。

```csharp
using System;
using System.Collections;
using System.Collections.Generic;

public class Product
{
    public string Name { get; set; }
}

public class ShoppingCart : IEnumerable<Product>
{
    private Product[] _products = new Product[]
    {
        new Product { Name = "苹果" },
        new Product { Name = "香蕉" }
    };

    // 1. 实现泛型的 GetEnumerator
    public IEnumerator<Product> GetEnumerator()
    {
        return new CartEnumerator(_products);
    }

    // 2. 显式实现非泛型的 GetEnumerator (为了兼容非泛型接口)
    IEnumerator IEnumerable.GetEnumerator()
    {
        // 直接调用上面的泛型方法即可
        return this.GetEnumerator();
    }
}

// 泛型枚举器需要实现 IEnumerator<T>
public class CartEnumerator : IEnumerator<Product>
{
    private Product[] _products;
    private int _position = -1;

    public CartEnumerator(Product[] products) { _products = products; }

    // 泛型的 Current，不需要装箱拆箱！
    public Product Current
    {
        get { return _products[_position]; }
    }

    // 非泛型的 Current
    object IEnumerator.Current => Current;

    public bool MoveNext()
    {
        _position++;
        return _position < _products.Length;
    }

    public void Reset() { _position = -1; }

    // IEnumerator<T> 继承了 IDisposable，必须实现 Dispose 方法
    public void Dispose() { /* 如果有非托管资源，在这里释放 */ }
}
```

## `yield return` 简化代码
看完上面的代码，你肯定会吐槽：“这也太麻烦了吧！写一个集合要写这么多样板代码？”
没错，C# 的设计者也觉得麻烦。于是他们引入了迭代器语法糖：**`yield return`**。

使用 `yield return`，编译器会**自动在底层帮我们生成那个复杂的 Enumerator 类（状态机）**！

让我们用 `yield return` 重写上面的购物车：

```csharp
public class ModernShoppingCart : IEnumerable<Product>
{
    private Product[] _products = new Product[]
    {
        new Product { Name = "苹果" },
        new Product { Name = "香蕉" },
        new Product { Name = "西瓜" }
    };

    public IEnumerator<Product> GetEnumerator()
    {
        // 只需要这一个循环和 yield return！
        // 编译器会自动帮我们生成 IEnumerator<Product> 的实现代码
        for (int i = 0; i < _products.Length; i++)
        {
            yield return _products[i];
        }
    }

    IEnumerator IEnumerable.GetEnumerator()
    {
        return this.GetEnumerator();
    }
}
```

**测试一下：**
```csharp
ModernShoppingCart cart = new ModernShoppingCart();
foreach (Product p in cart)
{
    Console.WriteLine(p.Name); 
}
// 输出: 苹果, 香蕉, 西瓜
```

## 总结
1. **类型安全与性能**：`IEnumerable<T>` 避免了装箱和拆箱，是现代 C# 集合的标准。
2. **接口继承**：实现泛型集合时，必须同时实现泛型和非泛型的 `GetEnumerator()`。
3. **语法糖**：`yield return` 极大地简化了迭代器的编写，它背后是编译器自动生成的状态机。

掌握了 `IEnumerable<T>` 和 `yield return`，你已经可以优雅地编写绝大多数自定义集合了。
