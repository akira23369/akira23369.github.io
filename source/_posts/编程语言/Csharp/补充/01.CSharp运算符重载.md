# C# 运算符重载完全指南

## 一、什么是运算符重载？

运算符重载（Operator Overloading）是C#提供的一项强大功能，允许开发者为自定义类型（类或结构体）重新定义内置运算符（如 `+`, `-`, `*`, `/` 等）的行为。这使得自定义类型可以像内置类型一样使用直观的运算符语法，而不是调用晦涩难懂的方法。

**核心优势：**
- **代码可读性**：`vector1 + vector2` 比 `vector1.Add(vector2)` 更自然
- **直观性**：数学对象的运算符合数学直觉
- **一致性**：与.NET框架内置类型保持统一风格
- **简洁性**：减少样板代码，提高开发效率

---

## 二、基本语法规则

运算符重载在C#中通过静态方法实现，使用 `operator` 关键字：

```csharp
public static 返回类型 operator 运算符(参数列表)
{
    // 实现逻辑
}
```

**关键约束：**
1. 必须是 `public` 和 `static`
2. 至少有一个参数是定义类型本身
3. 不能创建新运算符，只能重载现有运算符
4. 不能改变运算符的优先级和结合性
5. 重载某些运算符需要同时重载其对应运算符（如 `==` 和 `!=`）

---

## 三、可重载运算符分类详解

### 一元运算符
| 运算符 | 说明 | 方法签名 |
|--------|------|----------|
| `+` | 正号 | `public static T operator +(T operand)` |
| `-` | 负号 | `public static T operator -(T operand)` |
| `!` | 逻辑非 | `public static T operator !(T operand)` |
| `~` | 按位取反 | `public static T operator ~(T operand)` |
| `++` | 自增 | `public static T operator ++(T operand)` |
| `--` | 自减 | `public static T operator --(T operand)` |
| `true` | 真判断 | `public static bool operator true(T operand)` |
| `false` | 假判断 | `public static bool operator false(T operand)` |

**特点：**
- 只能有一个参数
- 参数类型必须是定义类型
- 返回类型可以是任意类型，但通常为定义类型本身

### 二元运算符
| 运算符  | 说明  | 方法签名                                             |
| ---- | --- | ------------------------------------------------ |
| `+`  | 加法  | `public static T operator +(T left, U right)`    |
| `-`  | 减法  | `public static T operator -(T left, U right)`    |
| `*`  | 乘法  | `public static T operator *(T left, U right)`    |
| `/`  | 除法  | `public static T operator /(T left, U right)`    |
| `%`  | 取模  | `public static T operator %(T left, U right)`    |
| `&`  | 按位与 | `public static T operator &(T left, U right)`    |
| `    | 按位或 | `public static T operator(T left, U right)`      |
| `^`  | 异或  | `public static T operator ^(T left, U right)`    |
| `<<` | 左移  | `public static T operator <<(T left, int right)` |
| `>>` | 右移  | `public static T operator >>(T left, int right)` |

**特点：**
- 必须有两个参数
- 至少一个参数是定义类型
- 可以混合不同类型（如 `Vector + int`）

### 比较运算符
| 运算符 | 说明 | 方法签名 |
|--------|------|----------|
| `==` | 相等 | `public static bool operator ==(T left, T right)` |
| `!=` | 不等 | `public static bool operator !=(T left, T right)` |
| `<` | 小于 | `public static bool operator <(T left, T right)` |
| `>` | 大于 | `public static bool operator >(T left, T right)` |
| `<=` | 小于等于 | `public static bool operator <=(T left, T right)` |
| `>=` | 大于等于 | `public static bool operator >=(T left, T right)` |

**重要规则：**
- 必须成对重载：`==` 和 `!=` 一起，`<` 和 `>` 一起，`<=` 和 `>=` 一起
- 通常也应该重写 `Equals()` 和 `GetHashCode()`
- 返回类型必须是 `bool`

### 类型转换运算符
| 类型 | 关键字 | 示例 |
|------|--------|------|
| 隐式转换 | `implicit` | `public static implicit operator T(S value)` |
| 显式转换 | `explicit` | `public static explicit operator T(S value)` |

## 四、完整实现示例

### 结构体示例：复数

```csharp
public struct Complex : IEquatable<Complex>
{
    public double Real { get; }
    public double Imaginary { get; }

    public Complex(double real, double imaginary)
    {
        Real = real;
        Imaginary = imaginary;
    }

    // 一元加号（通常返回原值）
    public static Complex operator +(Complex c)
    {
        return c;
    }

    // 一元负号
    public static Complex operator -(Complex c)
    {
        return new Complex(-c.Real, -c.Imaginary);
    }

    // 二元加法
    public static Complex operator +(Complex c1, Complex c2)
    {
        return new Complex(c1.Real + c2.Real, c1.Imaginary + c2.Imaginary);
    }

    // 二元减法
    public static Complex operator -(Complex c1, Complex c2)
    {
        return new Complex(c1.Real - c2.Real, c1.Imaginary - c2.Imaginary);
    }

    // 二元乘法（复数乘法规则）
    public static Complex operator *(Complex c1, Complex c2)
    {
        double real = c1.Real * c2.Real - c1.Imaginary * c2.Imaginary;
        double imag = c1.Real * c2.Imaginary + c1.Imaginary * c2.Real;
        return new Complex(real, imag);
    }

    // 与double的混合运算
    public static Complex operator *(Complex c, double multiplier)
    {
        return new Complex(c.Real * multiplier, c.Imaginary * multiplier);
    }

    // 反向混合运算（注意参数顺序）
    public static Complex operator *(double multiplier, Complex c)
    {
        return c * multiplier; // 复用上面的实现
    }

    // 除法（简化版：只处理除以实数）
    public static Complex operator /(Complex c, double divisor)
    {
        if (divisor == 0) throw new DivideByZeroException("Cannot divide by zero");
        return new Complex(c.Real / divisor, c.Imaginary / divisor);
    }

    // 相等运算符（必须成对实现）
    public static bool operator ==(Complex c1, Complex c2)
    {
        return c1.Real == c2.Real && c1.Imaginary == c2.Imaginary;
    }

    public static bool operator !=(Complex c1, Complex c2)
    {
        return !(c1 == c2);
    }

    // 比较运算符（复数通常按模比较）
    public static bool operator <(Complex c1, Complex c2)
    {
        return c1.Magnitude() < c2.Magnitude();
    }

    public static bool operator >(Complex c1, Complex c2)
    {
        return c1.Magnitude() > c2.Magnitude();
    }

    public static bool operator <=(Complex c1, Complex c2)
    {
        return c1.Magnitude() <= c2.Magnitude();
    }

    public static bool operator >=(Complex c1, Complex c2)
    {
        return c1.Magnitude() >= c2.Magnitude();
    }

    // 辅助方法：计算模（到原点的距离）
    public double Magnitude()
    {
        return Math.Sqrt(Real * Real + Imaginary * Imaginary);
    }

    // 必须重写Equals和GetHashCode
    public override bool Equals(object obj)
    {
        return obj is Complex complex && Equals(complex);
    }

    public bool Equals(Complex other)
    {
        return Real == other.Real && Imaginary == other.Imaginary;
    }

    public override int GetHashCode()
    {
        return HashCode.Combine(Real, Imaginary);
    }

    // 重写ToString方便调试
    public override string ToString()
    {
        if (Imaginary >= 0)
            return $"{Real} + {Imaginary}i";
        else
            return $"{Real} - {-Imaginary}i";
    }

    // 隐式转换：double -> Complex（安全转换）
    public static implicit operator Complex(double real)
    {
        return new Complex(real, 0);
    }

    // 显式转换：Complex -> double（可能丢失信息）
    public static explicit operator double(Complex c)
    {
        return c.Real; // 只返回实部，可能丢失信息
    }

    // true/false运算符（当Real不为0时为true）
    public static bool operator true(Complex c)
    {
        return c.Real != 0 || c.Imaginary != 0;
    }

    public static bool operator false(Complex c)
    {
        return c.Real == 0 && c.Imaginary == 0;
    }
}

// 使用示例
public class Program
{
    public static void Main()
    {
        Complex c1 = new Complex(3, 4);
        Complex c2 = new Complex(1, 2);

        // 使用重载运算符
        Complex sum = c1 + c2;      // 4 + 6i
        Complex diff = c1 - c2;     // 2 + 2i
        Complex prod = c1 * c2;     // -5 + 10i
        Complex scaled = c1 * 2;    // 6 + 8i
        Complex scaled2 = 3 * c2;   // 3 + 6i

        // 比较运算
        bool isLarger = c1 > c2;    // 比较模长

        // 类型转换
        Complex c3 = 5.0;           // 隐式转换 double -> Complex
        double real = (double)c3;   // 显式转换 Complex -> double

        // true/false测试
        if (c1) Console.WriteLine("c1 is non-zero");
        
        Console.WriteLine($"c1 = {c1}");
        Console.WriteLine($"c2 = {c2}");
        Console.WriteLine($"c1 + c2 = {sum}");
        Console.WriteLine($"c1 * c2 = {prod}");
    }
}
```

### 类示例：矩阵

```csharp
public class Matrix
{
    private readonly double[,] _data;
    public int Rows { get; }
    public int Columns { get; }

    public Matrix(int rows, int columns)
    {
        Rows = rows;
        Columns = columns;
        _data = new double[rows, columns];
    }

    public Matrix(double[,] data) : this(data.GetLength(0), data.GetLength(1))
    {
        Array.Copy(data, _data, data.Length);
    }

    // 索引器
    public double this[int row, int col]
    {
        get => _data[row, col];
        set => _data[row, col] = value;
    }

    // 矩阵加法
    public static Matrix operator +(Matrix m1, Matrix m2)
    {
        if (m1.Rows != m2.Rows || m1.Columns != m2.Columns)
            throw new ArgumentException("Matrices must have same dimensions");

        Matrix result = new Matrix(m1.Rows, m1.Columns);
        for (int i = 0; i < m1.Rows; i++)
            for (int j = 0; j < m1.Columns; j++)
                result[i, j] = m1[i, j] + m2[i, j];
        return result;
    }

    // 矩阵减法
    public static Matrix operator -(Matrix m1, Matrix m2)
    {
        if (m1.Rows != m2.Rows || m1.Columns != m2.Columns)
            throw new ArgumentException("Matrices must have same dimensions");

        Matrix result = new Matrix(m1.Rows, m1.Columns);
        for (int i = 0; i < m1.Rows; i++)
            for (int j = 0; j < m1.Columns; j++)
                result[i, j] = m1[i, j] - m2[i, j];
        return result;
    }

    // 矩阵乘法
    public static Matrix operator *(Matrix m1, Matrix m2)
    {
        if (m1.Columns != m2.Rows)
            throw new ArgumentException("m1.Columns must equal m2.Rows");

        Matrix result = new Matrix(m1.Rows, m2.Columns);
        for (int i = 0; i < m1.Rows; i++)
        {
            for (int j = 0; j < m2.Columns; j++)
            {
                double sum = 0;
                for (int k = 0; k < m1.Columns; k++)
                    sum += m1[i, k] * m2[k, j];
                result[i, j] = sum;
            }
        }
        return result;
    }

    // 数乘
    public static Matrix operator *(Matrix m, double scalar)
    {
        Matrix result = new Matrix(m.Rows, m.Columns);
        for (int i = 0; i < m.Rows; i++)
            for (int j = 0; j < m.Columns; j++)
                result[i, j] = m[i, j] * scalar;
        return result;
    }

    public static Matrix operator *(double scalar, Matrix m) => m * scalar;

    // 等号比较
    public static bool operator ==(Matrix m1, Matrix m2)
    {
        if (ReferenceEquals(m1, m2)) return true;
        if (m1 is null || m2 is null) return false;

        if (m1.Rows != m2.Rows || m1.Columns != m2.Columns)
            return false;

        for (int i = 0; i < m1.Rows; i++)
            for (int j = 0; j < m1.Columns; j++)
                if (Math.Abs(m1[i, j] - m2[i, j]) > 1e-10)
                    return false;
        return true;
    }

    public static bool operator !=(Matrix m1, Matrix m2) => !(m1 == m2);

    // 重写Equals和GetHashCode
    public override bool Equals(object obj)
    {
        return obj is Matrix matrix && this == matrix;
    }

    public override int GetHashCode()
    {
        unchecked
        {
            int hash = 17;
            for (int i = 0; i < Rows; i++)
                for (int j = 0; j < Columns; j++)
                    hash = hash * 31 + _data[i, j].GetHashCode();
            return hash;
        }
    }

    public override string ToString()
    {
        var sb = new System.Text.StringBuilder();
        for (int i = 0; i < Rows; i++)
        {
            sb.Append("[ ");
            for (int j = 0; j < Columns; j++)
            {
                sb.Append(_data[i, j].ToString("F2").PadLeft(8));
                if (j < Columns - 1) sb.Append(" ");
            }
            sb.Append(" ]\n");
        }
        return sb.ToString();
    }
}
```

## 五、高级主题与特殊运算符

### 类型转换运算符的深入

**隐式转换 (`implicit`)**
- 用于不丢失数据的"安全"转换
- 编译器自动应用，无需显式cast
- 示例：int → long，double → Complex

**显式转换 (`explicit`)**
- 用于可能丢失信息或不安全的转换
- 需要显式cast语法
- 示例：double → int，Complex → double

```csharp
public struct Fraction
{
    public int Numerator { get; }
    public int Denominator { get; }

    public Fraction(int numerator, int denominator)
    {
        if (denominator == 0) throw new ArgumentException("Denominator cannot be zero");
        Numerator = numerator;
        Denominator = denominator;
    }

    // 隐式转换：int -> Fraction
    public static implicit operator Fraction(int wholeNumber)
    {
        return new Fraction(wholeNumber, 1);
    }

    // 显式转换：Fraction -> double（可能丢失精度）
    public static explicit operator double(Fraction f)
    {
        return (double)f.Numerator / f.Denominator;
    }

    // 显式转换：Fraction -> int（截断）
    public static explicit operator int(Fraction f)
    {
        return f.Numerator / f.Denominator; // 整数除法
    }
}

// 使用
Fraction f1 = 5;          // 隐式转换
double d = (double)f1;    // 显式转换
int i = (int)f1;          // 显式转换，结果为5
```

### true/false运算符

独特之处在于它们总是成对出现，并且允许对象在布尔上下文中使用（如 `if` 语句）。

```csharp
public struct NullableBool
{
    private readonly bool? _value;

    public NullableBool(bool? value)
    {
        _value = value;
    }

    public static bool operator true(NullableBool nb)
    {
        return nb._value == true;
    }

    public static bool operator false(NullableBool nb)
    {
        return nb._value == false;
    }

    // 还可以重载逻辑与和或
    public static NullableBool operator &(NullableBool a, NullableBool b)
    {
        if (!a._value.HasValue || !b._value.HasValue)
            return new NullableBool(null);
        return new NullableBool(a._value.Value & b._value.Value);
    }

    public static NullableBool operator |(NullableBool a, NullableBool b)
    {
        if (a._value == true || b._value == true)
            return new NullableBool(true);
        if (!a._value.HasValue || !b._value.HasValue)
            return new NullableBool(null);
        return new NullableBool(false);
    }
}
```

## 六、不可重载的运算符

以下运算符**不能**被重载：
- 成员访问 `.`
- 方法调用 `()`
- 条件运算符 `?:`
- 赋值运算符 `=`（但可以影响 `+=`, `-=` 等复合赋值运算符）
- 逻辑与/或 `&&`, `||`（但可通过重载 `&`, `|` 和 `true`/`false` 间接支持）
- 空合并 `??`, `??=`
- `checked`/`unchecked` 运算符
- `=>` Lambda运算符
- `new`, `typeof`, `sizeof`, `is`, `as` 等运算符

**重要说明**：虽然 `&&` 和 `||` 不能直接重载，但重载 `&` 和 `|` 以及 `true`/`false` 运算符后，编译器会自动利用它们构建 `&&` 和 `||` 的短路求值行为。

## 七、设计准则与最佳实践

### 必须遵循的原则

1. **对称性原则**：如果重载了 `==`，必须重载 `!=`
2. **一致性原则**：运算符行为应与数学直觉一致
   - `a + b` 应该等价于 `b + a`（交换律，如果适用）
   - `(a + b) + c` 应该等价于 `a + (b + c)`（结合律）
3. **完整性原则**：重载比较运算符时，同时实现 `IEquatable<T>` 和 `IComparable<T>`
4. **避免副作用**：运算符不应修改操作数（`++` 和 `--` 除外）

### 性能考量

```csharp
// 不良实践：在运算符中创建大量临时对象
public static HugeMatrix operator +(HugeMatrix a, HugeMatrix b)
{
    // 每次加法都分配新矩阵，GC压力大
    var result = new HugeMatrix(a.Rows, a.Columns);
    // ...计算
    return result;
}

// 改进：提供in-place操作的方法
public void AddInPlace(HugeMatrix other)
{
    // 直接修改当前实例
}

// 运算符内部可以调用高性能方法
public static HugeMatrix operator +(HugeMatrix a, HugeMatrix b)
{
    var result = new HugeMatrix(a.Rows, a.Columns);
    result.AddInPlace(a);
    result.AddInPlace(b);
    return result;
}
```

### 选择合适的返回类型

```csharp

### 运算符重载与继承

public class Base
{
    public int Value;
    // 父类重载了 +
    public static int operator +(Base a, Base b) => a.Value + b.Value;
}

public class Derived : Base { }

Derived d1 = new Derived { Value = 10 };
Derived d2 = new Derived { Value = 20 };

```

### 空值处理

```csharp
public struct SafeComplex
{
    // 错误实现
    public static SafeComplex operator +(SafeComplex a, SafeComplex b)
    {
        // 如果a或b为null，抛出NullReferenceException
        return new SafeComplex(a.Real + b.Real, a.Imaginary + b.Imaginary);
    }

    // 正确实现：检查null
    public static SafeComplex operator +(SafeComplex? a, SafeComplex? b)
    {
        // 处理可空值
        if (!a.HasValue && !b.HasValue) return default;
        if (!a.HasValue) return b.Value;
        if (!b.HasValue) return a.Value;
        
        return new SafeComplex(a.Value.Real + b.Value.Real, 
                               a.Value.Imaginary + b.Value.Imaginary);
    }
}
```

public interface IArithmetic<T>

public abstract class Number<T> where T : Number<T>

    public static T operator +(Number<T> a, Number<T> b)
    {
        return a.Add(b as T);

public class MyNumber : Number<MyNumber>

### .NET 7+ 的泛型数学（ISignedNumber等）

.NET 7引入了静态抽象接口，可以在接口中定义运算符：

    public Length(double meters)
    {
        _meters = meters;
    }

    // 工厂属性

    public static Length FromFeet(double feet) => new Length(feet * 0.3048);

    public double Meters => _meters;
    public double Kilometers => _meters / 1000;
    public double Feet => _meters / 0.3048;

    public static Length operator -(Length a, Length b)

        => new Length(a._meters * factor);

    {

        return new Length(a._meters / divisor);
    }

    // 速度 = 长度 / 时间
    public static Speed operator /(Length distance, TimeSpan time)
        => new Speed(distance._meters / time.TotalSeconds);

    // 比较
    public static bool operator <(Length a, Length b) => a._meters < b._meters;

## 十二、总结与建议

### 何时使用运算符重载

**适合场景：**
- 数学对象（向量、矩阵、复数）
- 物理单位（长度、重量、时间）
- 自定义数值类型（分数、大整数）
- 集合操作（并集、交集）

**不适合场景：**
- 业务逻辑操作（订单合并、用户权限组合）
- 可能导致歧义的操作
- 开销昂贵的操作（应保持方法调用显眼）

### 检查清单

在重载运算符前，确认：
- [ ] 操作是否符合数学/直觉预期？
- [ ] 是否同时重载了对称运算符？
- [ ] 是否重写了 `Equals()` 和 `GetHashCode()`？
- [ ] 是否实现了 `IEquatable<T>` 和 `IComparable<T>`？
- [ ] 是否处理了 null/边界情况？
- [ ] 返回类型是否合适（值类型/不可变类型）？
- [ ] 性能是否可接受？
- [ ] 是否有清晰的文档注释？

### C#版本演进

- **C# 1.0**：引入基本运算符重载
- **C# 7.0**：改进元组支持，影响 `==` 和 `!=`
- **C# 8.0**：可为空引用类型，影响运算符null处理
- **C# 10+**：静态抽象接口，支持泛型运算符

运算符重载是C#中一个强大但需要谨慎使用的特性。正确使用可以极大提升代码可读性和自然度，但滥用会导致代码难以理解和维护。始终记住：**代码是写给人看的，只是恰好能被机器执行**。
