**关于 C# 语言版本演进与核心特性历程的深度笔记**

# **一、 C# 语言演进宏观概述**

自 2002 年发布 1.0 版本以来，C# 语言经历了一系列重大的范式转变。从最初纯粹的面向对象编程（OOP）语言，逐渐吸收了函数式编程（Functional Programming）、动态编程等多种特性的精华，演变成一门高度现代化、表达力极强的多范式编程语言。

掌握各个版本引入的核心特性，不仅是应对高级技术面试的必备知识，更是写出高质量、现代化 C# 代码的基石。

# **二、 历代大版本核心特性拆解与代码说明**

## **C# 1.0 —— 面向对象的基础奠基**
确立了 C# 作为现代面向对象语言的基础骨架。
*   **核心特性：** 类 (Classes)、对象 (Objects)、结构体 (Structs)、接口 (Interfaces)、事件 (Events)、基础多线程 (Threading)。

## **C# 2.0 —— 类型安全与灵活性的飞跃**
*   **泛型 (Generics)：** 允许在定义类、接口和方法时不指定具体数据类型，直到使用时才指定。彻底解决了早期使用 `ArrayList` 频繁装箱/拆箱导致的性能问题和类型安全问题。
*   **可空类型 (Nullable Types)：** 允许值类型（如 `int`, `bool`）也可以表示为空 (`null`)。
*   **分部类 (Partial Classes)：** 允许将一个类的定义拆分到多个物理文件中，极大方便了 UI 设计器自动生成代码与手写代码的分离。

```csharp
// C# 2.0 泛型与可空类型示例
List<string> names = new List<string>(); // 泛型集合，类型安全
int? age = null;                         // 可空的值类型
```

## **C# 3.0 —— 数据查询与语法糖的革命**
这一代引入了大量极其常用的语法糖，极大缩短了代码篇幅。
*   **自动实现属性 (Auto-implemented Properties)：** 摒弃了冗长的私有字段声明。
*   **对象/集合初始化器 (Object/Collection Initializers)：** 可以在创建对象的同时为其属性赋值。
*   **LINQ (语言集成查询)：** 允许使用类似 SQL 的语法直接在 C# 中查询各种数据源（集合、数据库、XML）。
*   **隐式类型局部变量 (`var`)：** 由编译器自动推断变量类型。
* **扩展方法 (Extension Methods)：** 允许在不修改原始类源代码、不使用继承的情况下，向现有的类（甚至是 .NET 框架自带的类，如 String）“动态”添加新方法。LINQ 的底层核心支撑就是扩展方法。

```csharp
// C# 3.0 特性综合示例
public class Employee 
{ 
    public string Name { get; set; } // 自动实现属性
    public int Age { get; set; } 
}

// 对象初始化器与 var 关键字
var emp = new Employee { Name = "Alice", Age = 30 };

// 扩展方法示例：为官方的 string 类添加一个“是否为大写”的方法（必须是静态类
public static class StringExtensions
{
    public static bool IsCapitalized(this string str) => char.IsUpper(str[0]);
}
// 调用是 对象.添加的方法： "Hello".IsCapitalized();
```

## **C# 4.0 —— 动态绑定与方法调用优化**
*   **动态类型 (`dynamic`)：** 引入 DLR（动态语言运行时），允许在编译时跳过类型检查，在运行时才解析。主要用于与 Python 等动态语言或 COM 组件的互操作。
*   **命名参数与可选参数：** 允许方法参数具有默认值，并在调用时无需记住参数顺序，直接通过参数名传值。

```csharp
// C# 4.0 命名与可选参数示例
public void Register(string name, bool isActive = true) { }

// 调用时可以只传必填参数，或打乱顺序使用命名参数
Register(name: "Bob"); 
```

## **C# 5.0 —— 异步编程的里程碑**
*   **`async` 和 `await`：** 彻底终结了使用回调函数（Callback）处理异步任务的复杂历史。让开发者能以写同步代码的思维和结构，写出非阻塞的异步代码。

```csharp
// C# 5.0 异步方法示例
public async Task<string> DownloadDataAsync(string url)
{
    HttpClient client = new HttpClient();
    // await 会挂起当前方法，交出线程控制权，直到网络请求完成
    string data = await client.GetStringAsync(url);
    return data;
}
```

## **C# 6.0 —— 进一步净化代码的语法糖**
*   **字符串插值 (String Interpolation)：** 使用 `$` 前缀，直接在字符串内部大括号 `{}` 中写变量或表达式，淘汰了老旧的 `String.Format`。
*   **空值传播运算符 (Null-conditional Operator `?.`)：** 极大地简化了深层嵌套对象防空指针异常的判断。
* **表达式主体成员 (Expression-Bodied Members =>)：** 极大地精简了只有一行代码的方法或只读属性的书写，淘汰了冗长的大括号和 return 关键字。

```csharp
// C# 6.0 特性示例
string userName = emp?.Name; // 如果 emp 为 null，userName 直接赋值为 null，不会抛出异常
Console.WriteLine($"User name is {userName}"); // 字符串插值

// 表达式主体成员示例：
public string FullName => $"{FirstName} {LastName}"; // 替代了仅有 get { return ...; } 的属性
```

## **C# 7.x 系列 (7.0 - 7.3) —— 模式匹配与轻量级数据结构**
*   **元组 (Tuples)：** 使得方法可以轻松、优雅地返回多个值，而无需专门定义一个类。
*   **弃元 (Discards `_`)：** 用于在解构或模式匹配时，主动忽略不关心的变量。
*   **模式匹配 (Pattern Matching)：** 增强了 `is` 和 `switch` 的能力，允许在判断类型的同时完成变量转换。
*   **异步 Main 方法 (`async Main`)：** 允许程序的入口起点也是异步的。

```csharp
// C# 7.0 元组与模式匹配示例
public (int min, int max) GetRange() // 返回元组
{
    return (1, 100);
}

var (minVal, _) = GetRange(); // 使用弃元 '_' 忽略第二个返回值

object data = "Hello";
if (data is string str) // 模式匹配：如果 data 是 string，则转换并赋值给 str
{
    Console.WriteLine(str.Length);
}
```

## **C# 8.0 —— 拥抱不可变与函数式风格**
*   **Switch 表达式 (Switch Expressions)：** 将传统的 switch 语句改造为更紧凑的表达式，能够直接返回结果。
*   **`using` 声明：** 去掉了传统 `using` 语句所需的冗长代码块（大括号 `{}`），变量离开作用域时自动释放资源。
*   **只读结构体 (Readonly Structs) 和 静态局部函数**。
*  **可空引用类型 (Nullable Reference Types)：** 为引用类型引入可空标记 `?`，编译器可静态检查空引用问题，从根源减少 `NullReferenceException`。
* **默认接口方法 (Default Interface Methods)：** 允许接口包含带实现的方法，打破 “接口只能定义契约，不能有实现” 的限制，支持接口的版本演进。

```csharp
// C# 8.0 Switch 表达式与 using 声明
public string GetStatus(int code) => code switch
{
    200 => "OK",
    404 => "Not Found",
    _ => "Unknown" // 丢弃符号作为 default
};

public void ReadFile()
{
    using var stream = new FileStream("data.txt", FileMode.Open);
    // 无需大括号，方法结束时 stream 会自动调用 Dispose()
}


// 可空引用类型示例
public class User
{
    public string Name { get; set; } // 非可空引用类型，必须赋值
    public string? Email { get; set; } // 可空引用类型，允许为 null
}

// Switch 表达式 + 只读结构体 + 静态局部函数
public readonly struct Result // 只读结构体（不可变）
{
    public int Code { get; } // 只读属性（无 set）
    public string? Message { get; } // 可空引用类型

    // 只读结构体的构造函数必须初始化所有字段
    public Result(int code, string? message) => (Code, Message) = (code, message);

    // 静态局部函数（C# 8.0，仅在当前方法内可见）
    public string GetResultInfo()
    {
        static string GetDefaultMessage(int code) => code < 0 ? "失败" : "成功"; // 静态局部函数

        // Switch 表达式
        return Code switch
        {
            200 => "操作成功",
            404 => "资源未找到",
            _ => Message ?? GetDefaultMessage(Code) // 空合并运算符处理可空引用类型
        };
    }
}

// 默认接口方法示例
public interface ILogger
{
    // 传统接口抽象方法（必须实现）
    void Log(string message);

    // 默认接口方法（可选实现，有默认逻辑）
    void LogWarning(string message)
    {
        Log($"[WARNING] {message}"); // 复用抽象方法
    }

    // 带默认实现的静态方法（C# 8.0 也支持）
    static void LogError(string message)
    {
        Console.WriteLine($"[ERROR] {message}");
    }
}

// 实现接口时，仅需实现抽象方法，默认方法可选重写
public class ConsoleLogger : ILogger
{
    public void Log(string message)
    {
        Console.WriteLine(message);
    }

    // 可选：重写默认接口方法
    // public void LogWarning(string message)
    // {
    //     Console.WriteLine($"[CUSTOM WARNING] {message}");
    // }
}

```

## **补充前瞻：C# 9.0 到 13.0 (现代云原生时代)**
虽然资料中仅提及了这些版本的存在，但补充其核心发展趋势非常重要。现代 C# 极力推崇**不可变数据（Immutability）**和**消除样板代码（Boilerplate Code）**。
*   **核心代表特性：** 记录类型 (`record`，提供基于值相等的不可变对象)、顶级语句 (Top-level statements，去除无意义的 `class Program` 和 `Main` 方法包裹)、全局 `using` 指令等。这些特性使得 C# 变得越来越轻量、现代，且非常适合微服务和云原生开发环境。


## C# 9.0 (2020) —— 数据建模的革命与极简入口
- **记录类型 (record)：** 专为承载数据（如 DTO、配置文件）而生的新引用类型。它天生具有不可变性（一旦创建不能修改），并且编译器会自动为它生成基于值的相等性比较（比较两个 record 是否相等，比较的是它们的数据内容，而不是内存地址）。
- **仅初始化设定项 (init)：** 属性的 set 访问器的替代品。它允许在对象创建时（对象初始化器中）赋值，但创建完成后立刻变为只读，保障了对象的不可变性。
- **顶级语句 (Top-level Statements)：** 彻底抛弃了 namespace、class Program 和 static void Main 这些冗余的启动代码，只需一行代码即可运行应用，极大地降低了微服务和控制台工具的编写门槛。
- **目标类型 new 表达式：** 实例化对象时，如果左侧类型已知，右侧可以省略类名。

```csharp
// C# 9.0 顶级语句（直接写在 Program.cs 顶端即可执行）
Console.WriteLine("Hello World!"); 

// 记录类型与 init 设定项
public record User(string Name, int Age); // 一行代码定义完整的数据结构（自带构造函数、相等性比较等）

public class Employee
{
    public string ID { get; init; } // 只能在初始化时赋值
}

// 目标类型 new
List<User> users = new(); // 省略了 new List<User>()
users.Add(new("Alice", 25)); // 省略了 new User(...)
```

## **C# 10.0 (2021) —— 全局治理与代码瘦身**

- **全局 Using 指令 (global using)：** 允许在一个统一的文件中声明 using 命名空间，整个项目的其他所有文件都会自动应用，彻底消灭了每个文件头部那长长的一排 using 语句。
- **文件范围命名空间 (File-scoped Namespaces)：** 去掉了命名空间后紧跟的大括号 {}，让整个文件的代码向左缩进一个层级，消除了无意义的水平空间浪费。
- **记录结构体 (record struct)：** 将 C# 9.0 中 record 的优秀特性扩展到了值类型（结构体）上。

```csharp
// 全局 Using（通常写在一个专门的文件中，如 GlobalUsings.cs）
global using System;
global using System.Collections.Generic;

// C# 10.0 文件范围命名空间（注意没有大括号了）
namespace Company.Project.Models;

public class Customer 
{
    // 类的内容不需要再缩进
}
```

## **C# 11.0 (2022) —— 字符串处理与模式匹配升级**

- **原始字符串字面量 (Raw String Literals """)：** 彻底终结了在 C# 中写 JSON、XML 甚至是 SQL 语句时繁琐的转义字符（如 \"）。只需用三个以上的双引号包裹，内部的任何换行、引号都将按原样输出。
- **必需成员 (required)：** 强制要求调用者在创建对象时，必须为带有 required 修饰符的属性赋值，否则编译器直接报错。这解决了过去使用对象初始化器时，容易漏掉关键必填字段的问题。
- **列表模式 (List Patterns)：** 允许对数组或集合进行极其复杂的模式匹配，包括匹配开头、结尾或跳过中间元素。

```csharp
// C# 11.0 原始字符串（完美嵌套 JSON）
string json = """
{
    "name": "Bob",
    "age": 30,
    "isActive": true
}
""";

// required 关键字强制初始化
public class Config
{
    public required string ConnectionString { get; init; }
}
// 编译报错：必须赋值 ConnectionString
// var conf = new Config(); 

// 列表模式匹配
int[] numbers = { 1, 2, 3, 4, 5 };
if (numbers is [1, 2, .., 5]) // 匹配以 1,2 开头，以 5 结尾的任意长度数组
{
    // ...
}
```

## **C# 12.0 (2023) —— 构造优化与集合表达**

- **主构造函数 (Primary Constructors)：** 允许直接在类名后面声明构造函数参数，消除了手动声明私有字段并在构造函数中一一赋值的死板样板代码。此前该特性仅限于 record，现在开放给了所有普通的 class 和 struct。
- **集合表达式 (Collection Expressions [])：** 统一并极大地简化了所有集合（数组、List、Span 等）的初始化语法，并支持展开运算符 ..。
- **默认 Lambda 参数：** 允许 Lambda 表达式拥有带默认值的参数。

```csharp
// C# 12.0 主构造函数示例（极大地简化了依赖注入时的代码）
public class UserService(ILogger logger, IRepository repo)
{
    // logger 和 repo 可以在整个类中直接使用，无需声明私有字段
    public void Run() => logger.Log("Running...");
}

// 集合表达式与展开运算符
int[] array1 = [1, 2, 3];
int[] array2 = [4, 5, 6];
int[] combined = [..array1, ..array2, 7, 8]; // 结果: 1,2,3,4,5,6,7,8
```

## **C# 13.0 (2024 / .NET 9 引入) —— 性能极致榨取与扩展**

- **增强的 params 集合：** 在过去，params 关键字（可变参数）只能修饰数组（params int[] args）。C# 13 开始，params 支持了更高性能、分配更少的集合类型，如 `ReadOnlySpan<T>`，以及通用的 `IEnumerable<T> 或 List<T>`，极大提升了底层 API 的性能。
- **新的锁对象 (System.Threading.Lock)：** 引入了专门用于并发控制的新 Lock 类型。与过去使用 lock(object) 相比，新对象在底层进行了深度优化，降低了内存分配并提高了高并发场景下的吞吐量。

```csharp
// C# 13.0 增强的 params 与 ReadOnlySpan (避免了数组分配内存的开销)
public void ProcessData(params ReadOnlySpan<int> numbers)
{
    foreach (var num in numbers) { /* ... */ }
}

// 高性能锁对象
private readonly Lock _dataLock = new();
public void Update()
{
    using (_dataLock.EnterScope()) // 更加安全高效的锁机制
    {
        // 临界区代码
    }
}
```
