**关于 C# 语言基础词法单元 (Tokens) 的深度笔记**

# **一、 什么是 Token (词法单元)？**

在 C# 编程语言中，Token 是编译器能够识别的最小、最基本的语法单元。如果把编写代码比作写文章，那么 Token 就是构成文章的独立单词和标点符号。当 C# 编译器（CSC）读取源代码时，它的第一步工作就是将大段的代码拆解、分类为一个个 Token。

C# 中的 Token 主要分为四大核心类别：关键字、运算符、字面量和标识符。

# **二、 四大核心 Token 深度解析**

## **关键字 (Keywords)**
*   **定义：** 语言层面预先定义好的、具有特定语法意义的保留字。
*   **强制规则：** C# 是严格区分大小写的语言，**所有的系统关键字必须全部小写**。
*   **作用示例：**
    *   `class`：声明一个类。
    *   `struct`：声明一个结构体。
    *   `void`：声明一个方法不返回任何值。
    *   `private`：访问修饰符，限制成员只能在当前类内部被访问。
    *   `int`, `string`, `static` 等。

## **运算符 (Operators)**
*   **定义：** 用于执行特定的数学运算、逻辑判断或赋值操作的符号。
*   **运作机制：** 运算符通常接收一个或多个**操作数 (Operands)**，经过计算后返回一个单一的结果值。
*   **常见示例：**
    *   算术运算符：`+`（加）。例如在 `10 + 5` 中，`+` 是运算符，`10` 和 `5` 是操作数，返回结果为 `15`。
    *   赋值运算符：`=`。用于将右侧的值赋给左侧的变量。

## **字面量 (Literals)**
*   **定义：** 在源代码中直接硬编码写死的、固定的数据值。它们不需要声明，直接代表其自身的值。
*   **数据类型与格式规范：**
    *   **数值型：** 直接书写数字，无需任何引号（例如：`10`, `3.14`）。
    *   **字符型 (Char)：** 仅包含单个字符，**必须使用单引号**包裹（例如：`'A'`）。
    *   **字符串型 (String)：** 包含零个或多个字符的文本，**必须使用双引号**包裹（例如：`"Hello World"`, `"ABC"`）。
    *   **布尔型 (Boolean)：** 表示逻辑上的真或假，只有两个固定值：`true` 或 `false`。

## **标识符 (Identifiers)**
*   **定义：** 为程序中的各类元素（如命名空间、类、方法、变量、属性等）所起的名称。
*   **范畴（重要理解）：**
    *   **自定义名称：** 开发者自己创造的名字。例如自定义的类名 `Employee`、变量名 `x`、方法名 `CalculateSalary`。
    *   **框架预设名称：** .NET 框架底层（FCL/BCL）已经写好的类名和方法名，本质上也是标识符。例如 `System`（命名空间名）、`Console`（类名）、`WriteLine`（方法名）。它们虽然是系统提供的，但并不属于“关键字”，而是系统预先定义好的“标识符”。

# **三、 综合代码拆解说明**

为了更清晰地理解这四种 Token 是如何协同构成 C# 程序的，以下面这段代码为例进行逐词拆解：

```csharp
using System;

public class Program
{
    static void Main()
    {
        int age = 25;
        string name = "Alice";
        bool isStudent = true;
        
        int nextYearAge = age + 1;
        
        Console.WriteLine(name);
    }
}
```

**代码 Token 解析：**

1.  **关键字 (Keywords) - 蓝色字体（在大多数 IDE 中）：**
    *   `using`, `public`, `class`, `static`, `void`, `int`, `string`, `bool`
    *   它们构成了程序的骨架和类型系统。

2.  **标识符 (Identifiers) - 类的名字、变量的名字：**
    *   `System`（预定义的命名空间标识符）
    *   `Program`, `Main`（自定义的类和入口方法标识符）
    *   `age`, `name`, `isStudent`, `nextYearAge`（自定义的变量标识符）
    *   `Console`, `WriteLine`（框架预设的类和方法标识符）

3.  **运算符 (Operators) - 执行操作的符号：**
    *   `=`：赋值运算符，把右边的值装进左边的变量里。
    *   `+`：算术运算符，执行加法计算。

4.  **字面量 (Literals) - 固定的数据值：**
    *   `25`, `1`：整型字面量（没有引号）。
    *   `"Alice"`：字符串字面量（被双引号包裹）。
    *   `true`：布尔字面量。
