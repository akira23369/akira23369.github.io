**关于 C# 面向对象编程基础概念（类、对象、字段、方法）的深度笔记**

C# 是一门严格的**基于类（Class-based）**的面向对象编程语言。这意味着在 C# 中，所有的具体逻辑和数据结构都必须依附于类而存在，不能脱离类直接凭空创建独立的对象。

理解 C# 程序的结构，必须首先掌握以下四个核心基础术语。

# **一、 类 (Class) —— 对象的蓝图与类型**

*   **定义与本质：** 类是一个抽象的模型、模板或自定义的数据类型。它描述了一类事物的共同特征和行为规范，但它本身并不占用存储具体数据的物理内存（不存实体数据）。
*   **设计原则：** 类不仅规定了对象内部应该包含哪些数据（字段），还规定了对象能执行哪些操作（方法）。类绝对不是“对象的集合”，而是“对象的描述”。
*   **类比理解：** 如果把“城市”看作一个类，那么具体的“纽约”、“北京”就是这个类实例化出来的对象。类就像是建造房屋的设计图纸。

# **二、 对象 (Object) —— 类的物理实例**

*   **定义与本质：** 对象是客观物理世界或业务逻辑中具体存在的实体。在程序中，对象是根据类（蓝图）在内存中实际分配空间并创建出来的具体实例。
*   **独立性：** 基于同一个类，可以创建出无数个对象。每个对象在内存中都是相互独立的，修改其中一个对象的数据，不会影响其他对象。
*   **类比理解：** 根据上述房屋设计图纸（类）在现实中建造出来的、具体可以住人的那栋房子，就是对象。

# **三、 字段 (Fields) —— 对象的状态与数据**

*   **定义：** 字段是直接声明在类内部的变量。它们用于存储对象特有的细节信息或状态数据。
*   **内存分布：** 当一个对象被创建时，系统会为该对象专属的字段分配内存。不同的对象拥有各自独立的字段值。例如，两辆车（两个对象）都有 `Price`（价格）字段，但它们具体的价格数值是不同的。

# **四、 方法 (Methods) —— 对象的行为与逻辑**

*   **定义：** 方法是一组为了完成特定功能或处理特定逻辑而组织在一起的语句块。例如，读取输入、执行计算（如计算汽车的 EMI 贷款利息）、输出结果等。
*   **深度理解（内存优化机制）：** 方法虽然从属于对象，可以操作对象的字段，但**方法的代码逻辑本身并不实际存储在每一个对象的内存空间里**。如果创建了 100 个汽车对象，系统不会在内存中复制 100 份“计算利息”的方法代码。方法的代码在内存中只保留一份，所有该类的对象在调用时都会关联并共享这一段指令代码。这种设计极大地节省了系统内存。

# **五、 综合代码说明**

以下 C# 代码完整展示了类、对象、字段与方法之间的协同关系：

```csharp
// 1. 定义类 (Class)：汽车的蓝图类型
public class Car
{
    // 3. 定义字段 (Fields)：规定每个汽车对象必须具备的具体数据
    public string RegistrationNumber; // 车牌号
    public string Model;              // 车型
    public int Year;                  // 年份
    public double Price;              // 价格

    // 4. 定义方法 (Method)：规定汽车对象可以执行的计算逻辑
    public void CalculateEMI()
    {
        // 方法内部可以读取和操作当前对象的字段（如 Price 和 Model）
        double emi = Price * 0.05; 
        Console.WriteLine($"The EMI for {Model} is: {emi}");
    }
}

class Program
{
    static void Main()
    {
        // 2. 创建对象 (Object)：根据 Car 类，在内存中实例化两个具体的汽车实体
        Car car1 = new Car();
        Car car2 = new Car();

        // 为第一个对象 (car1) 的专属字段赋值
        car1.RegistrationNumber = "AB-1234";
        car1.Model = "Tesla Model 3";
        car1.Year = 2023;
        car1.Price = 300000;

        // 为第二个对象 (car2) 的专属字段赋值（数据与 car1 完全独立）
        car2.RegistrationNumber = "XY-9876";
        car2.Model = "Toyota Corolla";
        car2.Year = 2021;
        car2.Price = 150000;

        // 调用对象的方法：它们共享同一段逻辑代码，但处理的是各自独立的字段数据
        car1.CalculateEMI(); // 输出依赖于 car1 的 Price 和 Model
        car2.CalculateEMI(); // 输出依赖于 car2 的 Price 和 Model
    }
}
```

**总结：**
在即将开始的 C# 编程实践中，哪怕是最简单的控制台应用程序（如 `Hello World`），也必然被包裹在一个 `class` 结构中，并且程序的执行起点必定是一个名为 `Main` 的方法。这就是 C# 语言纯粹面向对象设计的底层逻辑体现。
