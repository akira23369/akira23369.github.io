## 一、核心语法速查表

### 基本关键字

- `is`：类型检查 + 模式匹配  
- `switch`：语句 / 表达式  
- 模式关键字：`and`, `or`, `not`  
- 通配符：`_`（兜底 / 忽略）  
- 范围：`<`, `<=`, `>`, `>=`  

---

### 常见模式一览

#### 类型模式

```csharp
if (obj is string s)
{
    Console.WriteLine(s.Length);
}
```

```csharp
switch (obj)
{
    case int i:
        ...
        break;
    case MyType t:
        ...
        break;
}
```

---

#### 常量模式

```csharp
var msg = code switch
{
    200 => "OK",
    404 => "Not Found",
    _   => "Unknown"
};
```

---

#### 关系模式

```csharp
string level = score switch
{
    < 60       => "不及格",
    >= 60 and < 80 => "良好",
    >= 80      => "优秀",
};
```

---

#### 逻辑模式

```csharp
if (score is >= 60 and < 90)
    Console.WriteLine("中等");

if (score is < 0 or > 100)
    Console.WriteLine("非法分数");

if (obj is not null)
    Console.WriteLine("非空");
```

---

#### 属性模式

```csharp
if (person is { Age: >= 18, Name: var name })
{
    Console.WriteLine($"{name} 是成年人");
}

string tag = order switch
{
    { Amount: >= 1000, Customer.IsVip: true } => "VIP",
    { Amount: >= 1000 }                       => "Big",
    _                                         => "Normal"
};
```

---

#### 位置模式

适用于 tuple 和定义了 `Deconstruct` 的类型 / record。

```csharp
(string, int) t = ("Alice", 30);

var desc = t switch
{
    ("Alice", _)   => "Alice",
    (_, < 18)      => "Child",
    _              => "Other"
};
```

```csharp
public record Point(int X, int Y);

string pos = new Point(0, 5) switch
{
    (0, 0)      => "Origin",
    (0, var y)  => "On Y axis",
    (var x, 0)  => "On X axis",
    _           => "Other"
};
```

---

#### 列表模式

```csharp
int[] arr = { 1, 2, 3, 4 };

if (arr is [])
    Console.WriteLine("空");

if (arr is [var only])
    Console.WriteLine($"单元素：{only}");

if (arr is [1, 2, ..])
    Console.WriteLine("以 1,2 开头");

if (arr is [var first, .. var rest])
    Console.WriteLine($"首：{first}，其余：{rest.Length} 个");
```

---

#### var 模式

```csharp
if (obj is var x)
{
    Console.WriteLine(x.GetType().Name);
}

string text = value switch
{
    int i    => $"Int: {i}",
    string s => $"String: {s}",
    var other => $"Other: {other}"
};
```

---

#### 守卫条件 `when`

```csharp
string desc = person switch
{
    { Age: var age } when age < 0   => "非法年龄",
    { Age: var age } when age < 18  => "未成年人",
    { Age: var age } when age < 60  => "成年人",
    _                               => "老年人"
};
```

## 二、常用“模式匹配模板”合集

这里是你可以直接复制进项目的模板。

### 模板 1：枚举 / 状态转移（状态机）

```csharp
OrderStatus Transit(OrderStatus current, OrderEvent ev) => (current, ev) switch
{
    (OrderStatus.Created, OrderEvent.Pay)    => OrderStatus.Paid,
    (OrderStatus.Created, OrderEvent.Cancel) => OrderStatus.Cancelled,
    (OrderStatus.Paid,    OrderEvent.Ship)   => OrderStatus.Shipped,
    (OrderStatus.Paid,    OrderEvent.Refund) => OrderStatus.Refunded,
    (OrderStatus.Shipped, OrderEvent.Complete) => OrderStatus.Completed,
    _ => throw new InvalidOperationException($"非法状态流转：{current} -> {ev}")
};
```

---

### 模板 2：DTO 输入验证（规则分支版）

```csharp
IEnumerable<string> Validate(CreateOrderRequest? req) => req switch
{
    null => new[] { "请求不能为空" },

    { UserId: <= 0 } => new[] { "用户 Id 非法" },

    { Items: null or [] } => new[] { "商品列表不能为空" },

    { Items: var items } when items.Any(i => i.ProductId <= 0)
        => new[] { "存在商品 Id 非法" },

    { Items: var items } when items.Any(i => i.Quantity <= 0)
        => new[] { "存在数量非法" },

    { PaymentMethod: not ("Online" or "Offline") }
        => new[] { "支付方式非法" },

    { PaymentMethod: "Offline", StoreId: null }
        => new[] { "线下支付必须指定门店" },

    _ => Array.Empty<string>()
};
```

### 模板 3：命令路由

```csharp
abstract record Command;
record CreateUser(string Name, string Email) : Command;
record ChangeEmail(int UserId, string NewEmail) : Command;
record DisableUser(int UserId) : Command;

Task HandleCommandAsync(Command cmd) => cmd switch
{
    CreateUser(var name, var email)      => HandleCreate(name, email),
    ChangeEmail(var id, var newEmail)    => HandleChangeEmail(id, newEmail),
    DisableUser(var id)                  => HandleDisable(id),
    _ => throw new InvalidOperationException("未知命令类型")
};
```

### 模板 4：错误分类 → HTTP Response

```csharp
abstract record Error;
record NetworkError(string Message, bool IsTimeout) : Error;
record AuthError(string Reason) : Error;
record ValidationError(string Field, string Message) : Error;
record UnknownError(Exception Exception) : Error;

record ServiceResult<T>(bool IsSuccess, T? Data, Error? Error);

IResult ToHttpResult<T>(ServiceResult<T> result) => result switch
{
    { IsSuccess: true, Data: var data } 
        => Results.Ok(data),

    { Error: NetworkError { IsTimeout: true } }
        => Results.StatusCode(StatusCodes.Status504GatewayTimeout),

    { Error: NetworkError { IsTimeout: false } }
        => Results.StatusCode(StatusCodes.Status503ServiceUnavailable),

    { Error: AuthError }
        => Results.Unauthorized(),

    { Error: ValidationError { Field: var field, Message: var msg } }
        => Results.BadRequest(new { Field = field, Message = msg }),

    { Error: UnknownError { Exception: var ex } }
        => Results.StatusCode(StatusCodes.Status500InternalServerError),

    _ => Results.StatusCode(StatusCodes.Status500InternalServerError)
};
```

## 三、练习题

下面给你几道练习题，每道题都可以用模式匹配写出“规则表风格”的解答。你可以先自己思考实现，再对照我之前的篇章自己检查。

### 练习 1：用户等级判定

定义：

```csharp
record User(
    bool IsAdmin,
    bool IsVip,
    int Score
);
```

要求实现：

```csharp
string GetLevel(User? u)
```

规则：

- `u` 为 null → `"Unknown"`  
- 管理员 → `"Admin"`（无视其他条件）  
- VIP + Score > 1000 → `"VIP-Diamond"`  
- VIP + Score > 500 → `"VIP-Gold"`  
- VIP 其他 → `"VIP"`  
- 非 VIP + Score > 800 → `"User-Plus"`  
- 其他 → `"User"`  

要求：

- 用 `switch 表达式` + 模式匹配  
- 优先级上：Admin > VIP-Diamond > VIP-Gold > VIP > User-Plus > User  

```cs
public record User(bool IsAdmin, bool IsVip, int Score);

public string GetLevel(User? u) => u switch
{
    null                          => "Unknown",
    { IsAdmin: true }             => "Admin",
    { IsVip: true, Score: > 1000 } => "VIP-Diamond",
    { IsVip: true, Score: > 500 }  => "VIP-Gold",
    { IsVip: true }               => "VIP",
    { IsVip: false, Score: > 800 } => "User-Plus",
    _                             => "User"
};
```

### 练习 2：简化的 HTTP 路由解析

有一个简单的 HTTP 请求模型：

```csharp
record HttpRequest(string Method, string Path);
```

实现：

```csharp
string Route(HttpRequest req)
```

规则例子：

- `GET /users` → `"ListUsers"`  
- `GET /users/{id}`（例如 `/users/123` 且 id 为数字） → `"GetUser:{id}"`  
- `POST /users` → `"CreateUser"`  
- `PUT /users/{id}` → `"UpdateUser:{id}"`  
- 其他 → `"NotFound"`  

思路提示：

- `Path.Split('/')` 得到一个 `string[] segments`；  
- 对 `(Method, segments)` 使用模式匹配；  
- 对 id 部分用 `when int.TryParse(...)` 校验并返回。

```cs
public record HttpRequest(string Method, string Path);

public string Route(HttpRequest req)
{
    // 预处理：去掉首尾斜杠并拆分段
    string[] segments = req.Path.Trim('/').Split('/');

    return (req.Method, segments) switch
    {
        // GET /users
        ("GET", ["users"]) => "ListUsers",

        // GET /users/{id} (需为数字)
        ("GET", ["users", var id]) when int.TryParse(id, out _) 
            => $"GetUser:{id}",

        // POST /users
        ("POST", ["users"]) => "CreateUser",

        // PUT /users/{id} (需为数字)
        ("PUT", ["users", var id]) when int.TryParse(id, out _) 
            => $"UpdateUser:{id}",

        // 其他所有情况
        _ => "NotFound"
    };
}
```

### 练习 3：日志级别和分类

定义：

```csharp
enum LogLevel { Trace, Debug, Info, Warn, Error, Fatal }

record LogEntry(LogLevel Level, string Source, string Message);
```

要求实现：

```csharp
string GetLogTag(LogEntry entry)
```

规则：

- Level 为 `Error` 或 `Fatal` → `"ALERT"`  
- Level 为 `Warn` 且 Source 包含 `"Security"` → `"SECURITY"`  
- Level 为 `Info` 且 Source 为 `"System"` → `"SYSTEM_INFO"`  
- 其他 → `"NORMAL"`  

要求：

- 使用 switch 表达式 + 关系/逻辑模式/`when`；  
- 强调可读性，适当拆分辅助函数。  

```cs
public enum LogLevel { Trace, Debug, Info, Warn, Error, Fatal }
public record LogEntry(LogLevel Level, string Source, string Message);

public string GetLogTag(LogEntry entry) => entry switch
{
    // 使用逻辑模式 (or) 处理多个枚举值
    { Level: LogLevel.Error or LogLevel.Fatal } 
        => "ALERT",

    // 结合属性模式与 when 子句处理字符串包含关系
    { Level: LogLevel.Warn, Source: var src } when IsSecurityRelated(src) 
        => "SECURITY",

    // 精确匹配属性值
    { Level: LogLevel.Info, Source: "System" } 
        => "SYSTEM_INFO",

    // 默认情况
    _ => "NORMAL"
};

// 辅助函数：提取复杂的字符串逻辑，提高可读性
private static bool IsSecurityRelated(string source) => 
    source.Contains("Security", StringComparison.OrdinalIgnoreCase);
```

### 练习 4：订单风控规则（进阶）

可自行设计模型，例如：

```csharp
record RiskContext(
    decimal Amount,
    bool IsNewUser,
    string Country,
    bool IpSuspicious
);
```

写一个：

```csharp
string GetRiskLevel(RiskContext ctx)
```

自拟规则，比如：

- 新用户 + 大额 + 可疑 IP → `"High"`  
- 老用户 + 大额 + 海外 → `"Medium"`  
- 其他 → `"Low"`  

尝试用属性模式 + 关系模式 + `when` 组合写出一个清晰的规则表。

```cs
public record RiskContext(
    decimal Amount,
    bool IsNewUser,
    string Country,
    bool IpSuspicious
);

public string GetRiskLevel(RiskContext ctx) => ctx switch
{
    // 1. 高风险：新用户且金额大，同时 IP 可疑
    { IsNewUser: true, Amount: > 10000, IpSuspicious: true } 
        => "Critical-High",

    // 2. 高风险：任何 IP 可疑且金额巨大的情况
    { IpSuspicious: true, Amount: > 50000 } 
        => "High-Suspicious",

    // 3. 中风险：老用户大额跨境交易 (使用 not 模式)
    { IsNewUser: false, Amount: > 20000, Country: not "CN" } 
        => "Medium-Overseas",

    // 4. 中风险：新用户的中等金额尝试
    { IsNewUser: true, Amount: > 1000 and <= 10000 } 
        => "Medium-NewUser",

    // 5. 低风险：可信 IP 的小额交易 (使用 when 进一步过滤)
    { IpSuspicious: false } when ctx.Amount < 500 
        => "Low-Safe",

    // 6. 兜底
    _ => "Low"
};
```

## 四、如何继续进阶？

如果后续你还想在模式匹配和“更函数式”的 C# 上更进一步，可以考虑：

1. 多看 F# / Scala / Rust 中的 pattern matching 示例，  
   拿来对照着在 C# 里实现类似风格（你已经有了语法基础）。

2. 在自己项目中建立一些“模式匹配惯例”：  
   - DTO 分类 → 全用 `switch 表达式 + 属性模式`；  
   - 状态机 → 全用 `(State, Event) switch`；  
   - 错误分类 → 全用 `{ Error: X } switch`；  
   累积出一套适合团队的“pattern 风格库”。

3. 结合单元测试  
   用测试来锁定规则表行为（特别是状态机、风控、营销策略等），  
   在重构成模式匹配前后，确保行为一致。
