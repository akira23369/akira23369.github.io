# C# 各种模式类型详解

> 本文目标：  
> - 掌握 C# 支持的各种主要模式类型及其语法  
> - 理解每种模式适用于哪些场景  
> - 能在实际项目中灵活组合使用不同模式，提高代码表达力和可维护性  

---

## 一、引言：什么是“模式类型”

在 C# 中，**模式（pattern）** 代表“我期望匹配的形态或条件”。  
**模式类型（pattern kind）** 就是“匹配规则的种类”。

比如：
- “是某个类型” → 类型模式（Type Pattern）  
- “等于某个常量值” → 常量模式（Constant Pattern）  
- “大于 10 并且小于 100” → 关系模式（Relational Pattern）  
- “具有特定属性结构” → 属性模式（Property Pattern）  
- “是一个列表、数组，并且元素符合模式” → 列表模式（List Pattern）  

模式匹配的强大之处在于，你可以**混合这些模式**形成复杂逻辑，而不需要到处写 `if-else`。

---

## 二、C# 模式系统全景图

可以按以下层次进行归类：

| 分类   | 模式类型                 | 简要说明                 |
| ---- | -------------------- | -------------------- |
| 基础匹配 | 类型模式 (Type)          | 检查类型并可绑定变量           |
| 值匹配  | 常量模式 (Constant)      | 与具体值比较               |
| 比较匹配 | 关系模式 (Relational)    | 大小关系判断               |
| 逻辑组合 | 逻辑模式 (Logical)       | and / or / not 的逻辑组合 |
| 属性匹配 | 属性模式 (Property)      | 匹配对象的一个或多个属性         |
| 结构匹配 | 位置模式 (Positional)    | Deconstruct 解构匹配     |
| 集合匹配 | 列表模式 (List Pattern)  | 匹配数组、列表的元素形态         |
| 变量捕获 | var 模式 (Var Pattern) | 捕获匹配结果或兜底模式          |

---

## 三、类型模式

最常见的模式类型。  
用于检测对象类型，并在匹配时“绑定”变量。

### 基本语法

```csharp
if (obj is string s)
{
    Console.WriteLine($"字符串长度为：{s.Length}");
}
```

如果 `obj` 不是字符串，条件为 false；  
如果是字符串，则自动创建名为 `s` 的强类型变量。

### 更多示例
```csharp
void PrintShapeArea(object shape)
{
    switch (shape)
    {
        case Circle c:
            Console.WriteLine($"圆面积: {Math.PI * c.Radius * c.Radius}");
            break;

        case Rectangle r:
            Console.WriteLine($"矩形面积: {r.Width * r.Height}");
            break;

        case null:
            Console.WriteLine("空引用");
            break;

        default:
            Console.WriteLine("未知图形");
            break;
    }
}
```

**特点：**
- 自动类型转换；
- 安全（不会抛出 `InvalidCastException`）；
- 可与其他模式在 `switch` 中组合。

## 四、常量模式

检查一个值是否“等于”某个常量。  
通常用于枚举、数值、字符串等简单值。

### 示例
```csharp
int code = 404;

string message = code switch
{
    200 => "OK",
    404 => "Not Found",
    500 => "Server Error",
    _   => "Unknown"
};
```

在这里每个数字都是一个常量模式。  
这类写法对比传统 `switch (code) { case 404: ... }` 更简洁，且支持 **更复杂的组合表达式**（与 `when` 或 `and` 一起使用时尤其强大）。

---

## 五、关系模式

C# 9 引入。  
用 `<`, `<=`, `>`, `>=` 来判断数值范围等。

### 示例
```csharp
int temperature = 30;

string description = temperature switch
{
    < 0 => "结冰",
    >= 0 and < 10 => "寒冷",
    >= 10 and < 25 => "温和",
    >= 25 and < 35 => "炎热",
    _ => "高温警告"
};
```

非常贴合逻辑判断语义。

**特点：**
- 简洁，避免了大量 `if (x> && x<)`；
- 支持与 `and`, `or` 组合；
- 可嵌套在更复杂结构中（如属性判断）。

---

## 六、逻辑模式

用于将多个条件**用逻辑运算连接起来**。  
关键字有：
- `and`（且）
- `or`（或）
- `not`（非）

### 示例1：and 与 or
```csharp
int score = 85;

if (score is >= 60 and < 90)
    Console.WriteLine("中等成绩");

if (score is < 0 or > 100)
    Console.WriteLine("异常分数");
```

### 示例2：not
```csharp
if (obj is not null)
    Console.WriteLine(obj.ToString());
```

逻辑模式让条件逻辑结构化，摆脱复杂嵌套的布尔表达式。

---

## 七、属性模式

可以检查对象的属性值。  
非常适合业务实体对象的判断与分支。

### 示例1：基本用法
```csharp
var person = new Person { Name = "Alice", Age = 25 };

if (person is { Age: >= 18, Name: var name })
{
    Console.WriteLine($"{name} 是成年人");
}
```

解读：
- `person is { ... }` 表示匹配其属性集合；
- `Age: >= 18` 是内层模式（关系模式嵌套）；
- `Name: var name` 表示提取属性值到变量。

### 示例2：在 switch 表达式中使用
```csharp
string Level(Person p) => p switch
{
    { Age: < 13 } => "儿童",
    { Age: >= 13 and < 20 } => "青少年",
    { Age: >= 20 and < 60 } => "成年",
    { Age: >= 60 } => "老年",
    _ => "未知"
};
```

### 优点
- 不需要调用属性再写子逻辑；
- 对象结构清晰直观；
- 可以嵌套、组合。

## 八、位置模式

要使用位置模式，你的类（Class）或结构体（Struct）必须有一个 `Deconstruct` 方法，或者它本身是一个 **Record**或者元组（tuple）。
位置模式的核心在于**解构 (Deconstruction)**。它允许你直接把一个对象“拆解”开，按顺序提取其中的值。
要让一个类支持位置模式，它必须具备以下条件之一：
1. 是一个 **Record**（编译器自动生成解构器）。
2. 或者定义了 **`Deconstruct` 方法**。
3. 或者它本身是一个 **Tuple (元组)**。
### 示例1：元组
```csharp
var point = (3, 4);

string desc = point switch
{
    (0, 0) => "原点",
    (var x, 0) => $"X 轴上方点 ({x}, 0)",
    (0, var y) => $"Y 轴上方点 (0, {y})",
    (var x, var y) => $"普通点 ({x}, {y})"
};

Console.WriteLine(desc);
```

### 示例2：自定义类型
```csharp
public class Order
{
    public int Id { get; set; }
    public decimal Price { get; set; }
    public string Status { get; set; }

    // 必须叫这个名字，且必须用 out 参数
    public void Deconstruct(out decimal price, out string status)
    {
        price = Price;
        status = Status;
    }
}

// 使用位置模式
string CheckOrder(Order o) => o switch
{
    ( > 1000, "Pending") => "高价值待处理订单",
    ( < 10, _) => "小额订单",
    _ => "常规订单"
};


class Point
{
    public int X { get; }
    public int Y { get; }
    public void Deconstruct(out int x, out int y) => (x, y) = (X, Y);

    public Point(int x, int y) => (X, Y) = (x, y);
}

var p = new Point(0, 5);

if (p is (_, > 0))
    Console.WriteLine("在Y轴正半区");
```

**解释：**
- `(_, > 0)` 表示忽略第一个位置，仅关心第二个；
- 可以使用 `_` 省略模式；
- 非常简洁优雅，适合处理结构体与元组数据。

## 九、列表模式（C# 11 新特性）

列表模式用于匹配数组或集合是否符合某种结构。

### 示例1：匹配数组长度和内容
```csharp
int[] numbers = { 1, 2, 3, 4 };

if (numbers is [1, 2, 3, 4])
    Console.WriteLine("完全匹配");

if (numbers is [1, 2, ..])
    Console.WriteLine("以 1, 2 开头");
```

这里的 `..` 表示“剩余元素任意”。

### 示例2：结合变量捕获
```csharp
if (numbers is [var first, .., var last])
    Console.WriteLine($"首位是 {first}, 末位是 {last}");
    
    
string[] names = { "Alice", "Bob", "Charlie" };

// 匹配长度为3的数组，确保第一个是 Alice，并把第二个元素提取到变量 bob 中
if (names is ["Alice", var secondName, _])
{
    Console.WriteLine($"提取到了：{secondName}"); // 输出：提取到了：Bob
}
```

### 示例3：用于模式匹配表达式
```csharp
string Describe(int[] arr) => arr switch
{
    [] => "空数组",
    [var single] => $"单元素数组：{single}",
    [1, 2, .. var rest] => $"以 1,2 开头，剩余 {rest.Length} 项",
    _ => "其他情况"
};
```

**说明：**
- 列表模式非常适合解析消息包、命令序列、模式化输入；
- `..` 可灵活忽略、不关心中间部分。

## 十、Var 模式

`var` 模式用来接收匹配结果（哪怕是任何对象）。  
看似简单，却在「保底匹配」「占位存取」中很常用。

### 示例
```csharp
object data = new { Name = "Tom" };

if (data is var result)
{
    Console.WriteLine($"捕获的类型：{result.GetType().Name}");
}
```

### 在 switch 中用作兜底：
```csharp
string desc = data switch
{
    int i => $"整数 {i}",
    string s => $"字符串 {s}",
    var other => $"其他类型：{other.GetType().Name}"
};
```


### 提取子列表

```cs
int[] scores = { 100, 85, 92, 78, 60 };

// 匹配首尾，并把中间的所有成绩提取到 middleScores 变量中
if (scores is [100, .. var middleScores, 60])
{
    // middleScores 是一个包含了 { 85, 92, 78 } 的数组/切片！
    Console.WriteLine($"中间有 {middleScores.Length} 个成绩"); 
}
```

## 十一、模式类型的组合使用

所有模式类型都可以互相嵌套或逻辑运算。

### 示例1：属性+关系模式
```csharp
if (person is { Age: >= 18 and <= 30 })
    Console.WriteLine("青年");
```

### 示例2：属性+位置模式结合
```csharp
if (order is { Items: [var first, ..], Total: > 0 })
    Console.WriteLine($"第一件商品是 {first}");
```

### 示例3：逻辑组合
```csharp
if (value is not null and not "")
    Console.WriteLine("字符串非空");
```

## 十二、常见误区与注意事项

| 场景 | 正确做法 | 错误或陷阱 |
|------|-----------|-------------|
| 判断 null | `is null` / `is not null` | 不要与 `== null` 混用，尤其是在重载 `==` 的类型上 |
| 嵌套属性路径 | `{ Address.City: "北京" }` | 要确保 `Address` 不为 null，否则结果为 false 而非异常 |
| 模式顺序 | 从最具体到最通用 | `_` 模式放在最后，否则遮蔽后续分支 |
| 性能关注 | 编译器会优化模式分支 | 不必担心性能问题，除非极端循环体内使用 |

## 十三、总结：模式类型的对比与选择建议

| 模式类型 | 主要用途 | 常见场景 | 版本 |
|-----------|------------|-----------|------|
| **类型模式** | 检查类型并绑定 | 异构对象分派 | C# 7 |
| **常量模式** | 与固定值比较 | 枚举、返回码判断 | C# 7 |
| **关系模式** | 比较范围 | 数值分类 | C# 9 |
| **逻辑模式** | 组合逻辑 | 等价于复杂条件 | C# 9 |
| **属性模式** | 匹配对象属性 | 实体判断、过滤 | C# 8 |
| **位置模式** | 匹配结构顺序 / Deconstruct | 元组、记录类型 | C# 8 |
| **列表模式** | 匹配数组和集合 | 命令输入、数据结构 | C# 11 |
| **var 模式** | 捕获任意结果 | 兜底、调试 | C# 7+ |

## 十四、实践练习：从 if...else 到模式匹配的转化

### 旧写法：
```csharp
if (order != null && order.Amount > 1000 && order.Customer != null && order.Customer.IsVip)
    discount = 0.9;
else if (order != null && order.Amount > 500)
    discount = 0.95;
else
    discount = 1.0;
```

### 新写法（属性+关系+逻辑模式）：
```csharp
discount = order switch
{
    { Amount: > 1000, Customer.IsVip: true } => 0.9,
    { Amount: > 500 } => 0.95,
    _ => 1.0
};
```

结果相同，代码表达力却更强、更清晰、更容易维护。
