# System.Text.RegularExpressions命名空间
[System.Text.RegularExpressions 命名空间 | Microsoft Learn](https://learn.microsoft.com/zh-cn/dotnet/api/system.text.regularexpressions?view=net-10.0)


## 核心对象模型图解
掌握了正则表达式的语法，那么在 C# 中使用它就只需要了解 .NET 提供的**面向对象的正则封装模型**即可。

在 C# 中，正则表达式不是简单的几个函数，而是一套层级分明的对象模型。理解这个层级是掌握 C# 正则的关键：

> **`Regex`** (正则引擎/模式)
> └── **`MatchCollection`** (所有匹配结果的集合)
> 　　└── **`Match`** (单个匹配结果)
> 　　　　└── **`GroupCollection`** (单个匹配中的所有捕获组集合)
> 　　　　　　└── **`Group`** (单个捕获组，例如 `(\d+)`)
> 　　　　　　　　└── **`CaptureCollection`** (底层捕获历史，一般极少用到)

## 核心引擎类：`Regex`
这是打交道最多的类。它代表了一个编译后（或解析好）的正则表达式模式。
[Regex 类 (System.Text.RegularExpressions) | Microsoft Learn](https://learn.microsoft.com/zh-cn/dotnet/api/system.text.regularexpressions.regex?view=net-10.0#explicit-interface-implementations)


### 构造函数
*   `Regex(string pattern)`：传入正则字符串。
*   `Regex(string pattern, RegexOptions options)`：传入正则字符串和选项（如忽略大小写）。
*   `Regex(string pattern, RegexOptions options, TimeSpan matchTimeout)`：**微软强烈推荐**，设置超时时间，防止恶意正则导致死循环（ReDoS 攻击）。

### 常用枚举：`RegexOptions`
在实例化 `Regex` 时，可以通过按位或（`|`）组合这些选项：
*   `IgnoreCase`：等同于正则末尾的 `i` 修饰符。
*   `Multiline`：等同于 `m`，使 `^` 和 `$` 匹配每一行的首尾，而不是整个字符串的首尾。
*   `Singleline`：等同于 `s`，使 `.` 可以匹配换行符（`\n`）。
*   `IgnorePatternWhitespace`：等同于 `x`，忽略正则字符串中的非转义空白，并允许使用 `#` 写注释。
*   `Compiled`：**C#特有**。将正则编译为独立程序集，加快执行速度，但会增加启动时间和内存。**仅适用于被极其频繁调用的正则**。

### 常用方法（支持静态调用和实例调用）
*微软设计了静态方法（如 `Regex.IsMatch(...)`）和实例方法（`new Regex(...).IsMatch(...)`）。静态方法底层有一个内部缓存（默认缓存15个最近用过的模式），偶尔用用很方便；如果频繁使用同一个模式，建议创建实例。*

***`IsMatch(string input)` -> `bool`**
***作用**：判断输入字符串是否符合正则模式。通常用于**表单验证**（如验证邮箱、手机号）。
```cs
bool isValid = Regex.IsMatch("test@email.com", @"^\w+@\w+\.\w+$");
```


***`Match(string input)` -> `Match`**
***作用**：在字符串中搜索**第一个**匹配项。
```cs
Regex rx = new Regex(@"\d+");
Match m = rx.Match("abc123def456"); // 只会匹配到 "123"
```

***`Matches(string input)` -> `MatchCollection`**
***作用**：在字符串中搜索**所有**匹配项。常用于数据提取（爬虫、日志分析）。
```cs
MatchCollection matches = Regex.Matches("abc123def456", @"\d+"); // 匹配到 "123" 和 "456"
```


***`Replace(string input, string replacement)` -> `string`**
***作用**：替换匹配到的文本。`replacement` 中可以使用 `$1`、`${name}` 来引用捕获组。
```cs
string result = Regex.Replace("apple 123 banana", @"\d+", "XX"); // "apple XX banana"
```


***`Split(string input)` -> `string[]`**
***作用**：以匹配到的文本作为分隔符，拆分字符串。
```cs
string[] parts = Regex.Split("A,B;C|D", @"[,;|]"); // 返回 ["A", "B", "C", "D"]
```

## 结果类：`Match` 与 `MatchCollection`

### `MatchCollection` 类
它就是一个只读集合，实现了 `IEnumerable<Match>`。
*   **属性 `Count`**：匹配到的总次数。
*   可以通过 `foreach` 遍历出每一个 `Match` 对象。
```cs
MatchCollection matches = Regex.Matches("ID:123, ID:456", @"\d+");
foreach (Match m in matches)
{
    Console.WriteLine($"找到: {m.Value}，位置: {m.Index}");
}
```

### `Match` 类
表示一次成功的匹配。
*   **属性 `Success` (`bool`)**：非常重要！调用 `Match()` 后，第一件事就是检查它是否为 `true`。
*   **属性 `Value` (`string`)**：匹配到的完整子字符串。
*   **属性 `Index` (`int`)**：匹配项在原字符串中的起始索引。
*   **属性 `Length` (`int`)**：匹配项的长度。
*   **属性 `Groups` (`GroupCollection`)**：包含该次匹配中的所有捕获组。

*   **方法 `NextMatch()`**：返回下一个匹配项。适合用在 `while (match.Success)` 循环中（比 `Matches` 节省内存，因为是延迟执行的）。
```cs
Match match = Regex.Match("11 22 33", @"\d+");
while (match.Success)
{
    Console.WriteLine(match.Value);
    match = match.NextMatch(); // 移至下一个
}
```

## 分组类：`Group`
如果你在正则中使用了括号 `()` 进行捕获，结果就会存放在这里。

*   **索引器获取**：
    *   `match.Groups[1]`：获取第一个匿名捕获组（`Groups[0]` 永远等同于 `match.Value`，即整个匹配结果）。
    *   `match.Groups["name"]`：如果你用了命名捕获组 `(?<name>...)`，可以直接通过名字拿。
*   **属性 `Success` (`bool`)**：该组是否真的捕获到了内容（在使用 `?` 量词或分支 `|` 时很有用）。
*   **属性 `Value` (`string`)**：该组捕获到的具体文本。
*   **属性 `Index` (`int`)**：在原始字符串中找到捕获的子字符串的第一个字符的位置。
*   **属性 `Length` (`int`)**： 获取捕获的子字符串的长度。

```cs
// 匹配形如 "Name: Tom, Age: 20"
string input = "Name: Tom, Age: 20";
// 定义命名捕获组 <name> 和 <age>
Regex rx = new Regex(@"Name:\s*(?<name>\w+),\s*Age:\s*(?<age>\d+)");

Match match = rx.Match(input);
if (match.Success)
{
    // 通过名称提取
    string name = match.Groups["name"].Value; // "Tom"
    string age = match.Groups["age"].Value;   // "20"
}
```

## 综合实战代码示例

假设我们有一段文本，需要提取其中的商品信息（格式：`[商品编号] 商品名 - 价格`）：

```csharp
using System;
using System.Text.RegularExpressions;

public class RegexDemo
{
    static void Main()
    {
        string input = @"
            [A100] Apple - $1.99
            [B200] Banana - $2.50
            [C300] Cherry - $3.00
        ";

        // 1. 定义正则，使用命名捕获组 (?<name>...)，并开启忽略空白和多行模式
        // 推荐在字符串前面加上 @，这样就不用写双斜杠 \\d 了
        string pattern = @"^\s*\[(?<id>[A-Z]\d{3})\]\s+(?<name>\w+)\s+-\s+\$(?<price>\d+\.\d{2})\r?$";

        // 2. 实例化 Regex 对象 (推荐做法)
        Regex regex = new Regex(pattern, RegexOptions.Multiline);

        // --- 场景 A：验证是否有匹配 (IsMatch) ---
        if (regex.IsMatch(input))
        {
            Console.WriteLine("✅ 文本中包含符合格式的商品数据。\n");
        }

        // --- 场景 B：提取所有匹配的数据 (Matches -> Match -> Group) ---
        MatchCollection matches = regex.Matches(input);
        Console.WriteLine($"共找到 {matches.Count} 个商品：");

        foreach (Match match in matches)
        {
            // 获取命名捕获组的值
            string id = match.Groups["id"].Value;
            string name = match.Groups["name"].Value;
            string price = match.Groups["price"].Value;

            Console.WriteLine($"- ID: {id}, 名称: {name}, 价格: {price}");
            // 输出索引位置
            Console.WriteLine($"  (该匹配所在位置: {match.Index}, 长度: {match.Length})");
        }

        // --- 场景 C：正则替换 (Replace) ---
        // 把价格打8折，注意：正则的 Replace 支持使用委托(Delegate)来进行复杂的逻辑替换
        string discountedInput = regex.Replace(input, match =>
        {
            double price = double.Parse(match.Groups["price"].Value);
            double newPrice = price * 0.8;
            // $1 和 $2 代表原来捕获的 ID 和 Name 的位置，手动拼接新价格
            return $"[{match.Groups["id"].Value}] {match.Groups["name"].Value} - ${newPrice:F2}";
        });

        Console.WriteLine("\n🎉 打折后的文本:");
        Console.WriteLine(discountedInput);
    }
}
```


**“提取一加公司名，以及它后面跟随的任意多个产品名”**。

```cs
public class RegexObjectModelDemo
{
    public static void Main()
    {
        // 假设我们要解析这样的日志格式：[公司名称]: 产品1, 产品2, 产品3;
        string input = @"
            [Apple]: Mac, iPad, iPhone;
            [Microsoft]: Windows, Xbox;
        ";

        // 正则解析：
        // 1. \[(?<Company>\w+)\]        -> 匹配公司名，放入 Company 组
        // 2. :\s*                       -> 匹配冒号和空白
        // 3. (?: (?<Product>\w+) [,\s]* )+ -> 重点！匹配产品名放入 Product 组。
        //    外面包裹的 (?: ... )+ 是非捕获组配合加号，表示括号里的动作会重复多次！
        string pattern = @"\[(?<Company>\w+)\]:\s*(?:(?<Product>\w+)[,\s]*)+;";

        // 创建正则对象
        Regex regex = new Regex(pattern);
        MatchCollection matches = regex.Matches(input);

        Console.WriteLine($"总共找到了 {matches.Count} 条记录：\n");

        foreach (Match match in matches)
        {
            Console.WriteLine($"【第一层：Match完整匹配】");
            Console.WriteLine($"  完整文本 (Match.Value) : {match.Value}");

            // --- 第二层：Group ---
            Group companyGroup = match.Groups["Company"];
            Group productGroup = match.Groups["Product"];

            Console.WriteLine($"\n【第二层：Group捕获组】");
            Console.WriteLine($"  公司名 (Groups[\"Company\"].Value) : {companyGroup.Value}");

            // 注意！这里只能拿到最后一个产品，因为前面的被覆盖了！
            Console.WriteLine($"  最后被捕获的产品 (Groups[\"Product\"].Value) : {productGroup.Value}");

            // --- 第三层：Capture ---
            Console.WriteLine($"\n【第三层：Capture底层捕获历史】");
            Console.WriteLine($"  因为 Product 组被匹配了多次，我们去 Captures 集合里找回所有产品：");

            CaptureCollection productCaptures = productGroup.Captures;
            for (int i = 0; i < productCaptures.Count; i++)
            {
                Capture capture = productCaptures[i];
                Console.WriteLine($"    - 产品 {i + 1}: {capture.Value} (在原字符串索引 {capture.Index} 处)");
            }

            Console.WriteLine(new string('-', 50));
        }
    }
}
```

## .NET 现代开发补充 (微软最新实践)

如果你使用的是 **.NET 7 或更高版本**（C# 11+），微软强烈建议不要再使用 `new Regex(...)`，而是使用**源生成器 (Source Generators)**。

这可以通过在 `partial` 类的 `partial` 方法上打上 `[GeneratedRegex]` 特性来实现：

```csharp
public partial class MyRegexUtils
{
    // 编译时会自动生成高性能的正则是现代码！极大提升性能！
    [GeneratedRegex(@"^\d{3}-\d{4}$", RegexOptions.IgnoreCase, matchTimeoutMilliseconds: 1000)]
    public static partial Regex PhoneNumberRegex();
    
    public void Test()
    {
        bool isValid = PhoneNumberRegex().IsMatch("123-4567");
    }
}
```

## 总结
作为已经懂正则语法的人，你只需要记住 C# 的套路：
1. 验证格式用 `Regex.IsMatch`。
2. 抓取数据用 `Regex.Matches` -> 遍历 `Match` -> 读 `Match.Groups["名字"].Value`。
3. 复杂替换用 `Regex.Replace` (配合委托函数)。
4. 实例化正则时最好加上 `@` 前缀防止转义地狱，最好设置 Timeout。
