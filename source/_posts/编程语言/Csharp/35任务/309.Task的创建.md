# Task的创建

## 一、Task.Run()——最常用，无脑用

**大白话**：`Task.Run()` 就像点外卖，你把订单（任务）扔给平台，平台自动派给骑手（线程池），你只管等送餐，不用管骑手是谁、从哪来。

**特点**：
- **最简单**：一行代码搞定
- **最智能**：自动用线程池，性能最好
- **最推荐**：90%场景用它就够了

**代码示例**：
```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

class Program
{
    static void Main()
    {
        Console.WriteLine($"主线程 {Thread.CurrentThread.ManagedThreadId}: 开始下订单...");
        
        // 1. 无返回值任务
        Task.Run(() => {
            Console.WriteLine($"线程 {Thread.CurrentThread.ManagedThreadId}: 开始送外卖");
            Thread.Sleep(1000);
            Console.WriteLine($"线程 {Thread.CurrentThread.ManagedThreadId}: 外卖送达！");
        });
        
        // 2. 有返回值任务
        Task<int> orderTask = Task.Run(() => {
            Console.WriteLine($"线程 {Thread.CurrentThread.ManagedThreadId}: 计算价格...");
            Thread.Sleep(500);
            return 42; // 返回结果
        });
        
        Console.WriteLine($"主线程: 订单已提交，我继续追剧...");
        
        // 取结果（会阻塞，后面讲）
        int price = orderTask.Result;
        Console.WriteLine($"主线程: 收到账单，总价 {price} 元");
        
        Thread.Sleep(2000); // 等无返回值任务跑完
    }
}
```

**输出**：
```
主线程 1: 开始下订单...
主线程: 订单已提交，我继续追剧...
线程 5: 开始送外卖
线程 6: 计算价格...
线程 6: 计算完成，返回 42
主线程: 收到账单，总价 42 元
线程 5: 外卖送达！
```

**适用场景**：
- CPU 密集型计算
- 简单的后台任务
- 不需要精细控制的场景

## 二、Task.Factory.StartNew()——老方法，功能更细

**大白话**：`Task.Factory.StartNew()` 就像你打电话给外卖平台客服，可以指定"用哪个骑手"、"要不要保温箱"等高级选项。功能多，但麻烦。

**特点**：
- **更灵活**：可以指定调度器、任务选项、取消令牌
- **更啰嗦**：参数多，代码长
- **不推荐新手用**：除非你有特殊需求

**代码示例**：
```csharp
static void Main()
{
    // 1. 基础用法（效果跟 Task.Run() 一样）
    Task.Factory.StartNew(() => DoWork());
    
    // 2. 指定任务选项（告诉调度器这是长任务）
    Task.Factory.StartNew(
        () => LongWork(),
        TaskCreationOptions.LongRunning // 选项：这是长任务
    );
    
    // 3. 带取消令牌（可以中途取消，后面细讲）
    CancellationTokenSource cts = new CancellationTokenSource();
    Task.Factory.StartNew(
        () => WorkWithCancel(cts.Token),
        cts.Token
    );
    
    Thread.Sleep(500);
    cts.Cancel(); // 取消任务
}

static void DoWork() => Console.WriteLine("工作");
static void LongWork() => Thread.Sleep(5000); // 模拟长任务
static void WorkWithCancel(CancellationToken token)
{
    while (!token.IsCancellationRequested)
    {
        Console.WriteLine("工作中...");
        Thread.Sleep(200);
    }
    Console.WriteLine("任务被取消");
}
```

**TaskCreationOptions 选项**（简单了解）：
- `None`：默认
- `LongRunning`：告诉调度器"这是长任务"，建议新建线程，不要用线程池
- `PreferFairness`：希望任务按提交顺序执行（不保证）
- `AttachedToParent`：任务作为子任务，父任务等子任务

**适用场景**：
- 需要指定 LongRunning 的长任务
- 需要精细控制调度器（99%的人用不到）

## 三、new Task() + Start()——脱裤子放屁，别用

**大白话**：先 `new Task()` 再 `Start()`，就像你先点外卖但不提交订单，过一会再提交——多此一举。

**特点**：
- **多此一举**：Task.Run() 内部就是 new+Start，封装好了
- **容易忘 Start**：创建后忘记 Start，任务永远不执行
- **不推荐**：代码啰嗦，易出错

**代码示例（别学，只看别用）**：
```csharp
static void Main()
{
    // 1. 创建任务（但不执行）
    Task task = new Task(() => {
        Console.WriteLine("任务执行");
    });
    
    Console.WriteLine("任务已创建，还没开始");
    
    // 2. 手动启动（必须调用 Start）
    task.Start(); // 如果忘了这行，任务永远不跑
    
    task.Wait(); // 等任务完成
}
```

**唯一适用场景**（几乎遇不到）：
- 你想**先创建任务，但不马上跑**，等某个条件满足再 Start
- 99.999%的情况用 Task.Run() 就行

## 四、快速创建已完成/失败的任务

### `Task.FromResult()`——同步返回结果

**场景**：你有一个同步方法，但接口要求返回 Task，不想真的开线程。

```csharp
static Task<int> CalculateAsync()
{
    // 直接返回一个已完成的任务，值为42
    return Task.FromResult(42); // 不开线程，立即完成
}

static void Main()
{
    Task<int> task = CalculateAsync();
    Console.WriteLine($"结果: {task.Result}"); // 立即拿到42
}
```

### `Task.CompletedTask`——已完成的任务

**场景**：方法要求返回 Task，但你没什么异步操作要执行。

```csharp
static Task DoNothingAsync()
{
    // 直接返回成功完成的任务
    return Task.CompletedTask; // 用于占位，满足接口要求
}
```

### `Task.FromException()`——创建已失败的任务

**场景**：你想模拟一个异步方法抛异常。

```csharp
static Task<int> ErrorAsync()
{
    return Task.FromException<int>(new Exception("出错了"));
}

static async void Main()
{
    try
    {
        int result = await ErrorAsync(); // 会抛异常
    }
    catch (Exception ex)
    {
        Console.WriteLine($"捕获: {ex.Message}");
    }
}
```

## 五、Task 的状态（创建后自动变化）

Task 创建后，会经历这些状态（你不需要手动控制）：
```csharp
Task task = Task.Run(() => Thread.Sleep(1000));

Console.WriteLine(task.Status); // WaitingToRun 或 Running

task.Wait();

Console.WriteLine(task.Status); // RanToCompletion
```

**状态列表**：
- `WaitingToRun`：在队列里排队，还没轮到
- `Running`：正在执行
- `RanToCompletion`：成功完成
- `Faulted`：因异常失败
- `Canceled`：被取消了

## 六、选择指南（新手记住就行）

| 创建方式 | 适用场景 | 推荐度 |
|----------|----------|--------|
| **`Task.Run()`** | 90%的场景：CPU/IO计算、后台任务 | ⭐⭐⭐⭐⭐ |
| **`Task.Factory.StartNew()`** | 需要 LongRunning 或精细控制 | ⭐⭐ |
| **`new Task() + Start()`** | 几乎不用（先创建后启动） | ⭐（不推荐） |
| **`Task.FromResult()`** | 同步方法转异步接口 | ⭐⭐⭐⭐ |
| **`Task.CompletedTask`** | 无操作但需返回 Task | ⭐⭐⭐⭐ |

---

## 七、总结

**一句话**：**无脑用 `Task.Run()`**，遇到特殊需求再考虑别的。

**代码模板**：
```csharp
// 无返回值
Task.Run(() => { /* 干活 */ });

// 有返回值
Task<int> task = Task.Run(() => { return 42; });

// 后续处理
task.ContinueWith(t => Console.WriteLine($"结果: {t.Result}"));
```
