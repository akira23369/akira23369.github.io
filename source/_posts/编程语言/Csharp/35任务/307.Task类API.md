# Task类API速查

## 一、Task是什么？（极简版）

**大白话**：Task是一个"**更聪明的线程任务**"，它封装了线程池操作，能返回值、能等待、能取消。你不用管线程哪来的，只管告诉它干啥活。

**核心特点**：
- **基于线程池**：自动复用线程，省资源
- **能返回值**：不用写回调
- **能等待**：不用写 CountdownEvent
- **能取消**：不用写复杂的停止逻辑

---

## 二、创建Task的API（3种主要方式）

### `Task.Run()` —— 最常用，直接扔线程池
```csharp
// 无返回值
Task.Run(() => Console.WriteLine("干活"));

// 有返回值
Task<int> task = Task.Run(() => { return 42; });
```

### `Task.Factory.StartNew()` —— 老方法，功能更细
```csharp
// 基本用法
Task.Factory.StartNew(() => DoWork());

// 指定参数
Task.Factory.StartNew(
    () => DoWork(),
    CancellationToken.None, // 取消令牌
    TaskCreationOptions.None, // 创建选项
    TaskScheduler.Default // 调度器
);
```

### `new Task()` + `Start()` —— 不推荐，多此一举
```csharp
Task task = new Task(() => DoWork()); // 创建但不启动
task.Start(); // 手动启动
```

---

## 三、等待Task完成的API

### `task.Wait()` —— 阻塞等待（卡主线程）
```csharp
Task task = Task.Run(() => Thread.Sleep(2000));
task.Wait(); // 主线程卡住，等2秒
```

### `Task.WaitAll()` —— 等所有任务完成
```csharp
Task t1 = Task.Run(() => DoWork1());
Task t2 = Task.Run(() => DoWork2());
Task.WaitAll(t1, t2); // 等两个都跑完
```

### `Task.WaitAny()` —— 等任意一个完成
```csharp
Task t1 = Task.Run(() => DoWork1());
Task t2 = Task.Run(() => DoWork2());
int completedIndex = Task.WaitAny(t1, t2); // 哪个先跑完就返回哪个的索引
```

### `async/await` —— 非阻塞等待（不卡主线程）
```csharp
// 必须写在 async 方法里
async void Main()
{
    await Task.Run(() => DoWork()); // 主线程不卡，干完自动继续
}
```

---

## 四、获取Task结果的API

### `task.Result` —— 阻塞获取结果
```csharp
Task<int> task = Task.Run(() => 42);
int result = task.Result; // 等任务完成，拿结果（会卡主线程）
```

### `await task` —— 非阻塞获取
```csharp
Task<int> task = Task.Run(() => 42);
int result = await task; // 不卡，结果好了自动赋值
```

---

## 五、取消Task的API

### `CancellationTokenSource` + `CancellationToken`
```csharp
// 创建取消源
CancellationTokenSource cts = new CancellationTokenSource();

// 启动带取消令牌的任务
Task task = Task.Run(() => {
    while (!cts.Token.IsCancellationRequested)
    {
        DoWork();
    }
}, cts.Token);

// 1秒后取消任务
Thread.Sleep(1000);
cts.Cancel(); // 任务会收到取消信号
```

### `task.IsCanceled` —— 判断任务是否被取消
```csharp
try
{
    await task;
}
catch (OperationCanceledException)
{
    Console.WriteLine("任务被取消了");
}
```

---

## 六、Task状态的API

### `task.Status` —— 当前状态
```csharp
Task task = Task.Run(() => DoWork());
Console.WriteLine(task.Status); // Running, WaitingToRun, Completed, Canceled, Faulted
```

### `task.IsCompleted` —— 是否完成（成功/失败/取消都算）
```csharp
if (task.IsCompleted)
{
    Console.WriteLine("任务结束了");
}
```

### `task.IsCompletedSuccessfully` —— 是否成功完成
```csharp
if (task.IsCompletedSuccessfully)
{
    Console.WriteLine("任务成功跑完");
}
```

### `task.IsFaulted` —— 是否因异常失败
```csharp
if (task.IsFaulted)
{
    Console.WriteLine($"任务失败: {task.Exception}");
}
```

### `task.IsCanceled` —— 是否被取消
```csharp
if (task.IsCanceled)
{
    Console.WriteLine("任务被取消");
}
```

---

## 七、延续任务的API（任务链）

### `ContinueWith()` —— 任务完成后自动做另一件事
```csharp
Task.Run(() => DownloadFile())
    .ContinueWith(task => ProcessFile()); // 下载完自动处理
```

### `Task.WhenAll()` —— 所有任务完成再执行
WaitAll返回值为void, 所以不用WaitAll
如果你的任务都有返回值（比如都是 `Task<int>`），`WhenAll` 完之后，你会得到一个 `int[]` 数组。
任务无返回值(如下例)，就返回 `Task`（一个普通任务）
```csharp
Task t1 = Task.Run(() => {});
Task t2 = Task.Run(() => {});
Task<int> t3 = Task.Run(() => 1);
Task<int> t4 = Task.Run(() => 2);

Task task1 = Task.WhenAll(t1, t2);
Task<int[]> task2 = Task.WhenAll(t3, t4);

Task.WhenAll(t1, t2).ContinueWith(_ => Console.WriteLine("都干完了"));
```

### `Task.WhenAny()` —— 任意任务完成就执行
```csharp
Task t1 = Task.Run(() => {});
Task t2 = Task.Run(() => {});
Task<int> t3 = Task.Run(() => 1);
Task<int> t4 = Task.Run(() => 2);

Task<Task> taskAny1 = Task.WhenAny(t1, t2);
Task<Task<int>> taskAny2 = Task.WhenAny(t3, t4);


Task.WhenAny(t1, t2).ContinueWith(task => Console.WriteLine("有一个完成了"));
```

## 八、异常处理的API

### `task.Exception` —— 获取异常
```csharp
Task task = Task.Run(() => throw new Exception("boom"));
task.Wait(); // 会抛 AggregateException

// 获取原始异常
if (task.IsFaulted)
{
    Console.WriteLine(task.Exception.InnerException.Message);
}
```

### `AggregateException` —— 包装异常
```csharp
try
{
    Task.WaitAll(t1, t2); // 如果t1和t2都抛异常，这里会聚合
}
catch (AggregateException ae)
{
    foreach (var ex in ae.InnerExceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

---

## 九、Task的静态辅助API

### `Task.Delay()` —— 异步等待（不卡线程）
```csharp
Task.Delay(2000);

await Task.Delay(2000); // 等2秒，但线程不阻塞
```

### `Task.CompletedTask` —— 已完成的任务
```csharp
Task t = Task.CompletedTask; // 直接返回一个成功的Task
```

### `Task.FromResult<T>()` —— 直接返回带值的任务
```csharp
Task<int> t = Task.FromResult(42); // 同步返回42
```

### `Task.FromException()` —— 直接返回失败任务
```csharp
Task t = Task.FromException(new Exception("error"));
```

---

## 十、TaskCreationOptions 枚举（任务选项）

创建任务时可指定行为：
```csharp
Task.Run(() => DoWork(), TaskCreationOptions.LongRunning); // 提示是长任务
```

常用值：
- `None`：默认
- `LongRunning`：告诉调度器这是长任务，建议新建线程
- `PreferFairness`：希望任务按提交顺序执行
- `AttachedToParent`：任务作为子任务（父任务等子任务）

---

## 十一、总结

**Task类核心API速记**：
- **创建**：`Task.Run()` / `Task.Factory.StartNew()`
- **等待**：`task.Wait()` / `await task` / `Task.WaitAll()`
- **结果**：`task.Result` / `await task`
- **取消**：`CancellationTokenSource` + `cts.Cancel()`
- **状态**：`IsCompleted`, `IsFaulted`, `IsCanceled`
- **延续**：`ContinueWith()`, `Task.WhenAll()`
- **异常**：`task.Exception`, `AggregateException`
- **辅助**：`Task.Delay()`, `Task.FromResult()`

**一句话**：Task 封装了线程池的所有脏活累活，你只管提交任务，其他交给它。
