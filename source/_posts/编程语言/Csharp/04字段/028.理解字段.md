# C# 面向对象编程笔记：深入理解字段 (Fields)

## 核心概念：什么是字段？
在C#的面向对象编程(OOP)中，**字段（Field）** 是直接声明在类（Class）或结构体（Struct）中的变量，用于存储对象的数据或状态。

*   **类与对象的关系**：类是创建对象的“蓝图”或“模型”。我们必须在类中声明字段，但字段的实际数据是**存储在具体的对象中**的。
*   **数据隔离**：如果通过同一个类实例化了多个对象（例如两个 `Car` 对象），它们拥有相同列表的字段，但每个对象中的字段数据是相互独立、完全隔离的。这意味着修改对象A的字段不会影响对象B的字段。

## 字段的声明语法
声明字段的标准语法如下：
`[访问修饰符] [修饰符] [数据类型] [字段名称];`

![](028.理解字段/file-20260317172025705.png)
### 访问修饰符 (Access Modifiers)
C# 中共有6种访问修饰符：`private`、`protected`、`internal`、`protected internal`、`private protected` 和 `public`。
*   **字段的默认修饰符**：如果不显式指定，字段的默认访问级别是 `private`（私有），这意味着它只能在当前类的内部被访问。
*   **类的默认修饰符**：类的默认访问级别是 `internal`（只能在当前程序集中访问）。如果需要跨项目（如从控制台应用访问类库中的类），必须将类声明为 `public`。

### 修饰符 (Modifiers - 可选)
字段可以使用特定的修饰符来改变其行为，这些是可选的：
*   `static`：静态字段，属于类本身而不是特定的对象实例。
*   `const`：常量字段，其值在编译时确定，且不可更改。
*   `readonly`：只读字段，只能在声明时或在构造函数中进行赋值。

### 数据类型 (Data Type)
可以是任何有效的数据类型，包括：
*   **内置/基本类型**：`int`, `double`, `char`, `bool` 等。
*   **引用/非基本类型**：`string`, 自定义类名, 结构体, 接口或委托等。

### 命名规范
在C#开发中，声明私有或内部字段时，通常推荐使用 **camelCase（小驼峰命名法）**，即首字母小写，后续单词首字母大写（例如：`productId`, `productName`）。

## 内存分配与引用变量
理解对象在内存中的存储方式对于掌握OOP至关重要：

*   **堆内存 (Heap)**：当使用 `new` 关键字创建对象时（例如 `new Product()`），该对象的实际数据（包含所有字段）被分配在堆内存中。堆内存贯穿整个应用程序的生命周期。
*   **栈内存 (Stack)**：用于操作对象的变量（如 `product1`）被称为**引用变量**。这些变量仅仅存储了指向堆内存中真实对象的“内存地址”，它们被分配在方法执行的栈内存中。当方法执行完毕，栈内存会被回收。

*补充理解*：引用变量不是对象本身。如果执行 `Product p2 = p1;`，并不是复制了一个新对象，而是 `p2` 和 `p1` 这两个引用变量指向了堆内存中的同一个对象。

## 字段的默认值与初始化
当对象在堆内存中被创建时，如果未对字段进行显式赋值，C# 会自动为其分配默认值：
*   **数值类型**（`int`, `double`, `decimal` 等）：默认值为 `0`。
*   **引用类型**（`string`, 类对象 等）：默认值为 `null`。
*   **布尔类型**（`bool`）：默认值为 `false`。

**关于字段初始化的最佳实践**：
一般不建议直接在类声明中为字段赋予具体的业务值（如 `public int productId = 1001;`），因为所有实例化出来的对象都会带有这个相同的初始值，这违背了对象数据隔离的初衷。最佳的初始化时机是在**类的构造函数**中，或者在实例化对象后通过引用变量进行赋值。

## 实际项目架构与代码实现

在实际开发中，将所有代码写在控制台应用程序中是不规范的。良好的工程结构应该将**可复用的业务模型（如实体类）提取到单独的“类库 (Class Library)”项目中**，然后由主程序（如控制台应用）通过添加项目引用的方式来调用它们。

### 类库项目代码 (Class Library)
定义 `Product` 类。为了能被外部控制台程序访问，类必须是 `public` 的，需要暴露给外部的字段也需声明为 `public`。

```csharp
namespace ClassLibrary1
{
    public class Product
    {
        // 使用小驼峰命名法声明 public 字段
        public int productId;
        public string productName;
        public double cost;
        public int quantity;
    }
}
```

### 控制台应用程序代码 (Console App)
确保在项目中已添加对 `ClassLibrary1` 的引用。在这里实例化对象并对字段进行初始化和读取。

```csharp
using System;
using ClassLibrary1; // 引入类库命名空间

namespace FieldsExample
{
    class Program
    {
        static void Main(string[] args)
        {
            // 1. 创建引用变量并在堆内存中分配对象实例
            Product product1 = new Product();
            Product product2 = new Product();
            Product product3 = new Product();

            // 此时，如果直接打印 product1.productId，输出将是默认值 0
            // product1.productName 将是 null

            // 2. 通过引用变量初始化各个对象的字段数据（数据隔离）
            product1.productId = 1001;
            product1.productName = "Mobile";
            product1.cost = 500.50;
            product1.quantity = 50;

            product2.productId = 1002;
            product2.productName = "Laptop";
            product2.cost = 1200.00;
            product2.quantity = 30;

            // 3. 读取字段值并输出
            // 使用 + 号将字符串与数值拼接，C# 会自动将数值隐式转换为字符串
            Console.WriteLine("Product ID: " + product1.productId);
            Console.WriteLine("Product Name: " + product1.productName);
            Console.WriteLine("Cost: " + product1.cost);
            Console.WriteLine("Quantity: " + product1.quantity);
            
            // 使用转义字符 \n 进行换行
            Console.WriteLine("\n------------------\n");
            
            Console.WriteLine("Product ID: " + product2.productId);
            Console.WriteLine("Product Name: " + product2.productName);
            
            // 保持控制台窗口打开
            Console.ReadLine();
        }
    }
}
```

*补充理解：在实际的现代C#开发中，直接暴露 `public` 字段是不被推荐的。通常会将字段声明为 `private`，然后通过**属性 (Properties)** 来控制数据的获取(get)和设置(set)，以实现更好的封装性和数据校验。这通常是学习面向对象编程的下一个重要步骤。*
