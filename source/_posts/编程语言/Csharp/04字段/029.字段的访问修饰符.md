# 字段的访问修饰符

## 核心概念

**访问修饰符 (Access Modifiers)** 是面向对象编程中实现**封装 (Encapsulation)** 的关键机制。它们不仅适用于字段，也适用于类中的方法、属性、事件等成员。访问修饰符的作用是严格界定特定成员的**可见性或可访问范围**，即决定了代码的哪些部分有权读取或修改该字段。

为了彻底理解访问修饰符，必须先明确两个上下文概念：

1.  **程序集 (Assembly)**：在 .NET 中，一个项目编译后的输出文件就是一个程序集（通常是类库生成的 `.dll` 文件或控制台/桌面应用生成的 `.exe` 文件）。跨项目引用实际上就是跨程序集访问。
2.  **派生类/子类 (Child/Derived Class)**：通过继承机制从基类（父类）派生出的新类，它会自动拥有父类的特征。

## 可访问性的五个维度
评估一个字段是否可以被访问，通常需要在以下五种位置进行测试：
1.  **同一类中 (Same Class)**：定义该字段的类内部。
2.  **同一程序集的子类中 (Child Class at Same Assembly)**：与基类在同一个项目下的派生类内部。
3.  **同一程序集的其他类中 (Other Class at Same Assembly)**：与基类在同一个项目下，但没有继承关系的普通类中（需通过对象实例访问）。
4.  **不同程序集的子类中 (Child Class at Other Assembly)**：在另一个引用了基类所在项目的项目中的派生类内部。
5.  **不同程序集的其他类中 (Other Class at Other Assembly)**：在另一个项目中的普通类中（需通过对象实例访问）。

## 6种访问修饰符详解 (按访问权限由小到大排列)

### `private` (私有)
*   **规则**：**极其严格**。仅在声明该字段的**同一类内部**可见。
*   **理解**：这是字段的默认修饰符，也是最推荐的修饰符。它完全向外部隐藏了类的内部状态，外部要想交互，必须通过类提供的公开方法或属性。哪怕是自己的子类也无法直接访问 `private` 字段。

### `private protected` (私有受保护) - *C# 7.2 引入*
*   **规则**：属于**交集**关系。仅在**同一类中**，以及**同一程序集内的子类中**可见。
*   **理解**：它是 `private` 和 `protected` 的结合体，比纯粹的 `protected` 更严格。它不仅要求访问者必须是子类，还要求访问者必须和基类在同一个项目中。跨项目的子类无法访问。

### `internal` (内部)
*   **规则**：**程序集级别的公开**。在**同一个程序集**内的任何地方（同一个类、子类、其他类）都可见。跨程序集完全不可见。
*   **理解**：当开发一个类库（DLL）供他人使用时，如果不希望某些内部机制或字段暴露给最终用户，但又需要在类库内部的不同类之间共享数据，`internal` 是完美的选择。

### `protected` (受保护)
*   **规则**：**继承链级别的公开**。在**同一类中**以及**所有的子类中**可见（无论子类是否在同一个程序集）。非继承关系的其他类完全不可见。
*   **理解**：专门为继承设计的修饰符。它允许派生类访问和复用父类的底层数据，但对非相关类保持封闭。

### `protected internal` (受保护或内部)
*   **规则**：属于**并集**关系。在**同一个程序集内的一切位置**可见，**加上不同程序集中的子类**也可见。唯一不可见的地方是：不同程序集中的非继承普通类。
*   **理解**：只要满足 `protected`（是子类）或者满足 `internal`（在同项目中）这两个条件中的**任意一个**，就可以访问。

### `public` (公开)
*   **规则**：**无限制**。在任何程序集的任何类中都可见。
*   **理解**：完全放弃封装保护。通常不建议将字段直接设为 `public`，而应使用 `public` 属性来包裹 `private` 字段。

## 核心认知补充：可见性 vs 内存分配

一个极其重要但在编程中容易被误解的概念是：**访问修饰符只控制代码的编译级别“可见性”，不影响对象在内存中的实际结构。**

当一个子类（例如 `DomesticProduct`）继承自父类（例如 `Product`）并在堆内存中被实例化时，无论父类的字段是 `private` 还是 `public`，**所有的字段都会被分配到该对象的内存空间中**。
*   你不能通过代码在子类中直接操作 `private` 字段，是因为编译器阻止了你。
*   但在运行时的实际内存里，那个 `private` 字段是真实存在于子类对象内部的。

## 代码示例说明

以下代码演示了类库（Assembly 1）和控制台应用（Assembly 2）中各种修饰符的访问行为：

### 程序集 1：类库
```csharp
namespace ClassLibrary1
{
    // 基类
    public class Product
    {
        private int _privateId = 1;
        private protected decimal _privProtectCost = 10.0m;
        internal int _internalStock = 100;
        protected string _protectedName = "Base";
        protected internal string _protectIntCategory = "General";
        public string PublicDescription = "Visible to all";

        public void TestSameClass()
        {
            // 同一类内部：所有修饰符均可访问
            int a = _privateId; 
        }
    }

    // 同一程序集的子类
    public class DomesticProduct : Product
    {
        public void TestChildSameAssembly()
        {
            // var a = _privateId;      // 错误：private不可见
            var b = _privProtectCost;   // 成功：在同程序集且是子类
            var c = _internalStock;     // 成功：在同程序集
            var d = _protectedName;     // 成功：是子类
            var e = _protectIntCategory;// 成功：在同程序集或子类
        }
    }

    // 同一程序集的其他类（非继承）
    public class OtherClassSameAssembly
    {
        public void TestOtherSameAssembly()
        {
            Product p = new Product();
            // var a = p._privateId;      // 错误：private不可见
            // var b = p._privProtectCost;// 错误：不是子类
            // var c = p._protectedName;  // 错误：不是子类
            
            var d = p._internalStock;     // 成功：在同程序集
            var e = p._protectIntCategory;// 成功：在同程序集
            var f = p.PublicDescription;  // 成功：public
        }
    }
}
```

### 程序集 2：控制台应用 (ConsoleApp - 引用了程序集1)
```csharp
using ClassLibrary1;

namespace ConsoleApp
{
    // 不同程序集的子类
    public class InternationalProduct : Product
    {
        public void TestChildOtherAssembly()
        {
            // var a = _privateId;      // 错误：private不可见
            // var b = _privProtectCost;// 错误：跨程序集了
            // var c = _internalStock;  // 错误：跨程序集了

            var d = _protectedName;     // 成功：是子类 (protected跨程序集有效)
            var e = _protectIntCategory;// 成功：是子类
        }
    }

    // 不同程序集的其他类（非继承，如Main方法所在的类）
    class Program
    {
        static void Main(string[] args)
        {
            Product p = new Product();
            // 此时对象 p 只能访问 public 成员
            // p._internalStock // 错误：跨程序集
            // p._protectedName // 错误：非子类

            string desc = p.PublicDescription; // 成功：唯一可见的字段
        }
    }
}
```
