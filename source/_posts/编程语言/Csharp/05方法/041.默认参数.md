# C# 面向对象编程笔记：深入解析默认参数 (Default Arguments)

## 一、 核心概念：什么是默认参数？

在**C# 4.0** 及其后续版本中，引入了**默认参数（Default Arguments，也称为可选参数 Optional Parameters）** 的特性。

默认参数允许在**声明方法时，为参数指定一个默认的初始值**。
*   **特性**：如果方法的调用者在调用时**提供**了该参数的值，那么传入的实参将覆盖默认值。
*   **优势**：如果调用者在调用时**省略**了该参数，系统将自动使用预设的默认值。
*   **目的**：极大地简化了方法调用的复杂性。调用者不必为了那些“大多数情况下都一样”的参数每次都费力地传递相同的值，从而使代码更加简洁清爽。

---

## 二、 语法规则与底层限制

使用默认参数时，必须遵守 C# 编译器的严格规则：

### 基本语法
在方法签名中，直接使用等号 `=` 为参数赋值。
```csharp
public void CalculateInterest(decimal principal, decimal rate = 0.05m)
{
    // ...
}
```

### 位置限制 (必考点/易错点)
**所有的可选参数（带有默认值的参数）必须放置在参数列表的最后面。**
在可选参数之后，绝对不允许再出现必需参数（没有默认值的参数）。

*   **正确**：`void Method(int a, string b = "default", double c = 1.0)`
*   **错误**：`void Method(int a = 1, string b, double c = 1.0)` *(编译报错)*

### 常量表达式限制
参数的默认值必须是**编译时常量 (Compile-time constant)**。
你可以使用数字字面量、字符串、`null`、`const` 变量、或者是 `default(T)` 表达式，但**不能**使用需要在运行时计算的表达式（例如 `DateTime.Now`，或者 `new List<int>()`）。

## 三、 代码实战示例：灵活的税率计算

在原有的产品税率计算逻辑中，如果成本超过了 20,000，原本我们硬编码了 12.5% 的税率。现在我们将其重构为：**允许外部传入自定义税率，如果不传，则默认使用 4.5%**。

### 业务类中的方法定义

```csharp
public class Product
{
    private decimal _cost;
    private decimal _tax;

    public void SetCost(decimal cost)
    {
        _cost = cost;
    }
    
    public decimal GetTax()
    {
        return _tax;
    }

    // 重构 CalculateTax，引入默认参数 percentage
    // 默认值为 4.5 (注意：作为 decimal 类型需要加后缀 m)
    public void CalculateTax(decimal percentage = 4.5m)
    {
        if (_cost <= 20000m)
        {
            // 低于阈值，固定 10%
            _tax = _cost * 0.10m;
        }
        else
        {
            // 高于阈值，使用传入的自定义税率，或使用默认的 4.5%
            _tax = _cost * (percentage / 100m);
        }
    }
}
```

### 主程序中的灵活调用

```csharp
class Program
{
    static void Main(string[] args)
    {
        // 场景 1：完全符合默认情况，省略参数
        Product p1 = new Product();
        p1.SetCost(30000m); // 大于 20000
        p1.CalculateTax();  // 省略参数，系统自动应用默认值 4.5m
        Console.WriteLine(p1.GetTax()); // 结果基于 4.5% 计算

        // 场景 2：特殊业务场景，显式传入实参覆盖默认值
        Product p2 = new Product();
        p2.SetCost(50000m); // 大于 20000
        p2.CalculateTax(9.2m); // 显式传入 9.2m，覆盖默认值 4.5m
        Console.WriteLine(p2.GetTax()); // 结果基于 9.2% 计算
    }
}
```

## 四、 进阶认知：方法重载的替代方案

在 C# 4.0 引入默认参数之前，如果想要实现类似“支持多种参数数量调用”的效果，唯一的途径是编写**方法重载**（即定义多个同名但参数列表不同的方法）。

**传统的重载方式（较繁琐）：**
```csharp
public void CalculateTax() 
{ 
    CalculateTax(4.5m); // 委托给带参数的方法
}

public void CalculateTax(decimal percentage) 
{ 
    // 实际的计算逻辑
}
```

**现代的默认参数方式（更优雅）：**
```csharp
public void CalculateTax(decimal percentage = 4.5m) 
{ 
    // 实际的计算逻辑
}
```
默认参数通过一个单一的方法声明，就实现了类似于多个重载方法的效果。它不仅减少了代码的冗余，还在与 COM 互操作（如操作 Microsoft Office API 时，经常需要传递几十个大部分为默认值的参数）时发挥了极其重要的作用。
