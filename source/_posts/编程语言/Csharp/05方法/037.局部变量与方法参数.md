# C# 面向对象编程笔记：局部变量与方法参数深度解析

## 一、 核心概念：局部变量与参数

在 C# 的方法（无论是实例方法还是静态方法）中，除了可以访问类的级别的数据（字段），方法内部还会使用两种专属的变量类型来辅助完成业务逻辑：**方法参数 (Parameters)** 和 **局部变量 (Local Variables)**。

### 方法参数 (Parameters)
*   **定义位置**：声明在方法名后面的小括号 `()` 内。
*   **核心作用**：作为方法与外部世界沟通的“数据桥梁”。它们专门用于接收调用该方法时（外部传入）的数据。
*   **多参数规则**：一个方法可以包含多个参数。在调用时，外部传入的值通常会按照**严格的顺序**，依次赋值给对应的参数。
*   **数据类型**：可以是任何内置的基础类型（如 `int`, `double`），也可以是复杂的引用类型（如自定义的 `class`, `struct`, `interface`）。

### 局部变量 (Local Variables)
*   **定义位置**：声明在方法体的大括号 `{ }` 内部。
*   **核心作用**：作为方法内部执行计算或处理逻辑时的“临时草稿纸”。它们仅用于方法内部的数据流转和暂存。

## 二、 关键术语辨析：形参 (Parameter) vs 实参 (Argument)

在实际开发和技术交流中，必须严格区分这两个极其容易混淆的概念：

*   **形参 (Parameter)**：是**方法定义**时的变量名称。它是一个占位符，说明该方法需要什么类型的数据。
*   **实参 (Argument)**：是**方法调用**时真实传递过去的具体数值或对象引用。

```csharp
// 这里的 "amount" 是【形参 (Parameter)】
public void Deposit(decimal amount) 
{
    // ...
}

// 这里的 "1000m" 是【实参 (Argument)】
account.Deposit(1000m); 
```

## 三、 内存机制与生命周期 (底层原理解析)

局部变量和参数在内存中的表现与类的字段（Fields）有着本质的区别。理解这一点是掌握 C# 内存管理的基础：

### 存储位置：栈内存 (Stack)
*   类的实例字段存储在**堆内存 (Heap)** 的对象内部。
*   而方法的参数和局部变量都存储在当前线程的**栈内存 (Stack)** 中。

### 生命周期：极短 (Short-Lived)
*   **创建时机**：每次调用一个方法时，CLR (公共语言运行时) 会在栈内存中为该方法开辟一个新的空间，称为**栈帧 (Stack Frame)**。此时，参数和局部变量被分配到这个栈帧中。
*   **销毁时机**：一旦方法执行到最后一行并返回（执行完 `return` 或到达 `}`），该方法的栈帧会被**立刻弹出并销毁**。存储在其中的所有局部变量和参数也会随之灰飞烟灭。
*   **结论**：局部变量和参数的生命周期仅限于该方法的单次执行过程。不同方法之间的局部变量绝对互不干扰，哪怕它们同名。即使是同一个方法被多次调用（例如递归），每一次调用也会产生彼此独立的栈帧和变量副本。

## 四、 C# 局部变量的特殊安全规则 (重要补充)

C# 编译器对局部变量的检查比类字段严格得多：

*   **字段的默认值**：如果类中定义了一个字段（如 `int age;`）且没有赋值，系统会默认赋为 `0`。
*   **局部变量的明确赋值**：C# 规定，**局部变量在使用（读取）之前，必须被明确赋值**。如果仅仅声明了 `int count;` 并在下一行尝试 `Console.WriteLine(count);`，编译器将直接报错，拒绝编译。这一机制有效防止了由“未初始化内存”引发的不可预测的 Bug。

## 五、 代码实战示例

下面以计算产品税金为例，综合展示字段、参数与局部变量的协同工作方式：

```csharp
public class Product
{
    // 实例字段 (存在于 Heap 中，随对象存活)
    private decimal _cost;
    private decimal _tax;

    // Set 方法
    // 'value' 是形参 (Parameter)，存在于 Stack 中
    public void SetCost(decimal value)
    {
        // 将 Stack 中的参数值，赋给 Heap 中的对象字段
        _cost = value;
    }

    // 业务方法
    public void CalculateTax()
    {
        // 'localTax' 是局部变量 (Local Variable)，存在于 Stack 中
        // 必须先赋值才能使用
        decimal localTax = 0m; 

        // 使用类的字段参与逻辑判断
        if (_cost <= 20000m)
        {
            localTax = _cost * 0.10m;
        }
        else
        {
            localTax = _cost * 0.125m;
        }

        // 将局部变量的最终计算结果，存回类的持久化字段中
        _tax = localTax;
        
    } // 方法结束，'localTax' 被彻底销毁，栈帧清除
}

class Program
{
    static void Main()
    {
        Product p = new Product();
        
        // 调用方法，'50000m' 作为实参 (Argument) 传入
        p.SetCost(50000m);
        
        p.CalculateTax();
    }
}
```
