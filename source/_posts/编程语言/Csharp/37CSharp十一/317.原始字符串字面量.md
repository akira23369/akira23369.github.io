欢迎来到 **C# 11 新特性深度解析系列**！

作为本系列的第一篇，我们将详细探讨 C# 11 中最直观、最受开发者欢迎的语法糖之一：**原始字符串字面量（Raw String Literals）**。

如果你曾经在 C# 代码中硬编码过 JSON、XML、SQL 语句或者正则表达式，你一定会对那些满天飞的转义字符（`\`、`""`）深恶痛绝。C# 11 的原始字符串字面量正是为了彻底解决这个痛点而生的。

---

### 一、 曾经的痛点：为什么我们需要它？

在 C# 11 之前，如果你想在代码里写一段包含引号的 JSON 字符串，你通常有两种选择：

**1. 普通字符串（需要大量转义）：**
```csharp
string json1 = "{\n  \"name\": \"Alice\",\n  \"age\": 30\n}";
```
*缺点：可读性极差，复制粘贴外部 JSON 时需要手动修改所有引号。*

**2. 逐字字符串（`@` 符号，需要双写引号）：**
```csharp
string json2 = @"
{
  ""name"": ""Alice"",
  ""age"": 30
}";
```
*缺点：虽然解决了换行和反斜杠的问题，但内部的双引号必须写成两个（`""`），复制粘贴依然很痛苦。*

---

### 二、 救星登场：原始字符串字面量的基本用法

C# 11 引入了全新的语法：**至少使用三个双引号 `"""`** 来包裹字符串。

在 `"""` 和 `"""` 之间的所有内容，**不需要任何转义**，哪怕里面包含单引号、双引号、反斜杠、换行符。怎么写的，编译器就怎么认。

```csharp
string json3 = """
{
  "name": "Alice",
  "age": 30
}
""";
```
**优势：** 你可以直接把 Postman 或浏览器里的 JSON/HTML/SQL 原封不动地复制粘贴到代码里，一个字符都不用改！

---

### 三、 核心杀手锏：智能缩进管理

这是原始字符串字面量最优雅的设计之一。

在写多行字符串时，为了代码格式整齐，我们通常会对其进行缩进。但在以前，这些缩进的空格也会被算作字符串的一部分。C# 11 聪明地解决了这个问题：**结束引号 `"""` 的位置，决定了整个字符串的左边界。**

看下面这个例子：

```csharp
public class Example
{
    public void PrintJson()
    {
        string json = """
            {
              "name": "Alice"
            }
            """; // <- 注意这一行的位置
        
        Console.WriteLine(json);
    }
}
```

**编译器的处理规则：**
1. 结束符 `"""` 左侧的空白字符会被当做“基准空白”。
2. 编译器会自动把每行开头与“基准空白”对齐的部分**裁剪掉**。
3. 因此，上面的代码输出结果是完美靠左对齐的：
```json
{
  "name": "Alice"
}
```
*注意：如果你的内容比结束符 `"""` 还要靠左，编译器会直接报错，从而保证你不会写出格式错乱的字符串。*

---

### 四、 绝佳搭配：与字符串插值（`$`）结合

在写 JSON 或 SQL 时，我们往往需要把变量塞进去。但是 JSON 天然包含了大量的 `{` 和 `}`，这与 C# 字符串插值（`$"{var}"`）的语法冲突了。以前我们需要用 `{{` 和 `}}` 来转义大括号，非常反人类。

C# 11 引入了**多个 `$` 符号**的机制：**你用了几个 `$`，就需要用几个紧挨着的大括号 `{}` 来表示代码插值。**

```csharp
string name = "Bob";
int age = 25;

// 使用两个 $$，意味着需要用 {{ 和 }} 来包裹变量
string payload = $$"""
{
  "user": {
    "name": "{{name}}",    // 这里是变量插值
    "age": {{age}}         // 这里是变量插值
  },
  "status": "active"       // 这里的单层 {} 会被当做普通字符，不会引起编译错误！
}
""";
```
在这个例子中，因为前面是 `$$`，所以编译器只认 `{{...}}` 为代码，普通的 `{...}` 就安全地成为了 JSON 的一部分。

如果你遇到了极其变态的情况（比如字符串本身就包含 `{{`），你可以用 `$$$`，然后用 `{{{...}}}` 来插值，以此类推。

---

### 五、 极限拉扯：如果我的字符串里包含 `"""` 怎么办？

既然 `"""` 是原始字符串的边界，那如果我要输出的内容刚好是 `"""` 怎么办？

C# 11 的规则极其灵活：**包裹字符串的引号数量，只要大于字符串内部连续引号的最大数量即可。**

如果你的字符串内部有 3 个连续引号，你就用 4 个引号去包裹它：

```csharp
string edgeCase = """"
这段文本里包含了一个原始字符串字面量的示例："""这是一段示例"""，看，它没有引起报错！
"""";
```

---

### 六、 总结

C# 11 的**原始字符串字面量**带来了以下几个巨大提升：
1. **零转义**：彻底告别 `\"`、`\\`、`""`。
2. **复制即用**：可以毫无阻碍地粘贴外部复杂的文本（JSON/XML/SQL/Regex/HTML）。
3. **版面整洁**：智能左边界裁剪，让多行字符串在代码中保持完美的缩进对齐。
4. **插值自由**：通过 `$$` 彻底解决了 JSON/CSS 中大括号与 C# 变量插值的冲突。

这是那种“一旦用过就再也回不去”的特性。如果你的项目已经升级到了 .NET 7 / C# 11，请立刻开始使用它吧！
