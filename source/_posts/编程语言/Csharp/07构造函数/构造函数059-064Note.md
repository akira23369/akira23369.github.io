# 第七节：构造函数

## 第一讲：实例构造函数

### 引言

实例构造函数是类中的一种特殊方法，当使用 new 关键字创建该类的对象时，它会自动被调用。其主要且最关键的目的是初始化对象的字段，使对象进入有效、一致且可用的初始状态。构造函数确保没有任何对象会以随机或空值（在需要特定值的地方）开始其生命周期。它是新对象实例运行时执行的第一段代码。

### 工作原理：语法与执行流程

构造函数的定义方式类似于方法，但需遵循两条严格规则：

- 它必须与类名完全一致 。
    
- 必须不声明返回类型 ，连 void 也不行。
    

当调用 new MyClass() 时，其执行流程如下：

1. .NET 运行时在堆上为新对象分配一块内存。该内存块中的所有字段初始都被设为默认值（数值类型为 0，布尔类型为 false，引用类型为 null）。
    
2. 调用相应的实例构造函数。
    
3. 构造函数内部的代码执行，通常会对实例字段赋初始值。
    
4. 构造函数执行完成后，返回对新创建并初始化对象的引用。
    

### 默认构造函数

这是面试中经常考察的关键概念。如果你没有在类中定义任何构造函数，C# 编译器会在后台自动为你提供一个。这被称为默认构造函数。它始终是公开的且没有参数，其唯一职责是创建对象并将字段设为默认值。

但当你自行定义任何构造函数时（例如带参数的构造函数），编译器将不再自动提供默认构造函数 。如果此时仍需要无参构造函数，你必须显式编写一个。

### 示例：包含参数化构造函数的类
```cs
public class Car  
{  
    // 私有实例字段  
    private string _model;  
    private string _color;  
    private int _year;  
​  
    // 这是一个公开的、带参数的实例构造函数。  
    // 它的作用是强制每个新的Car对象都必须有型号、颜色和年份。  
    public Car(string model, string color, int year)  
    {  
        Console.WriteLine("Car object is being created...");  
        // 使用'this'将参数值赋给私有字段  
        this._model = model;  
        this._color = color;  
        this._year = year;  
    }  
​  
    public void DisplayInfo()  
    {  
        Console.WriteLine($"Car Info: {_year} {_color} {_model}");  
    }  
}  
​  
// --- 在你的Main方法中 ---  
// 使用构造函数创建对象。我们必须提供所需的参数。  
Car myCar = new Car("Ford Mustang", "Red", 2023);  
myCar.DisplayInfo(); // 输出: Car Info: 2023 Red Ford Mustang  
​  
// 下面这行代码会导致编译错误，因为默认的无参构造函数已不再可用。  
// Car anotherCar = new Car(); // 错误! 没有接受0个参数的构造函数。

```

## 第二讲：静态构造函数

### 引言

静态构造函数是一种特殊的构造函数，用于在创建任何实例或访问其他静态成员之前，初始化类的静态成员或执行类本身所需的一次性操作。

### 工作原理与规则

静态构造函数的行为非常特殊，是面试问题中常见的考点。

- 语法： 使用 static 关键字声明，与类同名， 没有访问修饰符 （实际上是私有的），且不能有任何参数 。
    
- 执行： 它由.NET 运行时自动调用 。您无法直接从代码中调用它。
    
- 时机： 它保证在应用程序生命周期内仅被调用一次 。这次调用发生在类的第一个实例创建之前 ，或类的任何静态成员（字段或方法）被引用之前的某个时刻。具体时机由运行时决定，但"首次使用前"的保证才是关键。
    

### 使用场景与实际案例

初始化复杂静态字段： 如果静态字段需要通过某些逻辑获取初始值（例如从配置文件读取、从操作系统获取值等），则应在静态构造函数中完成此操作。

设置单例实例： 在单例设计模式中，静态构造函数是创建类唯一共享实例的理想位置。

### 示例
```cs
public class AppConfig  
{  
    // 用于存储配置值的静态字段  
    public static readonly string LogFilePath;  
​  
    // 用于初始化静态字段的静态构造函数  
    static AppConfig()  
    {  
        // 这段代码在整个应用程序中仅运行一次  
        Console.WriteLine("--- Static Constructor Called: Initializing App Settings ---");  
        // 在实际应用中，这里可能会从文件或环境中读取配置  
        LogFilePath = "C:\\logs\\application.log";  
    }  
​  
    public static void LogMessage(string message)  
    {  
        Console.WriteLine($"Logging to {LogFilePath}: {message}");  
    }  
}  
​  
// --- 在你的Main方法中 ---  
Console.WriteLine("Program starting...");  
AppConfig.LogMessage("First log message."); // 静态构造函数会在这行代码之前自动调用  
AppConfig.LogMessage("Second log message."); // 静态构造函数不会再次被调用  
Console.WriteLine("Program finished.");  
​
```

Logging to C:\logs\application.log: First log message.  
Logging to C:\logs\application.log: Second log message.

## 第三讲：构造函数的类型

### 引言

虽然我们已经了解了实例构造函数和静态构造函数，但对我们将会遇到和编写的不同形式和模式的构造函数进行分类是很有帮助的。

#### 默认构造函数

定义： 当且仅当类中没有声明任何其他构造函数时，C#编译器会自动为该类生成的无参构造函数。

它的作用： 将所有实例字段初始化为系统默认值（0、false、null 等）。

关键点： 一旦编写了任意一个构造函数，系统就不再自动提供默认构造函数。

#### 无参构造函数

定义： 由开发者显式编写的、不带任何参数的构造函数。

使用场景： 当需要允许以默认、空或预定义状态创建对象时。如果已有其他参数化构造函数但仍想允许 new MyClass() 调用，则必须显式提供一个公开的无参构造函数。

#### 参数化构造函数

定义： 一种接受一个或多个参数的构造函数。

使用场景： 这是最常见且实用的构造函数类型。它能确保对象在创建时就具备有效状态所需的所有数据。

#### 拷贝构造函数

定义： 这是一种常见的编程模式 ，而非 C#的特定功能。它是一个参数化构造函数，接受同类对象作为参数。

它的作用： 通过复制现有对象的值来创建一个新对象，生成一个副本。

示例：
```cs
public class Car  
{  
    public string Model;  
    // ... 其他字段  
​  
    // 参数化构造函数  
    public Car(string model) { this.Model = model; }  
​  
    // 拷贝构造函数  
    public Car(Car otherCar)  
    {  
        this.Model = otherCar.Model;  
    }  
}  
Car originalCar = new Car("Mustang");  
Car copiedCar = new Car(originalCar); // 创建一个具有相同数据的新对象。  
```

​

#### 静态构造函数

定义： 一种特殊的构造函数，用于对类的静态成员执行一次性初始化。它没有参数，不包含访问修饰符，由运行时自动调用。

#### 私有构造函数

定义： 使用 private 访问修饰符声明的构造函数。

作用： 将构造函数设为私有可阻止类外部通过 new 关键字创建该类的实例。

使用场景： 主要用于特定设计模式，最典型的是单例模式 （确保类只有一个实例存在）或仅包含静态成员的工具类（如 System.Math），防止这些类被实例化。

## 第四讲：构造函数重载

### 引言

构造函数重载是指在同一个类中定义多个构造函数，每个构造函数具有不同的签名（即参数数量或类型不同）。这种做法提供了灵活性，允许根据调用者所掌握的信息，以多种不同方式创建对象。

### 为何及何时使用

使用构造函数重载来提供创建对象的便捷方式。例如，可以创建一个 User 对象：

- 仅需一个电子邮件地址（并生成默认用户名）。
    
- 提供电子邮件和用户名。
    
- 提供电子邮件、用户名及特定 ID。
    

无需强制用户传递 null 或默认值，您可以为每个常见场景提供专用的构造函数。

### 使用 : this(...) 进行构造函数链式调用

重载构造函数时的一个关键最佳实践是避免重复初始化逻辑。如果有三个构造函数都设置了 name 字段，之后需要修改 name 的处理方式，就不得不更新三个地方。

为解决这个问题，可以使用构造函数链 。: this(...) 语法允许一个构造函数调用同一个类中的另一个构造函数。最佳实践是设置一个执行所有实际工作的"主"构造函数，让较简单的构造函数通过提供它们没有的参数默认值来调用它。

### 示例
```cs
public class User  
{  
    private string _username;  
    private string _email;  
    private bool _isActive;  
​  
    // 1. 最简单的构造函数。  
    // 为'isActive'提供默认值，并调用下一个构造函数。  
    public User(string username, string email) : this(username, email, true)  
    {  
        // 这个方法体是空的，因为初始化工作由它调用的构造函数完成。  
        Console.WriteLine("Two-parameter constructor called.");  
    }  
​  
    // 2. "主"构造函数。所有初始化逻辑都在这里。  
    public User(string username, string email, bool isActive)  
    {  
        // 这是唯一的逻辑处理点。  
        Console.WriteLine("Master three-parameter constructor called.");  
        this._username = username;  
        this._email = email;  
        this._isActive = isActive;  
    }  
}  
​  
// --- 在你的Main方法中 ---  
// 这个调用匹配第一个构造函数。它会执行，然后立即  
// 链式调用主构造函数，之后再执行它自己的方法体。  
User user1 = new User("alice", "alice@example.com");  
```

​

Master three-parameter constructor called.  
Two-parameter constructor called.

## 第5讲：对象初始化器

### 引言

对象初始化器是 C# 3.0 引入的特性，它提供了一种简洁、可读且灵活的语法，用于在创建对象的同时设置其公共属性或字段。

### 工作原理：语法糖

对象初始化器语法是一种语法糖。这意味着它并没有引入新功能，而是提供了一种更简洁的代码书写方式。当你编写：
```cs
Book myBook = new Book { Title = "The Hobbit", Author = "J.R.R. Tolkien" };

C#编译器会在后台将其转换为以下等效代码：

Book myBook = new Book(); // 1. 首先，调用无参构造函数。  
myBook.Title = "The Hobbit";   // 2. 然后，为每个属性单独赋值。  
myBook.Author = "J.R.R. Tolkien";  
```

​
由于编译器必须先调用无参构造函数，因此一个类必须具有可访问的无参构造函数 （无论是自动生成的默认构造函数还是显式编写的构造函数）才能使用对象初始化器语法。

### 为何及何时使用

- 灵活性： 当您不想为可能需要设置的每个属性组合创建特定构造函数时，它是创建对象的理想选择。
    
- 可读性： 它能创建高度可读的声明式代码，特别是在创建数据传输对象（DTO）或模型对象时。
    

### 示例
```cs
public class Book  
{  
    public string Title { get; set; }  
    public string Author { get; set; }  
    public int PublicationYear { get; set; }  
}  
​  
// --- 在你的Main方法中 ---  
​  
// 不使用对象初始化器的"旧"方式  
Book book1 = new Book();  
book1.Title = "1984";  
book1.Author = "George Orwell";  
book1.PublicationYear = 1949;  
​  
// 使用对象初始化器的现代、简洁方式  
Book book2 = new Book  
{  
    Title = "1984",  
    Author = "George Orwell",  
    PublicationYear = 1949  
};  
```

​

## 第六讲：需要记住的重要知识点

- **构造函数的主要作用**： 构造函数的主要目的是强制执行不变量并确保对象在有效的初始状态下创建。一个设计良好的构造函数能保证对象在创建后立即可用。
    
- **默认构造函数的陷阱**： 这是初学者常见的错误来源，也是面试中的热门话题。C#编译器仅在你没有编写任何其他构造函数时才会自动生成一个公开的无参默认构造函数。一旦你定义了任何构造函数，这个自动生成的构造函数就会消失。
    
- **使用构造函数链提升可维护性**： 始终通过 : this(...) 来链式调用重载构造函数。这能避免重复初始化逻辑，减少错误几率，并通过创建一个负责核心逻辑的"主"构造函数使代码更易于维护。
    
- **静态构造函数与实例构造函数**：
    
    - 实例构造函数： 在每次使用 new 创建新对象时执行。用于初始化实例字段。
        
    - 静态构造函数： 在整个应用程序生命周期中仅执行一次 ，在类首次使用之前运行。用于初始化 static 字段。
        
- **对象初始化器需要无参构造函数**： 请记住，对象初始化器语法（new Book { ... }）是语法糖，它首先调用无参构造函数，然后设置属性。如果类没有可访问的无参构造函数，则无法使用此语法。
