# All(全部满足)
## 方法名与分类
*   **方法名**：`All`
*   **分类**：量词操作符 (Quantifiers) / 逻辑判断

## 签名
*   **带条件版本：判断集合中的“所有元素”是否都满足指定条件**
```csharp
public static bool All<TSource>(
    this IEnumerable<TSource> source, 
    Func<TSource, bool> predicate // 传入一个返回 bool 的 Lambda 表达式
);
```
*   **注意**：与 `Any` 不同，`All` **没有无参版本**，因为必须提供一个判断标准才有意义。
*   **参数**：`predicate` 是用于测试每个元素的条件（委托）。
*   **返回**：`bool`。只有当集合中的**每一个**元素都让 `predicate` 返回 `true` 时，才返回 `true`。只要有**任意 1 个**元素返回 `false`，结果就为 `false`。

## 核心逻辑
*   **执行方式：立即执行**
*   **是否短路：是**。在遍历过程中，只要遇到**第一个**不满足条件（返回 `false`）的元素，就会立刻停止遍历并返回 `false`。后续元素不再执行判断。
*   **空集处理**：**（极度重要！）** 如果集合是**空集**，`All` 会**直接返回 `true`**。这在数学和逻辑学上被称为“空真 (Vacuous truth)”。因为没有元素违反你的条件，所以条件默认成立。

## 实战代码
**场景 1：检查一组数据是否全部达标（例如：所有科目均及格）**
```csharp
List<int> scores = new List<int> { 85, 92, 78, 60, 88 };

// 判断是否所有成绩都在 60 分或以上
bool isAllPassed = scores.All(s => s >= 60); 

Console.WriteLine(isAllPassed); // 输出: True
```

**场景 2：表单/业务逻辑校验（例如：所有任务是否都已经完成）**
```csharp
public class TaskItem 
{ 
    public string Name { get; set; }
    public bool IsCompleted { get; set; } 
}

List<TaskItem> projectTasks = new List<TaskItem>
{
    new TaskItem { Name = "设计", IsCompleted = true },
    new TaskItem { Name = "开发", IsCompleted = true },
    new TaskItem { Name = "测试", IsCompleted = false }
};

// 检查项目是否可以结项
bool canCloseProject = projectTasks.All(t => t.IsCompleted);

if (!canCloseProject)
{
    Console.WriteLine("还有未完成的任务，无法结项！"); // 触发此分支
}
```

## 避坑/性能指南
**致命避坑 1：空集合的“背刺” (Vacuous Truth)**
*   **现象**：当你对一个没有数据的空集合使用 `All` 时，它会返回 `true`，这经常会导致意外放行业务逻辑。
*   **错误写法**：
    ```csharp
    List<string> emptyList = new List<string>();
    // 你以为空集合没有包含"Admin"，应该返回 false？
    // 错！它会返回 True！
    bool allAdmins = emptyList.All(x => x.Role == "Admin"); 
    ```
*   **正确做法**：如果你要求“**集合不能为空，且所有元素都必须满足条件**”，需要配合 `Any()`：
    ```csharp
    bool isValid = list.Any() && list.All(x => x.Role == "Admin");
    ```

**致命避坑 2：空引用 (Null) 引发异常**
*   如果调用 `All` 的集合本身是 `null`，会抛出 `ArgumentNullException`。必须先确保集合不是 `null`，或者使用 null 条件运算符：
    ```csharp
    // 安全写法：如果是 null，直接返回 false
    bool isSafe = list?.All(x => x.IsValid) ?? false; 
    ```

**思维指南：`All` 与 `Any` 的逻辑反转 (德·摩根定律)**
在某些复杂判断中，`All` 可以和 `Any` 互相转换，有时候换一种写法代码更易读：
*   “所有人都成年了”：`users.All(u => u.Age >= 18)`
*   等价于“没有任何人未成年”：`!users.Any(u => u.Age < 18)` (后者在某些业务语境下阅读起来更直观)。
