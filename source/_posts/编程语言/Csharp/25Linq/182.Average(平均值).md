# Average (平均值)
## 方法名与分类
*   **方法名**：`Average`
*   **分类**：聚合操作符 (Aggregation)

## 签名
`Average` 方法针对各种数值类型（`int`, `long`, `double`, `decimal` 等）及其可空类型（`int?` `double?`等）提供了大量的重载。且返回值一般就只有`double`，`float`，`decimal` 核心分为两类：

*   **无参版本：直接计算数值集合的平均值**
```csharp
// 以 int 集合为例，注意返回类型变成了 double！
public static double Average(this IEnumerable<int> source);

// 如果是 decimal 集合，返回类型依然是 decimal
public static decimal Average(this IEnumerable<decimal> source);
```
*   **参数**：仅扩展当前集合本身（集合元素必须是数值类型）。
*   **返回**：集合元素的算术平均值。**注意返回类型的变化**，为了保证精度，对整型（`int`, `long`）求平均会返回浮点型（`double`）。

*   **带选择器 (Selector) 版本：计算对象集合中某个数值属性的平均值**
```csharp
// 提取对象中的 int 属性，返回 double
public static double Average<TSource>(
    this IEnumerable<TSource> source, 
    Func<TSource, int> selector 
);
```
*   **参数**：`selector` 是一个提取数值的委托（例如 `student => student.Score`）。
*   **返回**：提取出的属性的平均值。

## 核心逻辑
*   **执行方式：立即执行**。
*   **是否短路：否**。必须遍历整个集合，内部会进行累加求和（Sum）并统计个数（Count），最后做除法。时间复杂度为 **O(N)**。
*   **空集处理**：**（极度危险！）**
    *   如果提取的值是**不可为空的值类型**（如 `int`, `double`），对空集调用 `Average` 会**直接抛出 `InvalidOperationException`** (Sequence contains no elements)。
    *   如果提取的值是**可空值类型**（如 `int?`, `decimal?`），对空集调用会**返回 `null`**。

## 实战代码
**场景 1：基础用法（计算基础类型数组的平均分）**
```csharp
int[] scores = { 80, 95, 87 };

// 内部计算：(80 + 95 + 87) / 3
double avgScore = scores.Average(); 

Console.WriteLine($"平均分: {avgScore:F1}"); // 输出: 平均分: 87.3
```

**场景 2：带选择器用法（计算订单列表的平均金额）**
```csharp
class Order { public string OrderId; public decimal Amount; }

var orders = new List<Order>
{
    new Order { OrderId = "A1", Amount = 100.50m },
    new Order { OrderId = "A2", Amount = 200.00m },
    new Order { OrderId = "A3", Amount = 50.00m }
};

// 提取 Amount 属性并求平均
decimal avgAmount = orders.Average(o => o.Amount);

Console.WriteLine($"平均客单价: {avgAmount}"); // 输出: 平均客单价: 116.833333333333
```

## 避坑/性能指南
**致命避坑 1：空集合引发的“序列不包含任何元素”异常**
*   **现象**：和 `Min`/`Max` 一样，在没有数据（比如查数据库没查到记录返回了空 List）时直接 `.Average()`，程序会直接崩溃。
*   **错误写法**：`emptyList.Average(x => x.Score);` (抛异常)
*   **正确做法 1（提前判定，推荐）**：
    ```csharp
    double avg = list.Any() ? list.Average(x => x.Score) : 0.0;
    ```
*   **正确做法 2（强转为可空类型）**：
    ```csharp
    // 把 int 强转为 int?，如果是空集就会返回 null 
    double? safeAvg = list.Average(x => (int?)x.Score);
    double finalAvg = safeAvg ?? 0.0; 
    ```

**致命避坑 2：累加溢出异常 (OverflowException)**
*   **现象**：`Average` 在底层是先算出 `Sum()` 再除以 `Count()`。如果你的集合非常大，且元素数值也很大，虽然平均值不会超标，但**中途求和那一步**可能会超过数值类型的最大上限（比如整型求和超过了 `long.MaxValue`），此时会抛出 `OverflowException`。
*   **解决方案**：如果在处理极大数据量，请在求平均前将其转换为容量更大的类型（如 `double` 或 `decimal`）。
    ```csharp
    // 强制按 double 来累加和求平均，避免中途溢出
    double safeAvg = hugeList.Average(x => (double)x.HugeValue);
    ```

**性能/常识指南：类型转换与精度丢失**
*   **整数求平均**：LINQ 设计得很好，`IEnumerable<int>.Average()` 返回的是 `double`。它**不会**像普通的 C# 整数除法那样截断小数（比如 C# 中 `5 / 2 = 2`，但 LINQ 中 `new[] { 2, 3 }.Average() = 2.5`）。
*   **货币/财务计算**：如果涉及到钱，**绝对不要用 `double`** 类型的 `Average`（因为浮点数有精度问题）。必须确保你的属性是 `decimal` 类型，这样 `Average()` 返回的也是高精度的 `decimal`。
