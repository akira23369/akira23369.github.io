**面向对象基础：类与对象**

在 C# 这种面向对象编程（OOP）语言中，类和对象是核心基础。
- **类 (Class)**: 类是对象的模型或蓝图 。在 C# 中，必须先定义类，然后才能基于该类创建对象 。C# 编程的一条铁律是：每个程序至少必须包含一个类 。
- **对象 (Object)**: 对象代表现实世界中的实体（如具体的人或事物） 。


**程序的入口：Main 方法**

每个独立运行的 C# 程序都需要一个启动点，这就是 `Main` 方法。

- **执行起点**: `Main` 方法是所有 C# 程序的绝对执行入口 。当程序编译并运行时，公共语言运行库 (CLR) 会自动寻找 `Main` 方法来启动执行流 。即使程序中定义了其他类和方法，除非在 `Main` 方法内部调用它们，否则它们永远不会被执行 。
- **命名规范**: 方法名必须以大写字母 `M` 开头 。如果是小写的 `main`，系统将无法将其识别为有效的程序入口点 。
- **静态修饰符 (static)**: 通常情况下，调用一个类的方法需要先实例化该类的对象（例如，先创建 `Calculator` 对象，再调用其 `Add` 方法） 。但是，CLR 在启动程序时，并不会为包含 `Main` 方法的类创建任何对象实例 。因此，必须将 `Main` 声明为 `static` 静态方法，允许 CLR 在没有对象的情况下直接调用它 。
- **无返回值 (void)**: `void` 关键字表示该方法在执行完毕后不返回任何数据 。虽然也可以让 `Main` 返回一个整数 (`int`) 作为给操作系统的退出状态码（例如 `0` 表示成功，`1` 表示出现错误） ，但在绝大多数常规应用中，直接使用 `void` 即可 。

**Visual Studio 项目结构**

在 Visual Studio 中创建 C# 控制台应用（.NET Framework）时，需要理解其底层的文件组织方式：

- **解决方案 (Solution)**: 是一个包含一个或多个“项目”的顶级容器 。
- **项目 (Project)**: 是相关文件的集合，通常对应硬盘上的一个独立文件夹 。
- **源文件**: C# 代码文件的扩展名始终是 `.cs` 。值得注意的是，类名不需要与所在的 `.cs` 文件名保持一致。例如，文件可以叫 `Program.cs`，但里面的类可以命名为 `Sample` 。

**编写第一个应用程序代码**

编写 C# 类的基本语法是使用 `class` 关键字，后跟不能包含空格的类名，并用大括号 `{}` 将类的内部逻辑包裹起来 。

为了在控制台中输出信息并保持窗口开启，我们会用到基础类库 (BCL) 中的 `System` 命名空间：

- **System**: 预定义的命名空间 。
- **Console**: `System` 命名空间内部的一个预定义类 。
- **WriteLine()**: `Console` 类的静态方法，用于接收字符串参数并在控制台打印输出 。
- **ReadKey()**: `Console` 类的另一个静态方法。它的作用是让控制台窗口暂停，等待用户按下键盘上的任意键。这解决了程序执行过快导致控制台窗口“闪退”而无法看清输出结果的问题 。

由于 `WriteLine` 和 `ReadKey` 都是静态方法，因此无需创建 `Console` 对象即可直接通过 `类名.方法名` 的形式调用它们 。


```cs
// 定义一个自定义的类，名称为 Sample
class Sample
{
    // 程序的静态入口点
    static void Main()
    {
        // 调用 System 命名空间下的 Console 类的静态方法 WriteLine 打印字符串
        System.Console.WriteLine("Hello, C# World!");

        // 调用 ReadKey 静态方法，挂起控制台等待用户按键，防止窗口立即关闭
        System.Console.ReadKey();
    }
}
```
