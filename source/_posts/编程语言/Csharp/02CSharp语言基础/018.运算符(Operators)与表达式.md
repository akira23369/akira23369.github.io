运算符 (Operators) 与表达式

# 运算符的核心概念
运算符是用于执行特定数学或逻辑操作的符号。它接收一个或多个**操作数 (Operands)**，经过计算后返回一个单一的结果值。
*   **表达式 (Expression)**：由运算符和操作数组成的有效代码片段。例如 `10 + 5` 中，`+` 是运算符，`10` 和 `5` 是操作数。

# 算术与赋值运算符 (Arithmetic & Assignment)

**算术运算符**
用于执行基础的数学运算：`+` (加), `-` (减), `*` (乘), `/` (除), `%` (取模/求余)。

> **深度补充：除法与取模的陷阱与应用**
> *   **整数除法截断**：在 C# 中，如果 `/` 运算符两边都是整数（如 `10 / 3`），结果会自动截断小数部分，返回 `3`。若要得到浮点结果，至少需要一个操作数是浮点型（如 `10.0 / 3`）。
> *   **取模运算 (`%`) 的高频场景**：常用于判断奇偶性（`num % 2 == 0`）、限制索引范围（如循环数组：`index % array.Length`）以及提取数字的特定位。

**复合赋值运算符**
结合了算术运算与赋值操作，是一种**语法糖（Syntactic Sugar）**，用于简化代码：
`+=`, `-=`, `*=`, `/=`, `%=`。
*   **执行逻辑**：先进行算术计算，然后将结果覆盖写入原变量。例如 `a += 10;` 等价于 `a = a + 10;`。

# 自增与自减运算符 (Increment & Decrement)

用于将变量的值增加 1 (`++`) 或减少 1 (`--`)。其核心难点在于**前缀（Pre）**与**后缀（Post）**的区别。

*   **前缀模式 (`++a` / `--a`)**：**先运算，后返回值**。变量在内存中先加/减 1，然后将更新后的最新值作为整个表达式的结果返回。
*   **后缀模式 (`a++` / `a--`)**：**先返回值，后运算**。先将变量当前的值作为表达式的结果返回并缓存，然后在内存中对该变量加/减 1。

**代码原理解析：**
```csharp
int a = 10;
// 后缀：先打印 10，随后 a 在内存中变成 11
Console.WriteLine(a++); 

// 前缀：此时 a 是 11，先在内存中变成 12，随后打印 12
Console.WriteLine(++a); 
```

# 比较 (关系) 运算符 (Comparison Operators)

用于比较两个值，**永远返回布尔类型 (`bool`)**，即 `true` 或 `false`。
包括：`==` (等于), `!=` (不等于), `<` (小于), `>` (大于), `<=` (小于等于), `>=` (大于等于)。

# 逻辑运算符与“短路求值” (Logical Operators & Short-Circuit)

逻辑运算符用于组合多个布尔表达式，这是条件判断的核心。

## 基础逻辑运算符（非短路）
*   **逻辑与 `&`**：两边都为 `true` 时返回 `true`。**缺陷**：即使左侧已经为 `false`（注定整体为 `false`），依然会强制计算右侧的表达式。
*   **逻辑或 `|`**：只要有一侧为 `true` 就返回 `true`。**缺陷**：即使左侧已经为 `true`（注定整体为 `true`），依然会强制计算右侧。

## 条件逻辑运算符（短路运算符 - 极度推荐）
为了解决性能浪费和潜在的运行时异常，C# 提供了双符号的短路运算符：
*   **短路与 `&&`**：如果左侧为 `false`，直接返回 `false`，**跳过（短路）右侧的执行**。
*   **短路或 `||`**：如果左侧为 `true`，直接返回 `true`，**跳过（短路）右侧的执行**。

> **深度补充：短路求值的实战意义（防止空引用异常）**
> 短路运算符不仅是为了优化性能，更是为了代码安全。例如在检查对象属性时：
> `if (user != null && user.Age > 18)`
> 如果 `user` 为 `null`，左侧为 `false`，右侧 `user.Age` 根本不会被执行，从而完美避免了抛出 `NullReferenceException`。如果此处错用单符号 `&`，程序将直接崩溃。

# 异或与取反
*   **逻辑异或 `^` (XOR)**：要求操作数**必须且只能有一个为 true**。如果两边同为 `true` 或同为 `false`，结果都是 `false`。（可以理解为“排他性判断”）。
*   **逻辑非 `!` (NOT)**：一元运算符，用于布尔值的反转。`!true` 变 `false`。

# 字符串拼接运算符 (Concatenation)

在 C# 中，`+` 运算符被**重载 (Overloaded)**。
*   当两边都是数字时，执行数学加法。
*   **只要其中一侧是字符串 (`string`)**，`+` 就会转变为**拼接运算符**，将另一侧自动转换为字符串并连接起来。整体结果必定是字符串。

> **深度补充：字符串拼接的性能考量**
> 字符串在 C# 中是**不可变类型 (Immutable)**。频繁使用 `+` 进行拼接（尤其是在循环中）会不断在堆内存中创建新的字符串对象，导致内存碎片和垃圾回收（GC）压力。
> 现代 C# 开发推荐替代方案：
> 1.  **字符串插值 (String Interpolation)**：`$"Name: {name}, Age: {age}"`，可读性极佳。
> 2.  **`StringBuilder` 类**：专门用于处理大规模、高频次的字符串拼接。

# 三元条件运算符 (Ternary Conditional Operator)

这是 C# 中唯一接受三个操作数的运算符，是简单 `if-else` 语句的优雅替代品。

**语法结构：**
`[布尔表达式] ? [若为True的结果] : [若为False的结果];`

**代码示例：**
支持链式嵌套（但不推荐嵌套过深，会破坏可读性）：
```csharp
int age = 20;
// 链式三元运算示例
string title = (age < 13) ? "Child" : 
               (age >= 13 && age <= 19) ? "Teenager" : "Adult";
Console.WriteLine(title); // 输出: Adult
```

# 运算符优先级与结合性 (Operator Precedence)

![](018.运算符(Operators)与表达式/file-20260315161950815.png)

当一个复杂的表达式中包含多个运算符时，C# 编译器按照固定的优先级规则执行计算。
*   **高优先级先执行**：例如，乘除法 `* /` 优先级高于加减法 `+ -`。
*   **结合性决定同级执行顺序**：
    *   多数算术和逻辑运算符是**从左向右**结合的（如 `10 / 2 * 5` 会先算 `10/2`）。
    *   赋值运算符（`=`, `+=`）和前缀自增/自减（`++a`）是**从右向左**结合的。

> **深度补充：控制优先级的最佳实践**
> 尽管背诵优先级表格（如圆括号最高，赋值最低）是有益的，但在实际工程开发中，**强烈建议使用圆括号 `()` 来显式圈定运算边界**。这不仅能覆盖默认的优先级规则，更重要的是极大提升了代码的**可读性**和**意图清晰度**，减少团队协作时的理解成本。
> 示例：`int result = 10 + (4 * (30 / 10));` 比单纯的 `10 + 4 * 30 / 10` 更安全易读。
