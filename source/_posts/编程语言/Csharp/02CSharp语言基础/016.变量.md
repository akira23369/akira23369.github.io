C# 核心基础笔记：变量 (Variables) 与内存管理

# 变量的核心概念
变量是计算机内存（RAM）中一个具名的存储单元，用于在程序执行期间临时存储特定类型的数据。
* **唯一性**：一个变量在同一时刻只能存储一个值。
* **强类型（Strongly Typed）**：C# 是一门强类型语言。声明变量时必须指定其数据类型（如 `int`, `string` 等）。一旦声明，变量的**数据类型不可更改**，但其**存储的值可以被多次修改**（这也是其被称为“变量”的原因）。
* **先声明后使用**：在 C# 中，所有变量必须在使用前被声明。

# 变量的内存分配机制（深入理解栈内存）
在 C# 中，方法的执行与内存分配密切相关。

* **栈（Stack）机制**：每次调用一个方法（例如 `Main` 方法）时，公共语言运行库（CLR）都会在内存中为该方法分配一块专属的内存区域，称为“栈帧（Stack Frame）”。
* **局部变量的生命周期**：在方法内部声明的变量称为**局部变量**。这些变量被分配在所属方法的栈中。
* **短生命周期（Short-lived）**：当方法执行完毕后，对应的栈帧会被自动销毁（释放），存储在其中的所有局部变量也会随之丢失。这意味着局部变量的作用域仅限于其所在的方法内部。

> **深度补充：栈（Stack）与堆（Heap）的初步区分**
> 虽然局部变量分配在栈上，但根据数据类型的不同，实际存储的细节有所区别：
> * **值类型（Value Types，如 `int`, `float`, `double`）**：变量的名称和具体的值直接存储在栈内存中。
> * **引用类型（Reference Types，如 `string`, `class`）**：栈内存中仅存储该变量的内存地址（指针），而真正的数据（如具体的字符串内容）被分配在**堆（Heap）**内存中。当栈被销毁时，指针丢失，堆中的孤立数据后续会由垃圾回收器（GC）清理。

# 变量的声明与初始化
可以分步进行，也可以在声明时直接赋值（初始化）。

**语法结构：**
`[数据类型] [变量名] = [初始值];`

**内部操作拆解：**
以 `int x = 100;` 为例，这行代码在底层执行了双重操作：
1. **创建（声明）**：在当前方法的栈中开辟一块名为 `x` 的整数类型空间。
2. **初始化（赋值）**：将数值 `100` 放入这块空间中。

## 变量命名规则与规范

**强制性硬规则（编译器会检查）：**
1. **不允许包含空格**：如 `student name` 是非法的，必须连写。
2. **不允许包含特殊字符**：不能使用 `#`, `*`, `+` 等，**仅允许使用下划线 `_`**。
3. **不可重复声明**：在同一个方法（同一个作用域）内，不能出现两个同名的变量。
4. **不能使用关键字**：如 `int`, `void`, `class`, `struct` 等保留字有语言层面的特定含义，不能作为变量名。

**最佳实践规范（业界共识）：**
* 局部变量应采用 **CamelCase（小驼峰命名法）**。即第一个单词首字母小写，后续每个单词首字母大写。例如：`studentName`, `totalScore`。

# 代码示例与解析

以下是一个完整的控制台应用程序示例，展示了变量的声明、赋值以及如何在控制台中输出拼接后的变量：

```csharp
using System;

namespace VariablesExample
{
    class Sample
    {
        // 程序的入口点
        // 补充：string[] args 用于接收来自操作系统命令行的参数传入
        static void Main(string[] args)
        {
            // 1. 变量的声明与初始化
            int a = 100;
            string studentName = "Scott";
            int age = 20;

            // 2. 打印变量的值 vs 打印字面量
            Console.WriteLine(a);   // 输出：100 (不带双引号，代表打印变量a存储的值)
            Console.WriteLine("a"); // 输出：a (带双引号，被视为字符串字面量)

            // 3. 变量值的拼接输出
            // 传统方式：使用加号（+）进行字符串拼接
            Console.WriteLine("Hey " + studentName + ", your age is " + age);

            // 深度补充：更现代、更推荐的 C# 字符串插值（String Interpolation）方式
            // 在字符串前加 $ 符号，可以直接在花括号内填入变量名，代码可读性更高
            Console.WriteLine($"Hey {studentName}, your age is {age}");

            // 暂停控制台，等待用户按键，防止窗口一闪而过
            Console.ReadKey();
        }
    }
}
```

# 扩展概念：关于全局变量
**C# 中不存在真正的“全局变量（Global Variables）”**。
作为一门纯粹的面向对象编程语言，C# 不允许在类的外部定义变量。如果需要在整个应用程序中共享某个状态或数据，通常的替代方案是在类中使用静态字段（`public static` fields）或属性。这种设计增强了代码的封装性和安全性，避免了传统 C/C++ 中全局变量满天飞导致的内存难以追踪问题。
