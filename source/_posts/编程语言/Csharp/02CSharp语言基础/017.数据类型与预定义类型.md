**C# 核心基础笔记：数据类型 (Data Types) 与预定义类型 (Primitive Types)**

# 数据类型的核心概念与分类体系

数据类型（Type）决定了变量或字段在内存中存储数据的种类、占用空间的大小以及可以对该数据执行的操作。

在 C# 和整个 .NET 生态中，数据类型有着严格的分类：
*   **按底层架构分类**：
    *   **值类型（Value Types）**：数据直接存储在栈（Stack）中。大多数基础数字类型、结构体（Structs）和枚举（Enums）属于此类。
    *   **引用类型（Reference Types）**：栈中仅保存内存地址（指针），真实数据分配在堆（Heap）中。类（Classes）、接口（Interfaces）和字符串（String）属于此类。
*   **按抽象层级分类**：
    *   **预定义类型 / 原生类型（Primitive Types）**：严格只能存储单一基础值（如一个数字、一个布尔状态、一个字符），它们是构建复杂数据类型的基石。
    *   **非预定义类型（Non-primitive Types）**：通常是预定义类型的组合，能够存储多个值或具有复杂的内部结构，如类、记录、字符串等。

> **深度补充：公共类型系统 (CTS)**
> C# 中的基本数据类型实际上是 .NET 框架中“公共类型系统（Common Type System, CTS）”类型的别名。例如，C# 中的关键字 `int` 只是底层 `System.Int32` 结构的简写。这保证了在使用不同 .NET 语言（如 C# 和 VB.NET）时，数据类型在底层是完全统一的。

# 整数类型家族

整数类型用于存储没有小数部分的数值。根据对内存的需求以及是否需要支持负数，C# 提供了多种选择。带 `U` 前缀的代表 **Unsigned（无符号）**，即不保留符号位，因此只能存储正数，但其正数的上限是对应有符号类型的两倍。

| C# 类型关键字  | .NET CTS 类型     | 内存占用       | 取值范围特征                                 |
| :-------- | :-------------- | :--------- | :------------------------------------- |
| `sbyte`   | `System.SByte`  | 1 字节 (8位)  | 有符号，-128 到 127                         |
| `byte`    | `System.Byte`   | 1 字节 (8位)  | 无符号，0 到 255                            |
| `short`   | `System.Int16`  | 2 字节 (16位) | 有符号，约 -3.2万 到 3.2万                     |
| `ushort`  | `System.UInt16` | 2 字节 (16位) | 无符号，0 到 65,535                         |
| **`int`** | `System.Int32`  | 4 字节 (32位) | 有符号，约 -21亿 到 21亿。**（代码中整数常量的默认类型）**    |
| `uint`    | `System.UInt32` | 4 字节 (32位) | 无符号，0 到约 42亿                           |
| `long`    | `System.Int64`  | 8 字节 (64位) | 有符号，极大的整数。**（超出 int 范围的常量默认被视为 long）** |
| `ulong`   | `System.UInt64` | 8 字节 (64位) | 无符号，最大支持到 $2^{64}-1$                   |

**字面量解析机制**：
如果在代码中直接写一个数字（如 `100`），C# 编译器会默认将其视为 `int` 类型。如果数字超出了 `int` 的范围，编译器会自动将其推断为 `long`。

# 浮点型与高精度小数(Floating-Point & Decimal)

当需要存储带有小数部分的数值时，需要使用浮点类型或十进制类型。

| 类型 | 内存占用 | 精度 (有效数字) | 字面量后缀 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| `float` | 4 字节 | 约 7 位 | `f` 或 `F` | 对内存敏感、精度要求不高的图形学或 3D 引擎运算。 |
| **`double`** | 8 字节 | 约 15 位 | `d` 或 `D` (可选) | **代码中小数常量的默认类型**，适用于常规的科学计算和测量数据。 |
| `decimal` | 16 字节 | 28 - 29 位 | `m` 或 `M` | 金融、货币等需要绝对无损的精确计算场景。 |

> **深度补充：为什么金融计算必须用 Decimal 而不能用 Double？**
> `float` 和 `double` 在计算机底层基于 **基数2（二进制）** 进行存储（遵循 IEEE 754 标准）。这会导致它们无法精确表示某些十进制小数（例如 `0.1` 在二进制中是一个无限循环小数），从而在计算时产生舍入误差。而 `decimal` 是基于 **基数10（十进制）** 存储的，虽然运算速度稍慢、占用内存更大，但它能保证在 28 位精度内不产生任何微小的二进制转换误差。

# 字符、字符串与布尔型 (Char, String & Bool)

**字符型 (`char`)**
*   **内存与编码**：占用 2 字节内存，基于 **16位 Unicode (UTF-16)** 编码。
*   **优势**：相较于早期的 ASCII 编码（仅支持英文字符和基础符号），Unicode 是 ASCII 的超集，能够支持全球几乎所有的自然语言字符（如中文、日文、西班牙文等）。
*   **语法**：使用单引号声明，如 `'A'`。默认值为 `\0`（空字符）。

**字符串 (`string`)**
*   **本质**：`string` **不属于预定义（原生）类型**。它是一个非预定义类型，本质上是由多个 `char` 字符组成的只读集合。
*   **内存特征**：它是引用类型。每个标准字符占用 2 字节空间（如果是复杂的 Emoji 或冷僻字，可能会使用 4 字节的代理项对）。最大容量可达约 20 亿个字符。
*   **语法**：使用双引号声明，如 `"Hello"`。默认值为 `null`。

**布尔型 (`bool`)**
*   用于表示逻辑上的真（`true`）或假（`false`）。
*   **内存特征**：在逻辑上它只代表 1 个 bit（0 或 1），但在物理内存分配中，由于 CPU 寻址的最小单位是字节，它实际上会占用 1 个字节（8 bits）的内存。默认值为 `false`。

# 变量的边界值与默认值初始化

在 C# 中，可以通过类型自带的常量或关键字来获取类型的极限值或默认值：
*   **获取极值**：使用 `[类型].MinValue` 和 `[类型].MaxValue`。
*   **获取默认值**：使用 `default([类型])` 关键字。数字类的默认值均为 `0`，布尔类为 `false`，对象引用类（如 string）为 `null`。

# 综合代码示例

以下代码展示了如何声明、初始化以及使用不同数据类型的极值和后缀：

```csharp
using System;

namespace PrimitiveTypesExample
{
    class Program
    {
        static void Main()
        {
            // 1. 整数类型极值与默认值演示
            sbyte maxSByte = sbyte.MaxValue; // 获取 sbyte 的最大值 127
            int defaultInt = default(int);   // 获取 int 的默认值 0
            
            // 2. 字面量后缀演示
            // 100 默认是 int。赋值给 int 没问题
            int standardInt = 100;
            
            // 10.5 默认是 double。
            // 必须加 f 后缀才能存入 float，否则编译器报错（防止精度丢失）
            float piFloat = 3.14159f;
            
            // 必须加 m 后缀才能存入 decimal
            decimal bankBalance = 100000.50m; 

            // double 的 d 后缀是可选的，因为带小数的字面量默认就是 double
            double scientificValue = 10.123456789; // 等同于 10.123456789d

            // 3. 字符与字符串演示
            char letter = 'A'; // 单引号，存储单个 Unicode 字符
            string message = "Hello World"; // 双引号，引用类型，存储字符集合

            // 4. 布尔型演示
            bool isActive = true; // 仅接受 true 或 false
            bool defaultBool = default(bool); // 获取默认值 false

            // 输出演示
            Console.WriteLine($"Max SByte: {maxSByte}");
            Console.WriteLine($"Default Int: {defaultInt}");
            Console.WriteLine($"Float value: {piFloat}");
            Console.WriteLine($"Decimal value: {bankBalance}");
            Console.WriteLine($"Letter: {letter}");
            Console.WriteLine($"Default Bool: {defaultBool}");

            Console.ReadKey();
        }
    }
}
```
