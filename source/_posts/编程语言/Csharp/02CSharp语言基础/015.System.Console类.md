# 一、 核心概念与定位

`Console` 是 C# 中用于在命令行（控制台）窗口执行输入/输出（I/O）操作的预定义类。它的作用类似于 C 语言中的 `printf` 和 `scanf` 函数，是构建交互式控制台应用程序的基础。

**关键特性理解：**
1. **命名空间归属**：`Console` 类属于 `.NET` 框架基础类库（BCL）中的 `System` 命名空间。调用时可以使用完全限定名 `System.Console`，但在实际开发中，通常会在文件顶部添加 `using System;` 指令，以便直接使用 `Console`。
2. **静态类（Static Class）**：`Console` 是一个静态类，这意味着它的所有成员（方法和属性）都是静态的。
    * *深度理解*：为什么设计为静态类？因为在控制台应用程序中，标准的输入流（键盘）和输出流（屏幕）通常只有一个上下文。将 `Console` 设计为静态类，意味着开发者**不需要也不能**使用 `new Console()` 来实例化对象，直接通过类名即可调用底层系统的 I/O 资源，这在架构设计上更加合理且节省内存。

# 二、 核心方法详解

在常规的应用程序开发中，`Console` 类最常用的方法主要有以下几个：

## 文本输出方法：`Write()` 与 `WriteLine()`
这两个方法都用于向控制台打印信息，返回类型均为 `void`（即不返回任何值），它们的主要区别在于对光标位置的处理：

* **`Write(参数)`**：将参数内容输出到控制台后，**光标保持在同一行**的末尾。如果要将多个信息并排连续输出，应使用此方法。
* **`WriteLine(参数)`**：将参数内容输出到控制台后，**自动添加一个换行符**，光标会移动到下一行的开头。如果要逐行打印信息，应使用此方法。

## 读取输入与屏幕控制：`ReadKey()`、`ReadLine()` 与 `Clear()`
* **`ReadKey()`**：等待用户按下键盘上的任意一个键。
    * *应用场景*：在调试控制台程序时，程序执行完毕后窗口往往会一闪而过瞬间关闭。在程序末尾加上 `Console.ReadKey();` 可以让程序暂停，直到用户按键后才结束，方便查看输出结果。
* **`Clear()`**：清空当前控制台窗口中的所有内容（返回 `void`）。
    * *应用场景*：在开发多步骤的交互式菜单时，可以通过清屏来保持界面的整洁，为用户提供更好的视觉体验。
* **`ReadLine()`**：等待用户输入一行文本，直到按下 Enter（回车）键为止。
    * *核心细节*：该方法**永远返回一个 `string`（字符串）类型的数据**。即使用户输入的是纯数字（如 "123"），程序也会将其视为字符集合。
    * *补充完善*：如果需要将用户的输入用于数学计算，必须进行**类型转换**（例如使用 `int.Parse()` 或 `Convert.ToInt32()` 将字符串解析为数值类型）。

# 三、 代码实战演示

以下代码综合展示了上述所有方法的实际工作流程以及类型转换的补充用法：

```csharp
using System;

namespace ConsoleClassExample
{
    class Sample
    {
        static void Main(string[] args)
        {
            // 1. 使用 WriteLine 逐行输出
            Console.WriteLine("Welcome");
            Console.WriteLine("to");
            Console.WriteLine("C# Programming");

            Console.WriteLine(); // 打印一个空行作为分隔

            // 2. 使用 Write 并排连续输出 (注意字符串内的空格)
            Console.Write("Welcome ");
            Console.Write("to ");
            Console.Write("C# Programming\n"); // \n 等同于换行

            // 3. 暂停程序，等待用户按键
            Console.WriteLine("\nPress any key to clear the screen...");
            Console.ReadKey(); 

            // 4. 清空控制台屏幕
            Console.Clear();

            // 5. 补充：使用 ReadLine 接收输入并进行类型转换
            Console.Write("Please enter your age: ");
            string inputAge = Console.ReadLine(); // 始终返回 string

            // 将字符串解析为整数进行运算 (补充知识点)
            int age = int.Parse(inputAge); 
            int nextYearAge = age + 1;
            
            Console.WriteLine("Next year, you will be: " + nextYearAge);

            // 再次暂停，防止窗口闪退
            Console.WriteLine("\nThank you! Press any key to exit.");
            Console.ReadKey();
        }
    }
}
```

# 四、 C# 命名规范（PascalCase）

在 C# 编程中，必须严格遵守命名约定，这不仅是语法要求（C# 大小写敏感），也是提高代码可读性的行业标准。

* **帕斯卡命名法（PascalCase）**：规定标识符中的**每一个单词的首字母都必须大写**。
* **适用范围**：
    * 命名空间名称（如 `System`）
    * 类名称（如 `Console`, `Sample`）
    * 方法名称（如 `WriteLine`, `Write`, `ReadKey`, `Clear`）

*补充区别*：在 C# 中，局部变量名和方法的参数名通常使用**驼峰命名法（camelCase）**，即第一个单词首字母小写，后续单词首字母大写（例如上文代码中的 `inputAge`）。

# 五、 IDE 调试基础 (Visual Studio)

在使用 Visual Studio 等 IDE 进行开发时：
* **启动程序**：点击工具栏上的 "Start" 按钮（快捷键 `F5`）将编译并执行代码。
* **停止调试**：可以通过点击工具栏的方形 "Stop Debugging" 按钮，或者通过菜单栏 `Debug -> Stop Debugging`（快捷键 `Shift + F5`）强制终止处于运行状态的程序。
* *补充技巧*：如果不想在代码末尾写 `Console.ReadKey()` 来阻止窗口闪退，可以使用 `Ctrl + F5`（Start Without Debugging）运行程序，IDE 会在程序结束时自动附加一行 "Press any key to continue..."。
