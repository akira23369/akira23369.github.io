# C# 面向对象编程 - 基础

## 第一讲：理解面向对象编程基础

### 简介

面向对象编程（OOP）是我们思考和构建程序方式的根本性转变。在 OOP 出现之前，主导风格是过程式编程，程序本质上是一长串作用于数据的指令或函数列表。这种方式适用于小型程序，但随着应用程序规模和复杂度的增长，管理变得极其困难。代码某部分的修改可能会不可预测地破坏其他部分，导致所谓的"意大利面条式代码"。

OOP 正是为解决这种复杂性而诞生的。其核心理念简单却强大：我们不再将数据与操作数据的行为分离，而是将它们捆绑成概念性的"对象"。我们不再将程序视为一系列步骤，而是开始将其看作交互对象的集合，每个对象都模拟了我们试图解决的问题中的一个独立实体。

### 核心理念：世界建模

在编程中，"对象"代表一个人、地点、事物，甚至是一个抽象概念。以一个简单的电商应用为例，过程式编程可能会为产品名称、价格和库存数量分别设置变量，并用单独的函数来更新库存或计算总额。

面向对象编程（OOP）会采用不同的建模方式：

- 我们会创建一个 Product 对象 。这个独立对象将包含它自己的数据：name（名称）、price（价格）和 stockLevel（库存量）。
    
- 它还会包含自己的行为：诸如 Purchase(quantity)（购买数量）或 IsInStock()（是否有货）之类的方法。
    

同样地，我们会有一个 Customer 对象，它拥有自己的数据（name、address）和行为（PlaceOrder()）。

我们还可以有一个 ShoppingCart 对象，包含自己的数据（商品列表）和行为（AddItem()、CalculateTotal()）。

程序就变成了这些对象交互的模拟：Customer 对象执行 PlaceOrder() 操作，这个过程可能涉及 ShoppingCart 对象在完成购买前检查每个 Product 对象是否 IsInStock()。

### 对象的三个核心概念

面向对象编程中的每个对象都具有三个关键特征：

- **标识**： 每个对象都是独特的实体，即使它们属于同一类型且拥有相同数据，也与其他所有对象不同。当我们创建两个不同的 Product 对象时，它们会占据内存中的不同空间。
    
- **状态**： 这是描述对象在任意时刻的数据或属性。Car 对象的状态可能包括其当前的 color（颜色）、currentSpeed（当前速度）和 fuelLevel（燃油量）。状态存储在对象的字段 （变量）中。
    
- **行为**： 这是对象能够执行的操作。Car 对象的行为由其方法定义，例如 Accelerate()（加速）、Brake()（刹车）和 Refuel()（加油）。这些方法通常用于修改对象的内部状态。
    

### 面试视角

**问题**："能否从高层次解释什么是面向对象编程？"

**理想回答**："面向对象编程(OOP)是一种围绕数据或'对象'而非函数和逻辑来组织软件设计的编程范式。它通过将数据（状态）和操作这些数据的方法（行为）捆绑成单一单元来管理复杂性。与自上而下的过程式方法不同，OOP 应用程序被建模为相互交互的对象集合，这些对象通常代表现实世界的实体。这使得代码更具模块化、可重用性，并且在规模增长时更易于维护。"

## 第二讲：创建类与对象

### 引言

既然我们已经理解了“对象”的概念，现在需要一种方式来定义对象的外观和行为。这就是类的作用。类是对象的蓝图、模板或设计方案，而对象则是根据该蓝图构建的具体实例。

你可以拥有一个 Car 类（蓝图），但可以用它来构建成千上万个独立的 Car 对象，每个对象都有自己独特的状态（可能一个是红色法拉利，另一个是蓝色福特）。

### 定义类

使用 class 关键字定义类，后跟类名（应采用 PascalCase 命名法）。在大括号 {} 内定义其成员：字段和方法。

​ 
```cs
// 这是所有Car对象的蓝图  
public class Car  
{  
    // 1. 字段：用于存储对象状态的变量  
    // 按照惯例，我们将字段设为私有以保护它们（封装）  
    // 下划线前缀(_)是私有字段的通用命名约定  
    private string _color;  
    private string _model;  
    private int _currentSpeed;  
​  
    // 2. 方法：定义对象行为的函数  
    // 我们将它们设为公共的，以便代码的其他部分可以使用它们  
    public void Accelerate()  
    {  
        // 该方法修改对象的内部状态  
        _currentSpeed += 10;  
        Console.WriteLine($"正在加速。当前速度：{_currentSpeed} 公里/小时");  
    }  
​  
    public void Brake()  
    {  
        if (_currentSpeed > 0)  
        {  
            _currentSpeed -= 5;  
            Console.WriteLine($"正在刹车。当前速度：{_currentSpeed} 公里/小时");  
        }  
    }  
​  
    // 用于受控访问私有字段值的方法  
    public string GetColor()  
    {  
        return _color;  
    }  
      
    // 用于受控修改私有字段值的方法  
    public void SetColor(string newColor)  
    {  
        // 如果需要，我们可以在这里添加验证逻辑  
        _color = newColor;  
    }  
}
```


### 创建对象（实例化）

一旦有了类（蓝图），就可以从中创建对象。这个过程称为实例化。我们使用 new 关键字来实现这一点。

​
```cs
// 程序运行的Main方法  
static void Main(string[] args)  
{  
    // 1. 声明：声明一个可以持有Car对象引用的变量  
    Car myFirstCar;  
​  
    // 2. 实例化：使用'new'关键字在内存中创建一个新的Car对象  
    //    并将其内存地址分配给我们的变量  
    myFirstCar = new Car();  
​  
    // 或者更常见的写法，一步完成：  
    Car mySecondCar = new Car();  
​  
    // 现在我们在内存中有两个不同的Car对象  
}
```

### 访问成员

使用点运算符（.）与对象的公共成员进行交互。

​
```cs
// 继续在Main方法中...  
​  
// 使用公共方法设置第一辆车的状态  
myFirstCar.SetColor("红色");  
​  
// 调用方法改变其行为  
myFirstCar.Accelerate(); // 输出：正在加速。当前速度：10 公里/小时  
myFirstCar.Accelerate(); // 输出：正在加速。当前速度：20 公里/小时  
myFirstCar.Brake();      // 输出：正在刹车。当前速度：15 公里/小时  
​  
// 现在操作第二辆车，它是完全独立的  
mySecondCar.SetColor("蓝色");  
mySecondCar.Accelerate(); // 输出：正在加速。当前速度：10 公里/小时  
​  
// 获取第一辆车的颜色不会影响第二辆车  
Console.WriteLine($"我的第一辆车的颜色是：{myFirstCar.GetColor()}");   // 输出：红色  
Console.WriteLine($"我的第二辆车的颜色是：{mySecondCar.GetColor()}"); // 输出：蓝色  
​  
// 重要提示：你不能从类外部直接访问私有字段  
// 下面这行代码会导致编译错误：  
// myFirstCar._currentSpeed = 100; // 错误！'_currentSpeed' 无法访问

```


### 面试视角

**问题**："类和对象有什么区别？"

**理想回答**："类是一个蓝图或模板，定义了某种事物的属性和行为。它存在于编译时，本身不占用内存。对象是类的具体实例，在运行时创建。它是实际占用内存并拥有自身状态的实体。就像可以根据一张蓝图建造多栋房屋一样，可以从单个类创建多个对象。"

## 第三讲：关于类和对象需要牢记的重要知识点

### 引言

理解类和对象背后的一些关键概念至关重要。这些知识点经常成为面试问题的主题，因为它们考察的是对基础语法之外更深层次的理解。

### 1. 类属于引用类型

这是现阶段需要理解的最重要概念。当你创建一个类类型的变量时，该变量并不持有对象本身，而是持有一个引用 ——本质上是内存地址——指向对象存储的位置。实际对象存在于称为堆的内存区域中。

#### 工作原理及其重要性：

由于变量持有的是引用而非对象本身，因此可以有多个变量引用同一个对象。

​  
```cs
// 我们在内存中创建一个Car对象  
// carA持有该对象的内存地址  
Car carA = new Car();  
carA.SetColor("绿色");  
​  
// 我们声明一个新变量carB  
// 然后将carA的值复制到carB中  
// carA的值是内存地址，而不是对象本身  
// 现在，carA和carB都指向内存中完全相同的对象  
Car carB = carA;  
​  
Console.WriteLine($"汽车A的颜色：{carA.GetColor()}"); // 输出：绿色  
Console.WriteLine($"汽车B的颜色：{carB.GetColor()}"); // 输出：绿色  
​  
// 现在，我们通过carB引用更改颜色  
carB.SetColor("黄色");  
Console.WriteLine("--- 通过carB修改颜色后 ---");  
​  
// 因为两个变量都指向同一个对象，所以当我们  
// 通过carA访问对象时，也能反映出这个变化  
Console.WriteLine($"汽车A的颜色：{carA.GetColor()}"); // 输出：黄色  
Console.WriteLine($"汽车B的颜色：{carB.GetColor()}"); // 输出：黄色
```

#### 面试视角：

**问题**："当你将一个对象变量赋值给另一个时会发生什么？会创建对象的副本吗？"

**理想答案**："不会创建对象副本。因为类是引用类型，变量持有的是对象在内存中位置的引用。当你将一个变量赋值给另一个时，实际上只是复制了引用。两个变量随后将指向堆中的同一个对象。通过任一变量对对象所做的修改，都会通过另一个变量反映出来。"

### 2. new 关键字解析

`new` 关键字不仅仅是一种语法，它按顺序执行三个不同的操作：

1. **内存分配**：它在**堆**上分配一块足够大的内存空间，用于存储类中定义的所有字段。
    
2. **构造函数执行**：它会调用类中的一个特殊方法，称为**构造函数**（后续章节会详细介绍）。构造函数的职责是将对象的字段初始化为有效的起始状态。
    
3. **返回引用**：对象初始化完成后，`new` 操作符会返回新创建对象的内存地址（即引用），该引用随后被存储在你的变量中。
    

### 3. 类的成员

目前我们已经了解了两种成员类型：字段和方法。不过，类还可以包含其他几种成员，这些将在后续学习中介绍。了解以下术语很有帮助：

- **字段**：存储对象状态的变量。
    
- **方法**：定义对象行为的函数。
    
- **属性**：一种更高级的数据暴露方式，它结合了字段的简洁性和方法的控制性（通常用于替代 Get... 和 Set... 方法）。
    
- **构造函数**：用于在创建新对象时进行初始化的特殊方法。
    
- **事件**：对象向其他对象提供通知的机制。
    
- 更多内容...（如终结器、索引器和嵌套类型）。
