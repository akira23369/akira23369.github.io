# CountdownEvent 简单讲解

## 一、CountdownEvent 是什么？（"等人到齐"神器）

**大白话理解**：`CountdownEvent` 就是一个**倒计时计数器**。你告诉它"要等3个人"，然后干自己的事去了。每有一个人到齐，就喊一声"我好了"，计数器减1。等3个人都喊完了，计数器变0，**它会自动通知你"人齐了，可以开始了"**。

**核心特点**：
- **倒计时**：初始值=N，每调用一次 `Signal()` 减1
- **自动开门**：计数器到0时，**所有**等待的线程自动通过
- **一次性**：计数到0后就不能重用（除非 `Reset()`）

---

## 二、核心方法（4个就够了）

```csharp
CountdownEvent countdown = new CountdownEvent(3); // 初始计数=3
```

| 方法 | 作用 | 大白话 |
|------|------|--------|
| **`Signal()`** | 计数器-1 | "我到了" |
| **`Signal(int count)`** | 计数器-count | "我们N个人到了" |
| **`Wait()`** | 等计数器变0 | "人到齐之前我等着" |
| **`Wait(int timeout)`** | 带超时等待 | "等N秒，人没齐我也走了" |
| **`Reset()`** | 重置计数器 | "重新数一遍" |

---

## 三、代码示例（一看就懂）

### 示例：等3个下载任务完成

```csharp
using System;
using System.Threading;

class Program
{
    static void Main()
    {
        Console.WriteLine("主线程：开始并行下载3个文件...");

        // 1. 创建倒计时器，初始值=3（等3个任务）
        CountdownEvent downloadCountdown = new CountdownEvent(3);

        // 2. 启动3个下载线程
        for (int i = 1; i <= 3; i++)
        {
            int fileId = i;
            new Thread(() => {
                Console.WriteLine($"线程{Thread.CurrentThread.ManagedThreadId}：开始下载文件{fileId}");
                Thread.Sleep(fileId * 1000); // 模拟下载耗时
                
                Console.WriteLine($"线程{Thread.CurrentThread.ManagedThreadId}：文件{fileId}下载完成！");
                downloadCountdown.Signal(); // 下载完喊一声，计数器-1
                
            }).Start();
        }

        // 3. 主线程等待计数器归零
        Console.WriteLine("主线程：等所有文件下载完...");
        downloadCountdown.Wait(); // 阻塞，直到计数器=0
        
        Console.WriteLine("主线程：3个文件都下载完了，开始合并！");
        
        // 4. 用完可以 Reset() 重用（可选）
        downloadCountdown.Reset(2); // 重置成等2个
    }
}
```

**输出**：
```
主线程：开始并行下载3个文件...
主线程：等所有文件下载完...
线程6：开始下载文件1
线程7：开始下载文件2
线程8：开始下载文件3
线程6：文件1下载完成！
线程7：文件2下载完成！
线程8：文件3下载完成！
主线程：3个文件都下载完了，开始合并！
```

**关键点**：
- 主线程调用 `Wait()` 后**卡住**，不会空转浪费CPU
- 3个子线程**各自**调用 `Signal()`，计数器从3→2→1→0
- 计数器到0的瞬间，主线程的 `Wait()` **自动返回**，继续执行

## 四、与之前学的同步机制对比

| 机制                   | 核心作用          | 适用场景      |
| -------------------- | ------------- | --------- |
| **ManualResetEvent** | 一次性通知**所有**线程 | 程序启动/停止信号 |
| **AutoResetEvent**   | **一个一个**通知线程  | 限流、轮流执行   |
| **Semaphore**        | **N个**线程同时通过  | 连接池、资源池   |
| **CountdownEvent**   | **等N个线程完成**   | 并行任务汇总    |

**一句话记忆**：
- 前三个是"**放行**"机制：控制线程**什么时候能走**
- CountdownEvent 是"**等人**"机制：主线程等子线程**干完活**

---

## 五、什么时候用 CountdownEvent？

**典型场景1：并行计算结果汇总**
```csharp
CountdownEvent calcCountdown = new CountdownEvent(4);
int[] results = new int[4];

for (int i = 0; i < 4; i++)
{
    int index = i;
    new Thread(() => {
        results[index] = CalculatePart(index);
        calcCountdown.Signal(); // 计算完喊一声
    }).Start();
}

calcCountdown.Wait(); // 等4部分都算完
int finalResult = results.Sum(); // 汇总
```

**典型场景2：多阶段任务**
```csharp
// 等3个服务都启动成功
CountdownEvent servicesReady = new CountdownEvent(3);

StartDatabase(() => servicesReady.Signal());
StartCache(() => servicesReady.Signal());
StartMQ(() => servicesReady.Signal());

servicesReady.Wait(); // 都启动好了才继续
Console.WriteLine("所有服务就绪，程序启动！");
```

**不适用场景**：
- 需要重复等待（每次都要 `Reset()`，麻烦）
- 需要限流（用 Semaphore）
- 需要持续通知（用 ManualResetEvent）

## 六、重要陷阱：Reset 的时机

```csharp
CountdownEvent countdown = new CountdownEvent(3);

// 第一次使用
Parallel.For(0, 3, i => {
    Thread.Sleep(100);
    countdown.Signal();
});
countdown.Wait();
Console.WriteLine("第一次任务完成");

// 错误：忘记 Reset 就再用
// countdown.Reset(); // 如果没这行，下次 Wait() 会立即通过

Parallel.For(0, 3, i => {
    Thread.Sleep(100);
    countdown.Signal();
});
countdown.Wait(); // 会立即返回，因为计数器已经是0了！
```

**教训**：每次使用前必须 `Reset()` 重新设置计数。**CountdownEvent 不是循环使用的**。
