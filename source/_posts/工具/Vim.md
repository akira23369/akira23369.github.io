# Vim语言
Vim 语言其语法结构可以概括为：

> **operator + motion = action**  
> **动词 + 名词 = 完整的指令**

- **Operator (动词)**：你想“做什么”。比如 d (delete), c (change), y (yank/copy), v (visual select)。
- **Motion (名词/范围)**：你的动作要作用在“什么范围”上。比如 w (一个单词), $ (到行尾), ib (一个括号内的内容)。

比如：
- `dw` = **d**elete a **w**ord (删除一个单词)
- `c$` = **c**hange to end of **l**ine (修改到行尾)
- `yi(` = **y**ank **i**nside **(**...**)** (复制括号内的所有内容)
- `dap` = **d**elete **a** **p**aragraph (删除一整个段落)

接下来要学习的，就是扩充“动词词汇表”和“名词词汇表”，然后像学习英语一样自由地组合它们。


# 光标移动

## 行内移动
- `0`: 移动到行首（第 0 列）。
- `^`: 移动到本行第一个非空白字符。
- `$`: 移动到行尾。
- `w`: **W**ord - 跳到下一个单词的词首。
- `b`: **B**ackward - 跳到上一个单词的词首。
- `e`: **E**nd of word - 跳到下一个单词的词尾。
- `ge`: 跳到上一个单词的词尾。
- `f{char}`: **F**ind - 跳到本行下一个 `{char}` 字符上。例如 `fa` 会跳到下一个 'a'。这是一个极其高效的行内移动方式。
- `t{char}`: **T**ill - 跳到本行下一个 `{char}` 字符的**前一个**位置。
- `;`: 重复上一次的 `f` 或 `t` 操作。
- `,`: 反向重复上一次的 `f` 或 `t` 操作。

## 垂直移动
- `{N}j` 或 `{N}k`: 向下 / 上移动 N 行。比如 `10j`。
- `H`: **H**igh - 移动到屏幕顶部。
- `M`: **M**iddle - 移动到屏幕中部。
- `L`: **L**ow - 移动到屏幕底部。
- `gg`: 移动到文件第一行。
- `G`: 移动到文件最后一行。
- `{N}G` 或 `:{N}`: 移动到第 N 行。例如 `100G` 就是去第 100 行。
- `Ctrl-D`: 向下滚动半屏 (**D**own)。
- `Ctrl-U`: 向上滚动半屏 (**U**p)。
- `{` 和 `}`: 在段落（空行分隔的文本块）之间跳转。写代码时，这通常是函数或代码块之间的跳转，非常有用。

## 其它移动
- `Ctrl + ]`: 跳转定义
- `Ctrl + o`: 向后回溯。(vsvim不支持)
- `Ctrl + i`: 向前回溯。
- `[[ 和 ]]`: 按段落 / 在函数、类、代码块之间跳转（如 Python 的函数定义、C 语言的函数块）

# 动词和名词
现在我们回到 `Vim` 的语言核心。你已经有了一批 “名词”（移动命令），现在我们来丰富 “动词” 和更高级的 “名词”。

## **核心动词 (Operators)**

- `d` - **d**elete: 删除。它不会进入插入模式。删除的内容会被存入剪贴板。
- `c` - **c**hange: 修改。删除后**立即进入插入模式**。这是重构的利器。
- `y` - **y**ank: 复制。相当于其他编辑器的 `Ctrl+C`。
- `p` - **p**aste: 粘贴。在光标后粘贴。`P` (大写) 在光标前粘贴。
- `v` - **v**isual: 进入可视模式。这是一种特殊的 “动词”，它让你手动选择 “名词” 的范围，然后再接其他动词。

## **文本对象 (Text Objects)**

这是从入门到进阶的关键一步。文本对象是一种特殊的 “名词”，它描述的是 “一块结构化的文本”，而不是一个方向或位置。它通常由两个字符组成：`i` (inner) 或 `a` (around)。
- `i` - **i**nner: 指代 “内部” 的文本，不包含边界符。
- `a` - **a**round: 指代 “环绕” 的文本，包含边界符。
常见的文本对象包括：

| 文本对象      | `i` (Inner) 的含义        | `a` (Around) 的含义         |
| :-------- | :--------------------- | :----------------------- |
| `w`       | `iw` - 当前单词            | `aw` - 当前单词及后面的一个空格      |
| `s`       | `is` - 当前句子            | `as` - 当前句子及后面的一个空格      |
| `p`       | `ip` - 当前段落            | `ap` - 当前段落及后面的空行        |
| `"`       | `i"` - 双引号内的内容         | `a"` - 双引号内的内容**及双引号本身** |
| `'`       | `i'` - 单引号内的内容         | `a'` - 单引号内的内容**及单引号本身** |
| `(` 或 `)` | `i(` - 括号内的内容          | `a(` - 括号内的内容**及括号本身**   |
| `[` 或 `]` | `i[` - 中括号内的内容         | `a[` - 中括号内的内容**及中括号本身** |
| `{` 或 `}` | `i{` - 大括号内的内容         | `a{` - 大括号内的内容**及大括号本身** |
| `t`       | `it` - HTML/XML 标签内的内容 | `at` - 整个 HTML/XML 标签    |

## **自由组合**

现在，将动词和文本对象组合起来，威力无穷：

- 光标在 `"Hello, world!"` 的任何位置，执行 `ci"` (change inner quote)，`Vim` 会立即删除引号内的所有内容，并让你进入插入模式，准备输入新的字符串。
- 光标在一个 JS 函数的 `{...}` 代码块内，执行 `ya{` (yank around brace)，你就复制了整个函数体，包括大括号。
- 想删除一整个段落？不需要用可视模式去从头选到尾，只需要 `dap` (delete a paragraph)。
- 想修改函数的参数列表？把光标移动到括号内，执行 `ci(` (change inner parenthesis)。

**心法**：忘掉鼠标选中！开始用文本对象来思考。当你想修改函数体时，你的内心独白应该是：“我要 `修改` `大括号里面的内容`”，然后自然地敲出 `ci{`。


# 重复、寄存器与宏
## **点命令 `.`**

点 `.` 命令，是 `Vim` 中最重要、最强大的命令，没有之一。它的作用是：**重复上一次的修改操作**。

“一次修改操作” 指的是任何导致文本变化的命令，例如 `dd`, `cw`, `x`, `I` 等，以及你之后在插入模式中输入的所有内容。

理解`.`的范围: . 重复的是从进入插入模式到退出插入模式之间所做的所有修改，以及进入插入模式前那个改变文本的命令 (c, s, i, a, cc, S, I, A, o, O, cgn 等)。

精心设计你的修改： 为了让 . 更有效，尽量让一次修改解决一个逻辑单元的问题。例如，用 ciw 改一个单词比用 i 进入插入模式手动删除再输入更精确，更容易被 . 正确重复。

结合宏 q： 有时一次修改太复杂，. 难以完美重复（比如涉及移动光标）。这时可以录制宏 q 来完成一次修改，然后用 @@ 重复宏。但 cgn + . 在简单替换上通常更快。

让我们回顾一下 `cgn` 的工作流：
1. `/foo` 搜索目标。
2. `cgnbar<Esc>` 第一次替换：`cgn` 删除 "foo" 进入插入模式，输入 "bar"，按 `Esc` 退出。
3. 现在，`bar<Esc>` 这个完整的 “输入” 行为被记录下来了。
4. 按 `n` 跳到下一个 "foo"。
5. 按 `.`。`Vim` 会自动执行 `cgn` + `bar<Esc>` 这一整套操作。

**点命令的精髓在于，它能重复 “意图”，而不仅仅是按键。**

**实战练习**：  
你想给多行代码的行首加上 `//` 注释。
1. 去第一行，按 `I` (在行首插入)。
2. 输入 `//` (注意末尾的空格)。
3. 按 `<Esc>` 回到正常模式。
4. 现在，移动到下一行（用 `j`），按 `.`。再下一行，按 `.`...  
    或者，更进一步，用可视模式选中多行，然后执行 `:'<,'>normal .`

## **数字与命令**

几乎所有的动词和名词都可以接受一个数字前缀，表示重复。
- `3dw`: 删除 3 个单词。
- `d3w`: 同上，效果一样。
- `5j`: 向下移动 5 行。
- `c2fa`: 修改到第二个 'a' 字符出现的位置。
- `3iabc<Esc>`: 插入 "abc" 三次，结果是 "abcabcabc"。
- 之后按 `.`，会再次插入 "abcabcabc"。

## **寄存器 (Registers)**

当你 `d` 或 `y` 时，内容存去了哪里？答案是**寄存器**。`Vim` 不只有一个剪贴板，它有几十个！

- `"`: 无名寄存器，默认的 `d`, `c`, `y` 都使用它。
- `"0` 到 `"9`: 数字寄存器。`"0` 存放最近一次的 yank 内容。`"1` 存放最近一次的 delete/change 内容，`"2` 是上上次的，以此类推。
    - **超级技巧**：你用 `dd` 删除了一行，然后又用 `dw` 删了一个词。现在你想把之前删除的那一行粘贴回来，怎么办？用 `"1p`！因为无名寄存器 `"` 已经被 `dw` 的内容覆盖了，但 `"1` 还保留着 `dd` 的内容。
- `"a` 到 `"z`: 命名寄存器。你可以指定将内容存入某个字母代表的寄存器，它永远不会被覆盖，除非你再次指定它。
    - `"ayiw`: 将当前单词**复制**到寄存器 `a` 中 (`"a` `y`ank `i`nner `w`ord)。
    - `"ap`: 将寄存器 `a` 的内容**粘贴**出来。
- `"+`: 系统剪贴板寄存器。与操作系统的剪贴板交互。
    - `"+y`: 复制到系统剪贴板（可以在浏览器中粘贴）。
    - `"+p`: 粘贴系统剪贴板的内容。
- `"_`: 黑洞寄存器。用它删除的东西不会进入任何寄存器，也不会覆盖你的剪贴板。当你只想删除而不影响剪贴板时，用 `"_d`。

## **宏 (Macros)**

宏是录制和回放一系列按键操作的终极武器。
1. `q{register}`: 开始录制宏，并存入你指定的寄存器（a-z）。例如 `qa`。
2. 执行你的任意一系列操作。
3. `q`: 停止录制。
4. `@{register}`: 回放宏。例如 `@a`。
5. `@@`: 重复上一次回放的宏。


**实战场景**：  
你有一系列这样的行：  
`"apple"`  
`"banana"`  
`"cherry"`

你想把它们变成：  
`const a = "apple";`  
`const b = "banana";`  
`const c = "cherry";`

**录制宏** (假设光标在第一行行首):

1. `qa` - 开始录制宏到寄存器 `a`。
2. `Iconst <Esc>` - 在行首插入 "const"。
3. `w` - 跳到单词 "apple"。
4. `y` - 复制首字母 'a'。
5. `A = <Esc>` - 在行尾插入 "="。
6. `"0P` - 粘贴刚才复制的首字母 ('a')。
7. `A;<Esc>` - 在行尾插入分号。
8. `j^` - 移动到下一行的行首非空白字符，为下一次循环做准备。
9. `q` - 停止录制。

现在，你只需要按 `@a`，第二行就会被自动处理。然后按 `@@`，第三行也会被处理。如果有 100 行，你可以按 `99@@`，瞬间完成所有工作。

# **搜索、替换与窗口管理**

## **搜索与替换**

- `/pattern`: 向下搜索。支持正则表达式。
- `?pattern`: 向上搜索。
- `n`: 下一个匹配。
- `N`: 上一个匹配。
- `*`: 搜索光标下的单词。
- `#`: 反向搜索光标下的单词。
- `:s` (substitute) 命令：强大的行内或全局替换。
    - `:%s/old/new/g`: 在整个文件 (`%`) 中，替换所有 (`g`) 的 "old" 为 "new"。
    - `:%s/old/new/gc`: 加上 `c` (confirm)，每次替换前都会询问你。
    - 我们之前讲的 `cgn` 工作流，在很多场景下比 `:s/.../gc` 更灵活、更直观。

## **可视模式 (Visual Mode)**

当你无法用一个简单的 `motion` 或文本对象来描述范围时，可视模式就派上用场了。

- `v`: **字符可视模式**。选中的文本会高亮。之后可以接 `d`, `c`, `y` 等动词。
- `V`: **行可视模式**。总是整行整行地选中。
- `Ctrl-V`: **块可视模式**。可以进行矩形选择。
    - **超级技巧**：用 `Ctrl-V` 选中多行的几列，然后按 `I` (大写)，输入文本，再按 `<Esc>`，你输入的内容会同时应用到所有选中的行上。这是批量加前缀的另一种方法。

## **窗口与标签页**

`Vim` 是一个多窗口编辑器。

- `:sp` 或 `:split`: 水平分割窗口。
- `:vs` 或 `:vsplit`: 垂直分割窗口。
- `Ctrl-W` + `hjkl`: 在窗口间切换。
- `Ctrl-W` + `w`: 循环切换窗口。
- `:tabe {filename}`: 打开一个新的标签页。
- `gt`: 下一个标签页。
- `gT`: 上一个标签页。
