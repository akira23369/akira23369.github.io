## 文本控件

前面三节讲了控件的通用外观、内容控件的核心机制、以及几个特殊容器。这些控件有一个共同点——它们都是“容器”，用来装别的东西或者把别的东西组织起来。但从这一节开始，咱们要进入一类更“实在”的控件：**文本控件**——专门用来显示和编辑文字。

文字是用户界面里最基础、最不可或缺的元素。标签、按钮、输入框、日志窗口、代码编辑器、密码框，全都要和文字打交道。WPF 提供了好几个文本相关的控件，各有各的分工：

- **`TextBlock`**：轻量级的只读文本显示控件。性能好，功能丰富（支持多行、换行、各种字体样式混排），但不允许用户编辑。
- **`TextBox`**：文本输入框。用户可以往里面输入和编辑文字。这是表单里最常用的控件之一。
- **`RichTextBox`**：富文本框，支持格式化的文本（不同字体、颜色、大小混排，甚至嵌入图片和控件）。更像一个迷你文字处理器。
- **`PasswordBox`**：密码输入框。用户输入的文字显示为掩码字符（默认是圆点），并且有专门的安全措施防止密码泄露。

这一节 6.4 重点讲三个最常用的：`TextBox`（多行文本与选择）、`RichTextBox`（拼写检查）、`PasswordBox`。`TextBlock` 在前面已经多次使用，这里不再单列一节，但会在和 `TextBox` 对比时反复出现。

### 多行文本

`TextBox` 默认是一个**单行**文本输入框。这意味着：

- 只有一个默认高度，刚好容纳一行文字。
- 用户按回车键不会产生换行（在单行模式下，按回车通常触发窗体的“确定”按钮）。
- 文字超出控件宽度时，内容会水平滚动（不会自动换行）。

这种单行模式适合短输入——用户名、搜索框、邮箱地址、电话号码等。但很多时候你需要让用户输入**多行文本**——比如评论框、备注栏、日志查看器、代码编辑器。这时就需要开启 `TextBox` 的多行模式。

#### 开启多行模式

将 `AcceptsReturn` 属性设为 `True`，同时通常也会开启 `TextWrapping`。

```xml
<TextBox Width="300" Height="120" 
         AcceptsReturn="True" 
         TextWrapping="Wrap" />
```

- **`AcceptsReturn="True"`**：用户按 `Enter` 键时会在文本中插入一个换行符（`\r\n`），而不是触发默认按钮。这是“多行”的核心标志。
- **`TextWrapping="Wrap"`**：当文本超出控件宽度时自动换行到下一行。如果设为 `NoWrap`（默认），文本会在同一行无限延伸，超出视口部分只能靠水平滚动查看。多行文本框通常都配合 `Wrap` 使用。

这两个属性独立运作：
- `AcceptsReturn="False"` + `TextWrapping="Wrap"`：文本会在宽度超出时自动换行（仅视觉换行，不插入实际换行符），但按回车不产生新行。适合显示长文本但不希望用户手动分行的场景。
- `AcceptsReturn="True"` + `TextWrapping="NoWrap"`：用户可以按回车换行，但文本不会自动折行。每行可能会非常长，需要水平滚动。典型的应用是代码编辑器。

#### 垂直滚动和水平滚动

当多行文本超出控件大小，不论是垂直方向还是水平方向，`TextBox` 都可以自动出现滚动条。这通过两个附加属性控制：

- **`VerticalScrollBarVisibility`**
- **`HorizontalScrollBarVisibility`**

取值和 `ScrollViewer` 一样：`Auto`（默认，超出时自动出现）、`Visible`（始终显示）、`Hidden`（隐藏但可滚动内容）、`Disabled`（不显示且不可滚动）。

```xml
<TextBox AcceptsReturn="True" TextWrapping="Wrap"
         VerticalScrollBarVisibility="Auto"
         HorizontalScrollBarVisibility="Disabled"
         Width="300" Height="120" />
```

典型配置：多行文本框开启垂直滚动条，关闭水平滚动条（因为有 `TextWrapping="Wrap"` 自动折行，水平方向不会超出）。

**注意**：`TextBox` 本身内置了 `ScrollViewer`（在它的控件模板里），所以不需要你手动在外面再包一层 `ScrollViewer`。上面这两个属性直接映射到它内部的 `ScrollViewer` 上。

#### TextWrapping 的三种模式

`TextWrapping` 是 `TextBlock` 和 `TextBox` 共有的属性，取值有三个：

- **`NoWrap`**：文本不自动换行，超出部分被截断或水平滚动。这是默认值（对于 `TextBox`）。
- **`Wrap`**：文本在到达控件边缘时自动换行。单词不会被切断，整个单词移到下一行（如果一行根本放不下一个单词，这个单词也会被切断）。
- **`WrapWithOverflow`**：和 `Wrap` 类似，但如果某一行有一个单词（或一个不可断的连续字符序列）本身比控件宽度还长，这个单词会溢出到右侧（而不是被切断）。在需要保证单词完整性的场景下比 `Wrap` 更合适，但可能产生水平滚动条。

```xml
<TextBox TextWrapping="WrapWithOverflow" Width="200" />
```

一般来说，多行文本框用 `Wrap` 是最常见的选择。

#### 最小和最大行数

`TextBox` 没有直接设置“行数”的属性，但你可以通过 `MinLines` 和 `MaxLines` 来控制：

- **`MinLines`**：最小**可见**行数。这决定了 `TextBox` 的最小高度。
- **`MaxLines`**：最大**可见**行数。当用户输入的行数超过这个值时，`TextBox` 内部出现滚动条。

```xml
<TextBox MinLines="3" MaxLines="8" AcceptsReturn="True" TextWrapping="Wrap" />
```

这个文本框至少显示 3 行的高度，最多显示 8 行。第 9 行开始出现垂直滚动条。

#### 只读和禁用

有时候你需要一个文本框来显示多行文本，但不允许用户编辑。可以用 `IsReadOnly` 属性：

```xml
<TextBox IsReadOnly="True" Text="这段文字只能看不能改" />
```

只读状态下的文本框外观和正常文本框一样（白底、有边框），用户可以选中和复制文字，但不能修改。这和设置 `IsEnabled="False"` 不同——禁用状态下文本框变灰，用户连选文字和滚动都不行。

`IsReadOnly` 配合多行模式，是一个常用的“日志窗口”实现方式。

#### TextBox 和 TextBlock 的选择

| 特性   | TextBlock                           | TextBox               |
| ---- | ----------------------------------- | --------------------- |
| 可编辑  | 否                                   | 是                     |
| 可选文本 | 可以（`IsTextSelectionEnabled="True"`） | 是                     |
| 性能   | 轻量，适合大量文本显示                         | 稍重，编辑功能有开销            |
| 多行   | 支持，通过 `TextWrapping`                | 支持，需要 `AcceptsReturn` |
| 内联样式 | 支持（`Run`、`Bold`、`Italic` 等）         | 不支持内联，整个文本统一格式        |
| 光标   | 无                                   | 有                     |
| 典型用途 | 标签、说明文字、只读内容展示                      | 输入框、编辑器、日志窗口          |

简单判断：**用户需要输入或编辑 → `TextBox`；只需要显示文字 → `TextBlock`。**

### 选择文本

`TextBox` 和 `RichTextBox` 都允许用户通过鼠标拖拽或键盘（`Shift + 方向键`）来**选中一段文本**。选中文本的背后有一整套属性和事件来支持：获取选中了什么、替换选中内容、响应用户选择变化等。

#### Selection 相关属性

这些属性是 `TextBoxBase` 提供的，所以 `TextBox` 和 `RichTextBox` 都有。

- **`SelectionStart`**（`int`）：选中文本的起始位置，从 0 开始计数。如果没选中任何文本，这个值表示光标的位置（插入符位置）。
- **`SelectionLength`**（`int`）：选中文本的长度（字符数）。如果值为 0，表示没有选中任何文本，只是一个闪烁的光标。
- **`SelectedText`**（`string`）：当前选中的文本内容。如果 `SelectionLength` 为 0，返回空字符串。你可以**设置**这个属性来替换当前选中的文本（如果没有选中，则在光标位置插入文本）。
- **`SelectionBrush`**（`Brush`）：选中文本的高亮背景色。默认是系统的选定文本颜色（通常是蓝色）。
- **`SelectionOpacity`**（`double`）：选中文本高亮背景的不透明度（0.0 ~ 1.0）。

#### 选择文本的常用操作

**获取当前选中的文本**：

```csharp
string selected = myTextBox.SelectedText;
if (!string.IsNullOrEmpty(selected))
{
    MessageBox.Show($"你选中了: {selected}");
}
```

**替换选中的文本**：

```csharp
myTextBox.SelectedText = "新内容";
```

如果没有选中文本，新内容会在光标位置插入。如果有一段被选中的文本，会被替换。

**在光标位置插入文本（不替换任何东西）**：

```csharp
int pos = myTextBox.SelectionStart;
myTextBox.Text = myTextBox.Text.Insert(pos, "插入的文字");
myTextBox.SelectionStart = pos + "插入的文字".Length;  // 光标移到插入文本之后
```

或者直接用 `SelectedText` 赋值简化：

```csharp
myTextBox.SelectedText = "插入的文字";  // 因为啥也没选，效果就是插入
```

**选中全部文本**：

```csharp
myTextBox.SelectAll();
// 或
myTextBox.Focus();
myTextBox.Select(0, myTextBox.Text.Length);
```

**清除选择（取消选中）**：

```csharp
myTextBox.SelectionLength = 0;
// 或
myTextBox.Select(myTextBox.SelectionStart, 0);
```

**滚动到光标位置**：

```csharp
myTextBox.ScrollToEnd();     // 滚到末尾
myTextBox.ScrollToHome();    // 滚到开头
myTextBox.ScrollToLine(5);   // 滚到第 5 行
```

#### SelectionChanged 事件

当用户改变选择（包括移动光标）时，`TextBoxBase.SelectionChanged` 事件触发。这在很多场景下有用——比如在状态栏显示当前光标所在的行列号：

```csharp
private void OnSelectionChanged(object sender, RoutedEventArgs e)
{
    int row = myTextBox.GetLineIndexFromCharacterIndex(myTextBox.SelectionStart);
    int col = myTextBox.SelectionStart - myTextBox.GetCharacterIndexFromLineIndex(row);
    statusBar.Text = $"行: {row + 1}  列: {col + 1}";
}
```

#### 获取光标位置的行列信息

`TextBox` 提供了一些辅助方法来在“字符索引”和“行列”之间转换：

- `GetLineIndexFromCharacterIndex(int charIndex)`：根据字符索引得到是第几行。
- `GetCharacterIndexFromLineIndex(int lineIndex)`：得到某一行的起始字符索引。
- `GetLineLength(int lineIndex)`：得到某一行的字符数。
- `GetLineText(int lineIndex)`：得到某一行的文本内容。

#### 使用 RichTextBox

`RichTextBox` 继承自 `TextBoxBase`，所以上面所有的选择属性和事件它都有。区别在于，`RichTextBox` 内部存储的不是纯字符串，而是一个 **`FlowDocument`**——一个支持复杂格式化的文档对象。

**塞内容给 RichTextBox**：

```csharp
// 直接塞纯文本
myRichTextBox.Document.Blocks.Clear();
myRichTextBox.Document.Blocks.Add(new Paragraph(new Run("这是一段文字。")));

// 或者塞带格式的文本
Paragraph para = new Paragraph();
para.Inlines.Add(new Run("正常文字 "));
para.Inlines.Add(new Bold(new Run("加粗文字 ")));
para.Inlines.Add(new Italic(new Run("斜体文字 ")));
para.Inlines.Add(new Run("红色文字") { Foreground = Brushes.Red });
myRichTextBox.Document.Blocks.Add(para);
```

**获取 RichTextBox 的内容**：

`RichTextBox` 的内容不是简单字符串，需要从 `FlowDocument` 中提取。如果只是要纯文本：

```csharp
TextRange range = new TextRange(
    myRichTextBox.Document.ContentStart,
    myRichTextBox.Document.ContentEnd);
string plainText = range.Text;
```

如果要富文本格式（RTF、XAML 等）：

```csharp
using (MemoryStream stream = new MemoryStream())
{
    range.Save(stream, DataFormats.Rtf);
    string rtfContent = Encoding.UTF8.GetString(stream.ToArray());
}
```

`RichTextBox` 的选择操作和 `TextBox` 一致（`SelectionStart`、`SelectionLength`、`SelectedText` 等），但它多了一个 `Selection` 属性（类型 `TextSelection`），提供更丰富的编程接口，比如获取选中文本的格式、应用格式到选中文本等。

大多数场景下，普通文本输入用 `TextBox` 足够。只有当你确实需要让用户对文字进行富格式编辑（加粗、变色、不同字号）时，才需要上 `RichTextBox`。


#### 选择文本的一个例子
```xml
<Window x:Class="WPFTestDemo.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
        xmlns:local="clr-namespace:WPFTestDemo"
        mc:Ignorable="d"
        Title="MainWindow" Height="450" Width="800"
        >
    <DockPanel>
        <StatusBar DockPanel.Dock="Bottom">
            <TextBlock x:Name="statusBar" Text="行: 1  列: 1" />
        </StatusBar>

        <WrapPanel DockPanel.Dock="Top" Margin="5">
            <Button Content="获取选中内容" Click="BtnGetSelection_Click" Margin="5" Padding="5,2"/>
            <Button Content="替换选中/插入新内容" Click="BtnReplace_Click" Margin="5" Padding="5,2"/>
            <Button Content="全选" Click="BtnSelectAll_Click" Margin="5" Padding="5,2"/>
            <Button Content="取消选中" Click="BtnClearSelection_Click" Margin="5" Padding="5,2"/>
            <Button Content="插入带格式文本(RTB)" Click="BtnInsertRichText_Click" Margin="5" Padding="5,2"/>
            <Button Content="提取纯文本(RTB)" Click="BtnGetRtbText_Click" Margin="5" Padding="5,2"/>
        </WrapPanel>

        <Grid>
            <Grid.RowDefinitions>
                <RowDefinition Height="*"/>
                <RowDefinition Height="*"/>
            </Grid.RowDefinitions>

            <TextBox x:Name="myTextBox" Grid.Row="0" Margin="5"
                     AcceptsReturn="True" TextWrapping="Wrap" VerticalScrollBarVisibility="Auto"
                     SelectionBrush="DarkOrange" SelectionOpacity="0.4"
                     SelectionChanged="MyTextBox_SelectionChanged">第一行：Hello WPF!&#x0a;第二行：你可以用鼠标选中我。&#x0a;第三行：点一下这里，看看底部的状态栏变化。</TextBox>

            <RichTextBox x:Name="myRichTextBox" Grid.Row="1" Margin="5" 
                         VerticalScrollBarVisibility="Auto">
                <FlowDocument>
                    <Paragraph>
                        <Run Text="这是 RichTextBox 的初始内容。"/>
                    </Paragraph>
                </FlowDocument>
            </RichTextBox>
        </Grid>
    </DockPanel>
</Window>
```

```cs
namespace WPFTestDemo
{
	/// <summary>
	/// Interaction logic for MainWindow.xaml
	/// </summary>
	public partial class MainWindow : Window
	{
		public MainWindow()
		{
			InitializeComponent();
		}

		// ==========================================
		// TextBox 操作示例
		// ==========================================

		private void BtnGetSelection_Click(object sender, RoutedEventArgs e)
		{
			// 获取当前选中的文本
			string selected = myTextBox.SelectedText;
			if (!string.IsNullOrEmpty(selected))
			{
				MessageBox.Show($"你选中了: {selected}", "获取选中内容");
			}
			else
			{
				MessageBox.Show("当前没有选中任何文本哦。", "提示");
			}
		}

		private void BtnReplace_Click(object sender, RoutedEventArgs e)
		{
			// 替换选中的文本，或者在光标位置插入文本
			myTextBox.SelectedText = "【新内容】";

			// 操作后让 TextBox 重新获得焦点，方便继续输入
			myTextBox.Focus();
		}

		private void BtnSelectAll_Click(object sender, RoutedEventArgs e)
		{
			// 选中全部文本
			myTextBox.SelectAll();
			myTextBox.Focus();
		}

		private void BtnClearSelection_Click(object sender, RoutedEventArgs e)
		{
			// 清除选择（取消选中）
			myTextBox.SelectionLength = 0;
			myTextBox.Focus();
		}

		private void MyTextBox_SelectionChanged(object sender, RoutedEventArgs e)
		{
			// 获取光标位置的行列信息并在状态栏显示
			if (myTextBox == null || statusBar == null) return;

			// 获取光标在第几行（返回索引从 0 开始）
			int row = myTextBox.GetLineIndexFromCharacterIndex(myTextBox.SelectionStart);

			// 获取当前行的起始字符索引
			int lineStartIndex = myTextBox.GetCharacterIndexFromLineIndex(row);

			// 计算列：当前光标总索引 - 当前行起始索引
			int col = myTextBox.SelectionStart - lineStartIndex;

			// 界面显示时，行和列通常从 1 开始，所以 +1
			statusBar.Text = $"行: {row + 1}  列: {col + 1}  |  已选中字符数: {myTextBox.SelectionLength}";
		}

		// ==========================================
		// RichTextBox 操作示例
		// ==========================================

		private void BtnInsertRichText_Click(object sender, RoutedEventArgs e)
		{
			// 清空已有内容
			myRichTextBox.Document.Blocks.Clear();

			// 塞带格式的文本 (构建 FlowDocument)
			Paragraph para = new Paragraph();
			para.Inlines.Add(new Run("正常文字 "));
			para.Inlines.Add(new Bold(new Run("加粗文字 ")));
			para.Inlines.Add(new Italic(new Run("斜体文字 ")));
			para.Inlines.Add(new Run("红色文字") { Foreground = Brushes.Red });
			para.Inlines.Add(new Run("\n这是新加的一行富文本内容。"));

			// 将段落添加到 RichTextBox 中
			myRichTextBox.Document.Blocks.Add(para);
		}

		private void BtnGetRtbText_Click(object sender, RoutedEventArgs e)
		{
			// 提取 RichTextBox 中的纯文本
			TextRange range = new TextRange(
				myRichTextBox.Document.ContentStart,
				myRichTextBox.Document.ContentEnd);

			string plainText = range.Text;
			MessageBox.Show($"提取到的纯文本如下：\n\n{plainText}", "提取纯文本");
		}
	}
}
```

### 拼写检查

WPF 为 `TextBox` 和 `RichTextBox` 内置了**拼写检查**功能。用户输入文字时，拼错的英语单词（或部分其他语言）会被自动用红色波浪线标出，用户右键点击可以弹出拼写建议菜单。这个功能不需要你写一行代码——只需要开启一个属性。

#### 开启拼写检查

```xml
<TextBox SpellCheck.IsEnabled="True" />
```

对，就是 `SpellCheck.IsEnabled` 这个附加属性。设为 `True` 后，文本框就自动具备了英语拼写检查能力。

`RichTextBox` 同理：

```xml
<RichTextBox SpellCheck.IsEnabled="True" />
```

#### 拼写检查的行为

开启后：
- 拼写错误的单词下方会出现红色波浪线。
- 用户右键点击拼错的单词，会弹出上下文菜单，提供拼写建议列表。
- 用户可以选择一个建议自动替换，或选择“忽略”/“全部忽略”。
- 自定义词典中的单词（如技术术语）不会被标错。

这些交互是内置于 `TextBox` 控件模板中的，完全不需要你写事件或命令。

#### 拼写检查支持的语言

WPF 的拼写检查器默认支持英语。要支持其他语言，需要安装对应的语言包，并在 XAML 中指定：

```xml
<TextBox SpellCheck.IsEnabled="True" xml:lang="de" />  <!-- 德语 -->
<TextBox SpellCheck.IsEnabled="True" xml:lang="fr" />  <!-- 法语 -->
```

`xml:lang` 是 XML 语言属性，值必须是标准的语言标记（如 `en-US`、`zh-CN`、`ja-JP`）。如果你的系统没有安装对应语言包，拼写检查可能退回到英语或无效果。

**中文**：WPF 内置的拼写检查对中文支持非常有限。中文的输入法校验（如拼音错别字）通常不在 WPF 拼写检查范围内。如果需要中文拼写检查，一般需要借助第三方组件或云端 API。

#### 自定义词典

你可以为应用程序添加自定义词典，让拼写检查器认得你业务中的专业词汇：

```csharp
SpellCheck.SetCustomDictionaries(myTextBox, new CustomDictionaryCollection
{
    new Uri("pack://application:,,,/MyApp;component/CustomWords.lex")
});
```

自定义词典文件（`.lex` 或 `.dic`）是纯文本文件，每行一个单词。添加后，这些单词就不会被标红色波浪线。

**一次性禁用某段文本的拼写检查**：在 `RichTextBox` 中，你可以通过设置 `SpellCheck.IsEnabled="False"` 附加属性在某个 `Run` 或 `Paragraph` 上，局部禁用拼写检查（比如代码片段、网址、邮箱地址）。

#### 拼写检查的原理（简单了解）

WPF 的拼写检查就是微软 Office 里用的那套引擎（MsSpellCheckFacility），通过 COM 接口调用。它拥有相当不错的准确性，支持波浪线标记和上下文菜单。但它**不负责语法检查**——只检查单词是否存在于词典中，不检查上下文是否合适（比如 "there" vs "their"）。

#### 实际开发中的使用建议

- **多行文本输入区（如邮件正文、备注、评论）**：强烈建议开启拼写检查，提升用户体验。
- **单行输入框（如用户名、搜索框、ID 字段）**：一般**不开启**，因为它们不太可能是需要拼写检查的英文单词，反而把技术术语和代码常量标红会很烦。
- **`PasswordBox`**：不支持拼写检查，也不需要。

### PasswordBox

`PasswordBox` 是一个**专用的密码输入控件**。它和 `TextBox` 很像，用户可以在里面输入文字，但有几个关键的区别，这些区别全部围绕**安全**展开。

#### 基本用法

```xml
<PasswordBox PasswordChar="*" MaxLength="20" />
```

用户输入时，所有字符都被替换成掩码字符（默认是实心圆点 •）。`PasswordChar` 属性可以自定义掩码字符（比如 `*`、`#`）。

#### PasswordBox 的核心属性

- **`Password`**（`string`）：获取或设置密码明文。注意这个属性是**不可绑定的依赖项属性**吗？不——`PasswordBox.Password` **不是一个依赖项属性**。这是 WPF 安全设计的一部分，后面会解释。
- **`PasswordChar`**（`char`）：掩码字符，默认是圆点 `'•'`（`\u2022`），可以自定义为 `'*'` 等。
- **`MaxLength`**（`int`）：密码最大长度，超过限制用户无法输入。
- **`SecurePassword`**（`SecureString`）：以 `SecureString` 形式获取密码。`SecureString` 是 .NET 中专门为敏感数据设计的安全类型——它在内存中是加密存储的，不会被 GC 移到硬盘交换文件，且可以随时手动清空。**处理密码时强烈建议用 `SecurePassword` 而不是 `Password`。**
- **`IsPasswordRevealButtonEnabled`**（自 .NET Framework 4.5+ / Windows 8+ 支持）：当设为 `true` 时，密码框右边会出现一个小眼睛图标，用户按住可临时看到明文密码。这个功能在移动端很常见，桌面端也逐渐流行。

#### 为什么 PasswordBox.Password 不是依赖项属性？

这是一个很重要的设计细节。依赖项属性的值可以通过数据绑定被读取和传播，也可以通过样式、动画、资源引用等方式被访问。这意味着如果 `Password` 是依赖项属性，它的值可能在不知情的情况下被其他控件、行为、甚至调试工具读取到内存中的明文。为了最大限度减少密码的暴露面，WPF 设计者故意把 `Password` 做成普通 CLR 属性，这样它就**不能直接参与 XAML 数据绑定**。

**这和 MVVM 怎么兼容？** 典型的 MVVM 框架（如 Prism、MVVM Light）通常会提供附加行为（Attached Behavior）来间接绑定 `PasswordBox` 的密码值到 ViewModel。原理是通过监听 `PasswordChanged` 事件，在密码变化时手动更新 ViewModel 的属性。这不是 WPF 内置的，需要你自己写一小段代码或者用框架提供的现成方案。

#### PasswordChanged 事件

每当密码内容发生变化（无论增加还是删除字符），`PasswordBox` 触发 `PasswordChanged` 事件。这是响应密码变化的主要方式：

```csharp
private void OnPasswordChanged(object sender, RoutedEventArgs e)
{
    string plainPassword = myPasswordBox.Password;
    SecureString securePassword = myPasswordBox.SecurePassword;
    // 验证密码强度、更新 ViewModel 等
}
```

#### SecureString 的正确使用方式

```csharp
private void ProcessPassword(SecureString securePassword)
{
    IntPtr ptr = System.Runtime.InteropServices.Marshal.SecureStringToBSTR(securePassword);
    try
    {
        string password = System.Runtime.InteropServices.Marshal.PtrToStringBSTR(ptr);
        // 使用密码（如创建登录凭证）
    }
    finally
    {
        System.Runtime.InteropServices.Marshal.ZeroFreeBSTR(ptr);
    }
}
```

使用时尽快取用，尽快清除，不要把 `SecureString` 转换成普通 `string` 后在内存中一直保留。

#### 掩码字符的视觉细节

`PasswordChar` 默认是圆点 `'\u2022'`，和 Windows 系统登录界面的密码掩码一致。你可以自定义，但要注意：

- 掩码字符只影响显示，**不影响实际存储的密码内容**。
- 掩码字符建议用一个固定宽度的字符（如圆点、星号），这样不会因为字符宽度变化泄漏密码长度信息。

## 总结

6.4 节覆盖了 WPF 里最核心的几个文本处理控件：

**多行文本（6.4.1）**：
- `TextBox` 默认单行，通过 `AcceptsReturn="True"` 开启多行模式。
- `TextWrapping="Wrap"` 让文本自动折行，配合 `VerticalScrollBarVisibility` 控制滚动条。
- `MinLines` 和 `MaxLines` 控制可视行数范围。
- `IsReadOnly="True"` 做只读显示，`IsEnabled="False"` 做不可操作禁用。
- `TextBlock` vs `TextBox`：显示用 `TextBlock`，编辑用 `TextBox`。

**选择文本（6.4.2）**：
- 核心属性：`SelectionStart`（光标/选择起点）、`SelectionLength`（选择长度）、`SelectedText`（选中文本，可读写）。
- 常用操作：获取选中文本、替换选中文本、插入文本、全选、清除选择。
- 通过 `GetLineIndexFromCharacterIndex` 等方法获取行列信息。
- `RichTextBox` 支持富文本格式，内容存储在 `FlowDocument` 中，选择和基本操作和 `TextBox` 一致，但格式操作更复杂。

**拼写检查（6.4.3）**：
- 在 `TextBox` 或 `RichTextBox` 上设置 `SpellCheck.IsEnabled="True"` 即可开启。
- 拼写错误自动标红色波浪线，右键提供建议菜单。
- 通过 `xml:lang` 属性指定语言，支持自定义词典。
- 多行文本区（评论、邮件、备注）建议开启，单行输入框（ID、搜索）一般不开，中文支持有限。

**PasswordBox（6.4.4）**：
- 专用密码输入控件，输入显示为掩码字符（默认圆点）。
- `Password` 是普通 CLR 属性（不是依赖项属性），不能被绑定——这是安全设计。
- `SecurePassword` 以加密 `SecureString` 获取密码，处理敏感数据时强烈建议使用。
- `PasswordChanged` 事件响应密码变化。
- `PasswordChar` 自定义掩码字符，`MaxLength` 限制长度。

文本控件是表单和编辑器类应用的核心。`TextBox` 和 `PasswordBox` 用得最多，`TextBlock` 是纯展示首选，`RichTextBox` 在需要富文本编辑时才上场。熟练掌握这些控件的文本编辑、选择、验证、密码安全处理能力，你的界面就能从容应对从简单登陆框到复杂文本编辑器的各种需求。
